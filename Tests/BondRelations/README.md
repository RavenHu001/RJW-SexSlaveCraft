# 主从社交关系一致性回归

直接编译生产关系规则、仪式奖励入口、绑定服务、性奴锁链、主人缰绳、旧档清理 GameComponent、称谓服务及两处 Harmony 显示补丁。原生接口模型依据本机 RimWorld 1.6 程序集反编译建立；双向关系、健康删除顺序和缓存通知为引擎边界，测试不运行 Unity 或实际存档。

```powershell
dotnet run --project Tests/BondRelations/BondRelations.csproj --configuration Release `
  -p:HarmonyAssemblyPath="本机/net9.0/0Harmony.dll" -- .
```

本套件覆盖：

- 仪式奖励保留 80 好感门槛；第三方 Master、性奴调教员及未绑定对象不能获得关系。
- 绑定、读档及修复不自动授予奖励；有效奖励不因后来好感下降被删除。
- 解绑、换绑和直接删除锁链清理双方关系，并使用原生移除接口通知双方缓存。
- 完整加载后清理世界快照中的旧错误关系，保留当前绑定、普通关系及仍有锁链的死亡主人；重复执行无副作用。
- 主人可以拥有多个性奴，每个性奴的关系按自己的锁链判定。
- 用实际 Harmony 安装生产补丁，验证四语、主从双方男女组合、混合关系名称及好感说明；其他关系的原版称谓保留。

`RitualLifecycle` 另运行真实整场 `Apply`，验证六阶段完成、一次性认领、79/80/100 门槛、第三方合法主持及回调撤销完成资格。`PersonalityTraits` 运行完整人格植入，验证成功/失败绑定恢复、旧凝胶错误关系过滤及主人人格跨体植入。`SharedBed` 验证旧第三方关系不能提供最高同床心情。

全部回归由 `Scripts/Test-All.ps1` 统一运行，本套件需要本地 net9.0 Harmony，不下载依赖。

绑定生命周期补充：

- 暂停中手动删最后一条性奴锁链后，即刻移除主人空缰绳和派生共振场；随后死亡不依赖健康 Tick 清理。
- 删除一条锁链保留同一主人的其他有效性奴；反向列表中的陈旧条目不能解绑已属于其他主人的角色。
- 正常 AddToPawn 换绑立即清旧关系；外部直接写公开 target 时，在该锁链的下一次 Tick 清旧关系并整理双方索引，不自动授予新奖励。
- 已移除旧实例的迟到 Tick 不得替换新缰绳或重置伤害分担偏好；读档同时清理死亡主人上不再对应锁链的缰绳。
- CE 1.6 直接删健康列表、跳过 `PostRemoved` 后发送 `Notify_HediffChanged` 的路径也必须立即清除双方关系、100 好感奖励、空缰绳和共振场，不等待 Tick 或读档；保留其他性奴及普通关系。
- 该兼容测试安装真实生产 Harmony 通知补丁；仍在身体上的锁链严重度变化、无关健康通知、重复通知和同主新链替换不误删有效关系或伤害分担偏好。

CE 边界依据本机 `1874644848/v1.6/Assemblies/CharacterEditor.dll` 的 `CharacterEditor.HealthTool.RemoveHediff` 反编译（MVID `3db27871e2d8425d98d1a758fe85d3bd`）；只模拟其直接移除集合并通知的行为，不模拟 Unity 界面。

原版 Anomaly 或其他模组自身的死亡机制异常不在 SSC 修复范围内；不添加跳过这些死亡回调的补丁。
