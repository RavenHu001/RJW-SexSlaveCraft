## 3A 实机测试

2026-10-12：维护者测试未发现问题，确认任务获取和读档去重均符合预期，并批准提交。未逐项列举的地图变化、无基地等待、运输舱途中存档及 DLC 组合继续保留下述专项步骤，不据此声称全部场景逐项通过。

### 准备

1. 在测试存档上操作。安装本批 DLL、`Defs/QuestScriptDefs/SSC_MasterQualification.xml`、四语 `Languages/*/Keyed/SSC_MasterEntry.xml`，保留此前两批的物品和研究 Def；完全退出并重启游戏。运行 DLL 的具体哈希见开发记录。
2. 先准备基础“调教”研究未完成、没有己方存活 SSC 主人的存档。研究零进度和部分进度均可；角色有资格但尚未选择主人也不影响触发。可新建游戏验证最初获取。
3. 将“允许直接手动赋予主人身份”关闭，以观察种子的实际资格效果。这个设置只影响身份选择，不影响本批任务和按钮。

### 首次领取与存档去重

1. 加载符合条件的存档，等待一个界面更新。应出现“SSC：情欲的呼唤”任务及任务信，任务可见、奖励恰好 1 个欲望之种，没有费用、战斗或接受时限。游戏暂停时也能完成初始任务创建。
2. 尚未接受时保存并重读：应保留同一任务，没有新任务/新信/物品；设置里的“创建主人资格领取任务”按钮应禁用，说明已有待处理任务。
3. 仅隐藏/关闭任务提示不等于结束任务，此时手动入口仍禁用，可回任务列表接受原任务。
4. 接受任务并推进时间：原版生成运输舱时，应出现一封标题为“答复”、正文为“一枚超凡造物落进了基地——没有署名，也没有留下任何说明。”的投放信，点击可定位投放处，不额外出现原版通用投放信。原版运输舱送来一个种子，任务成功；仍须正常开舱/搬运。确认领取本身不自动改变小人身份、资格或研究进度。
5. 在空投正在飞行或落地尚未开舱时保存，退出并读档。任务状态、运输舱及种子数量应保持，不出现第二份投放或第二封投放信。
6. 使用种子，验证此前第二批行为：只消耗 1 个，小人取得资格，研究只补蓝图而不直接完成。任务完成后再次读档不自动补发。

### 自动条件和手动入口

| 场景 | 预期 |
| --- | --- |
| 首次安装本批，基础研究已完成 | 不自动创建；设置手动按钮可创建同一免费任务。 |
| 首次安装本批，有己方存活、非空壳的 SSC 主人 | 不自动创建；手动按钮仍可用。手动选择且未取得永久资格的主人也算主人。 |
| 己方主人只在商队或运输途中 | 不自动创建；地图上没有主人不能绕过检测。 |
| 只有敌方/访客/死亡/空壳主人，或只有已取得资格但当前未设置身份的人格 | 不阻止自动创建。 |
| 领取任务成功后手动触发 | 再创建一个任务；当前任务未接受或进行中时不能连点重复创建。 |
| 主菜单、游戏尚未初始化或没有有效玩家基地地图 | 按钮禁用并显示原因；已有“生成一个种子”按钮保持独立用途。 |
| 切换到另一个未曾创建本任务的符合条件存档 | 独立触发，不沿用前一个存档的标记。 |

### 暂时无地图与目标变化

- 首次判定符合条件但只有商队、没有可接收空投的基地时，不创建任务或写已创建标记。请求随存档保留；建立基地后在最多 1200 tick（正常速度约 20 秒）的重试间隔内创建。等待期间不反复扫描全世界 Pawn。
- 先接受任务，立即暂停并移除原基地地图。还有其他有效基地时，应转投该基地；暂时没有基地时任务保持进行中，恢复基地后再投放，不提前报告成功。
- 无基地等待期间保存、退出、读档，再恢复基地，应继续原任务并只投放一个种子。
- 已有尚未交付的旧任务：载入新 DLL 后，应在实际投放时采用新通知；无基地等待期间不发投放信。旧任务的名称与正文可能保留生成时的旧文字，新名称与正文需用新任务检查。
- 首版任务没有自然过期时间。失败/过期等状态的去重有自动回归，实机若用开发模式结束任务，自动不补发，手动按钮应恢复可用。
- 有/无 Royalty 各跑一次“任务领取→使用种子”，确保免费任务、说明和个人资格不依赖 DLC；研究差异继续按第二批规则。

3B 的商队、普通随机任务奖励和遗迹稀有投放尚未接入，本测试不把手动免费任务视为那些长期随机来源的验收。
