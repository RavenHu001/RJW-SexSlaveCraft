# 宠物互斥、培养与共同效果回归

在仓库根目录使用 .NET 9 SDK：

```powershell
dotnet restore Tests/PetSpecialization/PetSpecialization.csproj --ignore-failed-sources --source Tests/PetSpecialization
dotnet run --project Tests/PetSpecialization/PetSpecialization.csproj --configuration Release --no-restore
```

套件无包依赖，直接链接生产 `PetSpecializationRules`、`PetSpecializationUtility`、特化组件及健康对账、共享培养入口和共享评分公式、`DogSpecializationUtility` 与 `JobDriver_PetAffection`，不复制宠物资格或工作成长公式。

61 个用例组覆盖（原有 29 组，共同效果追加 17 组，猫普通培养追加 15 组）：

- 猫／狗／兔的全部终极组合与切换、培养矩阵；奶牛及其他方向不受宠物组限制。
- 终极冲突的拒绝原子性，包括未规范化的 NaN／无穷／越界当前进度、历史字典、普通及终极 Hediff、留空标记、繁殖模式、身体奶量和通知副作用。
- 普通方向历史往返、同种终极内部认领、明确留空与旧档健康认领。
- 猫／狗玩家入口按 SSC 身份、基础及对应研究开放，兔玩家入口继续禁用；合法恢复与旧档培养独立于玩家选择研究门槛。
- 玩家提交时的资格复查，及旧菜单引用的训练组件已被替换时安全拒绝。
- 共享、特色和底层进度入口阻止任意宠物终极继续培养；冲突不创建普通显示标记；非当前历史不授予资格。
- 完成容差、剩余空间、非有限收益、显示严重度不成为经验、外部普通标记导入和实际绑定主人倍率。
- 当前方向 × 终极组合的效果矩阵；只读查询不写进度、历史或健康，残留普通标签不授予行为资格，终极按自身完成状态读取进度。
- 不生效普通状态及重复标签清理、终极与组外标签保留、留空及主人提前返回、旧档先认领再清理；恢复中不提前导入宿主严重度。
- 终极猫／狗／兔转练非宠物或留空仍可亲昵，普通从零至完成保留既有亲昵资格；全过程复查方向、成果与实际绑定主人，指定调教员不冒充绑定主人。
- 亲昵空闲调度、真实组件、完整 60000 tick 冷却、同 tick 重复完成、距离及物理条件；执行生产驱动注册的失败条件、朝向和完成动作。
- 真实狗训练及驯服尝试的既有成长参数、完成容差和上限；终极狗跨方向概率保持 0.18，不增长普通狗或当前其他方向，拒绝无效对象及过期资格。
- 猫选择无需绑定主人，初始 0.01 显示标记与重复选择不赠送经验；全部三宠物终极组合和菜单提交时身份、研究、成果及组件变化均复查。
- 当前 SSC 普通猫成功亲昵固定增加 0.01；真实驱动等待不发奖，完成容差、剩余空间、初始显示与外部标记导入、完成后的次日亲昵保持既有规则。
- 亲昵完成时读取当前方向：猫转狗／兔不奖励，狗／兔转猫可按当前资格奖励，猫转奶牛／留空使动作失效；终极与其他方向历史不污染。未指定身份或主人身份的旧猫可亲昵但不领取新增经验。
- 同 tick 重复、记忆回调重入、冷却边界和失效条件不会重复领奖；记忆定义或主人记忆容器缺失不影响原有成功完成语义。猫日常与仪式分数沿用真实共享入口及评分公式，不重新检查选择研究。

引擎替身提供定义表、Hediff 容器、Pawn、任务宿主及未修改的外部服务。随机宿主只记录真实工作入口提交的概率；亲昵宿主记录记忆请求和任务请求，暴露生产驱动的条件及动作，提供一次性记忆回调用于结算重入验证，不复制资格规则、不模拟游戏调度或真实记忆合并。外部狗事件许可在本套件恒拒绝，正式许可与调度回归由 `BusTrade`、`InteractionProtection` 验证。

本套件不验证原版动物工作是否实际完成、真实寻路、逐 tick 任务生命周期、XML 属性叠加、人格提取／植入或真实 Scribe。人格迁移由 `PersonalityTraits` 链接真实入口另行验证；游戏内完整行为及存读档仍需实机验收。
