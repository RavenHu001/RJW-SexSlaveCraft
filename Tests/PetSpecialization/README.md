# 宠物互斥、培养与共同效果回归

在仓库根目录使用 .NET 9 SDK：

```powershell
dotnet restore Tests/PetSpecialization/PetSpecialization.csproj --ignore-failed-sources --source Tests/PetSpecialization
dotnet run --project Tests/PetSpecialization/PetSpecialization.csproj --configuration Release --no-restore
```

套件无包依赖，直接链接生产 `PetSpecializationRules`、`PetSpecializationUtility`、特化组件及健康对账、共享培养入口和共享评分公式、`DogSpecializationUtility`、`Harmony_DogSpecialization` 与 `JobDriver_PetAffection`，不复制宠物资格、补丁动作包装或工作成长公式。

101 个用例组覆盖（原有 29 组，共同效果追加 17 组，猫普通培养追加 15 组，狗工作入口修整追加 17 组，亲昵可见互动追加 23 组）：

- 猫／狗／兔的全部终极组合与切换、培养矩阵；奶牛及其他方向不受宠物组限制。
- 终极冲突的拒绝原子性，包括未规范化的 NaN／无穷／越界当前进度、历史字典、普通及终极 Hediff、留空标记、繁殖模式、身体奶量和通知副作用。
- 普通方向历史往返、同种终极内部认领、明确留空与旧档健康认领。
- 猫／狗玩家入口按 SSC 身份、基础及对应研究开放，兔玩家入口继续禁用；合法恢复与旧档培养独立于玩家选择研究门槛。
- 玩家提交时的资格复查，及旧菜单引用的训练组件已被替换时安全拒绝。
- 共享、特色和底层进度入口阻止任意宠物终极继续培养；冲突不创建普通显示标记；非当前历史不授予资格。
- 完成容差、剩余空间、非有限收益、显示严重度不成为经验、外部普通标记导入和实际绑定主人倍率。
- 当前方向 × 终极组合的效果矩阵；只读查询不写进度、历史或健康，残留普通标签不授予行为资格，终极按自身完成状态读取进度。
- 不生效普通状态及重复标签清理、终极与组外标签保留、留空及主人提前返回、旧档先认领再清理；恢复中不提前导入宿主严重度。
- 终极猫／狗／兔转练非宠物或留空仍可亲昵，普通从零至完成保留既有亲昵资格；全过程复查方向、成果与实际绑定主人，指定调教员不冒充绑定主人。
- 亲昵空闲调度、真实组件、完整 60000 tick 冷却、同 tick 重复完成、距离及物理条件；执行生产驱动注册的失败条件、朝向和完成动作。
- 真实狗训练及驯服尝试的既有成长参数、完成容差和上限；终极狗跨方向概率保持 0.18，不增长普通狗或当前其他方向，拒绝无效对象及过期资格。
- 猫选择无需绑定主人，初始 0.01 显示标记与重复选择不赠送经验；全部三宠物终极组合和菜单提交时身份、研究、成果及组件变化均复查。
- 当前 SSC 普通猫成功亲昵固定增加 0.01；真实驱动等待不发奖，完成容差、剩余空间、初始显示与外部标记导入、完成后的次日亲昵保持既有规则。
- 亲昵完成时读取当前方向：猫转狗／兔不奖励，狗／兔转猫可按当前资格奖励，猫转奶牛／留空使动作失效；终极与其他方向历史不污染。未指定身份或主人身份的旧猫可亲昵但不领取新增经验。
- 同 tick 重复、记忆回调重入、冷却边界和失效条件不会重复领奖；记忆定义或主人记忆容器缺失不影响原有成功完成语义。猫日常与仪式分数沿用真实共享入口及评分公式，不重新检查选择研究。
- 狗工作入口显式执行生产 `TryTrain` Postfix 所包装的动作与真实互动观察 Postfix；只在确实发生训练互动且原动作正常返回后结算。互动拒绝、提前返回、动作执行前取消、作用域外通知和不同线程观察不发奖。原动作返回后保留原有延迟属性，后续尾停取消不撤销已完成互动的奖励。
- 随机训练失败仍按有效尝试成长；在宿主提供的互动后判定与反馈阶段，进度、掷骰、事件请求与冷却尚未变化，动作返回后才使用原有 `0.004` 基数成长并请求事件。同一动作重复观察只奖励一次，同 tick 独立动作各自成长，事件仍按原有一天冷却限制。
- 错误发起者、对象和不同互动定义不能冒充训练；目标索引 B、执行时 actor 及开始时捕获对象均参与实际入口验证。嵌套动作分别结算，内层异常恢复外层；未捕获异常不发奖、不吞异常、不泄漏互动，之后的新动作仍可正常执行。
- 普通狗完成培养后不再增长进度；终极狗转练或留空不污染当前方向或历史，事件概率固定 `0.18`；动作执行及结算时方向失效均不给普通狗奖励。驯服观察维持 `0.006` 基数与原结算时序，RJW 行为入口维持 `0.020` 基数，拒绝及无关互动不误结算。
- 亲昵发现范围保持 2.9 格，发现／接近与实际 Touch 结算分离；仅双方清醒、可行动、无精神状态且不在战斗时自动发起。原有绑定、方向、终极、存活、同图、倒地和征召条件继续复查。主人工作、强制命令、队列、已有带期限等待及 `Wait_MaintainPosture` 都不会被自动亲昵抢占。
- 真实驱动注册原版 `GotoThing(Touch)`、`WaitWith` 与完成动作；互动延时 120 tick，主人等待 121 tick，原版进度、原 tickInterval 回调及 `SSC_PetAffectionInteraction` 效果接线可观察。显式检查原版 init 前的失败谓词：尚未创建主人等待时不能误取消。接近与手动执行全部 120 次等待回调均不发奖励，只有完成动作才结算；任务被取消或接触、主人工作、身体及绑定资格失效时不消耗冷却。
- 等待归属同时验证 Pawn、Job ID、原版等待定义、期限、开始 tick 及非强制标记；成功与取消只释放确切等待，重复清理、主人后来的同定义不同 ID 等待／工作和改变目标引用都安全。原版等待安装回调重入取消或替换发起者任务时，旧驱动释放所建等待但不影响新任务；安装后抛出的原异常继续传播，最终清理也不会遗留等待。
- 保存主人引用、等待 ID 与已开始互动标记，字段往返后只显式执行恢复的 tick／finish，不重新运行 init；等待丢失或替换会拒绝结算。旧存档缺少新字段按未开始处理。旧 driver 的 init、tick、finish 不会发奖、改主人朝向或结束发起者的新任务。成功仍只有一次记忆、一天冷却及普通猫固定 0.01 收益，记忆回调重入不能重复领奖；缺失可见效果定义不阻止原有结算。

引擎替身提供定义表、Hediff 容器、Pawn、任务宿主及未修改的外部服务。随机宿主只记录真实工作入口提交的概率；亲昵宿主记录记忆请求和任务请求，暴露生产驱动的条件及动作，提供一次性记忆回调用于结算重入验证，不复制资格规则、不模拟游戏调度或真实记忆合并。外部狗事件许可在本套件恒拒绝并记录请求次数，正式许可与调度回归由 `BusTrade`、`InteractionProtection` 验证。Harmony 属性仅作编译宿主，测试显式调用生产 Postfix；训练原动作由测试提供，其成功率结果、提前返回、异常和尾停取消仅验证入口边界，不复制原版训练成功率算法。

本套件不验证真实 Harmony 自动挂钩、原版动物工作的随机结果、原版 100 tick 尾停的实际执行、真实寻路、逐 tick 任务生命周期、XML 属性叠加、人格提取／植入或真实 Scribe。人格迁移由 `PersonalityTraits` 链接真实入口另行验证；游戏内完整行为及存读档仍需实机验收。

亲昵 `WaitWith` 宿主只记录传入期限、姿势、接触、进度及回调接口。测试显式提供原版等待安装后可能返回的新任务、异常或重入，执行生产驱动包装与注册的失败／完成动作；不会重写 `ForceWait` 的选任务、寻路或停止移动算法。120 次等待回调的检查只证明生产回调不提前奖励，不能替代原版延时调度的实机检验。新增 Scribe 宿主仅记录／回放三个字段和 Pawn 引用，不模拟真实存档解析与剩余 tick 恢复。
