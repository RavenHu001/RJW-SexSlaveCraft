# 人格凝胶界面布局检查

在仓库根目录使用 .NET 9 执行：

```powershell
dotnet run --project Tests/PersonalityCardLayout/PersonalityCardLayout.csproj --configuration Release -- .
```

项目无外部包依赖，使用上级 `Tests/NuGet.Config` 禁用外部源。发布脚本会自动执行此项目。

第一个参数也可以指定实际安装的模组目录，检查该目录的语言文件是否与新界面配套，防止仅复制 DLL 导致新增文案缺失。例如，将命令末尾的 `.` 替换为安装目录的绝对路径。此模式仍执行当前生产绘制源码，不会加载安装目录中的 DLL，也不会启动游戏。

测试直接链接完整生产文件 `ITab_PES.cs`，记录真实绘制代码传给界面接口的矩形、文字、滚动视口及菜单回调。字体、物品和界面接口由 `GuiHost.cs` 提供最小替身；翻译文本直接读取仓库的中、英、俄语言文件。

共 18 项检查：

- 三种语言分别验证 0、3、15、30 个特质：固定文字互不重叠，摘要和按钮保留在窗口内，少量特质收缩，多量特质滚动。
- 长中文和英文特质名称自动增加行高，完整名称保留且不与下一行交叠。
- 两个滚动区域互不影响，第 30 个特质可通过滚动访问，摘要保持原位置。
- 同一凝胶刷新保留滚动位置，列表缩短后收回滚动位置，切换凝胶时重置。
- 缺失列表、失效定义以及缺失背景不会阻断绘制。
- 绘制结束后恢复颜色、字号、对齐和换行状态，正确退出全部分组。
- 分配菜单保留选择和取消行为；打开菜单后切换物品，回调仍操作原凝胶。

测试替身只近似测量字宽，并模拟“鼠标位于视口内时滚动”的界面接口行为。测试可以验证生产布局如何分配区域及传递独立滚动状态，不能替代 Unity 的实际字体、裁剪、工具提示或鼠标事件测试。仍需在游戏内验证不同界面缩放、长名称、多特质、滚轮及分配菜单的实际表现。

可选的第二个参数指定绘制记录输出目录，用于人工检查布局；输出记录及由其生成的示意图均不是游戏截图：

```powershell
dotnet run --project Tests/PersonalityCardLayout/PersonalityCardLayout.csproj --configuration Release -- . .builds/personality-ui/layout-records
```
