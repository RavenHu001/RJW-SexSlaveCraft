# 自我调教手动指派与任务生命周期验证

从仓库根目录运行：

```powershell
dotnet run --project Tests/SelfTrainingManual/SelfTrainingManual.csproj --configuration Release
```

当前 50 项检查直接编译生产 `JobDriver_SelfTraining`、`SSCSelfTrainingUtility`（含评分快照）、资格判断、交互解析和任务选择保存代码。汇总使用 `Test-All.ps1` 支持的标准格式，参与完整回归及发布前验证。

覆盖范围：

- 单人交互筛选、部位条件变化、按 Job 编号领取选择、取消与排队清理。
- 自动选型和手动选型进入同一个真实驱动；交互先于 RJW Start 准备，保留父类及动画框架追加的初始化回调。
- 正常计时结束、RJW 后处理与 SSC 结算顺序、阶段上限及零增量反馈。
- 走路或场景中取消，征召、锁链移除、身体能力失效、地图丢失及交互参与者变化。
- 提前结算、反馈期间重入、任务替换后的延迟回调不得错误发奖或结束新任务。
- 走路和场景中的存读档、所选交互与原始评分快照保持、计时恢复、恢复后中断及领取标记持久化。

`DriverHost.cs` 只模拟引擎/RJW 边界：父类的三个 toil、计时重置、当前任务调度、Start 凭据以及收益/反馈接收器。序列化宿主在 `LoadingVars` 创建新的深层对象、在 `ResolvingCrossRefs` 解析 Pawn 引用，并按原版顺序在 `PostLoadInit` 重建 toils；不会用原快照对象冒充读档。评分、快照、驱动流程和去重代码来自生产源码。

许可与场景守卫在此作为可控输入，其真实实现另由 `InteractionProtection` 测试。这里没有运行完整 RimWorld 引擎、已安装 RJW/动画 DLL、Unity 渲染或实际心情界面；动画测试验证回调接入与计时收尾，不代表实机动画视觉验收。游戏右键菜单、完整模组补丁组合和动画显示仍需实机确认。
