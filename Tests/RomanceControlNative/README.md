## 仅文案专项模式（2026-10-26）

此变量仅供独立宿主选择专项。统一 `Scripts/Test-All.ps1`（包括发布脚本间接调用）会在执行前移除它并在退出后恢复调用者原值，同时拒绝浪漫宿主输出的仅文案范围标记，不能用该模式代替总回归。隔离修复的[编排专项](../ValidationRunner/README.md#浪漫文案模式隔离专项2026-10-26)不运行本宿主的完整机制套件。

按本宿主原构建说明生成后，可设置环境变量SSC_ROMANCE_TEXT_ONLY=1再运行同一个宿主，仅执行四语名称／描述、原生语言注入／语法、本人日志视角及任务／结果参数格式化，当前590项。夹具直接构建保存事实作显示输入，不执行真实互动、命令调度、人格／克隆或其他机制测试；不据此声明整套机制回归通过。

```powershell
$env:SSC_ROMANCE_TEXT_ONLY = '1'
# 使用原运行命令及仓库／游戏目录参数。
# 结束后清除此变量，未设置时仍运行原完整相关机制套件。
Remove-Item Env:SSC_ROMANCE_TEXT_ONLY
```

本次三语落实实际只运行此模式，590／590通过；完整用例中的原占位文本断言已改为读取实际资源并保留事件／角色／回退检查，未借本次任务再跑完整机制套件。
