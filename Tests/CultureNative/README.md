# 文化步骤 1／2／3 原生专项

目标为本机 RimWorld 1.7，使用 .NET 10、真实游戏程序集和测试用 net9.0 Harmony。通过 ProjectReference 编译完整生产 1.7 工程，执行生产查询、快照和文化 workers；不使用模拟 MapPawns、领袖资格、刷新或结算算法。

## 覆盖

- 原生 XML 反序列化和交叉引用：1 个模因、1 个分组、5 个 Issue、22 条戒律；两类权重、挂载与排序、四语键和语言镜像。
- 原生 CanAdd／CanAddForFaction、完整 RandomizePrecepts（不是 requiredPreceptsOnly）、改革添加／移除、零权重合法旧项保留、禁止默认项的可行性负例。
- 读取本机原版模因的资格字段，用原版 XmlInheritance 合并继承、IdeoUtility.CanAdd 检查排斥，用原版 CanAddForFaction 检查 SSC 五组。当前包括 27 个普通模因配对及 340 个合法三模因组合资格检查；保留原版性别至上互斥。全面禁欲的资格配置随模因添加／移除保持。
- 真实地图来源、递归 ThingOwner／休眠舱、商队、可控异变者、任务额外势力借住者、飞行运输；名册／环境／每主绑定三种集合分别断言。
- 主／次文化实际职位及 ChosenPawnSingle、原版自由非奴隶资格、RequirementsMet、领袖四态和多有效任职者冲突；不写职位或显示顺序。
- 同代共享、按需项目与每主计数、99／100 tick、延后项目不延长寿命、周期内回退、加载／实例／DLC 边界、无读取不扫描。
- 原生人口属性入口和内部递归分别计数：两地图名册递归 4 次，加入环境首次查询后累计 6 次；50 次同代重复读取不增加递归。此为确定性工作量结果，不是 TPS 或耗时收益。
- 真实 Scribe 往返：文化保留零权重手选档位；组件不写快照字段，重载后首次有效查询重建。
- 累计 44 条原版 situational ThoughtDef／53 阶段，17 条态度及有限数量戒律挂载共 44 组件；三种漠视与两条不限无组件。逐格断言条件、上限、数值、每语 106 个阶段键／63 个戒律键及 19 条阶段说明，其中四条单阶段数量心情及神圣环境心情显式解释累进与封顶。
- 真实 ThoughtHandler／SituationalThoughtHandler 创建、来源、分组、MoodOffset／TotalOpinionOffset／最终 OpinionOf；态度、自身状态、艳羡互斥、全额叠加、环境倍率和领袖四态。
- 原版 NeedsTracker 的 150 tick 散列调度、社交 99／100 tick 缓存、环境/领袖约 250 tick 收敛；真实 SetIdeo 与改革 cache ID 驱动刷新，未调用手动 dirty 掩盖状态变化。
- 本机 Anomaly Inhumanized 的实际阶段字段经过真实最终好感系数；真实 TraitSet、发展阶段和原版亚人社交目标过滤；无 Ideology、加载、组件重置及 Game 切换。
- 步骤 2 的个人／双人态度项不收集人口；环境接收者和领袖共用成员名册，管理人数独立准备，同代反复查询不增加递归。数量本人心情和多人社交共用每主计数，同代只遍历实际被请求主人一次；有效零人数缓存，不限和非主人本人项先短路，无无关环境／领袖统计。未进行 FPS／TPS 或分配/耗时基准测量。

- 数量曲线字面量：主人心情 -6／-15／-27、本人名下心情 -3／-9／-18、观察者社交 -5／-15／-30，最多计三个超额，覆盖 0／达标／超额各档／远超封顶及回落；两组心情合计 -45／组合 -36、圣主社交叠加 -10。
- 观察者自身上限、目标不限仍被评价、观察者不限不评价、观察者非主人、跨文化、双人名册、自身排除；实际地图／纯商队与名册外绑定对象；换绑同时布置双方真实反向候选。
- 数量反馈通过真实 NeedsTracker／双人社交缓存刷新，100 种相位验证持续查询在 200 tick 预算内激活／恢复，原版改宗及戒律替换 cache ID 双向刷新；真实 Scribe 证明缓存不保存、有限旧戒律读档获得当前 Def 组件。

- 实机反馈调参：主奴秩序为原版最高影响三级，仍验证原生生成／改革／模因组合；神圣环境复用 SimpleCurve，逐点及实际结算验证 0／1／3／6／10／15、五人峰值、远超五人／完整人口不截断、回落与持链本人互斥；敌视／厌恶保留线性，同代共享计数不增加遍历。

- 敌视性奴新增实际持链者的负面社交：观察者文化、自身排除、身份预选不等于锁链、目标实际持链判断、原版 99／100 缓存、解绑后消失、与训导官态度相加、无人口统计或永久关系。

- 性奴担任原版有效领袖：尊奉／圣主心情 -6／-12、社交 -10／-20，互斥替代普通非主人阶段，保留原版法律奴隶任职限制。主人含领袖本人只取消正向领袖奖励，负面不豁免；观察者社交沿用一般态度资格，心情接收者仍限名册。覆盖最终结算与态度叠加、本人社交排除、实际需求 250 tick、社交所有 100 种相位在 200 tick 收敛、SetIdeo／戒律替换、真实 Scribe 与切档回退、同代只查询一次领袖且不查无关人数、无链目标先短路。

## 初始化与隔离边界

本宿主不启动游戏 UI 或枚举用户模组；用户配置写入仓库 `.builds/culture-step1/userdata`。世界根入口提供实际 Map、WorldObjectsHolder 和 Faction 夹具，时钟可控；MapPawns、容器递归、QuestUtility、原版职位要求、生成／改革／资格和生产查询均运行真实代码。健康列表和任职记录直接布置条件，不声称测试了完整绑定事务／授职仪式。

图形 Def 构造、贴图、翻译、容器增添时的界面通知、日志投递及 Scribe 的外观样式子对象被隔离；组件、文化及戒律自身的保存／读取不被替换。SSC 全局 Def 注册器预热时未加载本专项以外的完整资源，忽略该启动边界日志，随后布置所需锁链和缰绳定义；实际被测阶段的错误日志均使测试失败。

原版模因组合只装载相关资格字段，保留继承和原有排斥标签，未装载它们完整的仪式／建筑／故事／美术依赖。Lovin_Prohibited 只验证资格及改革保留，不执行其历史事件组件；不能称为启用全部 DLC／模组后的完整文化生成验收。无 Ideology 项验证 XML 加载保护与生产读取短路，不代替无 DLC 实机加载。

步骤 2 反馈夹具提供真实 story/traits、成年 LifeStage、唯一人物 ID、needs/mood、relations、WorldPawns 和注册到 Game 的生产组件。人物已处于成人阶段，直接布置年龄缓存以避免首次读取触发无关的生长转场；不替换 ThoughtUtility.CanGetThought 或目标发展阶段筛选。初始链/任职仍直接布置，因此不声明验证绑定事务或完整授职仪式。改宗用例单独提供真实空 WindowStack，隔离 HistoryEventsManager 根与改宗历史事件存储；SetIdeo、人物/文化缓存失效、配偶检查和改革算法继续执行原版。非人化只投影本机 Hediff 的阶段好感系数字段，无完整特效/能力依赖；可证明最终好感遵循原版系数，不代表完整非人化 DLC 实机流程通过。环境与领袖接收者采用有效人物栏名册；环境被统计的持链囚犯仍在独立管理集合中。

## 运行

已登记到 `Scripts/Test-All.ps1`，沿用 NativeGameRoot、NativeDotnetPath、HarmonyAssemblyPath；生产 RJW、动画和游戏 Harmony 引用由 `1.7/BUILD-INFO.json` 提供，缺失时构建失败，不回退旧 DLL。无需联网，也不安装、提交或发布模组。

直接构建本项目时同时传入 GameRoot、RjwAssemblyPath、AnimationsAssemblyPath、GameHarmonyAssemblyPath、HarmonyAssemblyPath；用匹配 .NET 10 运行生成 DLL，参数为仓库根目录和游戏根目录。首次使用 SDK 时将 DOTNET_CLI_HOME 指向仓库内可写目录。
