```powershell
dotnet run --project Tests/DesireInfestationFeedback/DesireInfestationFeedback.csproj -- .
```

宿主链接真实反馈工具、普通完成上下文、侵染准入／恶堕、人格运行时凭据及人格记忆工具；加载生产 Def XML，不复制业务算法。覆盖四格及两侧边界、双向主人、原结算前 C/O、旧反馈参与 OpinionOf、跨档／零偏移替换、多主人容量、期限衰减、写入回调换人格、载体替换、原生记忆字段及人格采集／复制／植入往返、定义和四语镜像。

`Tests/Shared/InfestationMemoryBoundary.cs` 是按本机 API 契约构建的最小引擎模型，不是原生游戏或完整 Scribe；同一模型也供 InteractionProtection 使用。真实 Harmony 入口集成由后者验证。PNA／身体分量仍由原各专项覆盖，完整游戏存档、实际界面、全部语言及模组组合须实机确认。

本批最终计数与构建、统一回归、同步结果在第四批记录统一登记；维护者现已明确确认“实机测试都符合预期”，验收范围见记录，模型与实机结论分别维护。
