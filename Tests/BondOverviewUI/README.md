# 主从关系概览界面与导航回归

直接链接生产会话、原版组件接入分文件、导航、卡片、窗口与共用绘制，复用 BondRelations 的健康／关系／世界替身。GUI、时钟、肖像、选择与相机只是计数边界，不另写绑定或位置判断算法。本套件不依赖游戏进程或 Harmony 测试程序集。

当前 **188/188**。本轮将分页契约替换为完整自适应网格，并新增 13 项批选现时归属／地图范围／原版 200 上限／过期输入、Small 字体、500 人完整绘制与固定纹理请求、主人底部文字叠放回归。原 175 项及先前按钮时序修复保留历史依据；鼠标继续按下捕获、松开成功。

- 首屏直接读取主人与调教员，缰绳逐项核对锁链；未知数量标注、已知补漏保留／移除、跨来源／游戏隔离、未知飞船点击实时解析、重复登记缓存和 75 方形主人和 130×75 调教员／性奴卡片的原版背景／材质。
- 2 秒全会话补漏预算、5 秒空候选探测、手动／换来源／重开／换图不能绕过预算、同源共享、双源轮换、时钟回退、慢查询退避与异常限频。
- 无身份且缰绳漏项的角色、单选／多选、死亡来源关闭、总览随当前来源退出、窗口替换与关闭、跨存档和引用释放。
- 点击时重新解析地图、容器、组件、世界对象、世界格、飞船位置，换船不跳旧船，死亡／复活重取主体；环、未知位置、改绑、外来行和不可达目标拒绝导航。
- 左键只分派一次，右键、禁用、变更代次与失效关系不执行；双向异常保留两端事实，普通 Bind 规则不放宽。
- 总览窗口的 500 对象只绘制可见网格，末项可达，卡片头像显示尺寸自动缩小，肖像请求仍为 40／56 两档和固定 1.5 缩放，GUI 异常恢复、滚动退出、屏幕尺寸限制和只读状态对照。
- 四语键集、参数占位符、镜像与结构化位置／指派／失败状态键齐全。
- 只生成可见／悬停行文字，64 行与 256 截断项上限、宽度／字体／缩放／语言隔离与释放失效；首次截断结果与原版形状一致，热窗口不重复截断。

运行：

```powershell
dotnet run --project Tests/BondOverviewUI/BondOverviewUI.csproj --configuration Release -- .
```

性能复现：

```powershell
python Tests/BondOverviewUI/Performance/Compare.py
```

默认固定比较性能阶段 `98b3ce6` 与 `67bb391`，三轮交替，分别读取各自工程清单；输出在 `.builds/bond-overview-ui-opt/reproduction/`，不覆盖原性能证据，源码／替身哈希与原始 JSONL 一并保留。固定字符宽度仅用于分配与调用对比，实际 1.7 编译单独验证，不能预测游戏帧率。缓存查找在短文字模型中有少量 CPU 成本；详细取舍、预算和实机边界见[本轮性能记录](../../Docs/Development/Verification/主从关系概览第二批性能优化与对比.md)。

指派入口直接编译共用菜单和生产 BondUtility；GUI 宿主只控制候选／事务边界返回值，不重写权限策略。[TrainerIdentity](../TrainerIdentity/README.md)另直接编译同一菜单和真实身份、候选、限制及原子指派，164/164 包含新菜单 8 项。当前网格同屏头像数量不同于旧表格，不与旧窗口直接做计时等量比较。
