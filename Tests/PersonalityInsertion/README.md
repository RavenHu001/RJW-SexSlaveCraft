# 人格植入接触与中断回归测试

直接链接生产 `JobDriver_InsertPersonality.cs`，验证植入等待期间及最终结算前的接触保护。

```powershell
dotnet restore Tests/PersonalityInsertion/PersonalityInsertion.csproj --source Tests/PersonalityInsertion --ignore-failed-sources
dotnet run --project Tests/PersonalityInsertion/PersonalityInsertion.csproj --configuration Release --no-restore
```

## 覆盖范围

16 项用例覆盖：

- 相邻目标等待 600 tick 后正常完成，人格继承、凝胶消耗、昏迷和成功提示只执行一次。
- 目标进入等待，并保留睡眠与姿势；前往目标的行走阶段仍允许双方相距较远。
- 操作阶段目标或操作者走远、接触被阻挡、目标消失、失去空壳状态、被禁止及操作者主动中断。
- 最终结算回调独立拒绝距离变化、接触阻挡、跨地图、操作者离图、目标死亡及空壳状态变化。
- 中断时没有人格继承、凝胶消耗、新增昏迷、主动清除分配或成功提示。

修复前同组用例为 6/16 通过，修复后为 16/16 通过。

## 验证边界

宿主依据本机 RimWorld 1.6 程序集核对的 `Wait`、`WaitWith`、`FailOnCannotTouch` 和任务失败条件构建。生产驱动的步骤、条件和回调均直接执行；测试从行走结束处设置场景，不模拟完整寻路、地图或 Unity 调度。

`WaitWith` 在原版会让目标等待、注册接触检查，并按参数保留姿势和睡眠。测试宿主模拟这部分行为。最终结算用例在调用生产结算回调前改变目标状态，独立检查写入边界，避免仅依赖等待步骤的失败条件。

人格继承在此套件中记录调用和模拟成功副作用；真实人格数据迁移由 `PersonalityTraits`、`PersonalityMemories` 套件验证。本套件不模拟地图分配组件的定期清理，也不保证其他原因造成的任务中断会自动重试。

本轮相关套件合计 55/55 通过，使用本机依赖的 Release 构建通过。维护者已在游戏中确认原问题，并在修复后确认有效，授权提交和上传。本次确认未提供逐项场景结果，不扩大为全部边界场景或模组组合均已实测。

## 后续游戏内回归清单

1. 给已恢复行动的空壳分配有效人格凝胶，确认目标在植入进度期间停留，600 tick 后正常植入并消耗一个凝胶。
2. 进度期间强制移动目标离开接触范围，确认植入中断、凝胶仍存在、空壳未被覆盖，也没有植入成功提示。
3. 对睡眠、卧床或昏迷目标植入，确认保持原有姿势与睡眠并正常完成。
4. 中途取消操作者任务，确认没有完成植入或消耗凝胶；目标等待由原版限时任务结束。
