# 永久泌乳累计计时回归

直接链接 `HediffComp_PermanentLactating.cs`，读取仓库实际 `SSC_Lactating_SubState` XML 参数。无包依赖，使用 `Tests/NuGet.Config` 的离线还原配置。

在仓库根目录运行：

```powershell
dotnet run --project Tests/PermanentLactation/PermanentLactation.csproj --configuration Release -- .
```

## 修复行为

- 将每次调用传入的 `delta` 累计到至少 60 tick，结算全部累计时间，随后清零。调用跨过阈值时也不丢掉超出的时间。
- 奶量与额外营养消耗使用同一段时间；接近满容量时按实际可存入量扣除营养。
- 满容量、关闭泌乳、HumanCattle 接管时清理累计时间；缺粮批次完成结算后不会在补食时补发。
- 新增存档字段 `sscPendingProductionTicks`，保留不足一批的进度；继续调用基类存档方法保存原有奶量。旧存档缺少字段时从零开始，不追补历史漏算产量。
- 原有永久状态、无食物需求时生产、食物不足时按比例生产，以及 HumanCattle 提前接管入口保持。

## 验证范围

修复前同一套用例为 6/22 通过，修复后为 22/22 通过。套件已接入 `Scripts/New-Release.ps1`，后续打包时运行。

使用本机 RimWorld、RJW、Harmony 和动画框架依赖的 Release 构建通过；运行 DLL 已更新，与验证后的候选文件 SHA-256 一致。确认 DLL 包含累计字段与存档入口，生产方法不再使用原哈希时点判断。

覆盖调用间隔 1、2、3、4、5、15、60、100、250，50 + 15 tick 的混合分段，不足一批等待，关闭/开启，满容量后挤奶，外部补满，缺粮、补食、容量截断，无食物需求，存读档，旧存档，接管入口，以及非正间隔。

当前配置为容量 0.125、充满 15,000 tick、额外营养每天 0.3。在食物充足、从空开始且无额外产量时，各固定间隔均约 6 个游戏小时充满，消耗约 0.075 额外营养。常规饥饿消耗不计入此数值。

宿主只模拟基础奶量字段、组件调用和 Scribe 字段读写，固定间隔用例有意覆盖不对齐哈希时点的调用。没有运行完整 Unity 调度、真实 XML 存档加载器或 HumanCattle 生产系统；不能把入口测试视为全部模组组合兼容性验证。

维护者已确认游戏内修复有效，并授权提交；未提供逐项场景和兼容组合的实测结果。

后续游戏内回归可重启后加载更新 DLL，排除储奶槽、额外催熟和挤奶消耗，比较不同镜头位置/缩放下的基础产奶；另检查关闭后重开、保存后读取、满奶后挤奶及缺粮表现。
