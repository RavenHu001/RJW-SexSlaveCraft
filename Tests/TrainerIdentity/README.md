# 调教员身份回归

使用 .NET 9，无第三方依赖，从仓库根目录运行：

```powershell
dotnet run --project Tests/TrainerIdentity/TrainerIdentity.csproj --configuration Release `
  -p:RestoreConfigFile="完整仓库路径/Tests/NuGet.Config" -- .
```

直接编译生产身份工具、开关存档字段、一次性迁移、指定调教员服务、绑定服务、日常 WorkGiver 和两个仪式角色。30 项覆盖：

- 主人/未选择固定状态，性奴可选及真实身份切换。
- 已绑定性奴和仍有绑定性奴的主人拒绝身份切换，保留锁链实例、严重度、恶堕与训练/仪式状态。
- 重复设置当前身份和重复绑定幂等；无绑定角色可切换，明确解绑后恢复资格。
- 绑定入口提前校验身份，拒绝把有绑定性奴的主人转成性奴，不残留半条绑定；首次绑定与归属冲突回归。
- 菜单和直接指派一致过滤，排除自身及原版候选范围外人员，工作条件和主人限制。
- 原版分类 getter 清空重填同一临时列表时，嵌套指派检查与外部分类查询不会破坏菜单候选枚举。
- 重新指派、停用记录保留、开放调教及公交车的身份门槛。
- 自动/强制工作、冷却排班和预留限制，停用后不得开始下一次调教。
- 绑定默认主人、无主归属回退、仪式角色与停用指派。
- 旧档缺字段、显式关闭、世界对象迁移及重复加载幂等。
- 四语提示键与格式参数。

不运行 Unity。存档使用字典模型，不能代替真实 Scribe 引用恢复；工作用例执行真实 WorkGiver，日常 JobDriver 的队列/走位回调另需在游戏内复测。总栏字体、缩放和鼠标操作也需游戏内确认。同床通过独立的 [SharedBed](../SharedBed/README.md) 套件验证。

本套件作为开发检查单独运行，尚未加入正式发布版本的打包入口。
