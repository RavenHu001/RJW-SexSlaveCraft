# SexSlaveCraft 2.2.12 — 恶堕衰减翻译与行为保护修复

适用于 RimWorld 1.6，包含 2.2.11 及更早版本修复。

## 中文

- 补齐恶堕衰减设置的简中、繁中、英文和俄文运行时翻译，修复开关、每日衰减量及说明显示原始键名的问题。
- 修复非主人加入已经开始的行为时绕过主从保护的问题；拒绝加入者时保留原双方的现有任务。
- 首次发起也在创建接收任务前校验，避免接收任务被过晚拒绝产生的预约黄字。玩家强制指派同样接受保护检查。
- 保留合法主人、他人训练许可及设置例外，补充未开始场景的收尾保护，并让 SSC 训练和仪式在 Start 被拒绝后停止后续开始通知或状态推进。

维护者已确认修复有效。Release 构建及八套件 173 项回归检查通过；新增 27 项保护用例另通过真实 Harmony 注册测试，四语言设置键与占位符检查通过。验证范围见随包 `Docs/2.2.12版本验证.md`。

安装：下载下方 `RJW-SexSlaveCraft-TieJin-Modify-2.2.12.zip`，退出游戏，将旧版模组文件夹移出 `Mods`，再解压本包至 `RimWorld/Mods`。依赖与加载说明见随包指南。相邻 `.zip.sha256` 用于校验完整性；GitHub 自动生成的 Source code 压缩包是源码归档。

## English

For RimWorld 1.6. Includes fixes from 2.2.11 and earlier versions.

- Adds missing runtime translations for Corruption decay settings in Simplified Chinese, Traditional Chinese, English, and Russian, fixing raw keys shown for the toggle, daily decay amount, and descriptions.
- Prevents non-owners from bypassing owner protection by joining an existing interaction, while preserving the original participants' jobs.
- Checks new attempts before creating a receiver job, avoiding the late reservation warning. Player-forced jobs are also checked.
- Preserves owner access, permitted training, and setting exceptions; guards cleanup for rejected scenes and prevents SSC training and rituals from continuing start notifications or state changes after a rejected Start.

The maintainer confirmed the fixes work. The Release build and all 173 checks across eight regression suites passed. The 27 new protection cases also passed real Harmony registration tests, and the four-language setting keys and placeholders passed validation. See the included validation record for coverage and limitations.

Download the attached installation ZIP, close the game, move the old mod folder out of `Mods`, and extract this package into `RimWorld/Mods`. See the included guides for dependencies. Use the adjacent `.zip.sha256` to verify integrity; GitHub's automatic Source code archives are source snapshots.
