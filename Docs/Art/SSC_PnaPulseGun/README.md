## 已确认构型与画风

采用类似P90的紧凑无托外轮廓，主体有圆润边角及清晰分件。后部竖置矩形液舱与枪托半融合，可从下方拆卸，保留独立接缝与侧卡扣，没有底部铰链盖板或传统弹匣。中央握持开口与前方扳机区域保持清楚。

前端为短小、齐平的枪口及细小发射口，枪身侧面两道横向开口向后延伸；前端根部有模块接缝，其上端止于连续顶部结构下沿，不穿过瞄具模块。低矮梯形瞄具位于前上方并融入枪身，保留可见浅蓝视窗。已取消先前试验的磁轨和外凸粗枪管。

冷灰白外壳、深蓝灰握持区与银灰嵌件沿用太空丝鞭柄的材质语言，液舱视窗和两道前端侧开口采用深紫色。加重黑色外轮廓，保留清楚部件色块、有限明暗及高光。提示词中缩小后9～11px等数值仅为生成目标，本轮没有进行256px导出、全图线宽测量或游戏内验证。
