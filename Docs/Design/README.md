1. 先读[总体完成状态](未来内容开发规划.md#完成状态速览)，确认条目中已经实现与仍待开发的边界。
2. 涉及 PNA 或主人侵染时，先读[PNA 机制重置](PNA机制重置开发规划.md)，再读[主人欲望侵染](主人欲望侵染开发规划.md)。前者负责共享基础，后者负责主人侧接入。
3. 查设计来源时再进入[历史设计归档](Archive/README.md)；接手代码时转到[已交付开发记录](../Development/Completed/README.md)。
