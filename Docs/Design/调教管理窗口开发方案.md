## 1. 原调教标签直接开窗

继续注册 `ITab_SexSlaveTraining`，保留原「调教」标签的位置、排序、`labelKey`、`tutorTag` 和可见条件。点击时复查当前单选角色及其训练 Comp，沿用对原版殖民者、本殖民地囚犯、原版奴隶和符合自我调教例外角色的准入。首次打开进入概况，同一角色已有窗口时复用实例。 [原标签和可见条件](../../Sexslavecraft/ITab/ITab_SexSlaveTraining.cs) · [种族注入](../../Sexslavecraft/common/ITabAddForRace.cs)

目标 DLL 的原生点击顺序为 `DoTabs → InterfaceToggleTab → ToggleTab`。`InterfaceToggleTab` 先检查教程许可，`ToggleTab` 在 `OnOpen()` 返回后写入 `OpenTabType`。1.7 接入精确签名的 `InspectPaneUtility.ToggleTab(InspectTabBase, IInspectPane)` Harmony Prefix，仅处理地图原生检查面板上类型精确匹配的 SSC 调教标签。匹配后转交窗口打开逻辑并跳过原展开流程。旧 SSC 展开状态若存在则清理，其他标签继续走原方法。1.7 工程显式纳入新窗口与补丁，真实点击和教程许可列入实机验收。 [1.7 工程](../../Sexslavecraft/SexSlaveCraft_1.7.csproj)

## 2. 窗口布局与角色切换

使用单实例原生 `Verse.Window`，以约 800 × 680 逻辑像素居中打开。窗口允许原版界面接收窗外点击，按殖民者栏的实际行高避让重叠。标题区固定显示当前角色肖像、姓名、SSC 身份及关系摘要。宽窗用左侧导航，窄窗把导航移到顶部换行，当前页内容独立纵向滚动。页面分为概况、关系、日常调教、特化、身体与外观、行为规则。 [窗口实现](../../Sexslavecraft/UI/Dialog_SSCTrainingManagement.cs)

- **选角。** 玩家从原版殖民者栏或地图单选，窗口读取 `Selector.SingleSelectedThing`，沿用原调教标签资格并核对角色所在地图。空选、多选和不可管理对象显示提示，下一次有效单选继续显示概况。切换地图时跟随有效的地图单选，进入世界视图或离开原游戏时关闭。角色肖像用于显示当前角色。
- **切换后状态。** 第一批切换角色或训练组件时将概况滚动归顶。可编辑页面接入后，当前页对新角色适用时保留页签，否则回概况。届时维护窗口编辑代次，清理旧视图与拖放状态。指派动作和能力行应复查原窗口代次与各自业务上下文，覆盖 A → B → A 后的迟到提交。

## 3. 关系页

复用第 29 项的直接关系事实与详情。主人按实际锁链读取，所属性奴按缰绳候选逐一核对实际锁链，指定调教员读取现有指派及工作状态。顶部预览与详情共用当前角色的关系视图和局部刷新。抽取原详情绘制内容，让新窗口跟随原版单选并管理滚动。原命令栏放大镜对可管理角色直达新窗口的关系页。仅满足旧概览资格的角色继续沿原详情入口，两个入口共用绘制器并明确详情视图的释放归属。地图上的原快捷定位和批选继续调用原入口。 [关系完成记录](../Development/Completed/主从关系概览完成核对.md) · [直接关系查询](../../Sexslavecraft/common/SSCBondOverviewUtility.cs) · [关系会话](../../Sexslavecraft/common/SSCBondOverviewSession.cs)

关系分组按当前 SSC `PawnIdentity` 显示。主人只显示所属性奴，零人时显示空状态。性奴只显示主人和调教员相关分区，保留「未绑定」和「未指派」状态。未设身份时只显示身份提示，历史锁链的显式身份恢复入口在概况。 [SSC 身份与历史恢复](../../Sexslavecraft/common/SSCIdentityUtility.cs)

### 性奴关系页三区

```text
┌──────────────┬────────────────────────────────┐
│ 1 主人       │ 2 已指派调教员                 │
│              │   每行五张头像和姓名           │
│   大头像     ├────────────────────────────────┤
│    姓名      │ 3 可指派调教员                 │
│              │   每行五张头像和姓名           │
└──────────────┴────────────────────────────────┘
```

- **1 区主人。** 左侧窄列跨右侧两区，内容为大头像和姓名。已绑定的正常状态用主人头像表达。
- **2 区已指派。** 右上按实际人数占高。2.4.10 显示零或一张头像卡，空区也可接收拖放。工作关闭或暂时离图的现任仍属于已指派区。
- **3 区可指派。** 右下常驻候选，排除已指派者。候选沿用原同图自由殖民者、调教员身份、工作条件及目标许可。可提交的候选包括工作已启用者和可随指派启用工作者，暂不可指派原因沿用现有判断。 [候选查询](../../Sexslavecraft/common/TrainerAssignmentUtility.cs) · [工作状态与指派事务](../../Sexslavecraft/common/SSCTrainerWorkUtility.cs)

2 区和 3 区每行五张卡，头像为主体，姓名常驻头像下方。悬停提示两行，第一行显示调教工作是否启用，第二行提示拖放操作。可指派头像提示拖入 2 区，符合同时启用条件时写明「指派并启用」。已指派头像提示拖回 3 区撤销。不可提交时用原受限原因替代操作提示。窄窗按 1、2、3 纵向排列，给两组五列头像留足宽度。肖像复用原版缓存和现有可见区裁剪。 [肖像、提示及网格](../../Sexslavecraft/UI/SSCBondOverviewWidgets.cs)

### 拖放和提交

| 操作 | 结果 |
| --- | --- |
| 从 3 区拖到 2 区 | 松手时指派。已有调教员时，新人成功指派即自动替换前任。前任仍符合条件时回到 3 区 |
| 从 2 区拖回 3 区 | 松手时手动撤销当前指派。撤销后符合条件的角色进入候选区 |
| 拖回原区、拖到无效位置或取消 | 结束手势，保留原指派 |

开始拖动时区分单击与拖放，记录原受训者、拖动角色、来源区、原指派和窗口代次。有效落区高亮，松手后用捕获的原业务请求提交，禁止为迟到操作重新取得新载体的权限。复用第 21.1 项的指派、启用和清除规则，并复查地图、Comp、人格、工作设置、实际主人及相关许可。替换由一次事务完成，新指派成功时前任才退出。失败时显示原原因并按实际保存值刷新，原事务只撤回仍由本次请求持有的新增工作值。成功后刷新 2、3 区和顶部摘要，地图单选与窗口编辑对象继续指向原受训者。 [共用菜单的现行规则](../../Sexslavecraft/UI/SSCTrainerAssignmentMenu.cs) · [第 21.1 项实现与验收](../Development/Completed/调教员指派与工作启用便捷操作实现与验证.md)

候选区在进入关系页、切角、提交后及受控刷新时生成，只读取得候选和工作状态。保留原菜单的同一套候选与事务，绘制使用轻量候选视图。当前保存只使用原 `selectedTrainer`，界面将其投影为零或一条。未来第 21 项可把真实多人列表接入 2 区，3 区承接新增，2 区拖出承接逐人撤销。人数上限、优先级、轮换、任务争用和旧档迁移由第 21 项单独定义。 [原保存字段](../../Sexslavecraft/Comps/Comp_Train.cs) · [第 21 项总体规划](未来内容开发规划.md#21-调教员指派系统重构与多调教员指派)

## 4. 其他页的接入边界

概况承接身份、任职和主人阶段。日常调教承接启停、排程、姿势和指派，特化保留独立研究及候选条件。锁链的 PNA 阶段维持放在日常调教的锁链区，身体生产的 PNA 开关放在身体与外观。行为规则保留性行为控制和浪漫控制各自的个人配置及恢复默认，详细许可测试和调色沿用专用弹窗。

各页按功能原资格决定可见及可改状态。界面复用第 28 项的能力控件、`GetView`／`TrySet` 和原上下文校验，身份、排程、枚举和工作设置继续用各自业务入口与原保存源。其他页的具体排布随控件迁移核定。 [能力开关接入规范](../Development/Reference/个人能力开关接入规范.md)

## 5. 实施批次与验收

1. **开窗与选角。** 接入原标签、独立窗口与选角上下文。核对原位单击、Esc／关闭键、重复打开、其他标签、囚犯等原适用角色。实机验证殖民者栏及地图单选、空选、多选与换图后的窗口反馈。
2. **关系页与拖放。** 接入原关系详情、三分区和指派事务。验证主人和性奴分组、零／一名指派、五列姓名及两行悬停、指派并启用、自动替换、手动撤销和无效落点。用代表场景覆盖强制许可拒绝、候选失效和换人后旧拖动失效，核对失败前后原指定者及工作值。优先复用现有宿主的相关用例。 [BondOverviewUI](../../Tests/BondOverviewUI/README.md) · [TrainerIdentity](../../Tests/TrainerIdentity/README.md)
3. **其他页迁移与联调。** 核对原控件可达性、旧档与载体替换。用简中、繁中、英语和俄语在常规及窄窗下实测名称、提示、滚动和落区命中。构建、自动回归、游戏内验收和发布门禁分别记录，按实际改动选择最小验证范围。 [测试编写与执行准则](../Development/Reference/测试编写与执行准则.md)
