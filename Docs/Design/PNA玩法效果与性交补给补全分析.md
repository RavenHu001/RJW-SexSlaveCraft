## 当前完成边界

P1～P3 已完成负荷、五档普通效果、分段清除、确定性满值成瘾、原版需求与十天恢复、摄入／普通目标枪械输入、锁链保护、身体归属和保存兼容。它们构成可用的基础框架，不代表全部 PNA 玩法已完成。

维护者提出性吸引力、性奴作用、成瘾负面及影响面、心情、可选特殊精神状态、与 PNA 分泌者性交时少量摄入。本页逐项核对，并补充来源一致性、效果叠加、完成认领和玩家可理解性等交叉问题。

## 六项主要缺口

| 项目 | 当前实现 | 建议的补全方向 |
| --- | --- | --- |
| 性吸引力 | 普通负荷只增加 SexFrequency，没有专门的 PNA 吸引效果 | 先确定要改变他人对身体的吸引，还是对特定供给者的偏好；前者可评估既有属性，后者是独立的来源／关系设计 |
| 性奴作用 | 有效锁链免普通成瘾／负面，性奴负荷只有一个无属性的“扎根”档 | 直接给既有性奴负荷增加固定 XML 正面阶段，先确定性行为、日常身体状态与战斗收益的主次 |
| 成瘾负面 | 普通／戒断两档均仅 SexFrequency ×1.25；戒断主要靠 -18 心情 | 优先扩展原版戒断档的固定效率／能力影响，保留正常成瘾与戒断区分，继续原版十天恢复 |
| 心情 | 普通 PNA 思绪两档均隐藏且为 0，只有戒断 -18 | 分别设计药效快感／不适、性奴适配后的感受和戒断压力，按最终总心情核算 |

### 性欲与性吸引力必须分清

当前 `SexFrequency` 调整自身性需求下降／欲望速度，不会直接让其他人更被这个身体吸引，也不会自动建立对供给者的专属渴望。

本机 RJW 的 `P_HumanToBeauty` 读取 `StatDefOf.PawnBeauty`，曲线为美貌 -2／-1／0／1／2 对应 0.5／0.8／1／1.1／1.25。区间内连续插值，达到美貌 2 后该项封顶；它还要与其他偏好组合。SSC 多种特化已有美貌增量，因此单纯继续增加美貌未必还有性吸引收益。

`PawnBeauty` 可以通过固定 XML offset 调整，但同时影响原版社交／恋爱，并非只影响 RJW 性吸引。原版相关社交判断还存在负／零／正的分段，不能承诺所有作用都线性变化。开发前需明确是否接受这一范围；如只需要性吸引，应再单独评估 RJW 偏好接口，不能把“加美貌”直接等同为完整实现。

本批先不新增供给者偏好、主人专属吸引或关系记忆；它们仍属于后续独立设计。

### 性奴需要真正的药效阶段

`SSC_Hediff_PnaRootedLoad` 当前只有无属性档，服药虽可积累性奴负荷，但缺少与含量对应的正面反馈。建议继续使用这份身体记录及既有清除机制，为它增加固定正面阶段；不增加第二份收益进度、插值、缓存或计时器。

需要确定收益重点及上限：增强性欲／性行为表现、身体舒适／恢复，还是兼有少量战斗强化。先评估与锁链、身体开发、特化及旧枪械 Buff 的叠加；避免把所有能力同时大幅提高。最高档仍遵守已确认的整体正面方向，不照搬普通对象末期晕倒和成瘾。

个人主动补给是另一项功能，尚未实现，也不应通过重新加成瘾／化学需求来驱动免成瘾性奴。

### 成瘾扩展优先放在戒断档

`PNA_Addiction` 使用原版 `Hediff_Addiction`：其普通／戒断阶段由化学需求类别决定，剩余严重度表示恢复中的成瘾程度。不能直接添加五个严重度阶段，就假定原版会按剩余 D 自动选择五档戒断。

建议先保留原版两档，在戒断档增加固定的工作／专注或适度能力影响，使戒断除了心情外也影响日常活动。常态成瘾是否另有负面需要单独决定；当前普通负荷已降低操控、移动、意识和视听，再让成瘾常态重复施加全部惩罚容易过度压制。

继续保留 -0.1／日原版恢复、普通／浓缩再次服药 +0.1／+0.2 及已确认的末期额外 +0.2。新负面属于效果层，不重新设计恢复门槛、计时器或替代需求。

### 心情需要完整对应阶段

当前 `PNA_Debuff_Thought` 仍是旧两档，而普通负荷已有五档。当前两档都隐藏且为 0，所以没有实际心情数值问题；一旦恢复有效思绪，原版取较小阶段索引会使后面四档都落入同一旧档，必须同时重建五档映射。

建议药效心情随当前负荷变化，性奴使用适配身体的独立曲线，戒断继续独立体现成瘾压力。具体正负方向和数值尚待确认；不要直接恢复旧 +5／+8 常驻愉悦，也不要只提高戒断负值而忽略其他正面心情的抵消。

“补给缓解戒断”已由需求脱离戒断和原版思绪自然完成，不必再增加一份固定“刚吃药”奖励来重复补偿。

### 特殊精神状态可以后置

高负荷下的失控性欲与成瘾戒断后的寻药是不同目标。建议先完成普通／性奴药效、戒断影响和心情，实机观察原版精神崩溃压力后，再决定是否需要专属状态。

若保留该方向，需先确定触发原因、适用对象、结束条件以及与 RJW 自主行为、调教任务和当前药物政策的关系。只需调用既有状态时，原版 HediffStage 已有精神状态／精神崩溃配置入口，不必先增加扫描或补丁。普通末期已压低意识并使身体倒地，依赖行动的行为状态可能无法执行；不能把倒地与强制寻性简单叠加。性奴无普通成瘾，也不能直接复用普通戒断状态。

目前“末期高潮晕倒”是健康能力效果与描述，不会自行生成连续的 RJW 高潮结算或动画。若将来需要真实反复高潮事件，应另行列项，而非视为现有实现。

### 分泌者性交补给是新的实际来源

明确来源是 `SSC_Purple_HyperLactation`，由相应身体开发授予。其严重度是产出进度，不是身体负荷；现有代码没有定义生产进度与可转移体液量之间的映射，不能直接以该严重度乘算摄入剂量。

该 Hediff 文案标注阴道，但当前是全身健康记录，没有可靠的 `Part`。若采用“与分泌者完成双人性交即少量输入”的简化规则，实现较小；若要求真实接触分泌部位，还要处理实际交互部位、手交／足交、避孕套以及原版 Lovin 缺少过程部位证据等边界。

`SSC_Hediff_RabbitCloneLowPNA` 是否也作为来源需明确；兔玩法正常入口仍未开放，不因此扩大本批开发范围。仅携带普通 PNA 负荷或成瘾，不应自动被当作分泌者，避免无意形成连锁传播。

最小接入建议：

1. 复用现有真实完成校验与成功认领，在同一次认领之后分发训导官经验及 PNA 来源处理。当前认领已被经验逻辑消费，不能另加调用抢占同一个凭据。
2. 在发放前确定双方分泌资格和接收方向；一方分泌则只向另一方输入，双方分泌可各方向一次。不把“发起者”当成固定供给者，也不把性别当作来源资格。
3. 使用共享 `ApplyExposure`，不要模拟吃药或直接操作成瘾／需求；普通身体走负荷和成瘾，有效链身体走性奴分支。主人侵染的主人对象豁免不自动扩展到这条身体来源。
4. 原版 Lovin 复用既有成功 Cleanup 的发起端完成记录，防止 RJW 转接、双端收尾与重复结算多次输入。不能仅看到 `ProcessSex` 被调用就认定真实完成。
5. 专用调教、绑定仪式等是否也允许身体体液传递须另定；主人侵染排除这些任务，并不自动意味着身体来源也必须排除。自我调教没有另一个对象，不构成传播。

剂量、每次满足度补充、是否消耗产出进度／营养、与主人侵染同场是否叠加，以及行为覆盖范围都尚待确认。建议先使用固定小剂量，不加入生产进度转移与营养核算的新系统。

`OrdinaryExposure` 当前预留需求 +0.12，普通侵染剂量常量 +0.08 属于主人侵染规划，不能直接当作此来源已确认参数。两种来源即使复用共享输入，也要明确同场处理，避免默默叠加两份 8%。

## 还需一并补齐的交叉问题

- **有效链枪械的负荷输入：** 当前枪械有链分支只治疗与发放旧战斗 Buff，然后返回，没有增加性奴负荷。未来添加性奴负荷正面阶段时，需明确是否同时接入枪械剂量；保留旧治疗／Buff 并不代表这条来源已接通新阶段。
- **最终叠加：** 普通负荷最高 ×4 与成瘾 ×1.25 会合成为 ×5，另有其他模组及身体状态修正；“最高 ×4”仅指负荷自身。性吸引、戒断能力和心情都应核算最终值，而非只看单份 XML。
- **低剂量与末期强化：** 按已确认规则，末期每次真实输入都可能给已有成瘾 +0.2，即使剂量很小或负荷已满。新增高频性交来源时，这一效果也会参与；应明确接受这种反馈还是另定来源政策，不能在接入时无声改变旧规则。
- **断供的可理解性：** 与分泌者性交也将成为补给，停药不再等于完全停止输入。来源 Hediff 说明和玩家指南需明确这一点，以免把持续暴露导致的效果理解为恢复失效。
- **主动补给与政策：** 普通成瘾对象沿用原版药物政策／需求，性奴主动维持尚待开发。新增收益后要检查浓缩液选择、过量摄入与旅队，不默认新增自动限制。
- **生命周期与回归：** 新效果仍按身体归属，复用已验证绑定／解绑、人格、空壳、克隆及旧档规则；新增心情与精神状态不能把来源关系或人格记忆偷偷并入身体记录。
- **空壳表现：** 空壳已有思想无效化、固定基础心情和阻止精神崩溃；其健康／需求继续更新，不代表新增 PNA 心情或特殊精神状态应绕过空壳原规则。

## 建议开发顺序及待确认项

先确定普通负荷／性奴负荷／正常成瘾／戒断四类效果的分工，再完成固定 XML 药效、心情与性吸引方案。随后接入分泌者性交来源，统一实际完成认领及来源规则。专属精神状态和性奴主动补给可后置，避免同时调整基础收益、供给频率和强制行为而难以判断平衡来源。

进入下一批实现前，需要确认：

1. 性吸引是否接受美貌影响社交／恋爱，作用于普通／性奴哪一类身体。
2. 性奴正面效果重点、阶段和强度，枪械是否增加性奴负荷以及旧战斗 Buff 是否并行。
3. 成瘾负面是否集中在戒断，新增哪些影响面，正常成瘾是否保持只有性欲变化。
4. 普通药效、性奴药效和戒断各自的心情方向及幅度。
5. 是否暂缓专属精神状态。
6. 性交传播的行为／任务范围、允许来源、每次负荷与满足度、生产进度是否消耗，以及与主人侵染的同场处理。

上述是待确认清单，不是已批准的新机制或数值。
