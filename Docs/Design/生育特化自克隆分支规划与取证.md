**当前定位：一种具有SSC特色的小人复制手段。** 性奴以自身为模板孕育复制体，复制体保留选定的个体资料与普通培养成果，并与本体保持部分联系。“姐妹”“独立新生人格”或“统一意识控制多个身体”均不作为已定机制前提。“人格划分”是最新提出、待整体讨论的解释与功能扩展。文件名中的“自克隆”和旧RabbitClone／Duplicate名称保留历史引用，不预定实现方式。

## 1. 当前已确定规则与明确目标

| 项目 | 当前确定内容 |
| --- | --- |
| 核心玩法 | 提供SSC式小人复制手段，保留已有培养投入；本体继续存在，获得额外可活动的小人，并有部分同步联系 |
| 出生复制范围 | 外貌、物种、基因、技能、特质等已讨论的主要个体资料可以复制；人格特化另按方案2，不将此概括自动扩成装备、伤病、全部模组私有数据或完整关系网络都复制 |
| 人格特化方案2 | 普通培养进度继承；来源已终极化的特化，在复制体上取得对应普通培养完成状态，不继承终极效果或其授予的专属能力 |
| 强弱定位 | 复制体保留本体大部分培养基础，初始缺少终极成果，体现一定程度弱于本体；不是已确定永久不能超过本体或永远不能终极化 |
| 既定身份／印记 | 出生即SSC性奴、淫欲之奴及永久性奴锁；不走普通出生初始印记分化，不受普通后代印记开关改写。人格印记继续随人格，不因初生年龄退态 |
| 社交关系结构 | 本体—复制体与复制体—复制体应有不同的特殊关系，不能继续统一为同一种对称“同源”关系 |
| 共鸣强度需求 | 维护者两次要求提高心情影响，最新要求高于此前±8建议；最终数值、门槛及算法尚未确定 |
| 空壳产出目标 | 希望玩家能自行产出空壳躯体，并有合理设定解释；不代表已确认某一回收流程、授予渠道或空壳属性模板 |
| 开发状态 | 先做宏观设计，旧代码只作事实参考；未授权开发，不自动继承旧兔的两只上限、三天成熟、休息平均、成熟补复制或低效PNA |

早先生育技能自指孕育、与对他人分支共享成功建孕后的7日冷却且无额外材料，保留为原孕育入口约束；新的回收／再占据是否拆出、如何付费须另定，不能由此静默改动已验收对他人技能。实际复制时点、妊娠后端及新生年龄在宏观重做后重新核对，不将旧接法当作已选实现。

## 2. 出生复制与普通培养继承

### 2.1 已采用的方案2

| 来源情况 | 复制体初始结果 |
| --- | --- |
| 普通培养尚未完成 | 继承对应普通培养进度 |
| 普通培养已经完成 | 保留对应普通培养完成状态 |
| 已终极化 | 取得对应普通培养完成的基础，不带终极效果及其授予的专属能力 |

例如，本体终极生育→复制体普通生育培养完成，不自带终极生育被动和专属技能。不能只移除终极Hediff而保留其技能；其他能力来源分别判定。原版技能、特质等的出生复制不因此一并削弱，尚未采用额外比例折损。

### 2.2 未确定的复制细节

当前培养方向与各方向历史如何组合保存、多个终极成果各自还原普通完成后如何供选择、需要哪些普通表现Hediff，留到规则细化；不从“普通进度继承”直接推导强制同时激活所有方向。

历史记忆、背景、恶堕历史、任职／主人资格、原版法律身份、身体改造及其开关等数据，仍需明确复制／重置清单；“主要个体资料可复制”不等于将原版Duplicate或旧SSC过滤结果整体认领为新规则。主人绑定与来源联系分开讨论。

**复制体以后能否自行终极化仍待定。** 本方案目前只约束生成时的继承；本体后续取得的新成果是否传递，由下面持续同步方案另议。

## 3. 持续同步候选方案，尚未整体确认

已确定的是存在部分联系，未确认具体同步名单和方向。下表记录助手最新建议，不是运行规则或已选开工方案。

| 内容 | 建议方向 | 建议边界 |
| --- | --- | --- |
| 原版技能成果 | 双向，本体与同组复制体互通 | 真实学习获得更高等级时，向较低等级成员分享成果；不降低已有更高等级，不复制同一份经验条或重复转发同步收益 |
| 技能热情 | 不持续同步 | 出生可复制，后天各自变化 |
| SSC普通培养进度 | 本体→复制体 | 按方向补足较低进度，不覆盖复制体自己更高的进度；本体终极化最多传普通完成基础 |
| 当前培养方向 | 不同步 | 各自选择，本体切向不强制其他成员切向 |
| 终极成果／专属能力 | 不持续传递 | 延续方案2的排除边界；是否另有独立取得渠道待定 |
| 心情 | 双向共鸣，最新建议区分本体与分体权重 | 使用有限心情影响，不直接平均、覆盖原心情；最终算法和数值另议 |
| 新记忆／好感／关系 | 不复制整个网络 | 各自形成经历；特殊关系及共鸣反馈独立定义 |
| 特质／基因／外貌 | 不持续同步 | 出生复制与后天改变分开 |
| 年龄／器官／伤病／伤害 | 不同步 | 身体分别维持，不设共同生命值或连带生死 |
| 饥饿／休息／性需求／PNA等 | 不同步 | 每个身体分别满足需要，不沿用旧兔休息平均 |
| 身份／印记／主人绑定 | 不纳入通用同步 | 按各自规则维护，不凭同步改绑或重新分化 |
| 装备／工作／时间表／个人开关 | 不同步 | 可分别安排，不广播本体设置 |

技能建议由“真实学习成果”触发，不周期性拿组内最高等级相互保级，以免自然遗忘被消除；具体是否共享等级内经验、遗忘怎样处理仍需确认。SSC普通进度建议不由分体反哺本体，避免自动汇总多个方向的培养；维护者尚未采用这一方向选择。

同步中断时保留已得技能／进度、停止临时共鸣，以及不因本体死亡强制杀分体，均为建议。距离／地图、离图休眠、世界Pawn更新、死亡复活及人格迁移后的联系归属尚未确定，不能沿旧身体引用自动定案。

| 参考状态 | 心情影响建议 |
| --- | ---: |
| 参考心情低于30% | −20 |
| 参考心情30%～70% | 0 |
| 参考心情高于70% | ＋20 |

早先参考“其他成员平均心情”；区分关系后，最新候选改为复制体主要受本体影响、本体受所有复制体整体状态影响。同源分体之间不再额外层层叠加。具体参考值、权重与边界取等仍待定；每人最多一项、不按数量叠加、精神异常仅经心情间接影响而不强制传播精神状态，也均是建议而非已确定规则。

## 4. 差异社交关系

**已确定需求：两类关系有区别。** 本体—复制体应区别于同源复制体之间；本体与复制体双方显示不同称谓、数值不对称是助手建议，尚未确认。

| 关系方向 | 暂用名称建议 | 好感建议 | 说明 |
| --- | --- | ---: | --- |
| 本体→复制体 | 人格分体 | ＋60 | 本体划分出去、与自己相连的意识 |
| 复制体→本体 | 人格本源 | ＋80 | 意识来源与联系中心 |
| 复制体→同组其他复制体 | 同源分体 | ＋40 | 来自同一本源的其他分化意识 |

名称、好感和不对称程度均为占位方案，不作为已定正式文案。此前统一对称“同源”关系不再作为当前方案；“姐妹”也不固定为血缘或机制要求。

建议特殊关系提供可见身份与好感，共鸣单独提供心情；二者与血缘、恋爱和SSC主人绑定分别维护。是否继承本体同一主人、是否建立生育亲子关系、切断后称谓和好感是否保留，仍须讨论，不能由“人格本源”推导本体取得SSC主人身份。

## 5. 人格划分、回收空壳化与再占据构想

本节是维护者新提出、纳入讨论的设定／功能方向，**尚未整体确认**。玩家自行生产空壳的目标明确，但其是否由生育特化提供正是待讨论问题。

| 构想 | 来源与当前状态 |
| --- | --- |
| 复制体意识来自本体的人格划分 | 维护者提出的设定方向；尚未决定划分是否永久依赖本体、联系是否随本体人格迁移 |
| 付出代价切断联系，使复制体成为空壳 | 维护者提出；“撤回分化人格”是助手对此的解释建议，代价、操作条件与空壳结果未定 |
| 付出代价让自己的划分人格占据空壳 | 维护者提出；可占据哪些空壳、是否恢复原分体或创建新分体、资格／代价未定 |

助手建议将“身体生成”和“意识分配”拆开解释：躯体由生育特化孕育，本体分化人格使之成为活跃复制体，未分配或已撤回时成为空壳。这是解释候选，不改变当前普通出生流程或已验收印记规则。

### 5.1 建议状态流转

| 操作 | 建议结果与未确定边界 |
| --- | --- |
| 孕育躯体并分配人格 | 得到活跃复制体，出生复制遵守方案2，建立相应联系 |
| 本体撤回分化人格 | 得到空壳、释放活跃意识名额；建议不额外产出人格凝胶，也不将分体全部后天成果再次合并给本体 |
| 向空壳再次分配人格 | 建议依据本体当时状态重新分化并遵守方案2；这不是已决定恢复原分体记忆／经验的存档机制 |

已通过届时选定的同步规则取得的成果可保留，是助手建议；回收究竟撤销原分体、保存原分体还是把它吸收回本体，需明确后才能定最终数据规则。旧分身禁止人格排泄不直接决定这种新回收操作是否可用。

人格印记／身份／培养等人格内容在空壳化时离体、身体及身体改造保留，为沿既有归属提出的衔接建议；具体如何回收、是否留作可恢复记录、绑定怎样处理尚未确定。不能直接把“回收”解释成调用现有人格排泄并执行其全部关系清理。

### 5.2 自行产出空壳的候选闭环

候选路径为**孕育复制体→撤回分化人格→获得空壳**。后续还可讨论“出生时不分配人格，直接产下空壳”的产出模式，目前没有确认增加新模式或胎儿调控项。

建议所得空壳也可用于普通人格凝胶植入；被其他人格占据后，原本体不再凭旧来源关系强制回收／再占据。只管理自有分体及其空壳是首版范围建议，所有空壳、其他来源空壳或已有人格身体的准入都未确定。

现有空壳按[未来规划第49项](未来内容开发规划.md#49-人格排泄后空壳身体的基础人格表现调整待分析待设计)讨论PNA基础人格、自理／技能／情绪等表现。本分支负责候选的**空壳来源与人格分配**，第49项负责**空壳处于该状态时的表现**；是否共用全部状态和行为需后续核对，不将两者自动合并开发，也不把空壳写成没有任何基础行为的躯体。

## 6. 功能授予、联系归属及代价建议

维护者尚未确定人格管理是否归生育特化。当前保留两种归属候选：

| 候选 | 说明 |
| --- | --- |
| 生育特化一并提供 | 孕育、人格划分、回收和再占据构成一条终极能力链；资格失效时已有分体怎样管理仍要决定 |
| 身体生产与人格管理分开授予 | 生育特化提供孕育／出生形成复制体；SSC人格进阶能力提供回收与再占据。此为助手当前推荐，不是已采用架构 |

后一候选可用独立研究或人格加工成果解锁；具体前置、成本和是否新增能力均未定。不要求另立一个新特化，也不确认现有生育终极化已隐含授予所有人格操作。

建议人格管理与当前子宫、培养方向分开，避免失去孕育资格时同时失去对已有分体的管理；联系属于身体、来源人格还是独立本体标识，及人格凝胶流转后如何续接仍未决定，不能照搬旧RabbitClone的source Pawn。

代价候选包括：活跃分化人格承载上限、回收的暂时精神负荷／恢复期、再分配的资源消耗与恢复期；空壳不占活跃名额、身体产量由孕育时间和过程限制，均为助手建议。数量、持续负荷、材料、冷却、回收收益和退款规则未定，不自动沿用两只／三天／低效PNA或把新成本加到已验收对他人技能。

### 9.4 身份、印记及成熟衔接

新分身最终必须清来源印记→完成Slave身份→授予淫欲之奴，复用已有[印记服务](../../Sexslavecraft/common/SSCImprintUtility.cs)；永久锁直接从Hediff读取。旧流程只复制来源身份并把主人改成未选择，不能代替这项初始化。

旧ShouldKeepSscHediff宽泛保留SSC前缀，初生和成熟均会带入来源印记。成熟补复制必须排除全部来源印记，保护分身自己的方向；还需明确排除绑定、个人设置和冷却等独立数据，不靠Hediff互斥兜底。身体快速成长和成熟赋龄建议在写入前限至25岁，不先超龄再等日检查。

普通胎儿性别／物种设置建议不应用于克隆，沿旧Duplicate复制本体性别、物种与基因；固定性奴印记已确定，其余设置处理仍属建议。已有特化成果、技能、记忆和SSC健康状态以旧机制为调查基线，不能把“成熟补健康状态”误记为再次完整人格覆盖。

绑定与分身来源关系分别处理。前轮建议本体有有效主人时仅为新分身建立同一主人双向绑定，无主则保持无主性奴，不带入仪式奖励；成熟不再改绑。此方案尚未确认，不能原样依赖复制出的空链，也不能解绑／重绑本体或改动人格切换绑定规则。

### 9.6 建议开发顺序与最小验收

建议先核对／整理旧创建服务，再实现新生身份与印记、来源保存及成熟过滤，然后接自指建孕／出生替换和共享冷却，最后补显示与联测。限制／浪漫新生默认、PNA身体排除和原能力默认必须沿用现行契约，不为克隆重做这些系统。

最小验收候选如下，待实现范围确认后采用现有宿主覆盖真实边界，不穷举全部旧参数：

- 自指成功建立原有妊娠并启动共享冷却；建孕失败不扣冷却，孕期／临产仍禁用。
- 普通妊娠及对他人技能不被替换；分娩没有额外普通婴儿、重复分身或残留预生成幼体。
- 新生唯一性奴态印记与身份锁，主人资格／成长清理；本体印记和绑定保持。
- 成熟与存读档不改变分身身份、个体设置和后来绑定，不重复成熟或复制来源冷却。
- 数量、禁止再分身、三天成长／25岁衔接、共享和低效PNA按已确认规则运行。
- 来源死亡、离图、失效与创建失败按届时确定的有限规则处理，不扩成通用生命周期框架。
- 分身仍禁止人格排泄；实际克隆放置如需接出生培养，仅成功后旁路Observe一次，不按进入GiveBirth就发放。终极施法者本身不继续获得普通培养进度。
