# 第 6 项无主性奴设计方案

**2026-11-19 讨论稿，目标为 1.7，待开发。** 无主性奴和有主性奴共用四阶性奴化进度。奴性爆发提供首次成形与继续升阶的机会，绑定仪式按原进度建立主从关系。 [第 6 项总体规划](未来内容开发规划.md#6-拆分主奴绑定与性奴化调教支持无主性奴) · [第 7 项现行规则](Archive/第7项奴性爆发开发方案.md#ssc-slave-breakdown-current-rules)

## 奴性爆发与阶段成长

开场信按发作前的状态选择。已有无主状态与已有主状态共用性奴开场信，首次成形走普通开场。发作期间临时赋予的身份不改变入场分支。

| 入场状态 | 调教请求对象 | 完成获批调教后的结果 |
| --- | --- | --- |
| 非性奴，或已有 SSC 性奴身份但尚未形成阶段 | 附近符合资格的调教员 | 成为一阶无主性奴。完成获批任务就是成形条件，取消原预留回调的结算后满恶堕条件。 |
| 一至三阶无主性奴 | 附近符合资格的调教员 | 结算普通调教收益，再按共用规则推进无主进度。 |
| 一至三阶有主性奴 | 锁链记录的实际主人 | 沿用现行的有主调教和锁链进度结算。 |

- **触发。** 现有高恶堕随机区间为实际 95% 至不足 100%。讨论稿推荐所有符合准入的分支在实际 100% 时必定触发。已处于满值的角色也参加判定，冷却到期后在首次满足准入的检查触发。沿用现有的玩家殖民者和原版殖民地奴隶准入、印记优先结算、发作结束后一天冷却和同场去重。SSC 主人与两类四阶性奴均排除在发作候选外。警报与启动使用同一规则。启用奴性爆发的设置改为缺省开启，已有明确保存的选择继续生效。 [现行触发与警报](../../Sexslavecraft/common/SSCSlaveBreakdown.cs) · [设置](../../Sexslavecraft/common/Settings.cs)
- **升阶。** 两类共用现行的 `10% / 30% / 50% / 90%` 阶段起点及推进算法。首次成形建议沿用一阶 `20%` 的起始进度。后续一场最多升一阶，推进受本场额度、实际恶堕和下一阶起点共同限制。例如满恶堕时，从三阶 `50%` 先到 `80%`，再经下一场到四阶 `90%`。普通收益先结算，阶段变化和成功结果各认领一次。玩家批准只授权当前任务，拒绝、中断或过期都不会新增身份或阶段。 [现行进度算法](../../Sexslavecraft/common/CorruptionProgressionUtility.cs) · [发作调教结算](../../Sexslavecraft/common/MentalState_SSCSlaveBreakdown.Training.cs)
- **结果信。** 共用现有有主成功信的主文。共用进度句将「锁链阶段／严重度」改称「性奴化阶段／进度」，按实际结果显示首次成形、跨阶、同阶进度或进度保持。本场若另有原版转奴结果，也写入同一封 SSC 结果信。 [现行简中结果信](../../1.7/Languages/ChineseSimplified/Keyed/SSC_BreakdownTraining.xml)

### 首次成形与原版转奴

**候选方案。** 首次请求信可给符合资格的自由殖民者提供「接受调教」和「接受调教并尝试转为原版奴隶」。实际完成后先确认一阶无主状态，再按玩家选择尝试一次原版转奴。若选普通调教或转奴失败，仍结算一阶。已是原版奴隶的角色直接进入普通成形。可复用现有评分、意志和恶堕的计算，采用非仪式参数。入口与是否启用这项选择仍待定。 [现有仪式转奴](../../Sexslavecraft/common/CorruptionProgressionUtility.cs) · [现有转奴概率](../../Sexslavecraft/common/WillReductionUtility.cs)

## 功能共用与归属

| 功能 | 无主与有主的设计 |
| --- | --- |
| 恶堕、特性与落差心情 | 共用规则。阶段提供恶堕下限，性奴特性按历史恶堕峰值，落差心情按实际恶堕与性奴化阶段计算。两类各自的持续状态心情独立派发。 |
| 调教、特化和身体功能 | 复用调教评分、部位经验、特化与身体开发。只要求阶段的功能读共用阶段，例如巴士二阶和生育特化三阶。泌乳、生产、生育与外观沿各自载体及资格。需要实际主人的特化互动或持续资格继续核对绑定。 |
| 日常调教 | 建议复用日常收益，首版将性奴化进度交给爆发调教。正式无主角色的日常流程须排除现有自动建链，首次绑定走绑定仪式。零阶角色的旧准备路径待细化。 [现行日常结算](../../Sexslavecraft/common/ConditioningUtility.cs) |
| 反叛保护与 PNA 成瘾免疫 | 两类从一阶起共享。现有反叛补丁同时涉及越狱、狂暴和压制条更新，接入时逐项核对现有资格。在实际保护入口扩充判断，保留通用锁链查询的原义。 [现行反叛相关补丁](../../Sexslavecraft/ThePatches/Harmony_HediffPreventRebel.cs) |
| 行为限制 | 无主的实际规则随阶段自动变化，调教管理显示当前规则和来源。个人编辑、恢复默认和旧菜单提交均按只读处理。RJW、浪漫行为、发作行为与调教派发读取实际规则。各阶条目及其与装备、特化和全局开关的优先级待定。获批调教需有可执行的许可，`仅限主人` 条目须有明确的无主取值。 [现行行为规则解析](../../Sexslavecraft/common/Restrictions/SSCRestrictionResolver.cs) |
| 敏感度 | 无主各阶自动应用 RJW `Vulnerability` 乘数，并显示当前值。无主 Hediff 的敏感度效果仅使用这一乘数。有主使用既有手动敏感度规则。 [现行敏感度接入规范](../Development/Reference/高潮推进与敏感度接入规范.md) |
| 主人专属功能 | 实际主从称谓、仪式关系奖励、主人点名命令、缰绳分伤和锁链的 PNA 阶段维持均取实际绑定。无主可以有调教员指派和调教好感。 |

## 阶段属性与平衡

无主能力值使用百分点偏移。维护者给出的最重能力减益、最高市值和最低持续心情按四阶落点记录。前三阶的能力、市值与心情，以及全部 RJW 乘数，均为首测候选。

| 无主效果 | 一阶 | 二阶 | 三阶 | 四阶 |
| --- | ---: | ---: | ---: | ---: |
| 意识偏移 | −5 | −10 | −20 | **−30** |
| 交谈偏移 | −5 | −10 | −20 | **−30** |
| 操作偏移 | 0 | −5 | −10 | **−20** |
| `MarketValue` 乘数 | ×1.25 | ×1.50 | ×1.75 | **×2.00** |
| 无主状态持续心情 | −3 | −7 | −11 | **−15** |
| RJW `Vulnerability` 乘数候选 | ×1.50 | ×2.00 | ×3.00 | ×4.50 |

| 有主对照 | 一阶 | 二阶 | 三阶 | 四阶 |
| --- | ---: | ---: | ---: | ---: |
| 意识偏移 | −30 | −20 | +10 | +30 |
| 交谈偏移 | −30 | −20 | +10 | +30 |
| 操作偏移 | −30 | −10 | 0 | +20 |
| `MarketValue` 乘数 | ×0.90 | ×0.80 | ×0.70 | ×0.50 |
| 锁链持续心情 | −10 | −5 | +3 | +12 |

| 基准为 100% 时的有主脆弱度对照值 | 130% | 175% | 250% | 400% |

- **脆弱度。** 有主对照值按 100% 基准比较手动敏感度的加算贡献。无主候选在此基准下各阶高约 13%～20%。实际差距取决于小人属性，尤其要复核意识和操作减益与爆发临时效果的叠加。本机 1.7.5013 rev802 的 RJW `get_vulnerability` 使用 `applyPostProcess: false`，部分判定可能超出属性面板的 300% 上限。实机比较三、四阶时应观察实际判定值。 [有主锁链定义](../../1.7/Defs/HediffDefs/HediffOfSexSlave.xml) · [手动敏感度定义](../../1.7/Defs/HediffDefs/SSC_OrgasmSensitivity.xml) · [程序集取证版本](../../1.7/BUILD-INFO.json)
- **心情与市值。** 实际恶堕为 100% 时，上表无主状态心情与现有落差心情合计依次为 −13、−13、−14、−15。`MarketValue` 进入原版财富结算与交易定价。四阶绑定前后的市值系数分别为 ×2.00 与 ×0.50，能力也随载体切换。建议在仪式预览中说明这些变化。 [恶堕落差心情](../../Sexslavecraft/common/SSCCorruptionStages.cs)

## 绑定与存档边界

- **进度来源。** 建议无主用独立 Hediff 严重度保存进度，有主用现有锁链严重度。统一阶段查询供窗口、恶堕下限、各阶段资格和反馈消费。手选身份及满值印记分化仍可形成零阶 SSC 性奴身份，正式完成入口后才建立无主阶段。旧档从已有身份、印记和实际进度读取各自状态。 [现行阶段查询](../../Sexslavecraft/common/SSCIdentityUtility.cs) · [印记分化](../../Sexslavecraft/common/SSCFullCorruptionImprint.cs)
- **无主转有主。** 复用绑定仪式，以原严重度建立锁链与缰绳，在同一次结算停用无主阶段效果。三阶 `80%` 绑定后仍为三阶 `80%`。现行首次建链默认写入 `20%`，此分支须传入原进度且跳过本场升阶。建议仪式的其他收益和独立的原版转奴设置沿用现行结算。已有主角色再办仪式继续用现行升阶规则。 [现行建链](../../Sexslavecraft/Hediff/Hediff_ChainOfSexSlave.cs) · [仪式进度和转奴](../../Sexslavecraft/common/CorruptionProgressionUtility.cs)
- **有主转无主。** 具体玩法入口归第 6.1 项。候选契约是在正式解绑时携带原进度、撤销旧主授权与在途命令。主人离图、死亡、外部删链和人格植入清理各自按生命周期判断。人格凝胶建议按现有锁链进度的迁移方式携带无主进度，克隆继承另定。 [第 6.1 项](未来内容开发规划.md#ssc-slave-release) · [人格植入结算](../../Sexslavecraft/common/ExcretionUtility.cs)

## 开发前待定与验收

- 确认无主各阶行为条目、自动规则的覆盖顺序、原版转奴选择及第 6.1 项的范围。后续仅调教仪式可用于两类角色，并保留原绑定状态和归属。仪式是否推进性奴化及具体结算待细化。
- 核对首次完成直接成形、拒绝与中断、持续满值跨冷却再次发作、与印记分化同场，以及四阶退出候选。
- 核对同阶进展和跨阶反馈、三阶 `80%` 等进度绑定、旧档零阶、读档及人格或绑定变化后旧请求失效。
- 实机观察阶段属性、自动规则与共享保护。重点比较三、四阶 RJW 实际判定、持续心情叠加、经济变化及绑定前后效果。 [测试编写与执行准则](../Development/Reference/测试编写与执行准则.md)
