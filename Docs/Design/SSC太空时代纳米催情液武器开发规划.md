## 1. 技术定位与范围

更先进的技术使纳米催情机械自身的机械特性能够得到进一步控制和利用。武器以外部约束控制 PNA 集群，使其暂时形成分子乃至纳米级的固态极细针或线；结构穿过防护并进入肉体后解除约束，纳米机械依其自身特性迅速分散并进入目标体内循环。

穿透能力来自受控形态，控制创伤则依靠极细结构、取消额外载体以及入体后的快速解体，不通过扩大伤道或保留针体实现投送。以上作为本 Mod 的科幻设定，不建立微观物理模拟。

| 阶段 | 核心手段 | 与本阶段的区别 |
| --- | --- | --- |
| 中世纪 | 对短矛、吹箭和轻弩运用淬毒工艺 | 使用传统武器，须留下合格开放伤口才能送药 |
| 工业时代 | 专用多股鞭束、气动载药射针与标准化投送机构 | 专业 PNA 武器已成为可能，但仍有实体载体和物理创伤 |
| 太空时代 | 直接约束 PNA 自身为针或线 | 高穿透、极低创伤；对适应 PNA 的身体可无伤吸收并有限修复 |

本批仍为近战、中近距离连续投送、远距离精确投送三种分工。首版不追加穿墙、多目标贯穿、自动追踪、持续缠绕、跨格近战或能量护盾穿透能力。射程可由集群脱离有效约束后失稳解释。

仅针对 1.7 开发；1.6／Common 继续冻结。前两代已验收武器不改变物理入口或补加无伤／修复效果。旧简易 PNA 发射器为废案，保留既有实现，不作为本批研究前置、平衡参照或默认实现模板。

## 2. 已确认名称与载体设定

| 已确认中文名 | 载体与定位 |
| --- | --- |
| **纳米催情液丝鞭** | 握柄控制 PNA 形成短距离纤丝，近身可靠投送并保留镇压用途 |
| **纳米催情液速射枪** | 紧凑枪形集群投送器，以三发短点射在中近距离积累药效 |
| **纳米催情液精确步枪** | 长枪形精密约束设备，单发、远距离、高穿透投送 |

名称统一使用“纳米催情液＋武器形态／用途”；不继续使用此前工作名称“纳米纤线鞭”“纳米针束投射器”“纳米穿刺投射器”。形态控制、集群成形与入体解体写入简明描述，不堆入物品名。

### 2.1 纳米催情液丝鞭

握柄控制工作端形成短距离紫色细丝或细束。参与穿透的微观纤线不必逐根可见；接触时进行短暂穿刺并释放 PNA，随后解除相应形态，避免持续勒割。

首版为普通相邻格近战，保留可靠命中与镇压装备属性。暂不设计跨格鞭击、缠绕任务或连续柔性物理。工作端的具体外观、姿态图数量与攻击特效后续另行分析，不直接承诺复制工业短鞭的全部美术和动画。

### 2.2 纳米催情液速射枪

保留紧凑枪械轮廓，功能结构从供气／供针转为 PNA 储存、集群成形和投送。每发代表一个完整的纳米机械集群，内部极细针的数量不转换为额外攻击或剂量。

维持三发短点射，强化短中距离，远距离精度明显下降。通过多个独立命中积累药效，不模拟持续射击输入、逐根针体或微观碰撞。

### 2.3 纳米催情液精确步枪

长枪形设备通过精密约束结构维持集群在较远距离上的稳定形态。单次投送剂量和穿透高于速射枪，保留明显的瞄准与再次射击间隔；接触距离精度较差，不能覆盖速射枪的全部用途。

不发射附带实体外壳的传统载药针，不在目标体内留下需要拔除的针体。

### 3.2 理论节奏与平衡观察

仅按基础准备＋首末发间隔＋冷却估算周期；近战只以配置冷却作比较，不作为真实完整近战动画周期的保证。忽略射手修正、命中失败、防护、飞行时间、意识抗性、负荷上限与清除：

| 定位 | 工业理论基线投送量 | 太空理论基线投送量 |
| --- | --- | --- |
| 近战 | 18 ÷ 1.4 ≈ **12.9 点／秒** | 20 ÷ 1.2 ≈ **16.7 点／秒** |
| 中近距离速射 | 24 ÷ (0.5＋0.2＋1.3) = **12.0 点／秒** | 30 ÷ (0.4＋10/60＋1.0) ≈ **19.1 点／秒** |
| 远距离单发 | 20 ÷ (1.5＋2.5) = **5.0 点／秒** | 25 ÷ (1.3＋2.1) ≈ **7.4 点／秒** |

速射型保留最高连续投送能力，精确型以投送速度换取射程、精度和穿甲。提高穿甲后对有甲目标的实效可能远高于单看本表的增幅；正式平衡应观察防护档位、距离分工、连续命中、低意识投送与多射手修复，不把本表视为实战结果。

## 4. 穿透、身份保护与 PNA 结算

### 4.1 独立投送入口

本代不继续使用“留下合格开放伤口才施药”的前置。一次有效穿透与一次极小创伤应当分开表达：穿透已经成立，即使低伤害取整或其他原因未留下可见伤口，仍可接受 PNA。

建议三种载体共用一个新的太空 PNA 处理器，以各自伤害扩展配置基础剂量和修复预算；类名、字段和 DefName 在代码分析时确定。复用现有公共工具，不因名称兼容而直接继承涂覆伤口准入，也不整套恢复旧发射器的固定伤害或按部位治疗行为。

### 4.2 一次命中的逻辑顺序

1. 先遵守实际攻击的命中、实体碰撞、掩体与适用护盾拦截；未到达目标，不构成施药或修复。
2. 对实际命中的存活肉体目标核对 SSC 主人和有效锁链保护，在任何创伤写入前锁定本次保护状态。主人免疫优先于锁链吸收分流。
3. 对其他可投送目标，核对受击部位和防护；仅命中非有机人工部位不投药。完全阻断、偏转或仅转为钝性接触时不投药、不修复；实际护甲 API、传播、取整及边界须在步骤一查证，不把 XML 穿甲当作保证成功。
4. 穿透成功后，普通目标走极小创伤与普通 PNA 输入；有效锁链性奴不写入创伤，输入活化负荷并尝试一次修复。受保护目标仍需实际有效入体才能获得活化／修复，不能通过护甲或护盾无条件补给。
5. 一次攻击或一个投射集群只认领一份药效／修复。传播到多个部位不重复结算，速射三发为三个独立命中，不按内部纳米针数量拆分。
6. 共享暴露或治疗触发同步健康回调后，重新核对身体、主人及有效链。失去有效链时停止后续修复；已受保护的本次攻击不因中途解绑补上一份普通伤害。

| 实际目标状态 | 纳米主攻击处理 |
| --- | --- |
| 普通有效肉体目标 | 穿透后极小创伤＋普通 PNA 输入 |
| 任一实际有效锁链的性奴 | 无创伤；穿透入体后活化＋有限修复，不限定由自己主人攻击 |
| SSC 主人 | 无创伤、无负荷，不额外治疗 |
| 仅为原版奴隶、无有效锁链 | 按普通目标处理 |
| 机械体、建筑、尸体或无效健康载体 | 不施药、不修复，首版不提供有效破坏能力 |

有效链复用 [SSCPnaExposureUtility.IsRooted](../../Sexslavecraft/common/SSCPnaExposureUtility.cs) 的实际引用规则，不以身份标签、恶堕阶段或无效残链替代。主人免疫仍由现有身份入口判断，不新增阵营识别或“自己人”过滤条件。

### 4.3 意识抗性、快照与负荷

继续复用 [共用剂量与快照工具](../../Sexslavecraft/common/SSCPnaWeaponDoseUtility.cs) 和 [统一暴露入口](../../Sexslavecraft/common/SSCPnaExposureUtility.cs)：

> 单次请求剂量 = min(基础负荷 ÷ 抗性除数, 0.50)。正常意识 100%、无快照时，分别为 0.20／0.10／0.25。

- 抗性取命中前意识，最低 20%；意识超过 200% 时建立记录，后续优先使用已有记录。药量准备与快照提交时点由新入口按有效投送安排，挡甲或拒绝输入不留下未使用新快照。
- 速射逐发取样，前发输入可能改变后发意识；三发全中基线合计 30 点，不保证实际固定增加 30 点。
- 主人不建立新抗性快照或负荷；有效锁链目标进入现有性奴活化载体，不发旧 Buff。
- 单次上限、身体负荷封顶、普通成瘾及需求补充继续交由既有工具；不为太空武器额外绕过意识抗性。
- `Accepted` 与 `AddedLoad` 分开使用：满负荷下真实正投送仍可被接受，不能因最终增量为零就否决修复。

## 5. 已确认修复强度与规则

### 5.1 直接按有效命中即时修复

首轮修复预算按各武器 `baseLoad × 5` 配置：丝鞭 1、速射枪每发 0.5、精确步枪 1.25。这里是伤势严重度，不是全身最大生命值百分比。

**明确取消此前建议的受击者共享修复额度、额度恢复计时和累计限速。** 首版不实现修复池、冷却、限流、延迟治疗队列或跨射手修复状态。每个有效命中独立即时结算，多次命中与多名射手的修复量可以直接叠加；每次命中只结算一次的事件认领不属于限速，仍必须保留。

修复量取配置基线，不取意识抗性放大后的请求剂量，也不取负荷钳制后的实际增量。可通过基线推导或在扩展中记录单次预算，但不能产生两份互相矛盾的有效数值。

### 5.2 可修复对象与选择

1. 只有本次成功投送、仍为存活有效肉体且具有实际有效锁链、并非 SSC 主人的目标可以修复。
2. 从现存、可自然愈合的非永久伤势中选择严重度最高的一处；不存在合格伤势则结束，不创建伤势或未来治疗量。
3. 本次实际修复不超过该伤势剩余严重度；治好后的剩余预算直接舍弃，不跨伤口分配。
4. 不修复人工部件，不恢复缺失部位，不直接治疗疾病或消除永久伤疤。
5. 不额外包扎、提供独立止血状态、免疫增益或持续再生；伤势减轻带来的改善由原有机制产生。

### 5.3 满负荷、失败命中与身份变化

| 情况 | 修复结算 |
| --- | --- |
| 满负荷且本次真实投送被接受 | 仍按完整单次预算尝试修复 |
| 低意识使药效输入放大 | 修复预算不变 |
| 一发集群含多个纳米针／命中传播到多个部位 | 合计只修复一次 |
| 三发点射全部有效命中 | 每发独立修复，最多合计 1.5 点，受实际伤势数量／严重度限制 |
| 多名射手同时命中 | 每个独立有效命中分别修复，不合并吞事件、不额外限速 |
| 未命中、被拦截、未有效穿透、仅接触人工部位或暴露被拒绝 | 不修复 |
| 无合格伤势 | 不储存或补发本次预算 |
| 结算期间解绑、换身体或转为主人 | 中止尚未发生的修复，不反向追加本次创伤 |

取消限速后的理想连续修复量，单个使用者约为丝鞭 0.83、速射枪 0.96、精确步枪 0.37 点／秒；仅按第 3.2 节基础周期与全部命中估算，不计防护、攻击选择、治疗溢出和人物修正。多射手可进一步增加，实际强度待实机观察，不将后续平衡疑虑预先改造成额外系统。

## 8. 开发步骤

本批涉及新的物理／投送分流，不能只拆成 XML 和贴图。建议按以下三步推进，每步单独记录实现、验证和维护者反馈，不因本规划获认可就开始执行。

### 步骤一：通用投送、无伤保护与即时修复的 C# 适配

范围：新建三种载体共用的太空投送处理器／配置扩展；复用剂量、快照和暴露工具；加入穿透成功与可见伤口解耦、创伤前保护、一次认领及第 5 节即时修复；扩展效力解析，并为丝鞭接入品质伤害标记。

实现前核对当时实际 1.7 构建与目标 DLL，查证护甲、部位、伤害取整、投射物命中及近战动作选择的真实流程。尤其是基础伤害 1 不能导致选拳击代替工作端；先核对原版动作选择与权重，不能用提高伤害掩盖选择问题。不得通过全局改甲或另造第二次伤害事件来保证施药。

必要测试覆盖：

- 普通身体穿透／阻挡／转钝／无可见伤口／有机与人工部位；确认护甲只按选定路线结算，不重复扣减。
- 主人、有链、无效链、原版奴隶无链，以及同步回调中绑定／解绑／身体切换；保护不依赖伤后治疗抵消。
- 正常、低／高意识与已有快照；有效投送才提交快照，满负荷输入仍可修复。
- 同次多部位只一次投送／修复，独立连发、同 tick 和多射手不吞事件。
- 修复固定值、最大伤口选择、溢出丢弃、无伤、永久伤、人工部件与缺失部位排除；无修复池、冷却或限速状态。
- 新效力读取、近战品质例外和普通武器不误显示；前两代与废案既有行为回归。

完成适当专项／回归测试和对应 1.7 编译；本阶段可用测试夹具／隔离临时定义验证，尚无正式 XML 时不宣称游戏完整可用。不在此步骤生成正式贴图。

### 步骤二：XML、研究、配方、四语文案与占位接入

先细化第 7 节研究与制作参数，区分建议值和已确认值。再新增三武器、两个投射集群、三伤害定义、丝鞭能力／动作、研究与自动配方，按实际入口接入扩展；需要独立声音定义时再核定素材与对象，不预先承诺其数量。

配置本表伤害／穿甲／节奏／精度／剂量／修复；丝鞭品质标记、文化条件属性；适配效力显示与既有尾迹／受药反馈；两枪普通防身工具按该阶段确认方案配置。维护简中、繁中、英文、俄文及仓库要求的源码镜像，不把解释性实现细节堆入玩家物品描述。

先使用可辨认的占位资源，完成 XML 格式、引用、继承、自动配方、镜像、布局和原生字段检查。若该步新增 C#，补做对应测试与编译。获后续接入／同步授权后备份同步本机 1.7，检查冻结内容不变，进入游戏验证制造、信息卡、各档目标投送与修复；尚未绘制正式美术时不把该项标为完成。

### 步骤三：正式美术、声音、反馈与最终验收

逐件分析、生成并预览正式图；按确认结果导出透明运行 PNG，资源尺寸、有效占幅和 drawSize 分开核定。丝鞭纤丝、两枪集群成形结构及无实体针体的投射表现应能与工业武器区分；借鉴[武器绘制与导入经验](../Art/RimWorld武器贴图绘制与导入经验.md)，避免细节缩小后不可读。

优先复用现有尾迹／受药反馈；额外丝鞭动画、发光或治疗特效需先确定方案，不自动增加持续动画或地图灯光。声音另查原版素材，区分集群投送与工业气动射针，不直接沿用枪口火光来表达。

分批接入、检查资源／引用、备份同步并实机比较，覆盖物品与手持、各方向、连发／单发、遮挡、护甲、主人／有效链保护及满负荷修复。机制改动须补回归与编译；纯资源替换不重复编译。最终记录已完成范围、平衡反馈与尚未测量的边界，更新资源表／玩法文档／完成核对；提交、打包和发布分别以届时明确授权为准。
