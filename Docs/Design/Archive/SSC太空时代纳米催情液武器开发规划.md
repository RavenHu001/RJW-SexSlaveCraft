## 1. 技术定位与范围

更先进的技术使纳米催情机械自身的机械特性能够得到进一步控制和利用。武器以外部约束控制 PNA 集群，使其暂时形成分子乃至纳米级的固态极细针或线；结构穿过防护并进入肉体后解除约束，纳米机械依其自身特性迅速分散并进入目标体内循环。

穿透能力来自受控形态，控制创伤则依靠极细结构、取消额外载体以及入体后的快速解体，不通过扩大伤道或保留针体实现投送。对具有实际有效锁链的身体，接触目标装备的集群可识别其 PNA 适应性，解除攻击形态并沿装备缝隙迁移、被身体吸收；游戏中简化为命中后的即时吸收，不受普通护甲厚度阻挡，不额外模拟迁移过程或增加动画。以上作为本 Mod 的科幻设定，不建立微观物理模拟。

| 阶段 | 核心手段 | 与本阶段的区别 |
| --- | --- | --- |
| 中世纪 | 对短矛、吹箭和轻弩运用淬毒工艺 | 使用传统武器，须留下合格开放伤口才能送药 |
| 工业时代 | 专用多股鞭束、气动载药射针与标准化投送机构 | 专业 PNA 武器已成为可能，但仍有实体载体和物理创伤 |
| 太空时代 | 直接约束 PNA 自身为针或线 | 高穿透、极低创伤；对适应 PNA 的身体可无伤吸收并有限修复 |

本批仍为近战、中近距离连续投送、远距离精确投送三种分工。首版不追加穿墙、多目标贯穿、自动追踪、持续缠绕、跨格近战或能量护盾穿透能力。射程可由集群脱离有效约束后失稳解释。

仅针对 1.7 开发；1.6／Common 继续冻结。前两代已验收武器不改变物理入口或补加无伤／修复效果。旧简易 PNA 发射器已从 1.7 移除并归档，不作为本批研究前置、平衡参照或实现模板；不提供旧发射器存档迁移，见[移除记录](../../Development/Completed/SSC旧简易PNA发射器移除与归档.md)。

## 2. 已确认名称与载体设定

| 已确认中文名 | 载体与定位 |

| **纳米催情液丝鞭** | 握柄控制 PNA 形成短距离纤丝，近身可靠投送并保留镇压用途 |
| **纳米催情液脉冲枪** | 紧凑枪形集群投送器，以三发短点射在中近距离积累药效 |

名称统一使用“纳米催情液＋武器形态／用途”；不继续使用此前工作名称“纳米纤线鞭”“纳米针束投射器”“纳米穿刺投射器”。形态控制、集群成形与入体解体写入简明描述，不堆入物品名。

### 2.1 纳米催情液丝鞭

握柄控制工作端形成短距离紫色细丝或细束。参与穿透的微观纤线不必逐根可见；接触时进行短暂穿刺并释放 PNA，随后解除相应形态，避免持续勒割。

首版为普通相邻格近战，保留可靠命中与镇压装备属性。对有效肉体目标，有可用纳米工作端时优先使用工作端，避免低物理伤害导致原版选择拳击或柄击而伤及受保护身体；遵守正常命中与冷却，对非敌对有效链目标的工作端免闪避并不新增近战威胁，其他目标保留原版闪避。不提高物理伤害来争取动作权重。暂不设计跨格鞭击、缠绕任务或连续柔性物理。工作端美术与姿态的后续实际进度见页首视觉记录，原批次设计时点不扩写为全部美术已完成。

### 2.2 纳米催情液脉冲枪

保留紧凑枪械轮廓，功能结构从供气／供针转为 PNA 储存、集群成形和投送。每发代表一个完整的纳米机械集群，内部极细针的数量不转换为额外攻击或剂量。

维持三发短点射，强化短中距离，远距离精度明显下降。通过多个独立命中积累药效，不模拟持续射击输入、逐根针体或微观碰撞。

### 2.3 纳米催情液投射枪

长枪形设备通过精密约束结构维持集群在较远距离上的稳定形态。单次投送剂量和穿透高于脉冲枪，保留明显的瞄准与再次射击间隔；接触距离精度较差，不能覆盖脉冲枪的全部用途。

不发射附带实体外壳的传统载药针，不在目标体内留下需要拔除的针体。

## 4. 穿透、身份保护与 PNA 结算

### 4.1 独立投送入口

本代不继续使用“留下合格开放伤口才施药”的前置。对普通目标，有效穿透与极小创伤分开表达：穿透已经成立，即使低伤害取整或其他原因未留下可见伤口，仍可接受 PNA。对有效锁链目标，实际接触后直接走无伤吸收，不再要求击穿普通护甲；这一例外不绕过护盾、掩体及其他实体拦截。

步骤一已实现三种载体共用的 `DamageWorker_SSCPnaSpacer` 与 `SSCPnaSpacerExtension`；扩展只配置 `baseLoad` 和 `recordHediff`，单次修复统一由 `baseLoad × 5` 推导。步骤二已按第 7.4 节创建正式 DamageDef／武器 DefName。复用现有公共工具，不继承涂覆伤口准入或旧发射器的固定伤害／按部位治疗行为。

### 4.2 一次命中的逻辑顺序

1. 先遵守实际攻击的命中、实体碰撞、掩体与适用护盾拦截；未到达目标，不构成施药或修复。不得在最外层给整次攻击设置忽略护甲来绕过护盾吸收。
2. 对实际命中的存活肉体目标核对 SSC 主人和有效锁链保护，在任何创伤写入前锁定本次保护状态。主人免疫优先于锁链吸收分流：无身体伤害、无负荷、无修复，不建立新抗性快照。
3. 对具有实际有效锁链的目标，在正常拦截之后、普通护甲判定之前分流。无视普通护甲的吸收阻挡，不磨损衣甲，不写入身体伤势；符合有效肉体与投送部位条件时，输入活化负荷并尝试一次修复。此分支不以穿甲数值或护甲结算后的伤害量作为准入。
4. 其他普通目标正常核对实际受击部位与防护。护甲仅结算一次，保留正常衣甲磨损；完全阻挡或偏转不投药、不修复；转为钝伤时保留原版减伤／取整后的物理钝伤，但不投药、不修复。成功穿透有机部位后执行极小创伤与普通 PNA 输入。
5. 无视普通护甲不取消部位资格：仅命中非有机人工部位仍不投药、不修复，也不在该部位模拟向其他组织迁移。普通物理柄击／枪身撞击不因持有太空 PNA 武器而获得无伤吸收规则。
6. 一次攻击或一个投射集群只认领一份药效／修复。传播到多个部位不重复结算，速射三发为三个独立命中，不按内部纳米针数量拆分。
7. 共享暴露或治疗触发同步健康回调后，重新核对身体、主人及有效链。失去有效链时停止后续修复；已受保护的本次攻击不因中途解绑补上一份普通伤害。

| 实际目标状态 | 纳米主攻击处理 |
| --- | --- |
| 普通有效肉体目标 | 正常判甲；穿透后极小创伤＋普通 PNA 输入；转钝则只保留减伤／取整后的物理钝伤 |
| 任一实际有效锁链的性奴 | 无创伤、无衣甲磨损；无视普通护甲吸收后活化＋有限修复，不限定由自己主人攻击 |
| SSC 主人 | 无创伤、无负荷，不额外治疗 |
| 仅为原版奴隶、无有效锁链 | 按普通目标处理 |
| 护盾、掩体或其他实体提前拦截 | 不向被挡住的目标施药或修复；若实际命中其他对象，按实际对象结算 |
| 仅命中非有机人工部位 | 不投药、不修复；主人／有效链的身体无伤保护仍保留 |
| 机械体、建筑、尸体或无效健康载体 | 不施药、不修复，首版不提供有效破坏能力 |

**主人伤害分摊与 PNA 投送已集中隔离。** 此前维护者发现并暂时保留的“先分摊、再在性奴身上投药”交互，现已按后续要求修复：六把中世纪／工业涂覆武器保留物理分摊，承伤者不接受 PNA；三把太空主攻击命中主人时不创建转移伤害，原主人免疫继续生效。直接命中性奴仍按原规则投送／修复。共用规则按处理器类型识别，单次上下文隔离嵌套真实攻击；实现、测试与本机同步见[分摊与投送隔离修复](../../Development/Completed/SSCPNA武器伤害分摊与投送隔离修复.md)。维护者已确认修复后实机运作正常并授权提交，旧“暂不修复”说明只按历史记录保留。

有效链复用 [SSCPnaExposureUtility.IsRooted](../../../Sexslavecraft/common/SSCPnaExposureUtility.cs) 的实际引用规则，不以身份标签、恶堕阶段或无效残链替代。主人免疫仍由现有身份入口判断，不新增阵营识别或“自己人”过滤条件。

本次确认替代初版“有效链目标也必须击穿普通护甲才能活化／修复”的约定；此前的高穿甲数值仍用于普通目标，不据此提高到必穿。前两代武器不继承本例外。

### 4.3 意识抗性、快照与负荷

继续复用 [共用剂量与快照工具](../../../Sexslavecraft/common/SSCPnaWeaponDoseUtility.cs) 和 [统一暴露入口](../../../Sexslavecraft/common/SSCPnaExposureUtility.cs)：

> 单次请求剂量 = min(基础负荷 ÷ 抗性除数, 0.50)。正常意识 100%、无快照时，分别为 0.20／0.10／0.25。

- 抗性取命中前意识，最低 20%；意识超过 200% 时建立记录，后续优先使用已有记录。药量准备与快照提交时点由新入口按有效投送安排，普通目标被护甲阻挡、目标被护盾／掩体拦截或输入被拒绝时，不留下未使用新快照；有效链吸收不以普通护甲穿透为前提。
- 速射逐发取样，前发输入可能改变后发意识；三发全中基线合计 30 点，不保证实际固定增加 30 点。
- 主人不建立新抗性快照或负荷；有效锁链目标进入现有性奴活化载体，不发旧 Buff。
- 单次上限、身体负荷封顶、普通成瘾及需求补充继续交由既有工具；不为太空武器额外绕过意识抗性。
- `Accepted` 与 `AddedLoad` 分开使用：满负荷下真实正投送仍可被接受，不能因最终增量为零就否决修复。

## 5. 已确认修复强度与规则

### 5.1 直接按有效命中即时修复

首轮修复预算按各武器 `baseLoad × 5` 配置：丝鞭 1、脉冲枪每发 0.5、投射枪 1.25。这里是伤势严重度，不是全身最大生命值百分比。

**明确取消此前建议的受击者共享修复额度、额度恢复计时和累计限速。** 首版不实现修复池、冷却、限流、延迟治疗队列或跨射手修复状态。每个有效命中独立即时结算，多次命中与多名射手的修复量可以直接叠加；每次命中只结算一次的事件认领不属于限速，仍必须保留。

修复量取配置基线，不取意识抗性放大后的请求剂量，也不取负荷钳制后的实际增量。可通过基线推导或在扩展中记录单次预算，但不能产生两份互相矛盾的有效数值。

### 5.2 可修复对象与选择

1. 只有本次成功投送、仍为存活有效肉体且具有实际有效锁链、并非 SSC 主人的目标可以修复。
2. 从现存、可自然愈合的非永久伤势中选择严重度最高的一处；不存在合格伤势则结束，不创建伤势或未来治疗量。
3. 本次实际修复不超过该伤势剩余严重度；治好后的剩余预算直接舍弃，不跨伤口分配。
4. 不修复人工部件，不恢复缺失部位，不直接治疗疾病或消除永久伤疤。部位及父级人工替换状态须显式过滤，不能只依赖原版 `CanHealNaturally()`；当前 1.7 该方法仅判断非永久伤势。
5. 不额外包扎、提供独立止血状态、免疫增益或持续再生；伤势减轻带来的改善由原有机制产生。

### 5.3 满负荷、失败命中与身份变化

| 情况 | 修复结算 |
| --- | --- |
| 满负荷且本次真实投送被接受 | 仍按完整单次预算尝试修复 |
| 低意识使药效输入放大 | 修复预算不变 |
| 一发集群含多个纳米针／命中传播到多个部位 | 合计只修复一次 |
| 三发点射全部有效命中 | 每发独立修复，最多合计 1.5 点，受实际伤势数量／严重度限制 |
| 多名射手同时命中 | 每个独立有效命中分别修复，不合并吞事件、不额外限速 |
| 有效链目标普通护甲过厚、按普通穿甲数值本来会被阻挡 | 仍可无伤吸收并按单次预算修复，不磨损衣甲 |
| 未命中、被护盾／掩体或其他实体拦截、仅命中非有机人工部位或暴露被拒绝 | 不修复 |
| 无合格伤势 | 不储存或补发本次预算 |
| 结算期间解绑、换身体或转为主人 | 中止尚未发生的修复，不反向追加本次创伤 |

取消限速后的理想连续修复量，单个使用者约为丝鞭 0.83、脉冲枪 0.96、投射枪 0.37 点／秒；仅按第 3.2 节基础周期与全部命中估算，不计防护、攻击选择、治疗溢出和人物修正。多射手可进一步增加，实际强度待实机观察，不将后续平衡疑虑预先改造成额外系统。

2026-10-19 已查阅本机 **1.7.4982 rev1280** 的实际 `Assembly-CSharp.dll`（MVID `a46e6f45-b616-4261-bb63-a9471bf7402a`）。原版近战伤害有 80%～120% 浮动，低于 1 时会改成钝伤；原版近战动作按伤害／穿甲／冷却等权重分档，过低的动作可能获得零选择权重。命中评分 +3 不解决动作选择。护甲判定本身会消耗衣甲耐久，不得试算后再重复判甲。以上为源码取证，不表示新机制已经编译、测试或在游戏中生效；正式实现时须复核当时构建。

按以下顺序细化开发：

1. **通用处理器与配置。** 已采用 `DamageWorker_SSCPnaSpacer` 及专用扩展；使用单一 `baseLoad` 来源，修复由 `baseLoad × 5` 推导。沿一次 `TakeDamage` 调用组织目标／部位、护甲及伤势写入，调用原版接口，不再进入会重复判甲的完整父类流程，不复制原版完整伤害实现。有效链在护盾等正常吸收之后、普通护甲计算之前分流；保留普通目标的转钝物理伤害。
2. **丝鞭近战入口。** 新增专用近战 Verb，保留原版命中、闪避、冷却、动作与日志；只适配命中后的纳米伤害构造，保留合法人物修正和正常伤害浮动，不因结果低于 1 就改为普通钝伤。对有效肉体目标，优先选择可用纳米工作端；动作选择适配仅作用于本代丝鞭，不提高真实伤害或改动全局近战权重。该类型保留发生在护甲之前，不撤销普通目标被护甲实际转钝的结果。
3. **共同工具与即时修复。** 受伤前取意识样本，成功投送才提交快照，拒绝时清理本次未使用的新快照；复用统一暴露和回调继续条件。用局部调用状态隔离传播、同 tick 独立命中及重入；身体／身份／有效链失效则中止尚未发生的修复，不补创伤、不回滚已合法输入。修复显式排除人工部位及其子部位，只处理最严重的一处合格伤势。
4. **效力与品质。** 解析器读取新处理器的同一剂量配置，显示单次 20%／10%／25%；当批曾复用品质例外，后续已撤下并恢复原版品质；工作端识别独立于品质，当前规则见第 3 节。步骤一隔离定义及步骤二 XML 的历史验证按原记录保留。
5. **测试与构建。** 扩展现有 PNA／品质专项，补充真实 1.7 程序集的护甲及近战入口检查；替身提供的物理结果不能证明原版随机、取整与动作选择。完成相关回归、必要全量检查与对应 1.7 编译，再记录实际验证范围。

必要测试覆盖：

- 普通身体穿透／完全阻挡／转钝／无可见伤口／有机与人工部位；转钝保留物理伤害但不投药，护甲判定和衣甲磨损不重复。
- 有效链目标在高护甲下仍无伤吸收／活化／修复，不磨损衣甲；护盾、掩体与其他实体正常拦截，不产生被挡目标的负荷、快照或修复。

- 正常、低／高意识与已有快照；有效投送才提交快照，满负荷输入仍可修复。
- 同次多部位只一次投送／修复，独立连发、同 tick 和多射手不吞事件。
