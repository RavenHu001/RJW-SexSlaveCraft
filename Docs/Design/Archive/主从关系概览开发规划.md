## 1 目标与开发边界

- 选中主人时显示绑定数量和从属头像；选中性奴时显示实际主人。
- 明确区分实际绑定、指定调教员与 SSC 身份。指定第三方调教员不计入主人或从属名单。
- 展示同图、异图、旅队、容器内、死亡和位置不可用等状态，并提供与状态相符的定位操作。
- 查询、查看和定位保持只读；明确更换／清空调教员复用现有事务及授权校验。解绑、改绑、互动模式和批量命令仍沿用原入口。
- 新功能仅面向 RimWorld 1.7。1.6 和 Common 保持 2.4.1 冻结内容；当前正式版本仍为 2.4.2，本规划不预设下一发行版本。
- 本功能不接入 RJW 行为结算，不增加 Biotech 等 DLC 依赖，不修改角色成长、共振场、承伤或仪式奖励。

## 3 归属数据与只读查询

### 3.1 数据职责

| 数据 | 当前职责 | 概览规则 |
| --- | --- | --- |
| 性奴侧 `Hediff_ChainOfSexSlave.target` | 保存实际主人引用 | 作为有向归属的最终依据 |
| 主人侧 `Hediff_BridleOfSexSlave.targets` | 保存反向索引 | 用作候选来源，逐项复查锁链并去重 |
| `CompSexSlaveTraining.selectedTrainer` | 保存指定调教员 | 仅作为明确标注的次级信息，不推断主人 |
| `pawnIdentity` | 保存 SSC 主人／性奴身份 | 决定空状态文案，不代替真实归属 |
| `SSC_FlawedLovers` 等社会关系 | 保存具有额外条件的仪式奖励关系 | 不用于构建绑定名单 |

[GetBoundMaster](../../../Sexslavecraft/common/SSCBondUtility.cs)直接读取锁链；同文件的 `GetResolvedMaster` 会回退到指定调教员，不用于本功能。社会奖励要求完整仪式、实际绑定及至少 80 好感，见[奖励入口](../../../Sexslavecraft/common/SSCBondRelationUtility.cs)，因此已绑定但没有奖励关系是合法状态。

### 3.2 从属枚举

普通概览直接读取主人侧 `Hediff_BridleOfSexSlave.targets`，逐项校验性奴锁链指向当前主人，按 Pawn 引用去重，排除空引用、自指、销毁和丢弃；保留死亡对象及离图、容器内的有效引用。数量、排序、头像和窗口行共用同一份本地快照，不枚举地图、世界、旅队或货物来补漏，不保留历史全局查询的候选。

主人直接读锁链，指定调教员直接读现有指派。常见位置沿已知角色的持有链解析；飞船缓存位置不明确时允许点击后实时定位，导航仍保留按需稀疏飞船索引，不因取消候选扫描删除定位能力。

生产开发诊断使用计数入口 `SSCBondOverviewUtility.Diagnose`，候选来源和去重逻辑保留，不构建展示快照或位置；完整 `Build` 仅保留作取证与回归。开发模式与 SSC 调试按钮开关均开启、当前单选有效来源后，显式点击诊断才扫描并报告“缰绳有效／全局绑定／索引遗漏”；结果不写入普通视图，不修复绑定，不保存名单。

### 3.3 反向索引的完整性

正常 [Bind](../../../Sexslavecraft/common/SSCBondUtility.cs) 同时建立锁链和缰绳。以下兼容入口说明仅凭缰绳不能保证完整：

- 外部直接改写公开 `chain.target` 后，[锁链 Tick](../../../Sexslavecraft/Hediff/Hediff_ChainOfSexSlave.cs) 才会整理双方索引；游戏暂停时可能尚未执行。
- 直接调用 `Hediff_ChainOfSexSlave.AddToPawn` 换主，会更新 target 和 observedMaster、清旧缰绳，但该入口自身不补新缰绳。后续 Tick 也可能因引用一致而提前返回；正常 Bind 会另外补齐。此为静态发现的兼容边界，后续应加入针对性夹具核验。
- [ValidTargets](../../../Sexslavecraft/Hediff/Hediff_BridleOfSexSlave.cs) 可以过滤旧归属，不能发现遗漏对象，也不负责去重。

普通概览接受上述异常入口造成的漏索引，开发诊断只报告差异。正常 Bind 和训练组件 PostLoadInit 会建立或补齐缰绳；若另行处理异常入口，应单独定义范围与回归，不在界面查询中调用 `RepairReciprocalLink`、`PruneInvalidTargets`、绑定、解绑或奖励维护。

### 3.4 状态语义

无锁链显示“未绑定主人”；有链但目标无效显示“绑定目标无效”。有主人身份而没有从属显示“暂无绑定性奴”。旧档身份未选择但仍有有效锁链时，照常显示真实绑定，不通过打开界面恢复身份。

[现有关系规则](../../../Sexslavecraft/common/SSCBondRelationRules.cs)允许保留死亡主人的绑定。死亡、复活、是否生成到地图与绑定有效性分别处理；`!Spawned` 不能直接解释为失踪。阶段读取复用 [SSCIdentityUtility](../../../Sexslavecraft/common/SSCIdentityUtility.cs) 的现行判定，不新增阈值。

## 4 界面与交互

### 4.1 单选关系卡片

入口为当前地图中单选的存活 Pawn，要求有现有训练组件，且有主人／性奴身份、有效绑定或需要说明的异常锁链。查询不要求可征召、允许调教或取得某项研究；无 SSC 身份且没有关系的普通角色不占用命令栏。多选时首版隐藏卡片。单选训练组件角色只登记直接关系；无关系角色停止周期重建，后续直接字段变化时仍可立即显示卡片。

性奴、调教员卡片均为 130×75，复用原版机械师命令背景和边框；性奴顶部优先完整显示“拥有性奴：n”，窄标题保留数量、只省略栏目文字，下方自动缩放全部头像，无分页。相邻的独立“选择所有性奴”按钮在点击时核对当前地图现时锁链并沿原生 200 上限批选。主人为 75×75 方形，头像显示矩形铺满按钮，与底部“选择主人”文字叠放；肖像纹理仍复用 40／56 两档，整块可安全定位并按实际目标选中。主人和调教员卡片不常驻姓名，详情移入悬停；即使同一人也分别标注，不存在的方向不占位置。主人卡片无总览或改主入口；其他面板的总览和调教员更换使用有底框的放大镜／铅笔图标，说明放入悬停。调教员面板提供更换入口，指派不进入绑定计数，异常双向数据保留各自事实。

头像悬停显示完整姓名、阶段、特化及位置；同图目标可高亮，头像直接承担定位，不再常驻逐行定位按钮。头像显示矩形随人数压缩，但原版肖像请求维持 40／56 两档，避免按人数产生新纹理尺寸；顶部数量使用与原版机械师一致的 Small 字号。正常同图不重复文字，死亡、容器和异地等特殊情况再提示。

### 4.2 完整列表窗口

总览为最大宽 680、按内容计算高度的紧凑头像网格。仅显示实际相关的主人／指定调教员／从属分区，采用 56 头像和短姓名，详情放入悬停；完整计数、既有排序及死亡成员仍保留，末项可达。调教员分区提供更换入口。

窗口支持滚动和可见网格裁剪，按屏幕限制尺寸，不强制暂停。更换选中来源、多选、来源死亡或失效时关闭，成功定位后关闭；普通使用不再维持异源固定浏览器。没有常驻手动刷新按钮或自动全局补漏；首次直接读取，既有关系按两秒局部刷新，直接字段变化与失效点击请求局部更新。

现有 [ITab](../../../Sexslavecraft/ITab/ITab_SexSlaveTraining.cs)已经包含多个功能区，且可见性受原版法律身份或自我调教资格约束，因此不是首版唯一入口。后续如需 ITab 入口，应复用同一模型与窗口，不复制绑定逻辑。

### 4.3 定位规则

| 关联角色状态 | 显示与操作 |
| --- | --- |
| 当前地图已生成 | 高亮，点击定位并选中 |
| 另一张已加载地图 | 提示地图名称，点击切图并定位 |
| 冬眠舱等地图容器中 | 标注容器，定位可用的持有物；不承诺选中内部 Pawn |
| 旅队／运输途中 | 标注位置类别，定位原版支持的世界对象或位置 |
| 死亡且有可定位尸体 | 显示死亡，定位尸体或其可用容器 |
| 有有效绑定但位置不可用 | 保留关系，禁用定位并说明原因 |
| 销毁、丢弃或无效引用 | 排除无效名单项；若来源锁链仍存在，显示目标无效 |

点击时重新核对来源、实际锁链和目标有效性，再用原版定位能力判断操作。头像绘制、高亮和按钮命中使用同一行快照；旧行不应在改绑后继续以原关系执行操作。首版不扩展旅队成员面板或尸体作为来源时的独立入口。

## 5 刷新、缓存和只读边界

会话仍由当前游戏拥有，最多两个视图，同源卡片与窗口共享快照，不保存到 Scribe。首次登记和主人、调教员、身份、缰绳引用／列表数量变化时直接读取；已有关系每两秒真实时间刷新阶段、姓名、死亡和持有位置，暂停时同样生效。等长原地替换由此定时刷新发现。

删除全局补漏调度、空结果五秒探测、双源轮换和慢查询共享退避。无关系角色只比较直接字段，不定时重建；无访问心跳／无窗口时释放视图。失效行只提交局部刷新请求，重复请求合并；每轮完整比较姓名、阶段、特化、生命、归属、顺序、位置名称／世界格值及调教员状态，无变化保留旧快照、文字和布局缓存；局部异常保留旧快照、两秒重试、三十秒日志节流，点击继续实时核链。

绘制不遍历世界，全部头像自动缩放、两档肖像请求、64 行与 256 截断项缓存及窗口可见行裁剪继续沿用。开发诊断完整扫描仍同步运行于主线程，只有明确点击时付出成本。查询上下文仍有界复用并在异常时清空引用，导航位置解析继续独立复查。

普通查看不修复缰绳或改写绑定、身份、社会关系及授权；显式更换调教员仍走原子事务，批选只改变原生选择。
