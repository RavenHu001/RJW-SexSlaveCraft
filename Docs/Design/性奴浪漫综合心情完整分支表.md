## 1. 判定顺序与读表约定

事件记忆严格按 **事件 → 当前锁链阶段 → 是否为有效受虐狂 → 互动前好感档位** 选择唯一分支。所有数值都是完整综合结果的最终基准值，不再叠加阶段、受虐狂或恶堕修正，不另加本次被替换的原版心情。事件值保持 −15～+15；这是本条 SSC 事件的基准范围，不是全部心情总和或原版倍率处理后的显示值上限。

| 项目 | 约定 |
| --- | --- |
| 厌恶 D | 本性奴在互动副作用前对对象的好感 ≤−10 |
| 一般 G | 好感 −9～59 |
| 亲近 C | 好感 ≥60；好感高不等同于爱情或已有关系 |
| 普通 N | 没有当时实际生效的原版 `Masochist`；被抑制时也走普通分支 |
| 受虐狂 M | 当时实际生效且未被抑制的原版 `Masochist` |
| 一阶 | 无本模块持续思想或受控事件记忆 |
| 二阶 | 可以有主动受限持续思想；禁止在互动前阻止，不生成受控事件记忆 |
| 三阶 | 开放本人的被动受控事件 E01～E05 |
| 四阶 | 开放 E01～E05 和本人实际执行的合法命令 E06～E13 |
| 零值 | 保留分支及两个文案占位，但不创建零值事件记忆，不刷新旧记忆；本次匹配的原版心情仍按替换契约处理 |
| 恶堕 | 不查询、不判档、不加减分，不以需求缺失生成特殊分支，也不因需求变化专门刷新本系统 |

适用身份、有效锁链、思想准入、本人原人格与载体、真实完成及同次去重仍是共同生成门槛，不作为加减分项。被动规则必须实际改变本次原版接受判定；命令必须有实际 worker 完成与结果证据。原版随机判定不是“真实意愿”，不得额外重抽。

三档好感只决定对应数值和文案。**长期资格另用原始好感＞0**：一般档的 −9～0 与 1～59 使用同一分支 ID、数值、名称和描述，仅期限与归组不同，不另造第四个好感档。原始好感须随本次事件快照冻结，不能只保存档位后再猜长期资格。

### 1.1 名称与描述占位

- `E01-S3-N-D` 等为设计分支 ID，尚不是已注册的 ThoughtDef 或翻译键。E 表示事件，S 表示阶段，N／M 表示特质，D／G／C 表示好感。
- 每行分别保留 `名称待定（分支 ID.name）`、`描述待定（分支 ID.description）`；不同阶段、特质或好感分支不因数值相同而合并文案。同一分支的三天／长期变体复用这一对占位。
- 占位只是待编写位置，未来实现仍使用获授权、非空且标明“文案待定”的临时运行文本，不能把带心情效果的原版思想描述留空。
- 记忆需保存完整分支 ID、最终数值、好感档位与原始值、旧关系、实际结果、期限／组别和年龄。以后阶段、特质或好感变化不改写历史名称、描述、数值或期限。

### 1.2 数值设计方向

被安排接受厌恶对象时，三阶普通仍明显负面；四阶与受虐狂可以逐渐体现适应、遵从或满足。接受亲近对象、受命成功的正面更强，四阶受虐狂的亲近成功可达到 +15。拒绝亲近对象或结束亲近关系通常仍有代价；受虐狂只缓和特定事件，不把严重失恋一律变成奖励。受命行为失败也可能因本人并不喜欢对象而得到小幅释然，综合结果不等同于机械的成功加分、失败扣分。

所有差异直接写入分支，没有统一的“受虐狂＋几分”公式。持续思想保留原 A／B 基础表并去掉恶堕，保持低幅度；不因事件范围扩大而同步提高持续奖励。

## 5. 原版替换、叠加与刷新

7. 比较冻结基准值，不比较衰减或原版倍率后的显示值。先通过准入及原人格复查，再完成组内替换；不能先删除旧记忆再尝试新记忆。
