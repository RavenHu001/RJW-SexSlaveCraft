# 人格特化历史与记忆数值迁移修复

## 状态与范围

**状态：修复完成，归入 `2.2.11`。** 代码修复及自动验证已完成，维护者已确认实际游玩修复有效，并同意提交及上传。最初提交时沿用 `2.2.10`，本次按维护者要求统一归入 `2.2.11`；版本归并不代表已正式发布。

本轮处理人格凝胶遗漏特化历史、混入宿主训练记录，以及记忆实际好感值恢复为定义默认值的问题。维护者的修复前实测确认记忆条目和阶段能够对上，手动修改的好感值会重置；阶段重置并未在该次实测中复现。本轮同时显式保存记忆阶段，用自动测试验证阶段和数值可以一起恢复，不将其描述为已完成游戏内复现的独立故障。

## 特化历史

角色以当前方向及进度字段保存正在训练的方向，以 `perTypeProgress` 保存其他方向的历史。原凝胶只采集当前字段，植入又复用普通方向切换入口，导致源人格历史遗漏而宿主历史残留。

- `Comp_Train.Specialization.cs` 集中保存特化状态和切换逻辑。导出返回独立字典，并以最新当前进度覆盖尚未归档的同方向记录。
- 凝胶新增 `specializationProgressByType`，参与采集、加工复制和存档；保留原有当前方向及进度字段。
- 植入通过专门接口整体替换接收身体的历史，随后恢复方向派生的开关，并由既有流程同步健康状态。
- 未选择方向时仍可携带其他方向历史；未知方向和损坏数值在迁移边界规范化。身体的奶量等资源不随人格复制。

例如源人格公交 50%、当前奶牛 20%，接收身体原有公交 80%、宠物狗 90%：植入后奶牛为 20%，切回公交为 50%，不会得到接收身体原有的狗方向进度。

## 记忆实例

`StoredMemoryData` 保留原类型名称、命名空间和旧字段，移入 `PersonalityMemoryUtility.cs`。版本 1 新增保存阶段、实际好感值及其存在标记、额外心情偏移、持续时间覆盖、永久标记和来源戒律引用；原有记忆年龄、心情倍率、关联人物继续保存。

- 采集记录实例字段，复制时创建独立快照，存档保留版本和字段存在标记。
- 恢复先按已保存阶段创建记忆，再写入实际数值。正数、负数、零及小数好感均保留，不以是否为零判断字段缺失。
- 向引擎添加记忆时显式传递关联人物，避免普通心情记忆的该引用被默认空参数覆盖。
- 继续使用游戏的可获得性判定和堆叠规则。失效社交对象会被跳过，单条异常不阻断后续记忆；定义更新造成阶段越界时记录警告并回退首阶段。

这不等于复制所有外部模组记忆子类的私有状态，也不修改直接社交关系的恢复规则。

## 旧凝胶兼容

- 缺少特化字典的旧凝胶以空引用标记，只恢复已保存的当前方向和进度，以及既有标签流程能够恢复的状态；不保留接收身体的历史来冒充源人格进度。
- 缺少记忆版本的旧条目继续按定义默认值创建，再恢复其已有年龄、倍率和人物数据。复制及再次存档不把旧条目伪装为完整新版快照。
- 新版记忆若没有好感存在标记，继续使用所选阶段的默认值。明确保存的零好感能够经过省略默认值的存档往返恢复。
- 从未写入旧凝胶的历史进度或自定义记忆值无法追溯重建，需要提取前的存档或其他原始数据。
