# SexSlaveCraft 2.2.11 — 人格、语言与种族分页修复合集

适用于 RimWorld 1.6，保留 2.2.10 的绑定仪式修复及此前维护版功能。

## 中文

- 修复人格迁移的普通特质恢复，保留宿主基因及基因授予的特质；改善凝胶卡片的长文本、多特质布局和滚动区域。
- 保存并迁移全部特化方向的历史及记忆实际数值，避免混入宿主进度或丢失自定义数值。
- 按当前特化方向正确显示完成状态，并为满级胸部改造补授予缺失的永久泌乳状态。
- 新增繁体中文 54 个 XML，补齐 2.2.11 新增的 10 个凝胶界面键；修正英文 14 条失效路径、移除 3 条过期翻译，并清理英、简、繁重复设置键。
- 保留种族已有的角色检查分页，仅在缺失时添加 SSC 分页，避免新角色原分页丢失，以及本模组额外触发 HAR 重复解析。

RimTalk 与渲染改动未纳入本次发布；当前武器隐藏行为保持原状。繁中覆盖以现有英文资源为参照。旧凝胶未保存的历史或自定义数值无法追溯补回。

Release 构建及七套件 146 项回归检查通过，语言静态检查 22 项通过。维护者反馈合并后目前未发现问题；未提供逐项游戏场景清单。详细范围见随包 `CHANGELOG.md` 和 `Docs/2.2.11发布验证.md`。

安装：下载本 Release 的 `RJW-SexSlaveCraft-TieJin-Modify-2.2.11.zip`，退出游戏，将旧版模组文件夹移出 `Mods` 后解压本包至 `RimWorld/Mods`。依赖与加载说明见随包指南。相邻 `.zip.sha256` 用于校验下载完整性；GitHub 自动生成的 Source code 压缩包是源码归档。

## English

For RimWorld 1.6. Includes the Binding Ritual fixes from 2.2.10 and earlier maintenance updates.

- Restores ordinary personality traits while retaining host genes and gene-granted traits; improves gel card layout, long text, and scrolling.
- Transfers history for every specialization and actual memory values without mixing in the host's progress or losing custom values.
- Corrects completion display for the selected specialization and grants missing permanent lactation at maximum breast development.
- Adds 54 Traditional Chinese XML files and ten current gel UI keys, corrects 14 English translation paths, removes three obsolete entries, and removes duplicate settings keys in English and both Chinese variants.
- Preserves existing race inspection tabs and adds the SSC tab only when missing, addressing missing tabs on new pawns and preventing this mod from rerunning HAR reference resolution.

RimTalk and rendering changes are deferred. Existing weapon visibility behavior is unchanged. Traditional Chinese coverage follows the current English resources. Data omitted from older gels cannot be reconstructed.

Release build, all 146 checks across seven regression suites, and 22 localization checks passed. The maintainer reported no issues with the merged version; no individual in-game scenario checklist was supplied.

Download the attached installation ZIP, close the game, move the old mod folder out of `Mods`, and extract this package into `RimWorld/Mods`. See the included guides for dependencies. Use the adjacent `.zip.sha256` to verify integrity; GitHub's automatic Source code archives are source snapshots.
