# 开发维护入口

[文档总索引](../README.md) · [开发资料](../Development/README.md) · [发布索引](../Releases/README.md)

这里集中构建、验证、打包和文档维护流程。当前工作区采用 1.6 冻结基线、1.7 独立开发与 Common 共享贴图，本批重布局与四项兼容修复已获维护者确认测试未发现问题，详见[验收记录](../Development/Completed/双版本重布局与1.7兼容修复验收.md)。已公开的版本为 **2.4.1**，包含原 2.4.0.5 开发版及其后全部开发。本版已对齐 About、文件版本 2.4.1.0 与产品版本 2.4.1，并重编正式 DLL。具体构建、验证和打包边界见[发布与打包](发布与打包.md)。

## 推荐阅读顺序

1. [发布与打包](发布与打包.md)：先确认环境、依赖、版本基准和常用命令。
2. [测试说明索引](../../Tests/README.md)：按改动选择专项，查看自动检查与实机步骤。
3. [发布与验证索引](../Releases/README.md)：准备对应版本的交付说明、验证记录和公告。
4. [文档维护约定](文档维护约定.md)：新增、归档、移动和检查文档时使用。
