这里集中构建、验证、打包和文档维护流程。当前版本为 **2.4.2**，采用1.6/2.4.1冻结基线、1.7独立开发与Common共享贴图，见[版本说明](../Releases/2.4.2/2.4.2发布说明.md)。1.7文件/产品版本及About对齐2.4.2，AssemblyVersion保持1.0.0.0；由实际构建生成BUILD-INFO并通过发布门禁。详见[发布与打包](发布与打包.md)。

## 推荐阅读顺序

1. [发布与打包](发布与打包.md)：先确认环境、依赖、版本基准和常用命令。
2. [测试说明索引](../../Tests/README.md)：按改动选择专项，查看自动检查与实机步骤。
3. [发布与验证索引](../Releases/README.md)：准备对应版本的交付说明、验证记录和公告。
4. [文档维护约定](文档维护约定.md)：新增、归档、移动和检查文档时使用。
