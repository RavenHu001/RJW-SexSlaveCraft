# 开发维护入口

[文档总索引](../README.md) · [开发资料](../Development/README.md) · [发布索引](../Releases/README.md)

这里集中构建、验证、打包和文档维护流程。当前仓库登记为 **2.4.0.5 开发里程碑**，本次只改文档与版本标记；四段版本暂不适用于现有打包脚本，正式包尚未生成。运行产物和历史 2.4.0 发布边界见[发布与打包](发布与打包.md)。

## 推荐阅读顺序

1. [发布与打包](发布与打包.md)：先确认环境、依赖、版本基准和常用命令。
2. [测试说明索引](../../Tests/README.md)：按改动选择专项，查看自动检查与实机步骤。
3. [发布与验证索引](../Releases/README.md)：准备对应版本的交付说明、验证记录和公告。
4. [文档维护约定](文档维护约定.md)：新增、归档、移动和检查文档时使用。

## 按任务选择
