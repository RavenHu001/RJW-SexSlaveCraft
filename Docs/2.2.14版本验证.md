## 永久泌乳回归

在仓库根目录运行：

```powershell
dotnet run --project Tests/PermanentLactation/PermanentLactation.csproj --configuration Release --no-restore -- .
```

本次结果：**22/22 通过**。覆盖固定及混合调用间隔、跨过结算阈值、不足一批等待、停产再开启、满容量、外部补满、营养不足与补食、容量截断、无食物需求、保存字段、旧存档缺省、HumanCattle 接管入口及非正间隔。首次修复前后的对比为 6/22 → 22/22，详见 [测试说明](../Tests/PermanentLactation/README.md)。

默认容量 0.125、充满需 15,000 tick、持续生产额外消耗每天 0.3 营养。在食物充足、从空开始且无额外产量或挤奶时，各测试调用间隔均约 6 个游戏小时充满，额外消耗约 0.075 营养。
