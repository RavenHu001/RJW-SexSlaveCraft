# SexSlaveCraft 2.2.15 — 公交车交易修复与未完成特化入口禁用

日期 / Date：2026-09-16。适用于 / For RimWorld 1.6。

状态：维护者已确认下述两项改动在游戏内有效；本次为版本归并与本地提交，尚未发布远端安装包。包含 2.2.14 及更早版本修复。

Status: the maintainer has confirmed both changes below in-game. This is a version consolidation and local commit; no remote installation package has been published for it yet. Includes fixes from 2.2.14 and earlier versions.

## 中文

### 公交车交易后互动

- 修复公交车本人完成商队交易后不启动互动的问题：原补丁查询不存在的任务定义，并在自愿分支中错误排除了普通女性角色。
- 改用实际 RJW 任务定义与合适的身体能力判断。保留原有概率及交易成长；仍需实际完成交易、双方状态正常、同地图 15 格内，并满足 RJW 能力及预约寻路条件。
- 接受方获得短时等待任务，由 RJW 驱动接管后续互动。直接启动并核对当前任务，避免 Shift 排队或沿用旧等待导致误报；失败只清理本次任务。

### 宠物猫、宠物兔入口

- 两种特化的选择项置灰，统一显示“未完成”。
- 旧档已有的对应当前方向及终极状态摘要同样显示未完成；兔子生育模式改为只读。
- 这是玩家入口停用；已有特化、分身和保存字段保留，未补完成长或分身系统。

旧 RimTalk 兼容继续暂停，等待整体重做。新限制系统与同床调整仍属于未来开发。

## English

### Public Use interactions after trading

- Fixes interactions failing after a Public Use pawn personally completes a caravan trade. The old patch queried nonexistent job definitions and incorrectly excluded ordinary female pawns from the consensual branch.
- Uses the actual RJW definitions and appropriate anatomy checks. Existing probabilities and trade growth are retained. A real trade, available participants within 15 cells on the same map, and valid RJW and reachability checks remain required.
- The partner receives a short wait before RJW takes over the interaction. Jobs start directly and are verified as current, avoiding misleading success messages from Shift queueing or an existing wait. Failure cleanup affects only jobs created by this event.

### Pet Cat and Pet Rabbit selection

- Both specialization choices are disabled and marked Incomplete.
- Existing specialization and final-state summaries show the same marker; saved rabbit birth modes are read-only.
- This disables player entry points. Existing specialization data, clones, and saved fields remain; the progression and clone systems have not been completed in this update.

Legacy RimTalk integration remains suspended pending a redesign. The new restriction system and shared-bed changes remain future work.
