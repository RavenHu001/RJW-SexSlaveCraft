## 构建与交付

从包含函数注释及新版本属性的最终源码进行 Release 重编译，使用本机 RimWorld、RJW、Harmony 与动画依赖。运行 DLL 随源码和文档一并提交。

版本归并时的候选 DLL SHA-256：

```text
c3921473ce7b8fb4dc11200c718a8d376570c890cdc8233a80cde3b5669b66f9
```

正式发布在合并后的 `main` 基线上重新编译。与已提交候选 DLL 比较，1629 个方法的 IL、局部变量、异常处理记录及程序集引用保持一致。正式 DLL SHA-256：

```text
fdef9b83da9f96bb95b31da1a0765830a571fb560d86f8bf1216c2d22e9e310b
```

提交发布文档及最终 DLL 后，从干净工作区构建正式包：

```powershell
pwsh -File Scripts/New-Release.ps1 -Build `
  -ReferenceTargetsPath .builds/ritual-fix/LocalReferences.targets `
  -OutputDirectory Releases/Published/2.2.12
```

正式安装包与 SHA-256 文件位于忽略目录，作为 GitHub Release 附件上传。包内 `RELEASE-MANIFEST.json` 记录最终提交、`workingTreeDirty: false`、`assemblyRebuilt: true` 及每个有效载荷文件的大小和 SHA-256。发布标签指向同一提交。

正式包包含新增的发布说明，共 352 个有效载荷文件；只包含本模组 DLL，不包含源码、测试、PDB 或第三方程序集。上传后核对 GitHub 返回的附件大小和 SHA-256，再将草稿公开并设为最新版本。ZIP 整体校验值以 Release 附带的 `.sha256` 文件为准。

早先的 `Releases/Candidates/2.2.12/` 包保留版本归并时的检查记录，不作为本次正式下载附件。
