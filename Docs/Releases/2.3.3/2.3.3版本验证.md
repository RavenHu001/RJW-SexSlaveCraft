- 运行版本、`VERSION` 与 About 描述均为 **2.3.3**；DLL 文件版本 **2.3.3.0**、产品版本 **2.3.3**，程序集引用身份继续为 **1.0.0.0**。RimWorld 支持版本仍为 **1.6**。
- 使用本机 Visual Studio MSBuild、.NET Framework 4.7.2 和已配置的 RimWorld、RJW、Harmony、动画框架引用，执行 `Scripts/New-Release.ps1 -Build`；Release 重建成功。该 DLL 包含 `229e220` 的 RJW 补丁和更新后的版本元数据。
- 发布候选以脚本打包；最终 ZIP 从提交后的干净工作区重新生成，来源以包内 `RELEASE-MANIFEST.json` 的 `baseCommit` 为准。
