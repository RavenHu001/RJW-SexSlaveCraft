## 起点与归属

当前没有 `v2.5.2` 发布标签，以已提交的 2.5.2 登记提交 `7e5d17a9` 为界。其前一开发截止点为 `1ada9192`，已归入 2.5.2。该登记提交只包含版本标记与文档，两个边界间没有新增机制实现。

第 6 项的后续方案细化、五批实现、验收和修复现归入 2.5.3。此前在 2.5.2 说明与验证中补录的无主性奴和解绑内容，改由本版的说明、验证与完成索引承接。2.5.2 的原逐提交和路径快照按原截止点保留。

PR #48 的各实现提交在非合并表中各登记一次，合并提交单列。阅读顺序为[本版完成索引](../../Development/Completed/README.md#ssc-253-completed) → [无主实施与验收](../../Development/Completed/无主性奴/README.md) → [已交付设计](../../Design/Archive/第6项无主性奴设计方案.md)。保留事项及构建来源见[版本验证](2.5.3版本验证.md)。
