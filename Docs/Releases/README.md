# 版本发布与验证索引

当前正式版为 **SSC 2.5.3**，2026-11-21 发布，面向 RimWorld 1.7；同包 1.6 内容保持 SSC 2.4.1。2.5.2 是随 2.5.3 交付的开发里程碑，没有单独的正式发布包。

[文档总索引](../README.md) · [更新日志](../../CHANGELOG.md) · [发布与打包](../Maintenance/发布与打包.md)

## 阅读顺序与资料归属

1. [版本说明](2.5.3/2.5.3发布说明.md)：玩家可见变化与正式版下载。
2. [开发归并](2.5.3/2.5.3开发归并核对.md)：开发截止点、提交与路径清单，原登记快照保留原时点。
3. [正式发布验证](2.5.3/2.5.3版本验证.md#ssc-253-release)：正式构建、完整门禁、安装包与发布回执；分批实机证据在同页另列。
4. [完成索引](../Development/Completed/README.md#ssc-253-completed)：实施与验收；[待验收](../Development/Verification/README.md#当前专项)和[当前规划](../Design/README.md#当前专项规划)分别记录保留核查与后续需求。

`Docs/Releases/` 存放版本文档，根目录 `Releases/` 存放本地 ZIP、校验文件等产物。历史门禁计数属于对应版本；本次文档整理不重新构建或覆盖已发布附件。旧索引头部摘录见[导航沿革](../Development/Reference/History/索引沿革/文档导航历史摘录.md)。
