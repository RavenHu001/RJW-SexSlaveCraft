# 2.3.6 构建与发布验证

日期：2026-10-02（维护者当地时间）。范围为 2.3.5 正式发布后至统一特化基础培养经验实现及本次版本文档。玩家内容见[中英发布说明](2.3.6发布说明.md)。

## 功能依据

- 统一基础经验实现于 `36e9483`，将当前方向的完整日常调教和整场成功绑定仪式接入同一发奖入口，沿用战斗员公式并保留特色来源。
- 实现阶段使用本机游戏依赖完成 Release 编译、20 套自动回归 968/968 通过；维护者随后反馈统一经验有效。该反馈未细分每种特化或记录定量培养速度。
- 猫狗技能、宠物互斥和亲昵扩展尚未实施；猫、兔培养入口仍禁用。详情见[专项规划](../../Design/猫狗特化与统一培养经验初步规划.md)。

## 版本与发布门禁

- `VERSION`、About、程序集文件／产品版本、更新日志及玩家指南统一为 **2.3.6**；程序集引用身份保持 **1.0.0.0**，支持 RimWorld **1.6**。
- 使用本机 RimWorld 1.6、RJW、Rimworld-Animations 和 Harmony 引用完成 Release 重编译，**0 警告、0 错误**；日志位于 `.builds/release-2.3.6/build.log`。实际 DLL 文件／产品版本为 **2.3.6.0／2.3.6**。
- 本次 `Scripts/Test-All.ps1` 完整回归 **20 套通过、968/968 项通过、0 失败、0 未运行**，使用本机 net9.0 Harmony 2.4.2；报告位于 `.builds/release-2.3.6/validation/summary.json`。正式安装包再由 `Scripts/New-Release.ps1 -Build` 执行相同发布门禁。
- 安装 ZIP 的 `RELEASE-MANIFEST.json` 记录来源提交、工作区状态、DLL 重编译状态和当次测试计数；相邻 `.zip.sha256` 给出整包校验值。

## 验证边界

自动测试覆盖共享发奖资格、旧奖励去重、当前方向及日常／仪式结算边界，但不执行完整 Unity 游戏流程。维护者确认功能有效；未据此声称所有模组组合、真实存档往返或培养速度的逐场景验收。
