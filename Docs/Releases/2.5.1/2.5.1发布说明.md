# SSC 2.5.1 · PNA Mist and Compatibility / PNA 雾气与兼容修复

[English](#english) · [中文](#中文) · [开发归并](2.5.1开发归并核对.md) · [验证记录](2.5.1版本验证.md)

## English

**2.5.1 development milestone · RimWorld 1.7.** The public package is still SSC 2.5.0. Its RimWorld 1.6 component uses SSC 2.4.1. [Download 2.5.0](https://github.com/RavenHu001/RJW-SexSlaveCraft/releases/tag/v2.5.0)

- **PNA mist series.** Adds mortar shells, IEDs and an adjustable PNA mist emitter. The emitter has separate range and mode controls and a dedicated sprite. The series passed in-game acceptance.
- **Relationship command bar.** Fixes flickering when WOWGAG reuses the command list. The Select All and Select Master buttons now use vanilla command handling. Both buttons passed in-game checks with list reuse enabled.
- **Patch loading and the Daily Training loop.** When a mod conflict causes a patch to fail registration at startup, SSC skips the failed patch or compatibility group and continues loading the rest. Daily Training checks its required hooks before issuing jobs. If a hook is missing, SSC blocks the affected jobs to prevent them from repeatedly starting, aborting and being assigned again. The fix passed in-game checks with Combat Extended.
- **Diagnostics.** The settings window shows patch registration status and reasons for skipped patches or fallbacks. It supports filtering, refreshing and copying reports. The updated interface is available in four languages.

The PNA and compatibility changes were validated on their respective development builds. See the validation record for open compatibility cases and release preparation. [Validation record](2.5.1版本验证.md)

## 中文

**2.5.1 开发版 · 面向 RimWorld 1.7。** 当前公开安装包为 SSC 2.5.0，包内的 RimWorld 1.6 内容为 SSC 2.4.1。[下载 2.5.0](https://github.com/RavenHu001/RJW-SexSlaveCraft/releases/tag/v2.5.0)

- **PNA 雾气系列。** 新增迫击炮雾气炮弹、雾气 IED 和可独立调节半径与档位的 PNA 发烟器。发烟器使用专用贴图。三项功能均已通过实机验收。
- **主从关系命令栏。** 修复 WOWGAG 复用命令列表时的闪烁。「选择所有性奴」和「选择主人」使用原版命令交互，两按钮在开启列表复用时均已通过实机验收。
- **补丁加载与日常调教循环。** SSC 调整了启动时的补丁加载逻辑。模组冲突导致某个补丁注册失败时，跳过失败的补丁或兼容组，继续加载其余补丁。日常调教派发前会检查所需钩子，缺失时停止派发受影响的任务，避免调教反复开始、退出和重派。修复已在启用 Combat Extended 的环境中通过实机复测。
- **诊断窗口。** 设置中的「诊断与兼容」显示补丁注册状态及跳过、回退原因，支持筛选、刷新和复制报告。更新覆盖四语界面。

PNA 与兼容修复的实机结果按各自的受测构建登记。未关闭的兼容场景与正式发布准备见[验证记录](2.5.1版本验证.md)。
