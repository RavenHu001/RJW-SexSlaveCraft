### 玩家可见变化

- RimWorld 1.6 继续加载冻结的 **SSC 2.4.1** 内容；本轮新功能仅在 **1.7** 路径开发，游戏自动选择对应目录。
- 完成全身凝胶化的角色，在“调教”ITab 中出现“凝胶外观”区，可切换个人渲染、查看色块与不透明度、打开调色弹窗。命令栏不再重复提供调色按钮。
- 默认深紫色为 HSV H272.5°／S90%／V68%，不透明度 **85%**；可独立调整并恢复默认。关闭渲染保留已选配色，不改变凝胶化玩法效果；恢复默认配色不改变个人开关。
- 旧档缺少个人开关字段时继承原全局设置，此后明确保存个人值；新获得的凝胶身体默认开启。颜色与开关属于身体，不随人格转移；克隆初始化后独立。
- 原版头图保留眼部，FA 保留五官分层、眨眼与遮挡；SA 保留软依赖适配。身份按钮和任职开关明确显示禁用，身份区删除重复的日常训练状态。

### 发布与版本状态

本次同步About及1.7文件版本2.4.2.0／产品版本2.4.2，沿用AssemblyVersion 1.0.0.0，通过实际游戏引用重编；BUILD-INFO与发布清单如实记录构建来源。完整发布门禁和ZIP字节/白名单检查由发布流程执行，结果归档在[验证记录](2.4.2版本验证.md)。

1.6与Common的532个冻结文件保持原字节。维护者已确认功能开发批次的UI、个人开关、旧档迁移、五官动画与遮挡正常；本次版本重标后的新DLL没有再次启动游戏，不把旧反馈改写为新构建完整实机测试。FA/SA隔离模型与历史待验收事项保留各自边界。

更新前备份存档，退出游戏后将旧模组文件夹移出Mods，再解压新包，避免残留旧根目录文件或两份DLL。不要手动合并1.6/1.7目录。公开下载为[v2.4.2](https://github.com/RavenHu001/RJW-SexSlaveCraft/releases/tag/v2.4.2)，[旧v2.4.1附件](https://github.com/RavenHu001/RJW-SexSlaveCraft/releases/tag/v2.4.1)保留历史用途。

## English

**2.4.2 — released 2026-10-17.** It groups all development after the published `v2.4.1` tag: package/document whitelists, separate 1.6/1.7 layouts and build tools, 1.7 compatibility fixes, mood-name localization, native body/head gel rendering, lighting alignment, material-cache optimization, vanilla/FA adaptation, per-body appearance, improved UI and persistent per-pawn rendering.

The 1.6 runtime remains frozen at SSC 2.4.1. New visual features target 1.7. Fully gelatinized pawns use the Training tab for appearance and rendering controls; the duplicate pawn-gizmo button was removed. Defaults remain dark purple at 90% HSV saturation and 85% opacity. Saved colors are retained when rendering is disabled; legacy global preferences initialize missing per-pawn fields once. Vanilla eyes and FA facial animation/occlusion are preserved.

The package contains the unchanged SSC 2.4.1 runtime for RimWorld 1.6 and a rebuilt 2.4.2 DLL for 1.7. About and file/product metadata are aligned; AssemblyVersion remains 1.0.0.0. The maintainer accepted the development functionality, including legacy migration and facial animation/occlusion. Version metadata changes do not constitute a new in-game test of the rebuilt DLL; automated and historical runtime evidence remain separate.
