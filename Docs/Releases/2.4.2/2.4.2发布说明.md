### 玩家可见变化

- RimWorld 1.6 继续加载冻结的 **SSC 2.4.1** 内容；本轮新功能仅在 **1.7** 路径开发，游戏自动选择对应目录。
- 完成全身凝胶化的角色，在“调教”ITab 中出现“凝胶外观”区，可切换个人渲染、查看色块与不透明度、打开调色弹窗。命令栏不再重复提供调色按钮。
- 默认深紫色为 HSV H272.5°／S90%／V68%，不透明度 **85%**；可独立调整并恢复默认。关闭渲染保留已选配色，不改变凝胶化玩法效果；恢复默认配色不改变个人开关。
- 旧档缺少个人开关字段时继承原全局设置，此后明确保存个人值；新获得的凝胶身体默认开启。颜色与开关属于身体，不随人格转移；克隆初始化后独立。
- 原版头图保留眼部，FA 保留五官分层、眨眼与遮挡；SA 保留软依赖适配。身份按钮和任职开关明确显示禁用，身份区删除重复的日常训练状态。

### 发布与版本状态

本次只登记文档与 `VERSION=2.4.2`。现有 `1.7` DLL、`BUILD-INFO.json`、About 及程序集属性仍保留其实际 **2.4.1** 元数据；它们是已验收的后续开发产物，不是已构建的 2.4.2 正式包。准备下一次有效构建/发布时须同步 About 与 1.7 文件/产品版本、重建并更新来源记录，再执行门禁。不能修改旧 BUILD-INFO 或哈希假装完成版本构建。

1.6 与 Common 的 **532 个冻结文件**继续保持原字节；旧 v2.4.1 标签、下载链接、附件与历史验证不改名。公开下载仍指向现有 [v2.4.1](https://github.com/RavenHu001/RJW-SexSlaveCraft/releases/tag/v2.4.1)，本页不提供 2.4.2 下载。

## English

**2.4.2 is a development version, not a published release.** It groups all development after the published `v2.4.1` tag: package/document whitelists, separate 1.6/1.7 layouts and build tools, 1.7 compatibility fixes, mood-name localization, native body/head gel rendering, lighting alignment, material-cache optimization, vanilla/FA adaptation, per-body appearance, improved UI and persistent per-pawn rendering.

The 1.6 runtime remains frozen at SSC 2.4.1. New visual features target 1.7. Fully gelatinized pawns use the Training tab for appearance and rendering controls; the duplicate pawn-gizmo button was removed. Defaults remain dark purple at 90% HSV saturation and 85% opacity. Saved colors are retained when rendering is disabled; legacy global preferences initialize missing per-pawn fields once. Vanilla eyes and FA facial animation/occlusion are preserved.

This documentation registration updates VERSION only. Existing binaries, About, assembly attributes and BUILD-INFO retain their actual 2.4.1 metadata until a separately validated rebuild. No 2.4.2 package, release tag or new runtime test is claimed. The existing public download remains [v2.4.1](https://github.com/RavenHu001/RJW-SexSlaveCraft/releases/tag/v2.4.1). See the [validation record](2.4.2版本验证.md) for the historical evidence and pending version-alignment work.
