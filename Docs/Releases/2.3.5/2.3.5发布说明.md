## 中文

### 自我调教首版

- 持有锁链的 SSC 性奴可在限制面板的调教栏独立开关自我调教。新角色及旧档缺少此字段时默认开启，手动关闭后会保存。
- 选中角色并右键本人，可在许可开启时手动指派，从当前身体条件可执行的 RJW 单人交互中选择部位。许可关闭时隐藏入口。
- 自动路径只对 RJW 已生成的自动自慰候选进行分流，不建立额外触发循环。普通自慰和自我调教均可用时，四阶段概率分别为 **30%／55%／80%／50%**；普通自慰被 SSC 关闭而自我调教可用时，直接选择自我调教。
- 复用 RJW 单人任务及动画接入，完整交互信息用于部位区分。首版仍受“禁止自慰”“传染性手淫障碍”基因阻断；RJW 未能生成自动候选时不补发任务，手动入口也检查原生能力。
- 评分在场景实际开始时记录恶堕与好感输入，有效主人优先，其次为有效指定调教员；无人可选时关系加分为零。公式、阶段上限及心情数值见[完整指南](../../../机制详解.md#44-自我调教)。
- 正常完成时给予恶堕收益和持续一天的专用记忆，不建立绑定，不更新日常调教冷却、预约日期或上次评分。记忆心情受阶段、受虐狂特质及好感影响；两种关闭普通自慰的许可组合有各自的状态心情。
- 完成提示采用“角色 | 评分 | 恶堕”格式，其中恶堕为公式计算增量；受阶段上限影响后的实际入账另记入诊断日志。中断不发放完整收益，领取状态随场景保存，避免重复结算。

### 调教任务交接修复

- 修复调教员与目标同步到同一格时，当前任务被打断并转去吃饭、加工等工作的问题。位置同步保留当前任务，由接收任务启动步骤统一交接。
- 防止已结束或被复用的 Job 的旧回调释放新工作的预约、结束新任务或清理新占用。
- 交接核对实际参与者配对，失败时只清理本次孤立接收器。共享流程的日常调教、绑定仪式、人格排泄及家具接收器均补充相应保护，保留正常取消和征召中断。

### 升级与版本状态

- RimWorld 支持版本仍为 **1.6**；所需 Harmony、RJW 及既有加载顺序保持不变。程序集引用身份仍为 `1.0.0.0`，文件／产品版本更新为 `2.3.5.0`／`2.3.5`。

## English

### Self-training

- Chain-bearing SSC Sex Slaves have a separate self-training permission in the restriction panel's Training section. It defaults to enabled for new pawns and old saves without the field; an explicitly saved disabled value is preserved.
- Select a pawn and right-click that pawn to issue a manual order while permission is enabled. The submenu lists currently valid RJW solo interactions; disabling permission hides the entry.
- Automatic selection only diverts an existing RJW automatic masturbation candidate. When both choices are available, stage chances are **30% / 55% / 80% / 50%**. If SSC disables ordinary masturbation while self-training remains available, it selects self-training directly.
- Reuses RJW's solo task and animation integration with complete interaction data. Anti-masturbation genes still block this version. It does not generate an automatic task when RJW returns no candidate, and manual orders also check native ability.
- Score inputs are captured at scene start, using Corruption and positive opinion. A valid Master takes priority over an assigned trainer; with neither, the relationship bonus is zero. See the [full guide](../../../PLAYER_GUIDE_EN.md) for formulas and mood values.
- Normal completion grants stage-capped Corruption and a dedicated one-day memory without creating a bond or updating everyday Training cooldown, appointment date or last score. Stage, Masochist and opinion affect the completion memory; the two permission combinations that disable ordinary masturbation have separate state moods.
- The result message shows `pawn | score | Corruption`, using the calculated gain. Diagnostics record the actual gain after the stage cap. Interrupted tasks do not grant the full reward, and the saved completion claim prevents duplicate rewards.

### Training handoff fixes

- Position synchronization no longer interrupts the trainer's current task and sends them to eating, crafting or other work before the receiver starts.
- Callbacks from ended or reused Jobs cannot release a replacement job's reservations, end it or clear its ownership state.
- Handoffs verify the actual participant pair and clean up only their own orphan receiver. The shared everyday Training, Binding Ritual, personality-excretion and furniture-receiver paths receive the same safeguards. Normal cancellation and drafting remain available.

### Localization, validation and upgrading

- Updates self-training menus, task reports, rejection reasons, memories and permission text in four languages. Completes Traditional Chinese and Russian restriction-panel entries and checks language mirror consistency before packaging.
- Fixes test summary formatting that blocked packaging despite passing cases. The self-training suite now has **50 checks**, including the production task driver. The feature baseline passed **20 suites, 966/966 checks**; see the [validation record](2.3.5版本验证.md) for scope and in-game limitations.
- Supports RimWorld **1.6** with the existing dependencies and load order. Assembly identity remains `1.0.0.0`; file/product versions are `2.3.5.0` / `2.3.5`.
- This is a repository version update, not a public release or installation package. Historical 2.3.4 packages do not contain these additions. When installing a later 2.3.5 package, close the game and move the old mod folder out of `Mods` before installing the replacement.
- Review individual permissions after loading an old save: missing self-training fields default to enabled. Gene compatibility remains future work; legacy RimTalk remains suspended and unfinished Pet Cat/Pet Rabbit choices remain disabled.
