## 舍入口径复核

弱值换算曾在开发期使用 `UnityEngine.Mathf.RoundToInt`（等价于 `Math.Round` 的默认取偶），导致基准 +5 得到 +2、+9 得到 +4、-5 得到 -2，与约定的 +3／+5／-3 不符；当时的测试替身把该 API 实现成“远离零”，所以全绿报告未能暴露问题。

修正后实现显式调用 `System.Math.Round(..., MidpointRounding.AwayFromZero)`，测试替身改为忠实复现 Unity 的取偶语义，并把 +5／+9／±3／±7／+11／+13 等半值边界逐项钉住。因在 PowerShell 中加载游戏 Unity 程序集不可行，改用反汇编**构建产物**确认：

```
SexSlaveCraft.TrainerTrainingMemoryUtility.WeakValue: il=44 bytes
  IL_000F: (prev const 1) Math.Round
  IL_0017: Math.Abs
SexSlaveCraft.TrainerTrainingMemoryUtility.WeakOpinionOffset: il=15 bytes
  IL_0003: (prev const 1) Math.Round
```

两处都是 `Math.Round` 且常量参数为 `1`（`MidpointRounding.AwayFromZero`），不再出现 `Mathf` 调用。仓库 `Assemblies/Sexslavecraft.dll` 与本次构建产物输出一致。只读校验器见 `.builds/trainer-training-memories/ilverify/`。
