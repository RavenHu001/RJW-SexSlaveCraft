## 候选包生成与自动检查

在仓库根目录执行：

```powershell
pwsh -File Scripts/New-Release.ps1 -Build `
  -ReferenceTargetsPath .builds/ritual-fix/LocalReferences.targets `
  -OutputDirectory Releases/Candidates/2.2.10
```

本机引用覆盖文件不随发行包交付。已有同路径产物时脚本停止；重新生成前确认需要替换，再显式使用 `-Force`。

脚本成功结束才会生成下列候选产物：

- `Releases/Candidates/2.2.10/RJW-SexSlaveCraft-TieJin-Modify-2.2.10.zip`
- `Releases/Candidates/2.2.10/RJW-SexSlaveCraft-TieJin-Modify-2.2.10.zip.sha256`

候选构建执行以下自动检查，任何一项失败都会阻止打包：

| 项目 | 检查内容 |
| --- | --- |
| 版本一致性 | VERSION、About、AssemblyInfo、DLL 文件/产品版本与 changelog 版本标题一致 |
| Release 编译 | 从当前源码重新生成运行 DLL |
| 阶段进度回归 | `RitualProgression`，29 项用例 |
| 生命周期回归 | `RitualLifecycle`，31 项用例 |
| 安装包组成 | 单一模组根目录；包含运行资源、指南与中英双语 changelog；排除源码、测试、PDB 和第三方 DLL |
| 完整性 | 包内 `RELEASE-MANIFEST.json` 逐文件记录大小和 SHA-256，外部 `.sha256` 校验整个 ZIP |

自动用例直接调用生产状态管理器及阶段回调，但不执行完整游戏调度、Harmony detour、真实奖励、动画或 Scribe 序列化。
游戏内验证的结论来自维护者确认，不由自动测试代替；候选包仍需完成最终提交和发行步骤。
