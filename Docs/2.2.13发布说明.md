# SexSlaveCraft 2.2.13 — 人格植入、手术记忆与仪式动画修复

状态：四项修复均已由维护者确认有效，已归入 2.2.13，尚未正式发布。

## 中文

本版包含四项修复，并保留 2.2.12 及更早版本的改动：

1. **人格植入隔空完成**：植入期间让空壳停留并持续检查接触；目标走远或失去有效状态时中断，最终写入前再次校验，避免隔空覆盖人格和消耗凝胶。
2. **性别重置术后记忆**：修正重复的记忆定义名称，恢复正常添加；缺失定义时安全跳过，避免手术收尾空引用。原有持续时间与心情数值保留。
3. **仪式 UAP 兼容**：清理阶段交接时遗留的位置锁，避免旧任务的检查把新阶段动画误停。
4. **仪式备用动画查找**：从正确的动画定义库筛选候选，修复已有适用动画却无法通过备用路径启动的问题。

Release 编译及 11 套件 **215 项回归**通过；另验证无 UAP 类型的 32 项和无动画框架类型的 1 项检查。详情见 [2.2.13 版本验证](2.2.13版本验证.md)。

动画仍需已安装的框架及适用资源；本版不会补发过去漏掉的术后记忆，也不会重建旧失败存档中已清空的动画队列。更新 XML 和 DLL 后需重启游戏。

## English

Status: the maintainer has confirmed all four fixes. They are included in 2.2.13, which has not yet been published as a release.

This version includes four fixes and retains all changes from 2.2.12 and earlier versions:

1. **Implantation completing at a distance**: keeps the Hollow waiting and checks contact throughout the procedure, then validates again before transferring personality data or consuming the gel.
2. **Memory after gender reassignment surgery**: fixes the duplicate memory definition name and safely skips missing definitions, preventing a null reference during surgery cleanup. Existing duration and mood values are preserved.
3. **UAP ritual compatibility**: clears stale position locks at stage boundaries so old job checks cannot stop a new stage's animation.
4. **Ritual fallback animation lookup**: reads the correct animation definition database, allowing the fallback to find compatible animations that are already loaded.

The Release build and **215 regression checks across 11 suites** passed. Additional checks passed with UAP types absent (32 checks) and animation framework types absent (one check). See the [validation record (Chinese)](2.2.13版本验证.md).

Playback still requires an installed framework and compatible assets. Previously missed surgery memories and animation queues already cleared in old failure saves are not reconstructed. Restart the game after updating the XML and DLL.
