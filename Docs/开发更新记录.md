## 2026-09-15 — 永久泌乳累计计时修复（修复完成，归入 2.2.14）

- 维护者观测到约 5 个游戏小时只增长 2% 奶量。核对源码与当前 DLL，确认每 60 tick 的哈希结算只使用当前调用的 `delta`，丢失此前跳过的时间。
- 改为累计实际调用间隔，达到至少 60 tick 后统一结算全部累计时间，奶量和营养消耗共用该时间；跨过批次阈值不漏算，接近满容量时只为实际存入奶量扣营养。
- 满容量、关闭泌乳及 HumanCattle 接管时清理累计值；保存不足一批的进度，旧存档继续保留现有奶量并从零开始累计，不补发历史损失。保留永久状态与缺粮比例生产。
- 新增直接链接组件、读取实际 XML 的 22 项回归，修复前 6/22 通过、修复后 22/22 通过，并接入后续打包检查。测试范围与游戏内复核条件见 [永久泌乳回归](../Tests/PermanentLactation/README.md)。
- 本机游戏依赖 Release 构建通过，已更新运行 DLL 并核对候选与运行文件哈希一致；二进制中确认新增累计及存档字段、移除原哈希结算条件。打包脚本语法检查通过。
- 维护者已确认游戏内修复有效，并授权提交。未记录逐项场景和兼容组合的实测结果；现归入正式版本 `2.2.14`。
