## 构建与安装包

正式 DLL 从当前源码 Release 重编译，包含合并后补充的方法注释对应的源码校验信息。SHA-256：

```text
a8b2611dbd42d796ec5978e72c0477fb0dc98dcfe51b15e39806aa5c2cfea938
```

方法 IL、局部变量、异常处理记录及程序集引用与合并核查时的 DLL 一致；源码注释进入构建输入后，DLL 文件哈希发生变化。合并前后行为范围核查见 [语言与种族分页合并记录](2.2.11语言与种族分页合并.md)。

正式包从最终提交的干净工作区生成：

```powershell
pwsh -File Scripts/New-Release.ps1 -Build `
  -ReferenceTargetsPath .builds/ritual-fix/LocalReferences.targets `
  -OutputDirectory Releases/Published/2.2.11
```

产物为 `RJW-SexSlaveCraft-TieJin-Modify-2.2.11.zip` 和相邻 `.zip.sha256`。ZIP 顶层为单一模组目录，包含完整运行资源和文档，不含源码、测试、PDB 或第三方 DLL。

包内 `RELEASE-MANIFEST.json` 记录最终提交、`workingTreeDirty: false`、`assemblyRebuilt: true` 及逐文件大小和 SHA-256。ZIP 整体哈希以随 Release 上传的 `.sha256` 为准；清单包含构建时间，因此再次打包的 ZIP 哈希可能不同。
