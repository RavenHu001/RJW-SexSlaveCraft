## 文档维护约定

- 玩家指南维护在根目录；玩家可见版本变化写入 `CHANGELOG.md`。
- 实现、修复及技术验证说明放入 `Docs/Development/`，开发日志集中在 [开发更新记录](Development/开发更新记录.md)。
- 未实现需求、设计及机制复盘放入 `Docs/Design/`；在正文中注明状态和检查基线。
- 发布说明和发布验证放入 `Docs/Releases/<版本号>/`，历史记录不改写成当前状态。
- 构建、打包与维护流程放入 `Docs/Maintenance/`；其中命令默认从仓库根目录执行。
- 测试与工具的 README 保留在所属目录；新增文档时同步本索引，使用相对链接。
- `Docs/Releases/` 存放发布文档，根目录 `Releases/` 存放本地发布产物。

打包脚本递归复制整个 `Docs` 目录，因此上述分类会随安装包保留。
