# 宠物亲昵后续事件实现与测试记录

记录日期：2026-10-06。实现基线：`codex/cat-dog-specialization` 分支、可见普通亲昵提交 `2188025`。本轮实现成功亲昵后的概率后续；自动验证与游戏目录同步完成后供维护者实机验收，本轮尚未收到实机确认。

## 游戏行为与参数

成功完成两秒亲昵后，先沿用原有记忆、当前普通猫 `0.01` 经验和一天完成冷却，再尝试一次后续。当前基线为 **20%**，普通及有效终极猫／狗相同，不随阶段增长；兔不参与此后续。概率未中、失格、权限拒绝或任务失败均保留已经完成的亲昵结果，不为同次亲昵再抽取。

配对固定为宠物发起、实际绑定主人接收；不寻找第三人或交换方向。双方须为同地图已生成且存活的人形角色，生理年龄至少18岁、发展阶段及 RJW 年龄类别均为 Adult，并且清醒、具有意识、未倒地、未征召、无精神状态或战斗。18岁条件避免原版 Teenager 也被发展阶段视为 Adult；较早成年的异族本轮仍采用此年龄下限。

RJW 自愿互动及快速互动开关、双方身体资格、近期互动与工作时段冷却、双向目标配对设置、欲求、忠诚和吸引力条件均参与检查。当前爱侣以及 RJW Wild/Hippie 模式按原有规则处理；其他固定配对须双方有欲求，忠诚条件沿用 RJW 的允许条件与既有例外。权限仍由 SSC 统一守卫按宠物→主人这一真实方向查询 Consensual，主人主动发起的特殊放行不适用于这里。

不增加额外配对／主人冷却或独立成长奖励。后续完成继续运行 RJW 的正常结算以及模组原有的普通互动结算钩子，不再次调用亲昵完成入口。

## 代码修改及影响

- [后续工具](../../Sexslavecraft/common/PetAffectionFollowupUtility.cs)负责固定配对资格、一次 `Rand.Chance(0.20f)`、统一许可预检与交接。使用公开 `AppraisalResult`、`FindBestResults` 和 `CasualHookupAllowedViaSettings`，只评估既定双方；RJW 内部吸引力可能使用带作用域的确定性种子，不调用全图找对象或额外概率选人。所有可能同步重入的检查／登记返回后重新核对原任务实例、编号和驱动。
- [亲昵驱动](../../Sexslavecraft/JobDriver/JobDriver_PetAffection.cs)增加持久化 `sscAffectionFollowupEvaluated`。成功结算后先保存已判定事实，再检查资格和概率；移交前撤销旧亲昵对等待的认领，使旧任务结束清理不会结束后续使用的等待。
- [后续驱动](../../Sexslavecraft/JobDriver/JobDriver_PetAffectionFollowup.cs)继承 RJW Quickie 并调用 `base.MakeNewToils()`，复用原版地点、移动、接收任务、互动和结算。开始前持续检查双方资格以及确切准备归属；任一方新工作或新增命令取消准备。专属 Start 补丁再次核对完整资格，Start 被任何前缀拒绝时中止本驱动的原初始化剩余语句；专属 End 补丁阻止尚未开始时读取空数据。场景真正开始后由原版正常收尾，不因绑定、欲求或冷却随后变化再次取消已开始场景。
- 原版 Quickie 地点准备调用 `StopAll()`。新驱动临时保管亲昵暂停的原空闲队列，回调结束后按原任务引用、顺序和 tag 恢复；登记的准备编号与本次新建接收任务编号均保存，取消仅撤销本次任务，不清空其他命令。
- [事件层](../../Sexslavecraft/common/Restrictions/SSCRestrictionJobEvents.cs)在已有枚举末尾追加 `PetAffection = 4`，保留旧存档数值。沿用实际 Start 后的一次提示及保存去重；准备或命中概率时不提示。准备工具和守卫增加确切归属的只读查询，并排除玩家强制任务；原生准备回调用 `finally` 认领新增准备，同步取消后晚创建的准备立即精确回收，异常继续传播，防止漏掉等待或误清玩家命令。这也保护现有共享该准备钩子的事件。
- 新增独立 `SSC_Job_PetAffectionFollowup` JobDef、四语任务报告和实际开始消息，并同步源码语言镜像。项目显式编入新工具和驱动，新增测试套件纳入统一测试清单。

新增及修改的影响游戏代码已添加代码块级职责注释。原普通亲昵、猫狗终极技能、凝胶配方、研究、被动数值与既有工作后事件分别保持自己的入口。

## 实机测试

1. 使用成年普通猫／狗及有效终极猫／狗，绑定同地图成年主人；启用 RJW 自愿与快速互动，确保双方具有欲求、身体条件、配对许可及冷却资格。在空闲、附近条件下完成亲昵，观察概率命中后沿用原版快速互动；真正开始时只有一条提示。20%不是每次必出，反复测试需等待一天亲昵完成冷却或使用调试工具重置。
2. 概率未中，或者 SSC 拒绝宠物发起自愿互动、RJW 开关关闭、双方无意愿、近期互动冷却未过时，亲昵仍应正常给予记忆和普通猫经验，双方恢复正常工作，不产生开始提示或强制替代任务。
3. 兔、非生效普通残留标签、错误绑定、未成年、动物／机械体、睡眠／无意识、倒地、精神状态、征召或战斗均不能进入后续。
4. 在后续准备中给任一方下新命令，或给主人追加排队命令，确认取消且保留新任务／队列；主人原先被亲昵暂停的空闲任务不会被 Quickie 清空。绑定更换、效果移除、冷却或权限改变也在真正开始前生效。
5. 分别在亲昵读条中、后续移动／等待中、接收任务创建后及实际互动中存读档，确认不重复奖励、重掷、强制等待或提示；取消后不留下本次等待／移动／接收任务。实际开始后的存档恢复沿用原版正常完成。
6. 与既有狗工作后事件、猫终极安抚、狗终极驯导分别测试，确认来源提示和经验互不误认。
