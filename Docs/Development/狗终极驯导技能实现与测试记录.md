日期：2026-10-05。分支：`codex/cat-dog-specialization`。实现基线为猫技能视觉修复提交 `2dfec48`。本轮按维护者“进行实现”的指令交付狗终极主动技能首版；维护者于 2026-10-05 反馈“以确认有效，提交”，确认首版有效并授权提交；未提供逐场景验收明细。

## 游戏行为变化

终极宠物狗获得“定向驯导”。玩家可以在同地图上选择一个无阵营动物，施放者追踪动物当前所在格，走至同格后进入原版 2 秒预热。预热期间目标暂停行动，显示进度条、原版训导社交符号和连续说话波纹；接近阶段没有预热、暂停或新冷却。完成后直接将目标驯服为玩家阵营动物，无需食物或额外材料，也不再进行成功率判定。成功释放后进入一天（`60000 tick`）冷却，征召与未征召时均可使用。

施放者必须属于玩家阵营、存活、已生成、未倒地、无精神状态并持有有效终极狗成果；终极成果独立于当前普通培养方向，不要求继续培养狗，也不额外要求绑定主人、SSC 身份或研究。选择目标要求同地图、存活、已生成、动物、无阵营、无精神状态、原版 `CanBeAwake` 意识合格，并通过原版 `TameUtility.CanTame`。普通睡眠可被原版预热唤醒；有足够意识的倒地动物不因倒地被单独排除。人形、机械体、已有阵营的动物、无意识对象、精神状态动物、原版不可驯服对象以及无法走到所在格的对象不能选。

合法目标显示原版选中圈、技能光标和“训导 {目标名}（走至同格后直接驯服）”提示。地图选择检查 `OnCell` 可达性，不要求短距离或直线视野；实际开始预热和生效时都必须处于同格。接近或预热中取消、目标离图、死亡、失去意识、进入精神状态、被其他施放者抢先驯服，或施放者失去资格时中断，不产生效果或新冷却。

首版只交付直接驯服分支。己方动物训练、群体训导、额外特化经验和技能后的工作事件留待后续确定；现有普通狗的动物训练／驯服尝试成长和终极被动数值保持。技能不调用既有普通狗工作通知，避免将一次主动驯服重复计入工作成长或触发工作后事件。

## 实现职责与游戏影响

- [狗技能工具](../../Sexslavecraft/common/PetDogAbilityUtility.cs)：统一终极资格、施放者、目标意识／精神状态、原版可驯服条件、地图可达及同格检查；实际结算使用原版 `InteractionWorker_RecruitAttempt.DoRecruit` 的动物成功驯服链路，保留原版阵营转换、命名、记录与反馈。读条结束时再次检查资格，避免两名施放者对同一动物重复结算。
- [技能激活](../../Sexslavecraft/Comps/Ability_PetDogTame.cs)与[效果组件](../../Sexslavecraft/Comps/CompAbilityEffect_PetDogTame.cs)：在原版激活扣冷却前检查当前技能归属、冷却与同格资格，要求恰好一个驯服效果组件；选择提示只描述接近流程，不提前视作成功驯服。原版成功接口没有返回值，效果以目标实际转换为玩家阵营确认成功；若第三方阻止转换，恢复本次新扣的冷却。
- [目标 Verb](../../Sexslavecraft/Comps/Verb_PetDogTame.cs)：地图选择／显示资格与实际同格命中分开；现继承原版 `Verb_CastAbilityTouch`，由原版绘制目标圈和鼠标附件，`IsApplicableTo` 接入完整选取资格，效果组件保留名字提示；预热和实际释放继续要求同格。后续复用优化及其独立验证见[猫狗目标选择复用记录](猫狗终极技能原版目标选择复用记录.md)。
- [施放任务](../../Sexslavecraft/JobDriver/JobDriver_PetDogTame.cs)：追踪动物引用进入同格，使用原版 `Toils_Combat.CastVerb` 预热／进度条与有限目标暂停；不增加第二段等待，不使用普通工作完成回调扣冷却。取消后清理本人预热，不主动删除目标其他来源眩晕；目标可能短暂保留原版有限暂停的剩余时间。
- [终极狗定义](../../Defs/HediffDefs/SSC_HediffDefs_PetSpecializations.xml)：新状态改用 `HediffWithComps`，在严重度至少 `0.01` 时由既有 `HediffComp_GiveAbility` 授予 `SSC_PetDogTame`；原有 `TameAnimalChance`、`TrainAnimalChance` 各 `+0.25` 不变。
- [旧档兼容](../../Sexslavecraft/Comps/Comp_Train.cs)：读档收尾与既有稀疏维护入口为旧存档的终极狗原普通 `Hediff` 实例幂等授予技能，不转换或删除原健康实例，不重建已有 Ability，不刷新冷却。这与本轮不增加旧档多终极冲突选择界面的约束相容。
- 人格冷却按绝对截止 tick 捕获、复制和恢复；提取后清除源身体的技能，存放／加工时间继续计入冷却。除[公共提取入口](../../Sexslavecraft/common/ExcretionUtility.cs)外，本轮同步补齐[真实人格提取任务](../../Sexslavecraft/JobDriver/JobDriver_PE.cs)的猫／狗技能清源，修复该任务原先未与公共入口对齐的猫技能残留。
- [技能资源](../../Defs/AbilityDefs/SSC_PetDogTame.xml)、[任务定义](../../Defs/JobDefs/SSC_PetDogTameJobDefs.xml)和[预热特效](../../Defs/EffecterDefs/SSC_PetDogTameEffects.xml)：只使用 Core 图标和原版绘制机制，不依赖 DLC、额外动画框架或新贴图。四语技能／任务／拒绝原因／目标提示与源码语言镜像同步。

原版图标来源已经在本机 Core 核对：按钮使用 `Trainables.xml` 的 `UI/Icons/Trainables/Tameness`；预热社交符号使用 `Interactions_Animal.xml` 的 `Things/Mote/SpeechSymbols/TrainAttempt`。持续特效使用 `Fleck_Special.xml` 的 `SpeechLines`，不使用猫技能的爱心。

## 实机测试步骤

更新运行文件后重启游戏。准备一名终极狗 A、普通野生动物 B、己方动物、其他阵营动物，以及第二名终极狗；另保留一个升级前已有终极狗的存档。

1. **正常驯服与提示**：A 在远处使用技能，悬停 B 应出现圈、正常技能光标与包含 B 名字的提示；选择后 A 追踪 B，走至同格才开始约 2 秒读条、训导气泡和说话波纹，B 暂停移动。完成后 B 直接成为己方动物，A 开始一天冷却，不消耗食物。分别在征召和未征召状态尝试。
2. **路径与移动**：隔着可绕行的墙仍可选择，A 能走到 B 当前所在格；完全封闭的目标不能选。让 B 在野外持续移动，应追踪 Pawn 当前位置，不在选择时的旧格子远程生效。
3. **非法目标**：己方／其他阵营动物、人形、机械体、无意识动物、精神状态动物与原版不可驯服动物不能选；这些目标不显示合法圈或提示。普通睡眠的可醒动物及有意识倒地动物仍可选，确认预热唤醒行为。
4. **取消与中途失格**：分别在走路和读条时取消，检查没有驯服、没有新冷却、没有旧回调稍后生效。读条中让 B 死亡、离图、失去意识、进入精神状态或取得其他阵营，或让 A 倒地、进入精神状态、失去终极成果，应中断。读条中开发模式移开任意一方，应中断且不隔格结算。
5. **竞争同一动物**：两名终极狗先后选择 B。第一名完成后第二名应停止，不能再次驯服、重复记录或消耗第二名新冷却；若第二名尚在远处，接近阶段也应识别目标阵营改变。
6. **旧档授予与成果资格**：载入升级前已有终极狗的存档，应获得技能、保留原被动及严重度。重复稀疏维护和存读档后只有一份技能，冷却不刷新。终极狗转练其他方向或明确留空仍可使用；只有普通狗状态或历史狗进度不会获得技能。
7. **存读档与人格迁移**：分别在行走、读条和冷却时存读档，检查不重复启动／结算。成功释放后进行真实人格提取：源身体不能残留技能；凝胶存放、加工并植入另一身体后，冷却按原绝对结束时间继续，不能重置为新一天或直接清零。另回归猫真实提取后的技能清源及冷却迁移。
8. **可见反馈与既有机制**：观察不同缩放下的圈、训导气泡和连续波纹；取消后不再生成波纹。技能不增加普通狗特色经验或触发工作后事件，原有普通动物工作、猫技能、猫亲昵经验、公共培养、宠物配方与兔禁用保持。
