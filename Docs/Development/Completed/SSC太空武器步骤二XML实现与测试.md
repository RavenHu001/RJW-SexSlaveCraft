| [太空伤害](../../../1.7/Defs/DemageDefs/SSC_PnaSpacerDamage.xml) | 3 个独立 DamageDef，共用步骤一太空投送处理器；不继承涂覆伤口门槛 |

| [形态控制研究](../../../1.7/Defs/ResearchDefs/SSC_PnaSpacerWeapons.xml) | 3000 点、Spacer，前置工业 PNA 武器＋精密装配；高科技研究台需多元分析仪，SSC 页签坐标 4／4.5 |

合计 11 个具体 Def，三件武器用 `recipeMaker` 交给原版生成 `Make_SSC_Weapon_PnaSilkWhip`、`Make_SSC_Weapon_PnaPulseGun`、`Make_SSC_Weapon_PnaProjectorGun`。未另外手写同名 RecipeDef。原生探针验证继承后的制作台、材料过滤及实际 `RecipeDefGenerator.SetIngredients` 的五项材料生成；完整账单执行仍待游戏验证。

材料、工作量、技能、质量、耐久和战斗参数严格采用[规划第 7 节](../../Design/Archive/SSC太空时代纳米催情液武器开发规划.md#7-已确认的步骤二-xml-方案)。三件武器只在制造时消耗浓缩 PNA，不增加余量、弹药、补液、运行燃料或电池状态，不投放 NPC／商人／圣物。

丝鞭仅一个纳米工作端，基础伤害 1、穿甲 60%、冷却 1.2 秒，保留品质及明确的品质伤害例外、命中评分 +3、文化 DLC 条件镇压 +0.20／恐怖来源 +15。通过专用 Verb、品质标记及有效太空伤害扩展使用已实现的工作端优先规则。两枪普通防身钝击为 9 伤害／2 秒，无 PNA，保留普通品质影响；普通钝击不享受纳米工作端的免伤或修复。

三个伤害扩展只有 `baseLoad` 与现有意识抗性记录引用；基线为 0.20／0.10／0.25，修复预算统一由步骤一代码推导为 1／0.5／1.25。主人保护、有效链绕普通护甲无伤吸收、普通目标判甲／转钝和每发独立修复均沿用既有代码，不新增生产 C# 或治疗状态。

## 实机验收清单与边界

1. 科技树形态控制的位置、3000 点及研究设施限制；研究后精密装配台出现三个配方，材料和技能分别符合规划。
2. 信息卡效力 20%／10%／25%，悬浮说明、四语和自动配方描述；丝鞭不同品质保持基础伤害不变，两枪普通防身仍为普通撞击。
3. 普通目标在各档护甲下的穿透／阻挡／转钝；有效链高护甲无伤活化与修复；主人免疫，人工部位不施药。
4. 连发三次独立投送及修复、满负荷仍修复、只选择一个最严重的合格伤势；护盾／掩体正常拦截，不向被挡目标投药或修复。
5. 占位图的装备方向、投射集群与尾迹、倒置紫心及临时声音；丝鞭本轮没有正式动画或额外命中特效。
