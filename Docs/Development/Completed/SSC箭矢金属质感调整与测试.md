## 资源与应用

以既有高清箭矢为输入，通过内置 image_gen 分别重绘箭头：均匀紫色覆盖，冷紫金属面、明确中脊、窄刃口反光；保留暖棕木杆。吹箭保留浅米色纤维尾塞，弩矢保留普通浅色尾羽，源图均箭头朝上。生成式编辑不宣称其他区域逐像素不变。

高清图在 `.builds/pna-projectiles/metal-head-v2/`；从高清图确定性等比缩放、透明居中导出精确 128×128 RGBA，Alpha 0～255。脚本、处理结果及前版 PNG 保存在其 `applied-128/Dart/`、`applied-128/Bolt/` 子目录。

替换 [SSC_PnaDart.png](../../../1.7/Textures/Things/Projectile/SSC_PnaDart.png) 和 [SSC_PnaBolt.png](../../../1.7/Textures/Things/Projectile/SSC_PnaBolt.png)，路径与 Def ID 不变。`SSC_Projectile_PnaDart` 的 drawSize 从 (0.6,0.6) 改为 (0.5,0.5)，弩矢保持 (0.6,0.6)。

本轮只应用独立飞行弹丸；吹箭筒下方备用箭与轻弩装填弩矢暂未回填新材质。武器本体、方向和显示参数不变，不修改伤害、穿甲、速度、PNA、C#／DLL 或版本。效力显示仍暂缓。

## 武器整体重绘应用与提交

维护者指出两件武器多轮修改后出现可见噪点，明确要求重绘。通过内置 image_gen，以既有紧凑结构、配色和两种新版紫色金属箭头为参考，分别重建吹箭筒及轻弩的轮廓、色块、材质明暗和绑带；减少细碎木纹及随机纹理。吹箭筒保留纤维尾塞和紫色浸染直筒口，轻弩保留普通尾羽和清楚的弩臂／弦结构，备用／装填箭采用新金属箭头表现。

维护者认可并要求应用回游戏及模组后提交。从高清重绘图等比导出 256×256 RGBA、Alpha 0～255，查看最终小图，替换两张武器 PNG；武器 drawSize=1 和角度配置不变。高清图位于 `.builds/pna-weapons/clean-redraw-v1/`，导出与前版备份在其 `applied-256/` 下。原先未回填本体图的描述保留为阶段历史，本批现已统一四张图。

保留独立投射物 128×128，吹箭 drawSize=0.5、弩矢 0.6；仅此前降低吹箭绘制尺寸的 XML 改动纳入本批，所有战斗与 PNA 参数不变。效力显示另行分析，不在本次实现。
