## 本批范围

首个能力为“欲望侵染”，默认关闭。当前主人可在原主人面板中操作，不要求缰绳、成长记录或永久资格；只读面板不创建这些记录。非玩家主人可以按保存偏好生效，玩家编辑权限单独检查。

本批只交付配置与状态闭环：**没有普通性交／Lovin 侵染收益，也没有把侵染加入来源吸引。** 既有普通产出者补给、训导官经验及 PNA 身体机制保持。维护者确定侵染已有成瘾基础 D+0.02、末期另加 0.20、合计 0.22，上限 1；这是第二批待实现参数，当前 PNA 预留分支基础仍为 0。

## 通用接入方式

| 职责 | 实现 |
| --- | --- |
| 独立保存容器 | `SSCAbilityToggleState`，字典保存稳定能力 ID 与 bool，保留明确 false 和未知键 |
| Pawn／凝胶组合 | `Comp_AbilityToggles.cs` 为两个现有 partial 组件增加独立容器和 Scribe 入口 |
| 定义与规则 | `SSCAbilityToggleDefinition` 声明 ID、Master／Slave 分组、当前身份、默认值、可选规则和标记；C# 注册表首项为 `SSC_MasterDesireInfestation` |
| 只读与写入 | `GetEnabled` 读偏好，`CanEdit` 判断操作权限，`IsActive` 判断实际状态，`TrySetEnabled` 复查组件与人格凭据 |
| 人格凭据 | `SSCPersonalityRuntimeUtility` 按 Pawn 保存运行时 token 和互斥流转作用域，不存档、不依赖训练组件 |
| 可选健康标记 | `Hediff_SSCToggleAbilityMarker` 共用可见性；`SSC_Hediff_MasterDesireInfestation` 提供首项文案，无属性加成 |
| 共用 UI | `ITab_SexSlaveTraining.AbilityToggles.cs` 按分组生成、测量、绘制和提交行；主人面板已显示侵染，性奴区域为已注册 Slave 定义自动留出实测高度 |
| 生命周期 | 提取／清理／植入／新克隆共用接口，载入一次同步；空壳增删、死亡、成功复活由窄范围事件补丁同步 |

保存路径为 `sscAbilityToggles/enabledById`；Pawn 与凝胶的容器互相独立。未增加 `masterDesireInfestationEnabled` 或实际生效状态的第二份保存值。旧档缺容器按能力默认值查询，侵染为 false。能力 ID 发布后保持稳定；以后调整默认值时须单独审查旧档语义。

新增同类能力的步骤：注册唯一 ID、UI 分组／身份、四语键、默认值及可选规则／标记，在实际事件中调用 `IsActive`。公共凝胶和人格入口不再按能力逐个增加布尔字段。现有缰绳伤害分担、排程、产奶等开关继续使用原载体；本框架首版只管理随人格流转的个人能力偏好。

## 生命周期与回调边界

- 查询偏好不等于查询生效；退出主人后偏好保留，标记移除，返回主人按原值重建。
- 两条提取路径先进入人格作用域，采集原始偏好；正常生成凝胶后才清源。缺失存储组件提前停止剥离。两条路径原来的整体操作顺序不同，作用域不声称提供全套人格事务回滚。
- 植入预检先检查宿主能否保存非空开关配置；失败不移除空壳、不消耗凝胶、不更换人格 token。通过后在首次移除空壳之前开始作用域，内部清理共享外层作用域，避免外部重入。
- 植入完整替换宿主配置，来源关闭覆盖宿主开启；恢复期间所有能力暂停。最终身体 PNA 协调仍使用宿主当前身体与身份规则，结束作用域后同步标记。
- 新克隆在准备阶段清来源偏好和标记；成熟只过滤来源标记，保留自身后来独立取得的配置和标记。
- 通用 hediffTags 的采集、复制和恢复均过滤能力标记；克隆也在宽泛 SSC 前缀匹配前排除标记。
- 标记的原生健康实例不是偏好真值。同步去重复、清关闭残留，健康回调重入合并为有界重评估；不增加 tick 全地图扫描。
- 人格 token 在替换开始时失效，旧 UI 请求即使面对同一 Comp、相同主人身份和相同布尔值也不能提交。已有伤害分担面板的迟到点击同样加入 token 核验。
