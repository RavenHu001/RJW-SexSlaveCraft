## P0 人格切换与绑定关系

先记录身体固定名称／编号，避免改名后把身体与人格混淆。对每项，在提取前、提取完成、植入完成、运行一段时间以及保存重载后，分别检查双方。

| 记录对象 | 操作前必须记下 | 操作后比较 |
| --- | --- | --- |
| 性奴身体 | SSC身份、印记、锁链主人、锁链阶段／严重度 | 主人指向和锁链进度是否变化，是否消失或重复 |
| 主人身体 | SSC身份、印记、缰绳中的性奴名单 | 名单是否增减，是否出现空缰绳或重复目标 |
| 对端角色 | 对应主人／性奴关系 | 两端是否一致，不能只看其中一端 |

- [ ] **B01 主人提取与植入**：让持主人态印记、已有绑定性奴的主人走正常人格提取，再植入可用的另一人格。分别检查提取和植入两个阶段；原性奴仍指向同一身体，该身体缰绳名单保留。人格印记按来源更换，不借此拆除绑定。
- [ ] **B02 已绑定性奴同体恢复**：S绑定M1，提取后再把原凝胶植回同一身体。每个阶段均不得额外丢链、换主或重置锁链进度；仅最终又显示M1不足以证明中间没有副作用。
- [ ] **B03 接收身体与来源主人不同**：接收身体原绑定M1，来源凝胶来自绑定M2的另一性奴。植入后接收身体仍绑定M1，不能被凝胶旧主覆盖；M1、M2双方名单同时核对。
- [ ] **B04 无绑定来源植入已绑定身体**：给原绑定M1的接收身体植入无绑定来源人格。原绑定不得因来源缺少锁链而被清除。
- [ ] **B05 方向不同的人格**：给有主人侧绑定的身体换入性奴态／无印记人格，另检查有受方锁链的身体换入主人态。绑定不得被当作身份恢复的障碍而自动拆除；合法植入若直接失败，也记录失败原因，不手动解绑后宣称通过。
- [ ] **B06 无关关系与重载**：以上任一成功切换后，检查同地图无关主从对、指定调教师及原有开关是否受影响，再保存、退回主菜单重载。不得延迟清除关系或出现一端仍绑定、另一端已丢失的情况。

出现凝胶已消耗但植入失败、旧人格已清却来源未恢复、关系单边残留时，保留当时存档和日志，停止继续覆盖该现场。

## P0 永久身份锁

- [ ] **L01 主人态**：已有和没有绑定性奴时都尝试改性奴或未选择；均拒绝。主动解绑最后一名性奴后，主人态与主人锁仍在。

- [ ] **L03 初始态**：不产生额外永久方向锁；已有普通绑定锁仍按原规则生效。选择身份本身不分化。

- [ ] **M03 跨体覆盖**：先用无绑定身体测试三态迁入；原宿主的不同印记被来源精确替换，不共存、不取较高阶段。无印记来源不得继承宿主旧印记，初始来源不得继承宿主原永久锁。
- [ ] **M04 资格独立**：迁移后核对永久主人资格与印记分别恢复，性奴态不凭空授主人资格；移出印记不反算已发生的回春。
- [ ] **G01 两处显示**：凝胶选中检查文字和人格卡均显示正确印记及锁；初始态显示未定型，无印记者显示无印记。印记不显示成“培养100%”。
