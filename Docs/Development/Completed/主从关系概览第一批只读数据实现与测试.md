## 实现与调用契约

| 生产文件 | 职责 |
| --- | --- |
| [SSCBondOverviewModel.cs](../../../Sexslavecraft/common/SSCBondOverviewModel.cs) | 不可变快照、两种关系方向、计数、阶段、特化、次级指派与位置事实 |
| [SSCBondOverviewUtility.cs](../../../Sexslavecraft/common/SSCBondOverviewUtility.cs) | 查询准入、锁链筛选、按引用去重、排序及旧行关系复查 |
| [SSCBondOverviewWorld.cs](../../../Sexslavecraft/common/SSCBondOverviewWorld.cs) | 原版集合物化、地图／世界容器／飞船候选补充及位置分类 |

公开入口为 `SSCBondOverviewUtility.Build(source, viewedMap)`。查询要求当前游戏处于 Playing、Scribe 未加载或保存、两种绑定定义可用；暂停仍属于 Playing，不依赖健康 Tick。来源为空、销毁或丢弃返回 InvalidSource；游戏或定义未就绪返回 Unavailable，不把暂时不可查询误报为无绑定。死亡来源可读取，第二批另行约束地图入口。

性奴侧锁链是唯一归属依据。来源的主人状态区分 NoChain、InvalidTarget、Bound 和 Unavailable；有链但目标为空、非 Pawn、自身、销毁或丢弃时均为 InvalidTarget。死亡不导致绑定失效。身份未选择或训练组件缺失，不阻止读取实际关系。

主人候选来自缰绳原始条目的副本、现有 AllPawns 独立快照、已加载地图的尸体及其容器、可访问世界对象持有树、当前及世界列表中飞船的运输字典。最后统一读取候选锁链，按 Pawn 引用去重，过滤空、自指、销毁和丢弃对象。只保留直接绑定，不递归展开关系图。

计数和顺序来自同一份只读集合。顺序为当前查看地图的存活对象、其他位置的存活对象、死亡对象，组内按姓名的 OrdinalIgnoreCase 顺序及 `thingIDNumber` 排列。位置、姓名、死亡状态、特化和锁链阶段均在构建时捕获；阶段复用 `GetSexSlaveStageFromChain`，不新增阈值或按主人身份抹去已有锁链阶段。

指定调教员保留为独立的 AssignedTrainer 和状态：None、Active、Inactive、InvalidTarget、Unavailable。状态读取原始指派与已有只读有效性入口，不清空失效指派，也不参与主人条目或绑定计数。

位置 Kind 区分 Map、MapContainer、Caravan、Transport、WorldObject、WorldTile 和 Unknown，另外保留地图、实际位置主体、外层已生成容器或世界对象引用。死亡时优先用现存尸体作为位置主体；未生成不等于失踪。ParentHolder 分类有引用循环保护。这里仅描述位置，不承诺能跳转或选中 Pawn。

`IsCurrent(snapshot, entry)` 只轻量复查行所属快照、游戏实例、来源与两端有效性及当前锁链归属。同主的新链替换继续有效，解绑、换主、离体删链、无效对象、加载中或切换游戏实例均拒绝旧行。行归属检查使用快照内部 HashSet，不逐行扫描整个列表。该入口不保证姓名、死亡或位置字段仍新鲜，显示变化需重新 Build，实际导航仍须第二批实时检查。

本批不接入定时刷新和静态 Pawn 缓存；快照由未来视图持有并释放。没有 Scribe、人格存储、修复或维护入口，隐藏界面也不会运行新增周期扫描。

## 原版取证与覆盖修正

取证目标为 `D:/STEAM/steamapps/common/RimWorld/Assembly-CSharp.dll`：**1.7.4981 rev136**，SHA-256 `eb0826b85af430d13962e5c097ef53d869cf6a031656fb6a3673168a761c9f23`，MVID `f1e6382600a84191bbc6d8a184fd6b57`；Version.txt 与当前 Player.log 头一致。

- `MapPawns.AllPawnsUnspawned` 递归取得 Pawn 后会移除死亡对象。`PawnsFinder` 的 AliveOrDead 集合补入世界死亡及临时集合，不能单凭名称视为所有地图尸体的全集。
- 地图尸体补充使用已核对的 `ThingOwnerUtility.GetAllThingsRecursively<Corpse>(Map, ThingRequest, List<Corpse>, ...)`，同时取得已生成和容器内对象；世界持有树使用其 IThingHolder 重载，输出集合立即消费。
- `Gravship` 自身不是 IThingHolder，Things 与 Pawns 来自运输字典的 Keys；另外读取 Things 及其中容器，避免遗漏货物尸体。
- `Pawn.Corpse` 读取 ParentHolder 中的 Corpse；位置分类参考原版持有链的事实，不复制原版导航代码，也不在本批调用 CameraJumper。

覆盖限于当前存档可枚举或仍被反向索引引用的对象；不恢复已经丢弃、销毁或无法通过任何受支持引用到达的角色。原版接口静态核对与模型通过，不等于真实游戏全部容器已验收。
