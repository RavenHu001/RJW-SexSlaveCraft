# 训导官特化阶段 4 开发记录

日期：2026-09-24。范围：调教员任职、特化限制强制条目、旧档迁移，以及这些入口所需的最低限度开关反馈。

## 已实现

- `SSCIdentityUtility.IsTrainer` 对主人维持固定资格；性奴必须开启个人选择、满足持续条件，且当前训导官普通进度达到 20% 或拥有有效终极状态，才能任职。开启操作再次核对资格，关闭操作允许在失格后清除保存选择。状态查询只读。
- 新增独立的 `HasActiveRestrictionEffect`。当前选中训导官方向且持续条件有效时，两项主动行为强制条目从零进度起生效；有效终极可跨方向生效。终极禁用标记优先排除，失去身份、自由殖民者状态、主人绑定或锁链阶段时立即失效，不等待低频维护。
- 限制 Profile 只声明 `consensualInitiation=Allow` 和 `forcedInitiation=Allow`，不设置个人默认或其他强制项。沿用装备强制、特化强制、个人保存值的现有优先级；接收方许可和任务原有条件继续分别检查。限制栏来源显示四语“训导官”名称。
- 工作候选先比较目标指派并排除无效目标，再查询训导官资格；无有效任职身份时自动工作不遍历地图目标。仪式、调教许可、指派和同床继续通过原有统一入口读取有效任职。
- 新增独立的 Pawn 迁移版本。旧指派身份迁移先运行，旧性奴的个人调教员选择随后仅关闭一次；不清除指派、绑定、进度和主人固定资格。新角色与兔子克隆使用当前版本。
- 开关显示保存的个人选择；失格但此前已开启时标明当前未任职，并允许关闭该选择。阶段 5 再补全特化选择菜单、细分失格原因与整体界面反馈。

## 验证

- 训导官身份、工作、仪式与限制解析直接链接生产源码的模型用例，覆盖零进度强制效果、20% 任职门槛、终极跨方向、禁用与失格即时排除、个人选择保留、目标接收许可、装备与总开关优先级、旧档缺字段及重复迁移。
- 同床套件验证保存开启但资格失效时，新增同床许可及调教员标签立即消失，资格恢复后随个人选择重新生效。
