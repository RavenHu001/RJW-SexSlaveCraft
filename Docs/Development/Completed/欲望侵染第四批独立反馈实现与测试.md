## 替换、期限和回调

`SSC_DesireInfestation_Mood` 持续 1 天，全局一份；不分施加者或档位，新反应替换旧反应并从年龄零开始。`SSC_DesireInfestation_Opinion` 持续 3 天，每位实际主人一份、共最多三位；按 Pawn 引用隔离，同名人物不会串组，第四位由原版移除年龄最老的记录。同一主人新档偏移为零时清旧记忆但不添加零实例。

好感沿用并显式配置原版 `lerpOpinionToZeroAfterDurationPct=0.7`：前约 2.1 天保持初值，最后约 0.9 天逐渐衰减。实际过期由引擎记忆更新处理；不是三天内始终固定 +5／-5／+10。心情未启用线性衰减。

每种记忆先验证 Def、阶段、类型、有限数值及原生可获得性，非零社交还验证施加者发育阶段筛选，再创建新实例；通过预检后才清理旧记忆。只收集本 Def 的旧实例，社交再限定实际 source；逐条调用 `RemoveMemory`，创建／移除／添加之间复查原完成上下文、人格 token、需求与记忆容器。失效立即停止，已消费认领不回滚、不重放。一个可选记忆分量异常只记录警告，不阻断另一个仍合法的分量。

人格记忆沿用 `PersonalityMemoryUtility` 的阶段、年龄、倍率、对象及社交偏移保存／复制／恢复；没有新格式版本。自动测试会重建独立实例验证字段往返，不等于完成真实游戏 XML 存档与所有第三方兼容测试。

## 原实机测试步骤（保留作复测参考）

以下为交付时的检查建议，不将每项分别补记为独立专项通过。

建议完全重启游戏后使用测试存档，开启一位当前主人的“欲望侵染”。观察本批独立思绪／社交条目，RJW 自身及旧 SSC 条目仍可同时存在。

1. **四档数值与文案。** 准备当前恶堕约 10%／40%、对实际施加者当前好感为正／负的四组对象，完成一次普通双人行为，按上表检查。高档选有合适锁链阶段的角色或专用测试存档；新评分无链自然上限 12%，不要求靠侵染自然升到 30%。以当前需求与当前社交页为准，不能只看历史最高或基础关系。
2. **同一主人重复与跨档。** 同档重复两三次，只保留一份侵染心情和该主人的一份社交反馈，期限刷新而非累加。改变当前 C/O 后再完成一次，旧档被替换。特别检查第 3 档：心情 +4，该主人的旧正／负侵染好感均清除，没有零偏移新条目。
3. **实际主人与多人。** 主人在行为两端分别测试；目标绑定给另一位主人时，社交反馈仍归实际施加者。条件允许时让四位开启能力的主人先后参与，确认最多三位的社交记忆、心情仍全局一份；刷新某人后，该人的记录应更新淘汰顺序。
4. **完成入口与独立分量。** 普通 RJW、获原许可的强迫行为及可用的原版 Lovin 各完成一次。相同 C/O 的独立侵染反馈一致，RJW 自身反馈允许不同。无部位研究、无可靠部位或开发已满仍有反馈；Lovin 没有部位开发。中断／取消不发新侵染记忆。
5. **期限与关闭。** 一天后心情到期；社交约 2.1 天后开始变弱、约三天后到期。关闭开关后完成新行为不刷新，旧记忆按剩余期限消退。重复接触会刷新，因此观察期限时停止后续接触。
6. **存读档和人格。** 已有反馈时存读档，检查档位、实际主人和剩余期限；进行中任务存读档后完成，只领取一次。条件允许时测试人格采集、凝胶复制／植入，确认记忆不重置为完整期限，新场反馈仍能跨档替换。
7. **豁免与排除。** 双方主人、开关关闭，以及日常调教、仪式、自我调教、人格排泄、单人行为不产生本批新记忆；原流程自身的合法反馈照常出现。检查日志没有新的空引用、Def 加载或思绪错误。

RimTalk 可额外观察实际思绪上下文，但本批没有专用适配，不凭游戏思绪可见就宣布模型一定读取。长期培养速度、全模组组合和四语所有显示仍由实际观察确认。
