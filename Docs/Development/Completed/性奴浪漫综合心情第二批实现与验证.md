## 2. 原生准入、替换刷新和回执

`SSCRomanceMoodRequest` 在工厂和准入回调前捕获原 Pawn、人格 token、Comp、心情需求、处理器和上下文独立副本。一次请求只能 `Execute` 一次；相同分支的两个真实事件各建请求，不能用分支 ID 去重事件。该基础设施不证明真实互动已经发生，第三批仍须提供自己的完成证据与帧去重。

非零候选经过原版 `TryGainMemory` 的 `CanGetThought`。进入生产合并后复查原载体、完整冻结快照和载体副作用契约；所有强弱、期限和虚方法读取后再次复查。先将本候选加入列表，再移除本语义组旧条目；这段局部提交不调用有外部回调的处理器方法，也不重放原生调用。

- 短期负面优先；同号同等或更强才替换并重计三天；正面不能覆盖或延长负面。
- 长期只接受负面；更强重计新事件完整二十五／三十天，同强取新旧较晚到期，较弱完全不动。
- 零值不创建、不刷新；实际新事件同强度可更新独立分支背景，不增加容量。
- 比较冻结基准，不读显示倍率、实例偏移、衰减或思想屏蔽后的值。
- 标准期限仍在 `NominalDurationTicks`，保留的实际期限仍在原生 `durationTicksOverride`；不把历史二十九天缩回标准二十五天。

`SSCRomanceMoodResult` 区分 Added、Replaced、Refreshed、Kept、Zero、NotAdmitted、InvalidContext、InvalidData、Conflict、Duplicate 和 Failed。`Applied` 仅实际新增／替换／刷新；`Completed` 另含正常较弱阻挡及有效零值，技术失败不伪装成正常容量阻挡。回执包含组、旧／新冻结值和实际剩余期限；永久历史保留时剩余期限以 −1 表示。

原生返回后验证实际成员、owner、冻结字段、组容量及期限。后置补丁删除候选、改写载荷／年龄／Def／owner、抛异常，均不能报告已获得。失败只撤销本请求创建的唯一实例；原载体有效、无后来同组事件且旧实例未被外部改写时，才恢复原条目。人格已换、后来事件已经接管或其他系统有合法副作用时，不整体回滚列表、不把旧历史搬入新人格。

旧实时事件仍由原 Award 发放旧 Def，合并共享上述语义；新 Request 尚未接入实际 worker。原版心情替换没有在第二批提前启用。

## 3. 三种历史路径

| 路径 | 实现 |
| --- | --- |
| 正常读档 | 原生还原列表及 owner，处理器 PostLoadInit 后局部整理；不调用新事件发放 |
| 人格植入 | 来源列表先独立复制，核对原 token／Comp／需求／处理器；SSC 历史经原版 CanGetThought 后直接还原实例，整批末尾统一整理 |
| 原版克隆 | 实际 CopyNeeds 调用 CopyFrom 后直接 Add，不经过 TryGainMemory；复制前后核对新身体原上下文，完成后清临时标记并整理副本 |

人格历史使用独立入口，不回放 Renew、thoughtToMake、replaceThoughts、气泡或逐条新事件容量淘汰；非 SSC 记忆保留原恢复流程，非 1.7 条件分支保持原样。恢复处于合法人格替换作用域中不被一概拒绝，只检查原作用域对应的 token 和实例仍有效。工厂返回的 Def／类型也需匹配保存载体。

可解释混合历史按短期负面优先及同号强度／长期更负优先保留整条记录；同强取较晚到期，完全相同时按保存 Def、分支、对象和实例事实的固定键排序。保留获选记录的原年龄、实际期限、倍率、偏移及背景，不把不同历史拼成新记录。期限边界沿原版 `ShouldDiscard` 的 `age > DurationTicks`。

**未知未来格式的保护例外：** 某组存在不可安全读取基准的载荷时，整组历史暂不做破坏性整理，允许保留超过一条原证据。必须先恢复整批才检查，六种排列都不能先删已知条目。新的 Request 在进入原生容量清理前返回 Conflict，避免原生按 Def 上限淘汰未知历史；不将这种技术阻断算作正常综合结算。此例外不产生新叠加奖励，不猜配未来分支。兼容的直接 CopyFrom 单条领取仍可恢复，但完整克隆以实际 CopyNeeds 收尾路径为准。

## 4. 人格、凝胶及克隆边界

普通采集／凝胶加工副本／植入保留历史值、完整分支、年龄、实际期限、原对象及历史主人；owner 绑定接收身体。宿主旧人格历史按原完整覆盖流程替换，来源快照与副本不共享可写 Data；来源配置仍在成功提取后清除，植入精确恢复来源选择。

### 7.1 复现与修复

| 边界 | 原问题 | 最终处理 |
| --- | --- | --- |
| 回调嵌套事件与撤销 | 准入回调先完成另一事件后，外层失败可能恢复到调用前更老历史；未提交也可能复活外部主动清理的条目 | 合并时保存实际观察记录，真正写入前保存精确移除记录；撤销只恢复本次确实移除的完整实例。正常 Kept 回执也以实际合并时记录作见证 |
| 历史第二次准入及工厂 | 保存载荷安装后的思想准入回调还能修改数值／年龄／Def；工厂替换强制阶段未拒绝 | 准入前冻结完整实例，返回后复查载体和全部保存字段；工厂返回必须匹配应恢复的阶段，不能把回调改值当成历史 |
| 原生剩余容量流程 | 技术 Conflict 后原生仍按 Def 淘汰条目，准入期间新到的未知历史可能丢失 | 在已取证的唯一 TryMerge 调用后加入 SSC 限定的早退：原生思想准入、人物绑定及生产合并保留，SSC 已处理则不再二次清容量／创建关联思想。其他思想完整执行原生尾部 |
| 克隆上下文失效和异常 | 真实 CopyNeeds 完成后若原上下文已失效，收尾会跳过，CopyFrom 临时历史领取标记可能残留 | CopyNeeds 调用栈显式进入临时复制模式，其中的 CopyFrom 不留单条领取标记；Finalizer 在正常／跳过／异常时释放嵌套深度。正常单条 CopyFrom 兼容路径仍保留 |
| 原生省略 thoughtClass | 原生 ThoughtClass 会在字段为空时推导记忆类型，直接比较字段可能跳过普通原版历史 | 恢复校验改用原生解析后的 ThoughtClass；增加真实默认类型恢复测试，并同步人格模型的 API 边界 |

原生限定早退仅适用四个 SSC 载体且已实际执行生产合并的实例，不拦截原版父社交记忆或其心情子记忆。唯一锚点缺失／重复、原分支不支持或存在外部异常区时返回原 IL，新 Request 技术拒绝；还核对补丁实际登记，动态卸载不能沿缓存继续放行。原版父思想重复获得仍会创建／续期子思想，已有原版共存断言继续通过。

临时观察／撤销记录、复制深度、领取模式和回执不进入 Scribe 或人格载荷。克隆原上下文失效时不整理接管者历史，异常也不影响下一次合法单条恢复；人格仍按已确认流程迁移，克隆默认及成熟边界不变。
