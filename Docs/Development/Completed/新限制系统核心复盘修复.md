# 新限制系统核心复盘修复

开发日期：2026-09-21。基于 `9b8c8a5`，修复核心复盘发现的异常诊断和接口问题，并降低规则解析分配。保留阶段 1 / 最小测试界面的范围，不接管实际任务，不改版本号。

## 修复与约定

- **错误来源保持准确**：特化层出现非法条目时立即返回，不再继续由装备层覆盖错误来源。错误结果包含非法值、条目及定义名；同层多个非法来源按 Ordinal 定义名稳定选择。
- **保存配置统一整份校验**：`SSCRestrictionConfig.IsValid()` 统一检查版本、规则对象及六项保存值。某一项损坏时，需要读取该角色配置的请求返回 `ConfigurationInvalid`，编辑入口同样拒绝修改；不静默重置。
- **最高许可与用途边界保留**：实际主人对自身绑定目标的请求仍最先放行，总开关关闭仍先于配置校验。独立调教只检查接收者，不读取发起者的无关配置；首次绑定准备仍采用自身资格检查。文件覆盖仍按本次所需条目解析，不因无关覆盖条目的错误而扩大限制。
- **方向必须明确**：`SSCRestrictionRequest` 不再默认声称方向已确认，调用方必须传入 `directionKnown`。界面和开发预览明确提供实际方向；用途显式分派，未实现的用途不会自动按普通自愿处理。
- **初始化失败不留半成品**：`TryCreateInitialConfiguration` 替代原创建工厂；失败返回 `config=null` 及具体错误条目，非法默认不再作为预期异常抛出。全局默认模板和特化默认具有独立来源名称，不会混称个体保存值或特化强制。
- **编辑失败可诊断**：`TryInitialize(pawn, out error)` 只有全部默认校验成功才写入角色；已有配置与不适用角色保持原样。已有配置或不适用导致的失败不产生默认错误条目，界面按原有状态变化提示处理。

这些调整没有改变有效配置的六项许可、装备高于特化的优先级、同层取最严格值的规则，也没有修改存档字段或触发自动迁移。

## 解析分配优化

移除每次查询的 LINQ 管道、临时 `Entry` 对象及同层排序。改用值类型累积器单遍比较严格程度和定义名，忽略没有强制条目的装备；在一次查询内复用特化选择和巴士状态读取，不跨查询缓存。装备、绑定或开关改变后，下次查询仍读取当前状态。

条目校验改用显式规则目录，避免高频 `Enum.IsDefined` 的反射和装箱；目录完整性由测试约束。

同机 .NET 9 边界模型、相同已构造请求、预热后执行 100,000 次的线程分配如下。测量包含测试边界的装备扩展查询，不代表 Unity 实机帧率或耗时。

| 场景 | 优化前约 B/次 | 优化后约 B/次 |
| --- | ---: | ---: |
| 一项巴士特化，无装备 | 896 | 88 |
| 一项巴士特化，六件普通装备 | 1,688 | 376 |
| 上述场景再增加一件强制装备 | 1,856 | 464 |
| 主人直接放行 | 40 | 40 |

复盘基准位于本机 `.builds/restriction-review/`，本轮结果位于 `.builds/restriction-core-optimization/benchmark.txt`。

## 验证与测试边界

真实游戏程序集的 Release 编译通过，核心回归 80/80、统一验证 16 套共 470/470 通过。报告位于本机 `.builds/restriction-core-optimization/validation-final/summary.json`。新增覆盖错误来源、多特化冲突与稀疏合成、整份保存配置损坏、初始化失败无写入、方向显式声明、全部用途映射、规则目录完整性及未知条目拒绝。

测试夹具读取所有实际规则 XML，按 `defName` 找到公交车定义，不再假定只有一份特化。每例创建独立可变定义对象；加载异常计入失败汇总。中英文诊断键及源码镜像一致性也纳入验证。

本轮没有自动初始化/迁移、协调指定者或切换实际任务。游戏内继续使用 **Mod 设置 → SexSlaveCraft 设置 → 旧版保护选项末尾的行为限制测试入口**。已同步本机游戏 mod 目录，覆盖前备份并核对哈希；维护者确认无问题后授权提交。该确认不扩展为所有真实存档往返场景均已验证。
