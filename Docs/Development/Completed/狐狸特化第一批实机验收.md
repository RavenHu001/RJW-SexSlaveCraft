# 狐狸特化第一批实机验收

本批归入 **2.4.10 开发版**。[版本验证](../../Releases/2.4.10/2.4.10版本验证.md)

**2026-11-09 · 实机验收通过。** 维护者按第一批清单测试后反馈均无问题，关闭本批实机验收。受测版本为本机同步的 **RimWorld 1.7.5000 rev1275** 开发版，源码提交 `14560586`，构建提交 `c20eecb1`。

验收范围包括中世纪研究及选择入口、研究台与对他人护理的培养结算、自疗与扫描的排除、20%／50%／终极三个档位的科研和护理加成，以及人格凝胶提取、雕刻台终极加工、植入和四种宠物终极互斥。终极狐转练组外方向后继续保有被动。

构建、自动回归及实机检查项见[第一批验证](../../Design/Archive/狐狸特化开发规划.md#第一批验证)。主动技能「应急包扎」及图标见[第二批实机验收](狐狸特化第二批实机验收.md)。
