## 共用范围

新增 [SSCPnaWeaponDoseUtility.cs](../../../Sexslavecraft/common/SSCPnaWeaponDoseUtility.cs)，由两种入口调用：

| 工具 | 作用 |
| --- | --- |
| `Capture` | 只读获取既有抗性快照或当前意识，返回一次调用的只读样本；不创建记录、不协调身体。 |
| `FromSeverity`／`FromLoad` | 共享除数校验、抗性修正与单次上限计算；分别接收旧枪的原始严重度和涂覆武器的归一化负荷。 |
| `StoreSnapshot` | 按调用方的抗性兼容策略写入快照；不决定目标准入、物理伤害、治疗或药效触发时点。 |
| `RemoveUnusedSnapshot` | 仅移除调用方持有的未使用新快照，不清理既有或其他独立命中建立的记录。 |

`SSCPnaWeaponResistanceSample` 为局部只读结构，不增加全局／按 tick 缓存或存档字段。`SSCPnaWeaponResistancePolicy` 只保留两种入口原有的抗性兼容差异，不将物理入口合并为一个处理器。

## 旧发射器行为保留

[DamageWorker_PNA.cs](../../../Archive/PnaSimpleLauncher/DamageWorker_PNA.cs) 仅替换低阶入口内部的抗性／剂量片段；一次输入认领、`FinishHit`、高阶兼容入口及各自物理分支保持原代码。

旧枪仍在原部位回调中认领一次输入，先刷新身体与检查主人免疫，再取样、保存快照、输入药效，最后进入固定创伤或有效链无伤／治疗分支。普通创伤、每部位治疗、活化反馈、同 tick 独立输入、传播与嵌套保护保持原有语义。

以下顺序也保留：

- 旧枪的新快照先 `AddHediff`，之后设置意识严重度。加入回调仍能观察 Def 初始值，回调内的嵌套命中仍可能读取该初值；本轮不将其提前初始化为涂覆武器的方式。
- 旧枪仍按“原始严重度除抗性 → 上限 1 → 除以满值 2”计算，保持运算顺序，不先换算再计算。基础 `0.15` 在意识 100% 时仍输入约 7.5 个百分点。
- 旧枪保留 `Mathf.Max` 和非有限意识读数的历史处理顺序；配置异常的处理时点也不顺带改为涂覆入口的预先拒绝。

共享 `SSCPnaExposureUtility` 未修改，既有发射器及 PNA 资源 XML、旧配置字段和存档类型均不迁移。高阶固定剂量入口不改用低阶单次上限计算。

## 涂覆入口行为保留

[DamageWorker_SSCPnaCoated.cs](../../../Sexslavecraft/DamageWorker/DamageWorker_SSCPnaCoated.cs) 仍在物理处理前只读锁定意识，执行通用物理伤害并确认本次实际开放伤口后才提交快照与药效；伤口及自然／人工部位检查方法保持原代码。

新快照先设置完整严重度再加入；提交前复查已有快照，不覆盖物理处理期间嵌套命中建立的记录。回调使伤口或身份失效时，仅清本次未使用的新快照。药量与外层候选不因内层命中重新计算。

涂覆武器继续使用归一化 `baseLoad`，单次最多 0.5；非法药量／缺配置只禁用药效。非有限意识读数用除数 1，不新建非法快照。两种入口的配置尺度和物理准入仍有明确区别。

## 回归与基线对照

新增 [WeaponDoseUtilityTests.cs](../../../Tests/PnaLoad/WeaponDoseUtilityTests.cs) **32 项**。既有 417 项及本轮新增用例共 **449/449** 通过，覆盖两尺度等值、只读取样、大数换算、既有快照复用、提交／清理及跨入口使用同一抗性记录。

旧枪特征用例另外核对：快照加入和严重度赋值顺序、回调移除快照、回调修改基础量或切换主人、初值回调内嵌套命中的剂量、异常意识／基础量及药效早于物理创伤的时序。

同一组当前测试也对提交 `6908447` 的原生产处理器运行，结果为 **449/449**。隔离宿主与原源码位于 `.builds/pna-weapon-dose-shared/baseline-host/`、`baseline-source/`；新增工具只为直接工具用例链接，原处理器不调用它。对照不复制一份旧算法当作测试预期，也不代表所有第三方回调组合或游戏内行为已经实测。
