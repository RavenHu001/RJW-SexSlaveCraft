## 本批已实现

- 沿用 `Hediff_PNA_Debuff`、原始严重度上限 2 与 `HediffWithComps`。五档起点为 0／0.30／0.80／1.40／1.94，健康页百分比显示 `L=S/2`。采用规划第 4 节阶段属性作为测试初值，删除旧普通负荷持续 +5／+8 心情效果。
- `SSCPnaMath` 使用基础＋比例慢性清除及末期分段快速清除；原始严重度 <=0.01 时结束负荷。只由负荷组件累计原生健康更新的有效 delta，150 ticks 分批写回；输入前结算不足一批的已累计时间。
- 组件仅保存不足一批的有效时间 `sscPnaPendingTicks`，不保存全局补算时钟或另一份负荷。冷冻／任务保留等 Suspended 状态不推进；恢复时不补算停止健康更新期间的全局时间。健康更新时点有一批内的离散误差；不把离线墙钟或游戏暂停当作清除时间。
- 共享输入拒绝无效身体、非正／非有限剂量和读档期调用，精确写入新实例实际剂量；返回真实暴露、实际负荷增量、最终负荷、满值与锁链分流。普通角色不需要调教组件，也不因主人身份或微量恶堕获得 PNA 免疫。事件去重由来源调用者负责。
- 实际有效锁链保护按锁链实例及仍有效的主人引用判断，不使用身份、恶堕或阶段 >0。零阶段有效链仍保护，无有效引用的残链不保护，重复链任一有效引用即可保护。按维护者 2026-10-14 确认，绑定仅清依赖／成瘾，将普通负荷原位转换为同严重度的 `SSC_Hediff_PnaRootedLoad`；解绑同严重度转回普通状态。原实例、严重度、loadID 和半批有效时间都保留，不改变绑定准入或归属。
- 对有效锁链将直接 AddHediff 的普通负荷来件转为性奴载体，阻止新增依赖，并关闭旧 PNA 药物的随机成瘾／需求补充分支；原版 PostIngested 和枪械治疗／战斗强化保持原流程。新链添加、已有链目标更新及初始化均协调负荷形态；移除链后即时转换，引用失效在有效健康更新中协调。由原版合法需求准入撤销被清依赖对应的 Need_PNA。
- 在完整引用恢复后一次规范化全存档角色负荷：保留合法原始严重度；非法值归零；重复实例保留最大合法单份，不相加；极低负荷删除。旧满不新建依赖，普通旧依赖及满足度不被重写。移除／跨阶段由原版健康接口刷新能力缓存。
- 性奴载体使用同一清除组件，不施加普通能力惩罚或预设完整正面加成。共享／调试输入可累计性奴负荷，原枪械战斗增益仍按旧支路；五个 `SSC / PNA P1` 调试动作：+8%、+20%、+70%、补满、清负荷。四语标签、悬停与提示以及语言镜像已同步。

## P1 边界

满值只由共享结果报告，**本批调试／共享输入不建立新依赖**。普通对象原药物的随机成瘾、原摄入剂量、枪械普通负荷写入仍是旧流程，不能用于验收 P2 的确定性成瘾、来源剂量和补给过滤；它们产生的既有负荷会接受新的阶段和清除规则。

已有依赖仅提前修复原版必须的第 0／1 档结构，避免戒断阶段越界；保留旧恢复速度和普通戒断心情。新依赖长期性欲、20% 门槛／8 个有效恢复日、需求补充、药物／枪械共享适配、地图／旅队补给过滤留在 P2。人格归属、空壳、凝胶／克隆及其他自动入口留在 P3。性奴完整正面阶段与主动补给仍待设计。

## 实机验收

1. 重启并加载本批测试 DLL／Def。启用开发模式，选中一个无实际锁链的健康成年角色；在调试动作菜单搜索 `PNA P1`。
2. 用 +8%、+20%、+70% 观察五档切换，健康页最大为 100%，微量及活跃没有操控／移动惩罚。末期意识上限 10%、疼痛因子为零；不出现旧 +5／+8 普通负荷心情。
3. 用补满动作开始断供，观察约 2.88 游戏小时退出末期、一天约剩 78.93%、约 10.01 个有效健康更新日移除负荷。保存读取不能凭空增加负荷或新依赖。冷冻、暂停和正常商队移动分别观察，暂停健康更新的时间不补扣。
4. 每天一次 +8% 应趋于约 29.13% 峰／21.13% 谷；每天两次等间隔维持约 69.07% 峰／61.07% 谷。每日三次等间隔约第 39 次满；实际行动时刻和健康更新粒度允许少量时间偏差。
5. 仅 Slave 身份或恶堕大于零但无链的角色仍积累负荷。取得有效链后既有依赖应实际移除，普通负荷变为同严重度性奴状态，普通能力惩罚停用；零阶段有效链也保护。解绑后同严重度恢复普通状态及对应能力效果，依赖不恢复。补满后绑定／解绑以及保存读取都不能新增依赖。枪械原有治疗／战斗强化应仍有效。
6. 读取旧满无依赖、已有依赖和有链旧对象，检查迁移静默且多次加载结果一致；已有普通依赖仍是旧恢复规则。分别切换简中／繁中／英文／俄文查看五档和负荷悬停。

本批需先在测试存档验证阶段强度、正常任务和 RJW 性需求实际下降，再决定 P2 平衡。健康页显示和宿主通过不等同于完整实机验收。
