# 多调教员指派第一阶段实现与验证

2026-11-12，`codex/multi-trainer-assignment` 完成 1.7 的名单保存、旧档迁移、逐人提交和生命周期接入。关系页、旧指派菜单和工作系统继续使用单人入口。多人工作准入和任务互斥归第二阶段，关系页多人管理及其他调用方归第三阶段。 [专项规划](../../Design/Archive/多调教员指派开发规划.md)

## 保存与提交

- `CompSexSlaveTraining` 的有序名单是 1.7 唯一保存源。版本 0 读旧 `selectedTrainer`，引用解析后迁为零或一条。版本 1 写 `sscTrainerAssignmentsVersion` 和 `sscAssignedTrainers`，显式保存空名单。移除死亡、销毁、丢弃、自身和重复引用，保留暂时不可工作的成员。旧任职迁移读取整份名单。 [组件](../../../Sexslavecraft/Comps/Comp_Train.TrainerAssignments.cs) · [任职迁移](../../../Sexslavecraft/common/SSCTrainerIdentityMigration.cs)
- 新增、逐人移除及就地启用共用原工作提交。请求保留名单版本、锁链、主人、组件、人格、规则和原版工作载体。新增未绑定目标的成员要求 SSC 主人身份。新增已绑定目标的第三方沿原规则预检和提交授权。工作设置回调使请求过期时，仅撤回本次仍持有的工作写入。现有单人替换和清空入口遇到多条名单时拒绝覆盖。 [提交入口](../../../Sexslavecraft/common/SSCTrainerWorkUtility.cs) · [许可](../../../Sexslavecraft/common/Restrictions/SSCRestrictionTrainerAssignment.cs)
- 有效「只准主人」规则将名单收敛为仍可引用的绑定主人，主人死亡时清空名单并保留锁链及许可。解绑移除原主人，保留第三方。退出 SSC 性奴身份清空名单，兔克隆复制独立列表。人格流转沿用原解绑和身份清理。 [限制协调](../../../Sexslavecraft/common/Restrictions/SSCRestrictionLifecycle.cs) · [解绑](../../../Sexslavecraft/common/SSCBondUtility.cs) · [克隆](../../../Sexslavecraft/common/RabbitCloneUtility.cs)
