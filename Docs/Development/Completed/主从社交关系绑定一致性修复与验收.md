## 修复范围

- `SSC_FlawedLovers` 奖励关系只允许存在于实际锁链绑定的双方之间，指定调教员、仪式主持者和单独的主人身份均不构成所有权。
- 保留原有完整绑定仪式及好感至少 80 的授予条件。绑定、换主、读档清理均不自动补发奖励，已经合法获得的奖励不因后来好感下降而撤销。
- 解绑、锁链移除、换主和旧档加载清理失效奖励；最后一条绑定解除时立即清理主人空缰绳与灵欲共振场，保留其他有效性奴及普通社交关系。
- 主从称谓按查看者与实际锁链方向显示，覆盖社交列表和好感说明，补齐简中、繁中、英文、俄文及发布目录镜像。

## CE 删除路径

维护者反馈：用 CE 删除性奴锁链后，主人缰绳会消失，社交关系仍在；切换选中角色不能清除，存读档后才消失。

本机 Character Editor 1.6 的 `CharacterEditor.HealthTool.RemoveHediff` 直接从健康集合移除实例并发送 `Notify_HediffChanged`，不调用原版 `RemoveHediff` 或 `PostRemoved`。旧档清理有效，但原先挂在 `PostRemoved` 上的即时关系清理没有执行。

`4d2e046` 为健康变化通知增加仅处理 SSC 性奴锁链的后置补丁，确认实例已离体后复用绑定清理。仍在身体上的严重度通知直接返回；重复通知、同主人新链替换、其他性奴和普通关系均保留。没有引入 CE 程序集依赖。

原版神秘加入者记录缺失 `aggressive` 的死亡异常不属于 SSC 修复范围。此前添加的保护补丁已在 `5862816` 撤销；不跳过原版或其他模组的死亡机制。
