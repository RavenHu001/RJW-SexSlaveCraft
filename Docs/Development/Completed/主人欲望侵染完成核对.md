## 2 当前参数与明确边界

| 项目 | 当前实现 |
| --- | --- |
| 侵染负荷 | 每次归一化 +0.08，即 +8 个百分点，原始严重度 +0.16 |
| 已有合法 PNA 需求 | 补满；不强行创建缺失需求 |
| 已有成瘾 | 基础 D+0.02，输入后末期另加 0.20、合计 +0.22，上限 1；首次仍须满负荷、不追加本次强化 |
| 有效锁链 | 正面活化，不建立普通成瘾；其他合法分量继续 |
| 恶堕 | 额外最多 +0.01；新评分无链 0.12、有链按阶段，旧评分按原需求上限；不倒扣超限值 |
| 弱开发 | 原结算前 score/1000 ×0.20×恶堕倍率×锁链倍率为总预算，去重均分；饱和或失效份额不重分 |
| 反馈分界 | 当前 C=0.30、当前原始好感 O=0，等号进入高 C／非负 O |
| 心情／好感初值 | 低 C 非负 O：+4/+5；低 C 负 O：-4/-5；高 C 非负 O：+8/+10；高 C 负 O：+4/0 |
| 心情期限 | 1 天、全局一份，新反应替换并刷新 |
| 社交期限与容量 | 3 天，每实际主人一份、最多三位；最后 30% 期限衰减；零偏移清该施加者旧记录 |

原版 Lovin 没有部位开发；被 RJW 替换成普通驱动时按实际普通入口处理。旧场景缺少部位凭据只跳过开发，不补造部位。未映射类别不猜测对应记录。新评分无链 12% 上限使自然侵染通常停留在低 C 反馈档，这是既定边界。

真实体液量、避孕套及特定器官目前不限制 PNA 输入；后续设计统一归未来第 22 项，实际部位仍单独决定本次身体开发。
