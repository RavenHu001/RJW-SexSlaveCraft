## 实现范围

- 凝胶外观弹窗使用原版色轮、分量输入、色板与滑块。色轮最大 220 像素，增加明度滑块；RGB/HSV 分页每次显示三个分量；使用 RectAggregator 实际高度与色板返回高度推进布局。窄屏纵向排列，底部按钮在滚动区外。
- 原/新颜色用棋盘背景呈现不透明度，仅绘制 UI 色块，不在拖动时刷新角色或创建 GPU 纹理。颜色继续使用草稿、失焦提交与接受按钮；取消/关闭不写入外观。
- 身份按钮显式置灰并拒绝点击；任职控件向 Widgets.CheckboxLabeled 传递 disabled，同时恢复外层 GUI 状态、保留原因提示与后台资格检查。失去任职资格但保存为开启时仍可关闭旧选择；主人和未选择身份只读。
- 从身份区删除“状态：已禁用”及相应高度，该行表示日常训练状态，仍保留在真正的训练区。
- ITab 身份区之后、所有身份/研究分支之前增加凝胶外观区块。仅有 SSC_FullGelatinizedBody 时显示；个人渲染开关、当前色块、不透明度与调整按钮共用生产数据。现有 ITab 角色可见范围不变。收尾移除 HediffComp 的调色指令，不再占用小人命令栏；统一从 ITab 的“凝胶外观”区打开同一弹窗。

## 个人开关与迁移

- 数据保存在当前 Hediff 的 HediffComp_FullGelAppearance 中，新增 sscGelRenderingEnabled；true/false 均强制写入存档，避免默认值被省略后再次继承旧设置。
- 缺个人字段的旧档在读取时继承 enableFullGelatinizedBodyTint。明确保存的个人值始终优先。新获得的凝胶身体默认开启；运行时不再查询旧全局设置，Mod 设置页面移除原总开关。
- 关闭不删除保存的颜色与透明度，“恢复默认配色”不改变开关。默认继续为 HSV H272.5° / S90% / V68%，RGB (0.3995, 0.068, 0.68)，不透明度 0.85。
- 克隆按值初始化开关，之后独立；不随人格转移。移除后重新获得 Hediff 使用新身体默认值。
- 个人准入同时覆盖身体、SA、头皮与五官光照阶段。切换时仅在主线程刷新目标的图形树和肖像；颜色和开关通过不可变快照发布。Shader 数学、深度状态、动画路径与开启时的光照响应不变。
