## 触发和回收进度

`Verb_MeleeAttackSSCPna` 仍只连接原专用携液刺击 Maneuver。完整调用一次父类并原样返回，仅在真实出手且父类返回 true 后开始泛光；miss／dodge 不亮。原版 true 包括完全护甲阻挡，因此接触泛光不依赖伤口、伤害量或施药成功，也不检查目标主人免疫。新一次出手先清理上次反馈，普通柄击不接入。

原版 `Notify_MeleeAttackOn` 在不同格时 AddOffset(0.5)，同格时为 0.25，JitterHandler 把总偏移限制在 0.35；每批 `ProcessPostTickVisuals(ticksPassed)` 衰减 `ticksPassed×JitterDropPerTick`，本机构建为每 tick 0.018。泛光只读实际回位方向和衰减率，给本次命中保存独立的初始／剩余位移，不移动武器、身体或目标。

在原版回位更新后的 Harmony 后缀中，以同一个 ticksPassed 减少本次余量；每次读取亮度再取独立余量与真实初始回位方向投影的较小值，并锁定缩短后的余量。当前亮度为 `clamp((剩余量/初始量−0.15)/(0.5−0.15))`：前半段回收保持满亮，剩余 50%～15% 时淡出。普通 0.35 回位约第 17 个视觉 tick 熄灭，原版约第 20 个 tick 归零；同格 0.25 回位约第 12 个 tick 熄灭，第 14 个 tick 归零。

独立余量只减不增，走路、目标移动或额外受击不能延长／重新点亮；若实际偏移提前消失或反向，则提早清理。保存加载、离图、死亡、换武器、跨地图等状态在查询时清理。弱键表与弱引用不序列化、不保留已回收武器／身体／地图，也没有额外全图 tick 扫描；暂停和加速跟随原版视觉更新。

## 整片矛尖的绘制

只在 `PawnRenderUtility.DrawEquipmentAiming` 最终唯一的四参 DrawMesh 位置，用局部 transpiler 换成“原样绘制一次，再尝试叠画”的包装函数。传递原方法已有的 mesh、最终 matrix、material、layer 和武器实例，完整保留左右翻面、大小、朝向及回位位置；没有重算瞄准角或改变待机姿势。未知 IL 布局明确拒绝挂接，不猜测其他调用点；未知网格只保留原武器绘制。

遮罩是裁切的四顶点网格，复用原短矛贴图与透明轮廓，UV 只采样横向 x≥183/256 的刃部区域。正常和镜像网格分别缓存，木杆、圆球与绑带不被采样；无需重画、生成或读取像素贴图。沿用原矩阵，仅给叠画抬高 0.001 绘制高度避免重叠。未来如果改动短矛贴图构图，需同步校准这个 UV 边界。

刃部提亮层使用原纹理、原版 MoteGlow 材质和独立 MaterialPropertyBlock，颜色乘数 `(1.6,1.1,2,亮度×0.85)`，不改变武器共享材质或贴图。其外增加一层原版 BrightFlash 柔边光晕，颜色 `(0.85,0.3,1,亮度×0.6)`，先画光晕、再画刃部，以保留矛尖细节。两层都使用武器最终矩阵，只作极小高度偏移；没有地图灯光、粒子、拖尾、新武器动画或新贴图，每次可见绘制最多两层额外网格。
