## 根因与边界

- [JobDriver_PE](../../../Sexslavecraft/JobDriver/JobDriver_PE.cs) 的场景准备固定使用 Sex_Anal，原调用未启用 `allowEmptyParts`。[RJWSexPropsUtility](../../../Sexslavecraft/common/RJWSexPropsUtility.cs) 在 RJW 返回 null 时失败，驱动记录 `SSC_PE_ACT` 校验冷却并以 Incompletable 结束任务；只有详细日志开启时才输出该冷却分支，不产生异常。
- 当前安装 RJW 的 `Sex_Anal.xml` 要求执行者满足 `CanPenetrate`，目标满足 Anus；`SexInteractionHelper.ResolveInteraction()` 在没有解析结果时返回 null。普通女性执行者缺少该交互要求的部位时，可走入上述静默中断分支；不是按 Pawn.gender 判断，也不能推断所有女性角色必然无匹配部位。
- 工作入口没有增加该固定交互的执行者部位准入；人格排泄应维持其固定场景。复用固定仪式已有的空接触机制，避免把 RJW 指定动作的解剖筛选追加为人格排泄工作限制。

## 修改范围

- 仅人格排泄调用显式启用 `allowEmptyParts: true`。解析为空时清除旧动作部位，保存当前动作与正确双方、空部位和空接触列表；有真实解析时继续使用真实结果。
- 复用现有工具，不按女性硬编码，不更改日常调教的严格解析行为；定义缺失、动作类型不符、参与者／部位归属错误仍失败。身份、实际主人、目标状态、兔分身排除、预约争用、位置同步、接收任务保护、人格快照与提取结算保持原流程。
- `RJWSexPropsUtility` 只补充注释说明适用范围，没有修改公共算法。无新增 UI 文案或翻译键，不改文化内容、1.6／Common 或正式版本。
