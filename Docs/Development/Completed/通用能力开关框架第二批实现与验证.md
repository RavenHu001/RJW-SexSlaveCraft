后三项不写入 `sscAbilityToggles`，同名人格字典键不能覆盖原字段。生育读取仍使用原 `FertilityEnabled` 有效值；凝胶缺组件时沿原读取回退开启，但不可编辑且不补建组件。凝胶旧档缺个人字段时仍按旧全局设置迁移一次，明确保存的 true／false 原样恢复。

**泌乳保存归属继续保留历史差异：** 该字段位于训练 Comp，由 `CompPersonalityStore` 采集／保存／加工复制，植入时覆盖宿主；本次不修改 `Comp_Train.cs`、`ThingsComp_PE_PES.cs`、`ExcretionUtility.cs` 或 `RabbitCloneUtility.cs`，不额外套用人格字典提取清源／克隆重置。生育和凝胶外观仍属于原身体，不进入人格能力字典。

## 实现边界

- 公共后端新增带 bool／原因返回的 `TrySetEnabled`，默认实现调用第一批 `SetEnabled`，兼容原后端。生育和凝胶覆盖该入口，将原 setter 的拒绝结果回传，避免预检通过而实际拒绝时被报告成成功。
- 泌乳与生育注册为 Body 组，凝胶渲染注册为 Appearance 组。身体栏取消 Milk／Fertility 专用 enum 分派；原充盈度由注册项的只读 `DetailRule` 提供，保持缩进和组间距，不增加进度／收益重复行。
- 三项继续使用原角色、Comp、人格 token 和身体 owner 凭据。查询、目标值预检、提交前后核验和选中角色检查保留；不添加主人／性奴／研究／绑定或空壳门槛。
- 凝胶颜色、不透明度、调色弹窗、原快照与缓存实现未改；关闭渲染后仍可调色，恢复默认颜色不改开关。
- 主页面已按同次视图测高／绘制且位于身份分支前，无需改动。复用全部现有翻译键，四语 XML 和镜像未改。新生产文件仅纳入 1.7 工程。

HumanCattle 接管仍先于 SSC 生产控制：普通泌乳走原外部接管入口，牛储液走原清零退出。SSC 开关不据此获得控制第三方所有生产的能力；本批不关闭总体规划第 17 项 Equal Milking／HumanCattle 兼容排查。
