## 1. 本批契约

- 点名命令是点击后交给原版调度的一次 Job；允许原 Job 内接近及有限等待，被打断、取消或失效即结束，不自动重排、重试或追踪迁移后的人格。保存记录只用于原任务恢复与防重放。
- 普通人格提取、凝胶加工和植入携带七项配置；来源缺配置精确恢复默认，未知版本在破坏宿主前拒绝。配置与命令授权分别保存。
- 新生克隆恢复五项许可允许、两个附加开关关闭；不继承来源命令。克隆后续选择随自身保存，成熟及正常读档不重复重置，绑定继续遵循既有流程。
- 外部实际进入空壳状态使旧人格凭据过期，取消本人及指向该旧人格的命令。加载一个既有空壳仅建立观察基线。

原有七项选择、关系结算及双板块界面语义不变；规划第 12 节心情／社交反馈仍为独立后续设计，本批未实现 Thought 或额外社交效果。

## 2. 实现与复核修正

| 边界 | 本批处理 |
| --- | --- |
| 外部空壳仅撤销执行者，旧目标预览和入站任务仍可执行 | 在 `SSCPersonalityRuntimeUtility` 的弱引用状态中观察空壳进入／离开；实际进入时更新人格 token，并由 `InvalidatePersonality` 取消双向旧请求，目标没有训练 Comp 也适用 |
| 重复通知、正常人格作用域及读档基线 | 健康观察先写状态再撤权；重复通知不旋转 token，正常替换中不使自身 scope 失效；`InitializeAfterLoad` 在完整恢复出口建立基线，加载期不处理运行事件 |
| 外部直接改健康列表 | 复用原 Add／Remove 通知和已有 `Notify_HediffChanged` 补丁；直接删除空壳也更新离开状态，保证下一次真实进入能够撤销旧凭据 |
| 原 Job 领取前被打断 | 驱动 `Finish` 查回原 Job 的清理归属并取消记录，防止停留 Pending；不据此取得执行授权，也不接管其他驱动的记录 |
| 凝胶放置回调替换训练组件 | 两条提取入口在放置后再次核对原人格 scope 与原 Comp，拒绝清理后来接管身体的新组件；共享源码新增检查以 `SSC_RW17` 隔离 |

普通人格作用域开始时即取消旧命令，结束时按最终状态协调；生成失败不提前清浪漫配置，进入替换后的失败不恢复旧授权。原人格流程并非全字段事务回滚，场景提取放置前已有部分空壳处理；本批不将其宣称为全流程可回滚。

本批未新增保存字段或改变配置版本。空壳观察缓存及人格 token 仅在当前进程中存在；失效命令的终态沿原记录持久保存，合法原 Job 仍按原世代和锁链 loadID 恢复。
