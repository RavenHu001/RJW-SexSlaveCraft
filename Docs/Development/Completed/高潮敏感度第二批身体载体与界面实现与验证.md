## 1. 实现及保存归属

`Hediff_SSCOrgasmSensitivity` 使用独立全身 `SSC_OrgasmSensitivity`，`Part=null`。缺记录为关闭，`Severity` 只保存一至四整数，不增加 Comp／人格副本，不安装自然衰减或成长组件。合法切档走原版严重度 setter，关闭走健康移除入口。

重复加入保留首个合法原实例及其选择，不相加、不取较大档。普通 getter 只选取健康列表中的首个合法实例，其他重复实例返回中性阶段，避免双份属性。显式加入、写入或 `PostLoadInit` 才清理异常与重复记录；非整数、越界、非有限值或错误部位不提供效果，运行时非法写入归零，不经原版上限裁剪变成四档。

统一 `SSCOrgasmSensitivityUtility.GetState` 返回保存档位、实际档位、锁链阶段、最高可用档位、系数、偏移和暂停原因。`GetMultiplier` 提供当前有效系数，当前没有计时消费者。实际准入检查当前 SSC 性奴身份、身体、真实锁链及主人引用；降阶限制有效档位并保留原选择。主人仅死亡／离图仍执行指令；解绑、失格、主人销毁／丢弃、性奴自身死亡、空壳及人格替换期间暂停。

新增源文件只编入 `SexSlaveCraft_1.7.csproj`，共享文件的调用受 `SSC_RW17` 保护。枚举没有注册到个人 bool 框架。

身体配置一次校验四项长度、有限数值、倍率至少一及阶段范围／顺序；没有 C# 数值兜底。派生只读 `HediffStage` 从同一偏移配置生成，原 XML 阶段只保存名称，不另抄一份 statOffsets。原生 `StatWorker` 按当前有效档位读取 `Vulnerability` 偏移，其余因子和终值边界保留。

本机 RJW 作者 `1.6/Defs/StatDefs/Stats.xml` 的 Vulnerability 默认基值为 1、下限 0、上限 3，并有技能、能力和其他属性修正。因此 +3 是进入原流程的偏移，不保证终值一定增加 3，也不绕过上限。此处是本机作者 XML 取证，**不是完整游戏最终合并 Def 快照**。

思想独立校验重复键、阶段／档位／索引范围、有限心情值及全部可达组合。身体配置失败则关闭本项效果及非零提交，仍可关闭；思想配置失败只停本项思想。修改解锁 XML 后若新增可达组合，需显式补映射。测试通过修改实际扩展证明查询没有使用硬编码参数。

`ThoughtWorker_SSCOrgasmSensitivity` 与属性共用有效状态；`Thought_SituationalSSCOrgasmSensitivity.MoodOffset` 实际消费前重新执行原版思想准入与专用查询，失格返回零，正常时继续原版思想倍率／屏蔽流程。无事后记忆、高潮事件条件或次数堆叠，不为缺心情需求的角色补建需求。思想允许原版离图情境查询。

## 3. UI 与生命周期

身体管理区域增加专用下拉行：关闭及一至四档，展示保存／实际档位、有效系数、偏移、暂停和不可编辑原因。只有这条枚举行时仍正常出现，行高计入换行文字、按钮和外层滚动范围。

菜单捕获 Pawn、Comp、人格 token、原链及主人、整组身体记录引用；没有记录也捕获空集合。点击不重新捕获凭据，角色切换、换 Comp／人格、解绑重绑、换主、记录替换或外部增删均使旧菜单失效。提交重查当前阶段；关闭不依赖有效身份／链／身体配置，但仍检查当前身体可编辑及原凭据。自有清理产生外部回调后再次检查阶段和原 owner，不接管回调新建的实例。重复选当前合法值保持幂等。

链阶段健康通知、锁链增删／换主、身份切换／显式恢复以及人格作用域开始／结束刷新本角色健康和情境思想缓存。属性 getter 和思想消费还会复查实际状态，不依赖已经过期的 owner 缓存。语言变化及实际 DefInjected 标签变化会重建派生配置，不逐 Pawn 改共享阶段。

`SSCBodyDevelopmentUtility.IsBodyStateDef` 显式纳入此 Def，现有采集、加工和植入过滤沿该分类生效，不泛化为全部 SSC 状态。身体设置保留在宿主，不转入人格载荷。兔分身沿原版出生健康复制继承一次，成熟复制明确跳过本项，不覆盖分身调档，也不重建它关闭的状态。完全凝胶化继续使用既有 SSC package 保留规则，本批没有增加第二次补建。

四语 Keyed、HediffDef 和 ThoughtDef 注入及源码镜像齐备。名称与思想描述为明确 **WIP／开发占位**，没有将占位稿标为正式设定文案。
