## 显示与接线

| 武器 | 纳米催情液效力 | 数据来源 |
| --- | --- | --- |
| 纳米催情液短矛 | 15% | 工具容量 → 携液近战动作 → SSC_Damage_PnaStaffStab |
| 纳米催情液吹箭筒 | 6% | 射击动作 → SSC_Projectile_PnaDart → SSC_Damage_PnaDartStab |
| 纳米催情液轻弩 | 10% | 射击动作 → SSC_Projectile_PnaBolt → SSC_Damage_PnaBolt |

- 新增 `1.7/Defs/StatDefs/SSC_PnaWeaponStats.xml`：属性 `SSC_PnaWeaponPotency`，归入 Weapon，PercentZero 格式，只供信息展示，不在武器 statBases 另存药量。
- `SSCPnaWeaponPotencyUtility` 校验真实处理器／扩展和正有限剂量，复用 `SSCPnaWeaponDoseUtility.FromLoad` 计算固定意识 100%、无快照的基线；不调用取样、身体协调、暴露或快照管理。普通 Blunt 被忽略，缺少有效配置不显示；多个不同剂量不随意取第一个或相加。
- `StatWorker_SSCPnaWeaponPotency` 对实体和定义信息卡使用同一读取路径，遵守原生可见性开关；覆盖数值和最终处理，避免物品品质、材料或场景因子把显示基线改成另一套数值。
- 原生悬浮气泡展示 StatDef.description；点击属性后右侧报告补充本武器基线、负荷百分点含义、一次携液命中仅输入一次、意识／抗性记录的计算与单次上限。四语文本同步到源码语言镜像。
- 原物理伤害、施药门槛、主人免疫、锁链活化、意识抗性、剂量与快照流程均未改动；无新增 UI 补丁、存档字段或物品组件。
