- 保留原贴图形状与细节，将黑色柔化为深紫，增加少量原画亮部光泽；不扩张或缩小轮廓。

## 实现与原理

入口为 `Sexslavecraft/ThePatches/Harmony_FullGelatinizationBodyTint.cs`。满足全胶状态和染色设置后，取得对应颜色的 Graphic，替换当前返回结果，不直接修改共享原图，也不额外叠画一层身体。

1.7 使用 `1.7/Defs/ShaderDefs/SSC_FullGelBody17.xml` 的原生 ShaderDef，以及 `1.7/Shaders/SSC/FullGelBody.frag.glsl` 和 `FullGelMath.glsl`。复用引擎的 Mote 顶点接口，支持普通与 INSTANCED 绘制。旧 Unity ShaderLab 文件保留为历史迁移资料，不是当前原生程序。

片元程序按像素读取原贴图 RGB 和 Alpha。每个颜色通道先计算：

```text
基础输出 = (0.34 + 0.66 × 原通道值) × 目标紫色通道值
```

普通乘色会令黑色保持为零；这里将黑色提升到目标紫色的 34%，因此黑线变成深紫。原通道从暗到亮的顺序保持，颈线、身体阴影等细节仍可辨认。对原通道超过 0.65 的区域，用平滑曲线逐步向白色靠近，最大混合强度为 12%，形成克制的原画亮部光泽。它没有实时折射、流体模拟或随视角移动的镜面高光。

以灰度贴图为例，应用最终深紫色后，未乘顶点颜色、未与背景混合前：

| 原贴图 RGB | 输出 RGB（约） | 作用 |
| --- | --- | --- |
| `(0, 0, 0)` | `(0.1564, 0.0680, 0.2312)` | 黑线变深紫 |
| `(0.5, 0.5, 0.5)` | `(0.3082, 0.1340, 0.4556)` | 保留中间调 |
| `(1, 1, 1)` | `(0.5248, 0.2960, 0.7184)` | 少量提亮 |

最终 RGB 继续乘游戏传入的顶点颜色。Alpha 独立计算为 `原贴图 Alpha × 0.85 × 顶点 Alpha`；完全透明像素丢弃，边缘抗锯齿和内部孔洞保留。源贴图与顶点均完全不透明时，通常按约 85% 身体颜色、15% 背景颜色混合；边缘及多层相交处由实际覆盖率、排序和背景共同决定。

材质选择先确认原生 Def 与 Waylith 注册项存在，并拒绝引擎默认条目；缺失时警告一次并回退内置 TransparentPostLight，不以 late-bound 对象非空或 isSupported=true 判定成功。回退仅保证基础染色，不能提供黑边柔化。

## 试色与实机反馈

初版采用较浅紫色与 0.76 不透明度。维护者确认“黑边解决的很好”，但身体更像淡紫色幽灵，因此先恢复旧 RGB `(0.72, 0.38, 0.95)` 与 0.8，再调整为深紫色 `(0.46, 0.20, 0.68)`。维护者确认深紫色配色可用，随后比较 0.85、0.9，并要求调回 0.85；最终明确确认当前效果可保留并提交。
