## 交付行为

| 区域 | 当前实现 |
| --- | --- |
| 绑定从属卡片 | 最大宽 300、高 75，标题只显示总数，保留“查看全部”；头像固定 40，人数超过容量时出现前后页及页号，不缩小头像 |
| 实际主人卡片 | 独立标题与唯一主人头像；无该方向时不显示空面板，坏锁链保留异常提示 |
| 指定调教员卡片 | 单独显示当前指定者及“更换”；主人和调教员即使是同一人也分开展示，调教员不进入绑定计数 |
| 总览窗口 | 最大宽 680、按内容和屏幕计算高度；实际存在的关系分区，使用固定 56 头像网格和短姓名，无常驻阶段／特化／地图详情及逐行定位按钮 |
| 悬停和点击 | 悬停显示完整姓名、阶段、特化、位置或指派状态；点击头像定位。普通同图没有额外位置文字，死亡／容器／异地／未知或失效用文字或小标记提示 |
| 窗口上下文 | 不强制暂停；更换选中对象、多选、来源死亡／失效或离开当前地图后关闭；成功定位后关闭 |

分页属于当前来源视图，快照刷新不回到第一页；人数减少或宽度变化时夹到有效页，换来源建立新视图时回首页。翻页只改变索引范围，不 Build、不扫描世界、不触发导航；完整计数与快照保持不变，逐页可达全部成员。

窗口没有常驻手动刷新按钮；旧行、打开、地图变化及显式指派后的刷新继续通过会话排队，服从完成后至少 2 秒、空候选 5 秒及十倍查询耗时封顶 30 秒的预算。文字仍为有界惰性缓存，64 行、256 截断项及 128 翻译模板；翻页和悬停不建立新的全名单文字副本。

肖像采用原版缓存的 40／56 两个档位与固定 `cameraZoom=1.5`，不强制 SetDirty、不拥有或销毁纹理。实际人物构图、FA／SA 表现和缩放仍需实机确认。同屏网格比旧逐行列表容纳更多肖像，首次渲染成本可能增加；本轮不复用旧表格窗口的模型计时来声称新网格 FPS 或零分配。

## 显式指派与导航边界

[SSCTrainerAssignmentMenu](../../../Sexslavecraft/UI/SSCTrainerAssignmentMenu.cs)统一训练页与概览的菜单，替换训练页中重复的私有候选和提交代码。只有明确打开菜单时才物化既有候选，选择后调用原 `SSCBondUtility.TryAssignTrainer`；候选资格、自由殖民者／同图范围、调教工作、强制限制、非主人调教授权及清空规则仍由生产后端判断。

打开、绘制、悬停、翻页和定位保持只读；维护者明确授权新增的“更换／清空调教员”是独立写入口，允许后端同步提交必要的调教授权，不改变锁链主人、绑定名单或普通互动许可。原训练页保留入口及授权说明，菜单保留非主人授权后缀。

菜单回调重新核对 Game、加载状态、原组件、原主人、原指派及新候选的现行资格；概览菜单还要求仍属于当前单选来源和活跃视图。打开菜单后换来源、外部改绑／改指派／换组件或失去资格时，不覆盖新状态。成功提交清掉旧展示，登记受预算控制的刷新，不允许继续点击旧调教员。

调教员定位有独立的引用复查，不能伪造锁链行。快照只增加指定者的位置字段和一个位置请求，与主人／从属共享原有稀疏索引；不增加绑定候选或计数。点击再次复查指定引用并重解这一人的当前位置，换船不跳旧船。原绑定行的 `IsCurrent` 和 `TryNavigate` 执行正文保留，世界收集／遍历文件保持原内容。
