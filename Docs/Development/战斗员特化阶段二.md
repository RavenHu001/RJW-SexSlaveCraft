## 经验结算

`CombatantSpecializationProgressUtility` 统一计算并提交进度，要求 SSC 身份为性奴且当前培养方向为战斗员；使用组件进度，成功后立即同步普通 Hediff。不增加研究、绑定或锁链阶段门槛，不套用恶堕／身体部位培养倍率，也不根据当前培养进度加速或衰减。

| 来源 | 公式及上限 |
| --- | --- |
| 正常完成日常调教 | `min(score / 2000, 0.04)`，非正或非有限评分不给经验 |
| 实际绑定主人完成日常调教 | 基础收益先封顶，再乘以 1.5；单次最多 6% |
| 直接击杀 | `min(0.01 × 实际BodySize, 0.03)`，体型必须为正的有限值，无最低奖励 |

主人加成只检查 `SSCBondUtility.GetBoundMaster(receiver) == trainer`。其他主人及指定调教员也有基础收益；未绑定者不会在经验入口被拒绝。调教任务仍须满足既有行为许可和任务规则。

当前进度先沿用阶段一规范化，再通过公共 `AddSpecializationProgress` 写入并限制在 0～1。普通完成采用公共 0.999 容差，达到门槛后停止发奖；接近完成时只补足剩余进度。普通完成保留熟练属性，不添加终极状态或能力。终极记录尚属阶段三，届时须在统一经验入口补上终极记录拒绝条件。

## 日常任务与评分

日常任务只在场景真正结束后进入结算，保存认领事实后才调用 RJW `ProcessSex` 与正式收益。内部字段改名为 `dailyOutcomeClaimed`，保留原存档键 `sscTrainerProgressAwarded`，已完成的旧任务不会因升级补发经验。

整次结算的重复回调、同步重入和读档恢复均受同一认领保护。中途异常保留认领事实，避免再次运行已发生的部分收益；异常前尚未到达的战斗员奖励不会补发。正常的新任务仍独立结算。

`ConditioningUtility` 增加接受既有评分的重载，新旧评分分支均使用日常驱动传入的同一个 score；身体经验和战斗员经验共享该值。原两参数接口保留。该调整消除正式日常收益重新抽取旧评分随机项的问题，不改动其他功能独立使用评分的逻辑。

战斗员发奖只接入日常驱动，未接入绑定仪式、普通 RJW 双人经验回调或中断清理。

## 直接死亡与来源排除

`Harmony_CombatantExperience` 包装 `Pawn.Kill(DamageInfo?, Hediff)`：死亡前采集实际 `Pawn.BodySize`、本次攻击者和来源判定，返回后确认真实死亡再提交奖励。不使用物种基础体型，不从历史伤害记录追溯最后攻击者。

- 不额外筛选目标种族、阵营、敌对或倒地状态。原版子弹的伤害来源为发射者，狩猎及处决补刀可以正常归属。
- 屠宰与处决都使用 `ExecutionCut`；排除时同时核对 `JobDriver_Slaughter` 及其目标，不能统一屏蔽该伤害类型。
- 持续燃烧可能保留点火者。`Fire.DoFireDamage` 的短期作用域明确排除该来源；直接火焰攻击不因此被统一屏蔽。
- 主从分摊复用已有 `SSCMasterBondUtility.IsRedirectingDamage`，即便复制了攻击者也不发奖。
- 爆炸在每次 `Explosion.AffectCell` 执行时核对已有 `projectile`／`weapon` 来源。原版武器／射弹爆炸可以计入；没有这些来源的环境连锁，即使保留攻击者也不计入。这样不依赖创建爆炸时的临时调用栈，能够覆盖延后传播。
- 没有本次 Pawn 攻击者的失血、陷阱等不追溯归因。无本次伤害、非健康伤害、自身致死及无效体型不发奖。

同一目标的嵌套死亡调用只由最外层凭据结算一次；完成凭据先认领再发奖，Finalizer 在正常及异常退出时释放。已死亡对象的重复通知不发奖，不使用按 tick 限频或永久击杀名单，因此同 tick 多目标及复活后的新死亡可正常处理。

新增经验采样及奖励自身异常仅记录一次错误，不阻止原死亡流程；原死亡方法自身的异常保持传播。没有地图扫描、长期伤害贡献表或新增存档字段。

- Release 主工程构建成功，更新 `Assemblies/Sexslavecraft.dll`。
- 统一验证 19 个套件、827/827 项通过；战斗员套件 37/37，日常／仪式生命周期套件 69/69，相比阶段一共新增 28 组测试。

模型测试不等同于完整原版伤害链、实际 Scribe 存读档或实战平衡测试。自定义死亡覆盖、未走原版 Fire 的持续伤害、丢失武器／射弹来源的模组爆炸需要单独核验，未宣称对所有战斗模组兼容。

## 实机验收

2026-09-27 同步更新 13 个文件，444 个发布资源及文档文件哈希核对通过，覆盖前已备份。维护者实机确认阶段二新增内容没有问题并批准提交。以下清单作为后续回归参考；本次反馈未逐项列出测量结果，不等同于全部边界或数值平衡均已量化验证。

1. 分别让实际主人和获准的其他调教员完成日常调教；核对本次评分及普通 4%／主人 6% 上限，低评分保持动态收益。
2. 中断日常、完成绑定仪式，确认没有战斗员进度；分别在日常完成前后存档再读档，确认正常续接且不重复发奖。
3. 近战、单发、连射、狩猎补刀及处决分别直接致死；使用不同实际体型和种族，确认按体型发奖且无最低奖励。
4. 对照屠宰、失血、点火后的持续燃烧、陷阱、环境连锁爆炸及主从分摊死亡，确认不发奖；直接武器爆炸和直接火焰命中另测。
5. 跨越 20%、50% 和普通完成门槛，核对健康状态立即更新；切换方向、切回及读档后历史一致，普通完成无技能。

凝胶终极化、人格标签恢复和终极能力仍按阶段三、四开发。
