## 3. 本人视角与原文保留

SSCRomanceLogGrammar 只消费 BackgroundFromPOV 返回的有效事实副本。既有角色／行为检查保留：命令侧必须是发起者，受控回应侧必须是接收者，事件行为必须匹配原 InteractionDef。

发起者仅显示自己的受命背景；接收者仅显示自己的受控接受或拒绝背景；双方受控时同条日志保存两个事实，并分别生成各自补句。普通另一方和第三人的背景查询为空。原版本人视角仍是人物第三人称，不改为第一人称对白，也不推断第三方知情。

原 ToGameStringFromPOV_Worker 先由基类生成正文和全部原 extras，再追加本人句子。专属包不进入双方共用 extraSentencePacks，不替换全局 InteractionDef 或删除原结果句，第三方追加句也保留。原版正文中吸引／求爱方式等原措辞仍保留，专属句只说明受控事实。

人物信息沿原 GrammarUtility 的 INITIATOR／RECIPIENT 规则；没有保存命令下达者，不查询当前主人补造历史下令者。原文与 SSC 句子分开解析，既有原生结果包仍只运行一次。

## 4. 解析与故障边界

背景解析独立 PushState，以原 logID 设种子，finally 无条件 PopState；直接背景查询、完整日志、强制语法诊断和信件路径都不消耗世界随机。完整显示继续使用原版按 POV 的缓存。

先检查明确根，再调用原生 GrammarResolver.ResolveUnsafe 的 success 回执；非默认语言保留未翻译副本回退。缺包／缺根、解析失败或异常返回空补句，保留基类原文，不把 ERR 写进日志；故障诊断沿 SSC 闸门按包／根／原因去重。损坏规则仍可能产生原版解析器 ErrorOnce，SSC 不吞原生诊断。无缺失包负缓存，资源恢复后强制解析可以恢复背景；不提供游戏内热重载系统。

显示过程不读取 MoodFrame、当前控制、阶段、好感、特质、记忆准入或命令权限；不重新确认结果、抽取接受概率、领取命令、发记忆／消息或产生第二条互动。

## 5. 历史保存与人格边界

继续原 sscActorFact／sscTargetFact 字段，只深存事件和互动前关系；参与者、原 InteractionDef、原 extras、logID／时间仍由基类保存。本批无新增保存字段，不保存翻译文字、语法包选择或另一份类别；原有第一批事实即可显示分类背景，无事实的普通原版历史不补造背景。

解绑、身份／配置变化、人格 token 变化及后来关系结束，不改写既有事实。存读档不重放互动、补发记忆、消息或命令；不以当前关系推断当时是分手还是离婚。原日志归世界，不向人格或克隆记忆流添加副本，普通人格／新克隆配置规则不改。

历史冻结事件，不冻结姓名及旧版措辞；日志正文按原参与者及当时安装的语言规则显示。正式文案将来更新可以影响历史日志的重新解析；已经发出的原版信件另按下一节处理。

## 6. 原版信件显示

核对当前 TryInteractWith：先创建并提交日志，再以发起者 POV 调用 ToGameStringFromPOV，拼接 worker 提供的 letterText，并调用 ReceiveLetter。LetterMaker 创建原 ChoiceLetter／StandardLetter；其正文作为 TaggedString 保存，**不是持有日志引用供以后重生成**。

| 场景 | 原版信件显示 |
| --- | --- |
| 仅发起者受命 | 原互动／结果与发起者受命补句，再接原版补充正文 |
| 仅接收者受控 | 发起者普通正文；接收者本人背景只在接收者日志显示 |
| 双方受控 | 发起者自己的受命背景，不泄露接收者本人背景 |
| 普通求爱被拒 | 原版不发关系信件，不新增信件，原命令结果提示照常 |

沿原标题、正负类型、定位目标、姓氏／改名、旧伴侣／纽带及分手原因补充等既有逻辑，不新增信件补丁或第二条通知。实际专项验证了原信件正文生成／标题非空／正负类型／原参与者目标和保存正文；没有覆盖所有可选补充内容组合。

信件存档保留发出时的正文，不因安装第二批、开关变化或以后文案更新自动重写；原生 XML 会将 Windows CRLF 标准化为 LF，专项按相同换行语义比较。读档不再次发信。

### 9.1 发现与修正

- **本地化解析异常未走英文回退。**初次实现只在解析返回失败时尝试未翻译规则，异常会直接落入 Format 外层回退。现将每次本地化／英文尝试各自隔离异常；本地化根读取或解析异常仍尝试原 PostLoad 的英文副本，英文也失败才省略补句、保留原文。依旧使用显式根和原生 success，不把 ERR 当作已确认文字。
- **诊断接收器异常可能阻断原日志或信件。**现沿既有心情诊断的隔离契约包住故障警告；警告输出异常不能再次外溢到日志、信件或命令终态。总日志或重要日志关闭时不消耗首次诊断名额，恢复后仍有一次真实诊断请求；同类故障继续去重。保留原生解析器自身 ErrorOnce，不吞正常原文路径的异常。
- **补齐双方历史及入口独立覆盖。**同条日志同时保存 E10 命令拒婚分手和 E05 受控拒婚分手，实际 Scribe 往返后更改双方身份、配置、链、关系及人格 token；切换简中／俄文／英文后双方仍只见各自事件，原信件正文仍是发出时文字，不重发消息、命令或互动。另将命令包的规则顺序反转，确认 E07 仍由显式根选中。

三包与十三入口、固定翻译索引、四语占位、原正文及结果／第三方 extras、任务报告和结果提示、保存字段均符合范围。没有添加当前主人查询、心情准入条件或未发布旧格式迁移；没有更改关系结算、五语义组／数值及人格／克隆配置契约。
