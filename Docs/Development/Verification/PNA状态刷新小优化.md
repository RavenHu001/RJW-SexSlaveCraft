## 改动

仅修改生产 `SSCPnaExposureUtility.RefreshBodyState`：

- 负荷记录一次遍历选择最大合法严重度；同值保留首实例。只有发现第二份记录才建立按原顺序排列的清理快照，去掉稳态的 Where／ToList／OrderByDescending 开销。
- 有链清依赖时，无依赖或单份依赖也不分配临时列表；多份时在移除前收集其余记录，仍按原顺序调用 RemoveHediff。
- 每次依赖移除继续使用已有 RemoveHediff 后置补丁即时刷新需求，取消外层清理完成后的重复刷新。N 份依赖的本模块需求刷新由 N+1 次降为 N 次；不会为了合并成一次而延后中间回调可见的需求变化。
- 无依赖时，绑定／初始化所需强制刷新继续保留，覆盖孤立旧需求。

输入过程的多次健康回调核对、最多三次形态重评估、移除后重新读取保留实例严重度、原实例／组件／半批时间、已有 try/finally 重入保护均保留。没有新缓存、静态状态、补丁、保存字段或数值机制；原版恢复／服药、五档、末期、单份零营养与枪械去重不变。
