## 实现范围

- 共用资格按实际 Beauty 特质检查，固定 `-2→-1→无特质→+1→+2`。原版 +2／模组更高档、冲突、基因来源、抑制、重复／未知条目与恢复期均拒绝；只操作已确认的普通 Beauty，不改独立属性加成。
- 工业研究“纳米催情液医美应用”：1500 点，前置 PNA 简易应用与无菌材料。手术工作量 4000、医术 8、普通原液 10＋工业／闪耀药 3。原版负责账单、麻醉和消费；继承原版成功率组件及 98% 上限，专用失败只加反应，无自定义外科伤害。
- 仪式仅主奴秩序文化可选／开始；主持者与受塑者同文化且不同人，主持医术 6。受塑者限殖民者／殖民地奴隶，囚犯仅走手术；成年观众可跨文化，零观众可进行，不计两名必需角色的观众加分。
- 仪式用原版搬运预放普通原液 20＋草药 2，原版活动范围内可访问的地面堆才计入。开窗、开始、消费共用筛选规则；集合后一次消费，再举行 5000 tick 正式阶段。缺料调用原版取消结算，结果回调不扣料。
- 原版质量基值 0.40，医术／房间／观众组件直接配置；权重 0.80／0.20，继承原版质量修正与一次抽取。配方／仪式说明提供静态基础概览，没有额外预测窗口。
- “纳米塑貌反应”沿用草案：手术成功／失败 0.05／0.25，仪式成功／失败 0.15／0.60，每天自然消退 0.10，阈值 0／0.20／0.50，疼痛 0.05／0.10／0.20，工作倍率 0.95／0.85／0.70。已有实例取最大严重度，归零前不能再次受塑。
- 活体最终资格失效直接选失败，死亡／销毁跳过医美效果。重复安排扫描、自建名单、独立状态机、人员锁、退款、回滚和恢复任务均未增加。技术异常红字记录。

## 原版复用与实现细节

手术只覆盖 `AvailableReport`、`ApplyOnPawn`，接单补丁只针对新配方并保留原版拒绝；`AvailableOnNow`／`CompletableEver` 沿用父类。仪式不覆盖 `Apply`、`GetQuality` 或 `CreateLordJob`，使用原版准备窗口、角色分配及 Lord。正式提交前复用原版 `PawnNotAssignableReason` 复查当前人员，SSC 不重写活动占用／伤势／温度规则。

消费动作放在中间必经阶段转换后的 `postAction`，替代早期方案的 preAction。此时原版已初始化正式阶段及职责，但尚未发生正式 tick；同步扣料后才开始计时，成功返回后由原版完成 essential 标记。缺料调用原版取消／清理后不再 GotoToil，防止刚释放的角色又被重设仪式职责；原生专项已覆盖实际 Transition／GotoToil 与 Lord.Cleanup 的顺序和职责释放。

前两阶段不累计正式进度；原版阶段和 Lord 保存承担读档恢复，未增加“已扣料”字段或加载修复。没有结果回调的中断不补发效果；主动取消沿用原版。须注意本机原版在前置 essential 完成后，部分非主动取消的结束路径可能按部分进度结算，这属于复用的原版语义，不承诺所有中断都没有结果。

Beauty 继续作为普通人格特质迁移；反应留在身体。四语 Keyed／DefInjected 和源码资源镜像均配套。1.7 编译项显式列出新类，共享注册与种族注入受 `SSC_RW17` 门控，旧版编译清单不包含新类。

## 实机验收

1. 无 Ideology 载入：无新缺定义错误，完成研究后手术可见。启用 DLC 时只有主奴秩序文化可选择塑貌仪式；旧文化需在正常改革／编辑入口添加该仪式，不自动注入存档。
2. 健康页菜单：四段成功升级；+2／模组更高档、冲突和恢复期拒绝，重开清单取新状态。试殖民者、奴隶、囚犯、成年人形异族；核对患者已麻醉／倒地仍可手术，未成年与机械身体被拒绝。
3. 正常医疗：医术 7／8、医生工作禁用、自行手术、药物政策、工业药／闪耀药及草药排除；核对正常完成原液 10、药 3（含麻醉），成功／失败不二次扣料，中断、重接单仍为原版行为。
4. 仪式准备：医术 5／6、低社交高医术、同文化、同人双槽、两种选角顺序／拖放、零观众及 Beauty 满级主持／观众；关闭重开沿用原版名单，伤势、征召和其他活动按原版拒绝／等待。
5. 供料与阶段：先搬到活动范围；缺任一项、跨堆、禁止、无法到达、被他人预留／搬走、室内与室外、两场竞争。集合可长于两小时，正式阶段仍约 5000 tick；扣料前后主动取消、原版其他中断和存读档均核对实际损耗与是否结算，避免重复消费。
6. 最终资格变化：进行中改为 +2／冲突／恢复／改革移除模因，正常结果固定失败并取较重反应；死亡／销毁不施加效果。确认成功／失败文本一致，未额外发放文化点、附加奖励或绑定／调教经验。
7. 完整恢复与四语：四种初值、0.20／0.50 阶段及约 0.5／2.5／1.5／6 天恢复；恢复期限制受塑，不限制符合条件的医生／主持／观众。核对 UI 文案、仪式实际质量显示和人格迁移。
