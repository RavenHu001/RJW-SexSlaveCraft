## 1. 目录与解析

- 新增 `SSCRomanceMoodCatalog`：十三类完整事件共 108 个分支，A／B 持续状态 14 个分支，ID 严格区分大小写且与显示数值分离；不可变描述对象通过只读集合提供。
- 事件解析顺序为事件→当前锁链阶段→有效受虐狂→原始好感三档。目录仅接收调用方已冻结的值，不读取 Pawn、需求或授权，不调用 `TryGainMemory`。新目录完全不读取恶堕；旧实际 worker 暂未切换。
- 三档为 ≤−10、−9～59、≥60。一般档原好感＞0另用于长期资格；五个零值分支是有效解析但无记忆，无效／未知事件及阶段返回失败，不默认为零值。26 个长期期限变体、12 个一般档跨零分支均对照 Markdown 验证。
- 持续思想目录不具有目标好感（Opinion 为 null），零值持续分支有效。现行 worker 与按值计算的缓存本批未改，十四分支的实际状态刷新留第四批。

## 2. 保存契约及旧历史

`SSCRomanceMoodData` 增加版本 2、BranchId、独立 CompositeEvent、HasRawOpinion／RawOpinion、OpinionBand、Group、NominalDurationTicks。保留旧 Kind、Opinion 和可空 Corruption 字段；新枚举与旧枚举独立，不能重命名已有保存枚举名称或重排编号。缺版本字段仍为旧格式 0，未知未来版本不被解释为版本 2。

- 新快照不采集恶堕、人格 token、命令、授权或待结算请求。可选上下文只复制已冻结的旧关系、主人及实际规则；不反推旧关系、不复制旧分支或旧恶堕。运行 owner 由恢复目标的记忆处理器绑定，关联对象及历史主人引用独立保存。名称／描述保存的是分支身份，不把整段语言文本写入存档。
- 数值与标准期限是历史字段；实际 age、moodPowerFactor、moodOffset、durationTicksOverride 等仍由原生记忆保存。标准二十五天与实际保留二十九天剩余期限分别往返，不恢复成一次新事件。
- `TryReadSnapshot` 校验版本和结构，不用当前目录基准值重算历史；保存值可以与未来重平衡后的目录值不同。无效数据不猜配分支。
- 原 `CopyFrom` 和 `PersonalityMemoryUtility` 的可选载荷入口可承载派生新记忆，无须改变 Common／1.6；真实 Scribe、采集／复制、单条人格恢复及原生 CopyFrom 均已验证。提交前另补齐单条未知历史的恢复标记，限定在 1.7 条件分支；完整跨系统、旧新混合容量、克隆出生／成熟及新事件刷新仍留第二批专项。
- 原 `SSC_Romance_Experience`／`SSC_Romance_Loss`／`SSC_Romance_Control` XML、阶段顺序和旧显示路径保留。新旧组映射尚未启用，不追溯转换或重新命名旧记忆。

## 3. 新载体及独立文案

新增 `SSC_Romance_CompositeShort`／`SSC_Romance_CompositeLong` 两个 Def，分别默认三天／二十五天，均含 −15～+15 的 31 个固定数值阶段。这里阶段索引只承载数值，唯一文案身份仍是 BranchId。三十天等实际期限使用原生 override 保存。

`Thought_MemorySSCCompositeRomance` 派生原记忆类，复用保存与复制；按新保存组复用原有按 Def 的长期期限处理。跨旧 Def 语义分组及完整提交回执尚未实现，不宣称第二批已经完成。`TryCreate` 只构造独立实例，不获得记忆或证明实际事件授权；零值、缺载体、错误 thoughtClass／数值阶段返回失败。真实 worker 没有调用该入口。

- 新类通过冻结分支分别取名称／描述，通过 BaseMoodOffset 提供冻结基准，继续保留原版屏蔽、倍率、实例偏移与衰减流程。旧记忆类只增加长期组虚拟查询点，原 Kind 判断行为不变。
- 新显示保留人物参数格式化、Worker 后处理、适用的文化来源及原版思想屏蔽说明。相同 +15 的不同事件有独立文案键，换语言只变显示、不变分支。
- 每语 122 对独立占位键＋2 个未知历史兜底键，共 **246 键**；简中、繁中、英语、俄语以及源码镜像共八个 XML 新文件。所有文本均明确为开发占位，不是正式心理描述。
- 两个载体沿用 Adult 过滤，并保留 Anomaly 的 Inhumanized 条件屏蔽作者配置；本次宿主对照实际作者 XML 构造 Def／检查数值阶段与 ConfigErrors，未声称完整模组合并后的运行 Def 或实机 DLC 验收。
