## 实现范围

- 真实有效正输入后普通负荷达到满值，建立一份 `PNA_Addiction`，新依赖 D=1；已有依赖不重复创建或叠加因子，再次服药沿用原版增加严重度。上限截掉额外增量的真实暴露仍可建立缺失依赖；依赖解除后再次有效达满可复发。自然消退、读取、迁移与外部直接修改严重度不自动建依赖。
- 继续使用原版 `Hediff_Addiction`、`Need_Chemical` 和原需求条。按原版合法准入刷新；首次新需求设满，已有需求不额外重置。缺少合法需求但仍有正常需求管理器的身体可以保有依赖；缺少原版需求管理器的异常载体不强行建立原版无法正常处理的依赖。
- 普通／浓缩每份原始剂量 0.40／1.40，对应 20%／70% 负荷。专用摄入 Doer 按实际份数计算，原摄入修正只调用一次；沿用现有未启用体型／基因修正的默认配置，不额外引入新倍率。普通／浓缩已有依赖按原版物品 +1 经体型／耐受修正后补充，钳制到满，首次新生成需求设满；普通侵蚀预留入口 +0.12，枪械按实际有效负荷增量 ×2 补充，调试入口不额外补充旧需求。
- 扩展原 P1 `CompDrug.PrePostIngested` 补丁，对已接入专用 Doer 的 PNA 仅在尚无依赖时关闭旧随机成瘾；已有依赖放行原版严重度增加和需求补充，Doer 不重复补充。保留原 `PostIngested` 的其他药物行为；其他药物不受影响。未适配的第三方 PNA 摄入保留原流程，不宣称已完成第三方全来源适配。
- 低阶枪原始基数由 0.125 提为 0.15，原意识除数、快照与单次上限保留；正常意识时 +7.5% 负荷。普通负荷写入接共享入口；同一次有效伤害调用的多部位传播只输入一次，同 tick 的独立命中分别输入，完整偏转不新增负荷。仅在当前调用期间保留认领状态，退出即恢复，支持重入；不保存命中历史或按全局 tick 去重。
- 有效锁链继续使用 P1 的真实主人引用口径，无效残链不触发枪械治疗保护。有链治疗／强化、原伤害和禁用高阶武器的范围保留；不额外设计性奴完整正面阶段。绑定清依赖、负荷同严重度双向转换规则不变。
- 依赖两档固定 `SexFrequency ×1.25`，与普通负荷固定 XML 因子乘算；普通深度档综合 ×4.0625，末期 ×5，实际需求下降仍受 RJW 其他条件影响。普通负荷自身最高 ×4、第三档视听下降和末期意识上限 10% 保留。
- 恢复采用原版 `HediffCompProperties_SeverityPerDay`／`HediffComp_SeverityPerDay`，速率配置 -0.125；原版负责 200-tick 调度、严重度更新、保存、恢复百分比／天数显示和耗尽移除。取消低负荷及戒断门槛，无恢复速率补丁。没有自写恢复组件、恢复计时器或自定义恢复悬停，较大 delta 的更新行为也沿用原版。
- 戒断思绪只在戒断档生效，心情 -18。普通档沿用原版空阶段标签，避免“依赖 90%”误导；括号百分比代表已完成恢复，D 才是剩余依赖。四语及源码语言镜像同步。
- 初始化扩展原一次性规范化：旧合法 D 和需求值保留，重复依赖取最大合法单份，不相加；异常值清理、旧满无依赖不补建。DefName、Hediff 类、身体负荷与需求保存字段保留，读档幂等。
- 人格采集通用标签过滤 PNA 负荷／依赖，植入跳过历史凝胶中的同类标签；不采集或搬迁 Need_PNA。身体原值由身体保留，完整空壳与克隆处理仍留 P3。

没有新增自动补给过滤或安全负荷门槛。地图／旅队原有化学需求补给以及药物计划、娱乐／狂欢等入口继续按原物品摄入流程处理；浓缩液仍可能被自动选中。

## 实机验收步骤

2026-10-14 维护者反馈“大部经测试没有问题”，恢复专项仍报告疑问；不将该反馈扩大为整批验收。按随后“尽可能复用原版”要求，恢复机制已调整，最新依据见[原版恢复调整](PNA成瘾原版恢复调整.md)。当前调整全量 29/29 套、1932/1932 项，PNA 132/132；上方 `.builds/pna-p2/` 的构建与通过数保留为调整前历史。

1. 退出游戏后加载本次测试 DLL／Defs，重启进入测试存档；对无有效链的普通角色观察摄入一份普通／浓缩液约 +20%／+70%，未满不出现随机依赖。
2. 集中输入到满，确认只出现一份依赖和合法需求条，首次满足度为满；反复满值不重复通知，再次服药会按原版加深已有依赖。使用 `PNA P2: fill load` 可快速验证，清负荷不清已有依赖。
3. 完全断供：需求满足度降到 ≤1% 才是原版戒断，6% 仍未戒断；首次满需求约 2.97 天进入戒断并出现 -18 心情。依赖从建立起持续恢复，与负荷和戒断独立；完全断供约 8 个有效日解除，边界存在原版调度及浮点误差。恢复期间服药增加严重度（默认 +0.1/次），不是暂停计时。观察原版百分比逐渐增加，不把 0% 已恢复误读为零依赖。
4. 检查当前催情、日常任务、末期晕倒与约 5 天戒断压力的实际平衡；依赖加成不改变普通五档的能力／疼痛数值。缺合法需求的合法健康对象也应按原版恢复。
5. 测试普通和浓缩的自动／手动摄入、地图和旅队原有补给；当前不增加浓缩筛选或 90% 门槛，不以“不会自动过载”作为验收要求。
6. 用低阶枪观察正常意识约 +7.5%，高意识抗性快照、低意识保底及伤害／治疗／强化；同次多部位传播不重复加 PNA，独立连发命中仍分别增加。有链不出现普通依赖，无效残链不能保护。
7. 满负荷绑定／解绑保持同严重度，绑定清依赖，解绑不补回；检查新建依赖期间链回调不会留下普通依赖。
8. 保存读取旧依赖、旧满无依赖、部分恢复和既有满足度，重复加载不灌满、不重置、不补建。采集／植入人格后，PNA 身体状态与需求值不随来源人格迁移；特殊空壳与克隆细则仍需 P3。
