## 身体归属实现

统一原则：所有 PNA 身体状态只属于当前这具身体。人格采集不带走，植入不覆盖宿主，SSC 克隆不继承来源状态。Need_PNA 与满足度也不随人格搬迁。

`SSCPnaExposureUtility.IsBodyStateDef` 使用明确的 DefName 排除八类状态，不按名称片段或描述中的“纳米机械”推断人格归属：

| 身体状态 | DefName |
| --- | --- |
| 普通负荷 | `Hediff_PNA_Debuff` |
| 性奴负荷 | `SSC_Hediff_PnaRootedLoad` |
| 成瘾 | `PNA_Addiction` |
| 两种枪械临时强化 | `Hediff_PNA_Combat_Buff`、`Hediff_PNA_Combat_Buff_Plus` |
| 意识抗性快照 | `Hediff_PNA_Consciousness_Record` |
| 普通 PNA 产出与克隆低效产出 | `SSC_Purple_HyperLactation`、`SSC_Hediff_RabbitCloneLowPNA` |

人格专精、恶堕、身份及已有记忆流转仍使用各自原机制。负荷输入和成瘾判断继续使用较窄的专用判断，不因为扩大身体排除清单而把产出或强化当作负荷。

- 人格：复用采集与旧凝胶标签恢复中的现有过滤；植入全部身份、锁链、专精和技能恢复完成后，调用现有身体协调和原版需求准入。仍合法的需求保留宿主满足度，不补满、不从凝胶赋值。
- 新生克隆：`ShouldKeepSscHediff` 在宽泛 SSC 前缀／包名判断前排除身体 PNA，因此新生清理移除来源八类记录。年龄、特质和身体准备完成后协调最终锁链并刷新原版需求准入；若仍合法存在 Need_PNA，仅在新生入口使用原版 `SetInitialLevel` 初始化，绝不沿用来源满足度。
- 成熟：同一过滤只跳过来源 PNA，不清除或覆盖克隆自行获得的记录。自行获得的负荷、成瘾、满足度、强化、快照和产出进度保留；低效产出仍由成熟入口独立生成，已有记录不重置。成熟标记及健康回调完成后按最终有效链协调。
- 例外：最终有效锁链仍优先，清除普通成瘾／需求，同严重度原位转换负荷；解绑不恢复历史成瘾。合法需求是否存在始终由原版决定。
- 空壳：不增加空壳冻结、隐藏、寻药 AI 或健康更新分支。健康有效更新继续消退负荷，成瘾沿用原版恢复；冷冻、暂停及需求冻结沿用原规则。
- 保存：沿用 P1/P2 规范化与保存字段；读取不是输入，不补建成瘾，不重置合法进度。维护者确认当前无历史克隆案例，不做旧克隆迁移或追溯清理。仅覆盖 SSC 自己的流程。

没有新增缓存、计时器、Harmony 补丁、保存字段或正常玩法入口。既有五个 PNA 补丁保留。关键分支均补充中文代码块级注释；四语身体归属说明与源码语言镜像同步。

## 实机确认与复测范围

1. 准备有负荷／成瘾的普通身体，抽取人格；确认原身体状态保留，空壳仍逐渐消退和恢复。冷冻后停更，解冻不补算冻结时间。
2. 将该人格植入另一具有不同 PNA 状态的身体；来源数值不带入，宿主仍合法的负荷／成瘾／满足度保留。再覆盖有链／无链组合，确认最终有效链正确分流。
3. 使用隔离测试存档及已有开发者工具检查 SSC 克隆内部流程；正常兔玩法入口仍禁用。本批不新增入口，也不处理历史克隆。新生不继承来源 PNA、临时强化、快照、产出进度或满足度。
4. 新生克隆自行服用 PNA 后再成熟：自身负荷／成瘾／满足度继续存在，来源同期高值不覆盖；成熟自行生成低效产出。另测未摄入的克隆不会从来源补建成瘾。
5. 保存并重载普通、性奴及空壳身体：合法负荷、成瘾恢复和需求进度保留，不凭旧满值补建成瘾；绑定／解绑继续同严重度转换。
