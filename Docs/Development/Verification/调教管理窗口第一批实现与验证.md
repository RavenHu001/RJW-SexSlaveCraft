## 实机反馈与原版单选修订

- 实机截图显示窗口已打开并呈现 Carr 的只读概况。截图裁切了游戏画面，窗口尺寸本身正常。概况中的重复身份行已删除。
- 核对本机 1.7.5005 的 `WindowStack.HandleEventsHighPriority` 和 `GetsInput`，旧窗口启用 `absorbInputAroundWindow` 时会抢先消费原版单选所需的鼠标按下事件。窗口现在允许窗外输入，使用 `ColonistBar.Entries`、`DrawLocs` 和 `Size` 避开实际头像行，常规尺寸和居中布局沿用原窗口。
- 原版 `Selector` 负责选角。概况每次绘制读取实际单选和训练组件，空选、多选、不可管理对象显示选角提示，恢复有效单选后在同一窗口更新。角色或组件变化时滚动归顶，离开原游戏的地图视图时关闭。
- 修订使用本机 1.7.5005 rev1082 隔离构建，零警告、零错误。边界宿主通过 **17/17**，覆盖原标签路由、原版选择跟随、空选及不可管理对象、跨地图、组件替换、非模态窗口与殖民者栏避让。四语资源 28 项对齐，670 份语言镜像无差异。产物和回执位于 `.builds/training-ui-native-selection/`。

## 窗口原型布局补齐

- 实机反馈指出初版仅显示头像和若干状态文字。按原型补齐角色标题区、独立关系摘要、左侧六页导航和右侧概况，窄窗导航改为顶部换行。概况字段和值分别对齐并独立滚动。未接入页面以禁用态显示，悬停可见说明。
- 关系摘要随原版单选刷新。性奴读取锁链主人及保存的指定调教员，主人侧使用现有本地候选及逐项核链规则生成计数和至多两张缩略图。未设身份的角色保留任职概况。空选和多选时保留窗口布局与选角提示。
- 本机 1.7.5005 rev1082 隔离构建零警告、零错误。宽窄布局和原版选择联动的边界宿主通过 **10/10**，`BondOverviewUI` 通过 **233/233**，四语资源 64 项对齐且镜像无差异。候选和回执位于 `.builds/training-ui-layout/`。
