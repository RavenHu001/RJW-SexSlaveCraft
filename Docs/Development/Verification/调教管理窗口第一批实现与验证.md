## 本批实现

- 原「调教」标签继续使用原注册与显示资格。1.7 的 Harmony Prefix 精确接入 `InspectPaneUtility.ToggleTab(InspectTabBase, IInspectPane)`，只处理原生地图检查面板中的 SSC 调教页。真实接口已核对为 private static void，原教程检查先于该入口。 [标签接入](../../../Sexslavecraft/ThePatches/Harmony_TrainingManagementTab.cs)
- 原标签和新窗口共用 `CanInspect`，保持殖民者、本殖民地囚犯、原版奴隶及自我调教例外的条件。窗口单实例，显示当前肖像、姓名、身份、任职及现有调教选择与冷却，概况只读。 [原可见条件](../../../Sexslavecraft/ITab/ITab_SexSlaveTraining.cs) · [新窗口](../../../Sexslavecraft/UI/Dialog_SSCTrainingManagement.cs)
- 点击当前角色头像打开菜单，从当前地图已生成角色中筛选。选角先复查原 Comp 与窗口代次。清空选中后再次核对地图与候选，避免其他模组在清空回调中换图时继续选人。原生单选成功后更新窗口。选择失败时尝试恢复原对象，恢复失败或外部换图时关闭。候选选择代理在选中前拒绝。关闭、换档、源 Comp 替换和外部改选会撤销旧请求，A → B → A 后旧菜单仍过期。
- 新增简中、繁中、英文和俄文各九项 UI 文案，并同步源码镜像。已允许日常调教与当前冷却分开显示。 [简中资源](../../../1.7/Languages/ChineseSimplified/Keyed/SSC_TrainingManagement.xml)

## 待实机验收

1. 从原位「调教」单击开窗，核对教程模式、Esc／关闭、重复打开及其他原生标签。确认普通游戏会话中补丁实际命中。
2. 点击当前角色肖像打开菜单，切换殖民者、囚犯、原版奴隶和自我调教例外，核对原准入。概况显示真实状态，切换角色后地图单选、标题、肖像及概况一致，镜头保持同图原位置。
3. 在真实选择通知及模组组合下验证失败回退、外部改选、角色离图和组件替换，检查旧菜单失效。
4. 用四语、长姓名和较小逻辑分辨率检查原生标题、选择菜单和纵向滚动。后续批次将原业务控件逐步迁入，首批候选用于上述独立链路测试。
