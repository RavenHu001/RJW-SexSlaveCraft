## 直接读取与补漏

| 数据 | 首屏路径 | 补漏与后续更新 |
| --- | --- | --- |
| 唯一实际主人 | 当前角色的锁链，检查引用、自指、销毁与丢弃 | 直接字段变化立即重读；不回退到调教员 |
| 指定调教员 | 训练组件保存的 selectedTrainer，独立判定指派状态 | 显式更换后立即重读；不清空其他有效关系 |
| 已知从属 | 缰绳 targets 按引用去重，逐个核对该角色锁链是否指向来源 | 合入本视图过去补漏发现的引用，每次重新校验；改绑、销毁或丢弃后排除，死亡仍保留 |
| 其他遗漏从属 | 首屏不依赖世界扫描 | Update 按原完整候选路径补漏，包括身份未设置、缰绳漏项的来源 |
| 位置 | 只沿角色／尸体的持有链读取地图、容器、世界对象或世界格 | 本地路径不索引飞船；补漏共享位置索引，点击重新解析当前位置 |

[BuildLocal / BuildWithKnown](../../../Sexslavecraft/common/SSCBondOverviewUtility.cs)共用原有筛选、快照和排序规则。本地读取不枚举地图、世界角色集合、容器内容或飞船成员／货物；只遍历缰绳、本视图已知引用和必要的父持有链。其成本随已知关系数量增长，不承诺常数时间或零分配。全局补漏保留全部原候选来源，额外纳入本视图已知引用，不因反向索引完好或身份为空而跳过扫描，也不修复锁链、缰绳、身份或指派。

`CoverageComplete=false` 时显示“已知从属：N”；已知为零显示正在补查，不能提前断言没有绑定。从完成过一次全局补漏起显示原总数口径；该字段仅说明本视图完成过补漏，不保证此后数据永不变化。跨来源、跨游戏拒绝沿用旧已知引用；同源地图切换重新计算位置，最后一个使用位置退出即释放引用。

[会话](../../../Sexslavecraft/common/SSCBondOverviewSession.cs)在登记新来源时建立本地快照。重复登记只比较锁链／主人引用、调教员、身份、缰绳及列表引用和长度，不重复遍历全名单或分配快照；直接字段变化立即重读，原地等长换项、阶段、死亡、位置等由独立的两秒本地刷新兜底。更换调教员成功后立即显示新指派，同时保留其他有效关系及全局刷新期限。

全局补漏仍遵守完成后至少两秒、空候选五秒、耗时十倍退避封顶三十秒的会话预算；换来源、打开总览、旧行请求和显式指派均不能绕过。卡片／总览同源共享，两个持续活跃来源公平轮换；同帧至多一次全局构建。全局失败保留可展示的本地事实，记录失败并按原预算重试，日志仍节流。扫描退避不阻止直接关系展示或本地刷新。

“不阻塞展示”在这里指直接关系不等待扫描结果或扫描期限；**完整补漏仍同步运行于主线程 Update**，不是后台线程或分帧扫描，大存档的一次扫描仍可能造成帧耗时尖峰。本轮未新增每 Tick 全局遍历或静态 Pawn 索引。

[Gizmo](../../../Sexslavecraft/UI/Gizmo_SSCBondOverview.cs)直接调用原版机械师使用的 `GenUI.DrawTextureWithMaterial` 与 `Command.BGTex / BGTexShrunk`，背景和边框来自同一纹理；低亮度使用 `Command.LowLightBgColor`，禁用／低亮度使用 `TexUI.GrayscaleGUI`。保留调用者 GUI 状态，空调教员面板仍可进入更换，不添加 Biotech 依赖或复制机械师控制组逻辑。

本地快照没有飞船索引时，未知位置标记和悬停提示表示“点击后复查当前位置”，不会仅因没有预览位置就屏蔽点击。头像仍先检查现时关系，ProcessInput 继续核对游戏、单选来源、快照与代次；导航沿原路径再次检查锁链／指定引用并重解地图、容器、尸体、世界对象、世界格或飞船。不可达目标显示拒绝信息，改绑和跨存档仍拒绝。原绑定 `IsCurrent`、`TryNavigate` 正文及整个 World 收集／遍历文件保持性能基线内容。

普通查询、查看、分页和定位只读；更换／清空调教员仍是明确操作，通过已有原子指派与授权服务提交，不改变实际锁链主人。
