## 公共接口与采样语义

`CaptureBeforeAdvance(driver, observationContext)` 捕获只读快照，`TryGetOriginalAdvance` 返回有效结果或具体失败原因。观察上下文显式包含来源、周期 owner、周期编号、操作编号及阈值变化许可；调用方须在游戏线程提供可信边界，不能从两个任意时点的差值反推速度。

`RawAdvance = CounterAdvance + ThresholdAdvance`，差值中间量使用 long。自动覆盖的四种来源只允许计数下降，阈值变化会拒绝；外部观察者可以显式使用 External 来源允许阈值变化。该扩展不等于已经适配 Onahole，本批没有安装它的专用补丁。

自动采样发生在原表达式已算出新计数、字段即将写回之处：捕获旧值，原写回一次，形成原始结果，然后沿原高潮调用继续。无效上下文、加载期或适配关闭时仍保留原写回；原字段访问和原高潮异常不在 SSC 的可恢复检查 catch 中吞掉。本批没有对计数做第二次效果写入。

`TryGetLastObservedAdvance(driver, out result)` 读取当前驱动最近一次仍有效的不可变结果，不创建记录、不补采、不消费、不重新差分。自动采样的提交前复查可调用 `IsStillCurrent(result)`，直接核对采样器现行凭据；外部观察者的重载须传其发行者当前上下文，不能拿旧 Context 自证有效。初始化、真实高潮、任务／SexProps 变化或后续外部写入会使结果不可用；它不是历史队列。多个消费者应共享已取得的结果；将来敏感度消费者应在桥内预留位置接入，不能在已补充后重新取前后差值。

这些凭据只说明物理计时的归属与时效，不授予 SSC 身份／人格／身体效果权限。后续业务消费者仍须另外复查其原 Comp、人格 token、锁链与身体 owner；不能把公共 `IsStillCurrent` 当作业务准入。

## 路径、顺序与生命周期

| 自动来源 | 实际写回 |
| --- | --- |
| RJW `JobDriver_Sex.SexTick` | 自身、受方各一处，共两处 |
| 动画 `HarmonyPatch_SexTick.Prefix` | 替代基础 SexTick 的自身写回一处 |
| UAP `TickInitiatorOnly` | 发起方一处 |
| UAP `TickSharedReceiverOnce` | 共享受方一处，在其 SexProps 修复之后；原 PrimaryInitiator 去重保留 |

Transpiler 只接受整段锚点数量、同实例减法及后续原高潮调用均匹配的输入，保留原标签／异常块。真实表达式的变量减量得到保留；不匹配时返回收到的原指令，不留下半段修改，不回退到固定减 1。

安装先处理动画 Prefix 方法本身，再生成基础 SexTick 包装。适配以 Last 和已知 owner 的 after 约束安排，并检查最终排序及 before／after 约束是否真的满足；循环依赖被 Harmony 打破也不能当作成功。保存安装时 Transpiler 集合凭据，后来新增／修改集合即使本适配仍排最后，也不沿用旧安装证明。

运行开关只在安装／低频验证完成后提交，桥内是数组查询；Transpiler 的诊断重放不提交开关或清执行记录。新 Job／读档的 SetupToils 入口低频复核依赖；不在逐 tick 或每次高潮反射。任意运行中重打补丁仍不属于兼容承诺，失配后不自动猜测修复，原任务继续。

观察基础 Setup、自慰独立 override、原 Orgasm、动画 Start、UAP 时长同步、任务 Cleanup 和加载入口。嵌套重设范围合并失效，并由成对 Prefix／Finalizer 关闭；Orgasm 未真正触发时不凭调用次数伪造新周期。共享必需观察点缺失时停止相关采样，不能只因写回锚点仍在就继续发布结果。

本批读档处理只废弃瞬时样本；**没有执行余数要保存，也未实现规划中的 IExposable 载荷、SetupToils 成功标记或恢复接续**。这些仍属于后续倍率／保存批次，不以此次加载期清理测试冒充已完成真实存档恢复。
