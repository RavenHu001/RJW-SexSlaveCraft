## 宿主边界与待实机验收

组件、工具类、身体 Hediff 及其存档来自真实生产 DLL。独立 CLR 使用 Harmony 2，生产游戏引用 Harmony 3，二者的 CodeInstruction 不能混用；本专项直接链接同一份生产孕期补丁源码，用 Harmony 2 编译后安装到真实游戏／RJW 方法，不复制匹配或倍率算法。测试文件局部抑制刻意同名链接产生的 CS0436。生产 Harmony 3 构建通过，但游戏自动特性扫描、其他模组共同补丁及 Waylith 实机执行仍待确认。

属性测试使用本机 StatDef 的实名与正常基础值，隔离能力、装备、特性、疲劳等独立修正，实际执行原版 StatWorker 的完整未终结属性运算及真实 Hediff CurStage。没有证明最终属性在所有上下限与其他模组组合中都等于基础值乘表格倍率。

食物类别由夹具固定，原版 BodyResourceGrowthSpeed 与 HungerMultiplier 保留；测试未执行完整饥饿／伤势流产。StartLabor 记录实际调用后隔离后续临产健康状态、地图与出生流程，不能把本轮当作完整分娩实测。

RJW 创建与缺胎儿重建测试只把遗传选择、基因集合及婴儿生成作为外部边界提供；原 Create、PostMake、Add、Initialize、原始时长和时间写入实际执行。不验证遗传、完整胎儿或产后处理。存档测试不深存完整胎儿 Pawn 列表，也不重建地图；母体健康、组件、时间及引用／PostLoadInit 链保留。为避免扫描 RJW 旧 IMGUI 类型，只将所需真实类型名称定位到依赖程序集。xxx 静态表的其他模块引用在宿主预热时隔离日志，业务测试期间所有错误仍纳入失败。

维护者后续实机检查：四个目标 Def 的组件实际加载、原版和 RJW 新妊娠缩短、普通／旧妊娠不补发、读档及 RJW 缺胎儿恢复、临产／分娩继续正常，以及阶段属性与现有身体状态叠加。尚未取得新的运行时 Def 快照，不以作者 XML 或独立宿主替代完整环境加载结论。
