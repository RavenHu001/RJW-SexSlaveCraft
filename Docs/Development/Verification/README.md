## 如何继续验证

1. 先读关联记录，沿用其中的条件、步骤和历史反馈范围。
2. 记录本次版本、场景、结果与日志位置；自动回归和实机反馈分别记录。
3. 得到对应实机结论后，更新关联记录、开发日志和本表。只关闭实际已确认的范围；涉及新功能时回到[当前规划](../../Design/README.md)另行定义。

其他历史记录中的测试建议仍可作为复测参考；本表汇总当前版本已明确保留的专项缺口，不将所有可能的兼容组合列为待办。
