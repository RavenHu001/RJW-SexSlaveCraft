## 如何继续验证

1. 先读关联记录，沿用已约定条件，核实目标游戏、依赖与产物版本。
2. 记录具体场景、结果与日志，分别说明自动回归、源码取证和实机反馈。
3. 只关闭本次实际确认范围，更新对应记录、开发日志和本表；新增功能另回规划定义。
