## 实机验收

1. 实际主人手动服用普通／浓缩液，确认没有负荷、成瘾或对应需求；原物品娱乐按旧规则保留。普通角色服药和十天恢复仍正常。
2. 普通角色先获得负荷、成瘾及需求，再成功切为主人：立即清药并由原版撤销需求；退出主人不恢复旧状态，之后可以重新受药。只有主人资格但未选择主人身份者仍正常受药。
3. 带 PNA 产出能力的身体切为主人，确认普通产出 Hediff 和生产进度保留，能够继续生产。开发验证低效产出时同样保留，不新增克隆正常玩法入口。
4. 使用主人旧档或先用开发工具准备状态，再保存重载：清除药效、成瘾、旧强化和抗性快照，保留生产状态；重复加载不重复生成状态或通知。
5. 人格植入后若宿主最终为主人，清宿主药效并保留宿主产出；若最终为普通／性奴，继续遵循原身体归属和有效链转换规则。
6. PNA 枪命中主人不产生药效或抗性快照，物理伤害／原治疗保持既有行为；绑定／解绑普通对象继续同严重度转换。

两种新性交来源目前只有共享输入准备，没有正常玩法触发入口；本批不应通过实际性交观察到新增补给。待后续接通完成事件再验收真实接触、来源资格和一次结算。
