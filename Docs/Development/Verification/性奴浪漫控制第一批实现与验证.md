## 1. 本批实现

| 范围 | 实现及边界 |
| --- | --- |
| 保存源 | 训练 Comp 的 `sscRomanceConfig`，七项原始选择及格式版本；五项许可缺省 true、两附加开关缺省 false。不写能力字典或旧性行为限制配置，查询不补建配置。 |
| 角色解析 | 明确 SSC Slave 身份、有效从属锁链、当前锁链阶段及实际主人；不回退指定调教员，不修复关系。主人死亡或离图不自动解绑。 |
| 双边策略 | `CanInitiate` 与 `Reception` 分别表达发起和接收。被动返回普通判断／必拒／保证接受；主人保证仅影响接收者且优先于被动禁止，主动仅主人不限制结束第三人关系。允许并不代表原版条件、任务或关系成功。 |
| 安全提交 | 捕获 Pawn、Comp、人格 token、链、主人、配置实例及授权世代；提交复查原上下文及阶段、玩家资格。原人格／载体／绑定下的迟到请求不能取得新权限。 |
| 普通人格流转 | `StorePawnData` 采集独立副本、`CopyFrom` 复制凝胶快照，`InheritEverything` 预检后按来源精确覆盖。显式 false 和暂停选择保留；旧凝胶缺配置覆盖为默认。 |
| 两条提取入口 | 通用 `ExcretionUtility.DoExcretion` 与场景结束的 `JobDriver_PE.CompletePersonalityExtraction` 都在剥离前检查未知配置格式，成功放置凝胶后才清原体浪漫配置；沿用既有人格替换作用域及原流程失败边界，不新增事务回滚。 |
| 新生克隆 | 复用 `SSCRestrictionCloneHook` 的现有时机，调用独立浪漫重置，恢复五项许可允许、两附加开关关闭并获得新授权世代。不复制偏好或命令，不改绑定、旧模板和其他能力；成熟与正常读档不重新套默认。 |
| 授权有效期 | 持久世代与偏好分开保存，不进入人格凝胶；命令凭据绑定执行者、目标、行为、实际主人、世代及原锁链存档身份。换主、解绑、退阶、身份退出、空壳状态或人格替换使旧授权失效；普通存读档保留合法世代及原链身份并重建运行时 token。仅提供凭据契约，任务领取、执行与结算去重留第三批。 |

新增生产模块位于 [common/Romance](../../../Sexslavecraft/common/Romance/SSCRomanceConfig.cs)，Comp 与凝胶存档接入位于 [Comp_Train.Romance](../../../Sexslavecraft/Comps/Comp_Train.Romance.cs)。新增文件仅编入 1.7，共享源码调用受 `SSC_RW17` 保护，原 1.6 编译清单及 1.6／Common 冻结产物不变。

加载后的授权观察复用已有读档 Pawn 遍历，运行中使用身份、锁链与人格局部通知；不新增世界 Tick 扫描。外部直接写锁链 `target` 沿现有锁链 Tick 检测，绕过通知且在检测前恢复原值的外部写入不作已覆盖声明。

## 2. 异常配置契约

- 缺配置或缺单项字段按本模块默认解释，保留现有原版行为。
- 未支持格式保留版本及已读取字段，状态返回 `UnsupportedConfig`；普通互动不施加 SSC 浪漫覆盖，拒绝修改及新命令授权。
- 人格提取／植入在破坏原人格前拒绝未支持格式，不能静默重置或丢弃非默认选择；缺少接收 Comp 而无法保存非默认配置时同样提前拒绝。
- 本批固定格式不承诺无损保存未来未知字段；未升级读取器时不将未知版本伪装成当前格式。

## 5. 提交前复核与修正（2026-10-24）

按维护者要求逐项复核第 10.1 节，发现并通过新增原生回归复现三处授权问题，修复后未发现第一批范围内剩余阻断问题：

1. **外部空壳状态使旧授权复活。**原实现只在 SSC 人格替换作用域内撤权，外部添加再移除空壳标记会恢复原凭据。现复用既有空壳健康通知，在首次进入空壳状态时旋转世代，保存偏好保持；同时覆盖观察基线尚未建立的旧编辑请求。
2. **同主换链后读档丢失运行时引用检查。**绕过通知替换锁链时，运行时能拒绝旧引用，但原存档凭据只比较主人和世代。现保存原版锁链 `GetUniqueLoadID()`，恢复时同时核对；缺链身份及负 loadID 不授权，正常读档重建实例但保留原 ID 的合法请求仍可续行。无需持有已离体健康实例的跨引用，不新增人格侧授权副本。
3. **关系清理回调掩盖中间换主。**原通知晚于关系清理，回调通过生产入口恢复原主人时可能漏掉换主。现于主人引用写入后、缰绳及关系回调前立即观察；以真实关系清理的 Harmony 重入回归验证旧授权不复活。
