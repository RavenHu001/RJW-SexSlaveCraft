## 实现范围

- 两种现有伤害工人均将有效命中接入 `ApplyExposure(..., Weapon)`；有链分流到原性奴负荷，普通分流、满值成瘾、末期强化和实际增量补需求规则不变。
- 低阶原始基数 0.15，旧意识快照、>2 建立快照、无快照时 0.2 保底和原始单次上限 1 保持。归一化输入为原始增量除以 2；有链不增加独立参数。剂量在本次强化、治疗之前计算，意识 100% 时每枪约 +7.5 个负荷百分点，300% 时约 +2.5，实际能力及旧快照会改变后续结果。
- 有效链命中保留治疗和无枪伤分支；普通分支仍调用原伤口方法，伤害量／穿甲设置不变。原治疗及普通伤害仍按原部位回调次数执行，只有 PNA 输入和活化提示每次命中认领一次。
- 命中保护只属于当前 Apply 调用，保存／恢复方式与既有认领一致，支持嵌套调用，finally 释放；不作为身体状态缓存或保存字段。输入回调中解绑，不向这次受保护命中的后续部位追加伤害；已解绑不再治疗。输入中新获有效链也跳过普通枪伤。
- 紫色弹丸图形、尺寸、颜色、速度与枪械射击参数保持。低阶实际治疗时显示四语治疗飘字；成功输入且最终仍是有链非主人、负荷存在时显示 PNA 活化。满值性奴仍显示成功输入反馈，不把饱和当作失败；无伤口不虚报治疗。离图不创建地图飘字。高阶原先关闭的治疗飘字保持关闭，入口可显示新活化反馈，但高阶武器／弹丸继续注释禁用。
- 主人跳过低阶抗性快照建立，沿用统一药效免疫；有链主人仍可治疗、无枪伤，无活化；无链主人保持原普通伤害。
- 两种旧 Buff 不再由枪械生成。现有身体协调在无负荷早退前清理旧实例，现有健康添加补丁拒绝重新添加；读档、身份及人格／克隆收尾继续复用原协调调用。仅在发现旧 Buff 时创建移除快照，避免回调修改健康集合；不把旧严重度转换成负荷。兼容 Def 与扩展字段保留，运行 XML 删除 combatBuff 引用，保留两种生产能力、意识抗性、合法负荷／成瘾与需求。
- 修改必要中文块注释，四语反馈／枪械说明及源码语言镜像同步。没有新增缓存、计时器、Harmony 补丁或存档字段。性吸引与实际性交来源未接入。

## 源码证据与检查边界

初始提交 `94cd803` 和当前枪械的有链分支均在治疗／强化后 return，不调用基类伤口处理。本机 RimWorld DLL MVID `61e4173561894da49d210260257b5097` 的 `DamageWorker_AddInjury.ApplyDamageToPart` 先做护甲与剩余伤害检查，再调用特殊部位效果；当前接通保留该时机，完全偏转不输入 PNA。Bullet 本身仍通过 TakeDamage 进入命中流程，不能将无枪伤描述为完全跳过伤害事件或全部第三方回调。MoteMaker.ThrowText 的原参数 3f 是淡出前时间，沿用原样。

测试宿主模拟部位回调、伤口处理调用和显示请求，不替代 Unity 绘制、完整护甲与伤口算法、第三方补丁或运行时合并 Def。当前无可用运行时合并快照；维护者已确认本轮实机测试没有问题，该反馈不扩展为所有第三方组合均已验证。

## 游戏内测试步骤与预期

1. 完全退出后重启游戏，加载测试档。准备非主人射手与简易 PNA 发射器，选一名有真实主人引用的有效链性奴。记下其伤口、负荷、意识与其他增益，必要时用已有 PNA 调试清负荷隔离观察。
2. 征召射手并强制攻击这名性奴，逐发暂停检查：应出现原紫色弹丸和 PNA 活化飘字，性奴负荷上升，按五档获得强化和对应心情；健康栏不新增枪伤，也不新增两种旧战斗催情强化。意识受锁链等影响，单发不必正好是 7.5%。
3. 给同一性奴准备一个可自然恢复的伤口，再射击：应治疗该伤口并出现治疗飘字，同时保留活化；健康性奴只显示活化，不虚报治疗。不要用不可自然恢复的病症作为治疗对象。
4. 将性奴负荷调至满值后继续射击：仍有活化反馈、治疗（若有合适伤口）和无枪伤保护；不新增普通负荷、成瘾或其化学需求。停止输入后沿原负荷规则消退，解绑回同严重度普通负荷。
5. 对无链非主人、失效残链目标各射击：仍进入普通负荷与原枪伤分支，不出现性奴活化／治疗反馈。普通负荷达满仍建立成瘾、末期保留倒地；已有需求按实际枪械负荷增量补充。
6. 分别检查无链主人和有有效链的主人：都不增加 PNA 药效、成瘾或抗性快照；无链保持原枪伤，有链保持治疗／无伤且不出现 PNA 活化。
7. 加载含两种旧战斗强化的旧档，检查两种记录在完整初始化后消失，不折算出新负荷，合法已有负荷／成瘾／需求和产出进度保留。再保存重载应保持一致。开发模式直接添加旧强化应被拒绝。
8. 用护甲完全挡下命中时不应输入、治疗或显示成功活化；护甲结果会随机，结合战斗日志确认确实完全偏转。切换四语检查飘字和枪械说明，查看启动及操作日志没有新增红字。
