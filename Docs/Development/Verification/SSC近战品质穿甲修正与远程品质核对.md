## 问题与修正

维护者确认太空远程武器 XML 和机制正常，并发现三件近战的穿甲没有品质增益。本机原版 `VerbProperties.AdjustedArmorPenetration` 复用 `MeleeWeapon_DamageMultiplier`；旧品质例外跳过其中品质项，因而伤害与穿甲一起失去了品质系数。

[共用品质适配](../../../Archive/PnaMeleeQuality/Harmony_SSCPnaMeleeQuality.cs) 保留原有品质伤害例外，新增实物与抽象装备的两个底层穿甲重载 Postfix，只为显式标记的近战武器补回品质系数。系数从当前近战伤害 StatDef 的实际 `StatPart_Quality` 曲线读取，不在 XML 或代码复制七档常量。其他修正已在原版结果中，只保留一次；不更改共享属性缓存，也不临时开启全局品质。

Verb 包装重载会调用实物重载，因此不重复补丁包装入口。短矛、短鞭的原版近战及丝鞭专用 Verb、实物信息卡数值与详细说明共用该入口。原版无实物重载没有品质参数，按普通品质显示定义／配方预览，不凭空构造高品质实物。未修改三武器的 XML、伤害处理器、PNA 剂量、修复、护盾或身份保护。

伤害的品质系数仍为 1，主攻击基础保持 5／3／1；人物、场景、其他合法倍率和原版随机浮动仍可改变最终伤害。短矛／短鞭零穿甲柄击仍为 0；信息卡的平均穿甲会对多个动作加权，不等同于本表主工作端数值。普通武器及远程武器的防身近战不在这项例外中。

## 六把现役远程武器的品质核对

本轮只检查远程规则，不改动远程武器 XML 或品质行为；废案简易发射器不作为现役武器恢复。

| 品质 | 远程伤害／穿甲倍率 | 武器精度倍率 |
| --- | --- | --- |
| 极差 | 0.90 | 0.80 |
| 较差 | 1.00 | 0.90 |
| 一般 | 1.00 | 1.00 |
| 良好 | 1.00 | 1.10 |
| 优秀 | 1.00 | 1.20 |
| 大师 | 1.25 | 1.35 |
| 传奇 | 1.50 | 1.50 |

伤害由实际 `ProjectileProperties.GetDamageAmount` 取整，不能将倍数直接当最终整数；例如 2×1.25 得到 2、3×1.5 得到 4。穿甲按浮点数缩放，不自动封顶为 100%；武器精度经原版属性最终化限制在 1%～100%，仍不等于实际每发最终命中率。

下表为普通／大师／传奇的实际原生调用结果，格式为物理伤害／穿甲：

| 武器 | 一般 | 大师 | 传奇 |
| --- | --- | --- | --- |
| 吹箭筒 | 3／5.00% | 4／6.25% | 4／7.50% |
| 轻弩 | 7／18.00% | 9／22.50% | 10／27.00% |
| 速射针枪 | 2／30.00% | 2／37.50% | 3／45.00% |
| 精确针枪 | 4／40.00% | 5／50.00% | 6／60.00% |
| 脉冲枪 | 1／70.00% | 1／87.50% | 2／105.00% |
| 投射枪 | 1／90.00% | 1／112.50% | 2／135.00% |

太空两枪传奇品质伤害从 1 变成 2，穿甲可达 105%／135%；本轮保留此原版行为，不额外施加固定伤害例外。射程、预热、冷却、连发数／间隔没有原版品质项；人物及其他修正另算。六枪普通防身近战仍吃原版近战品质。PNA 基线始终从伤害扩展读取，太空修复从 baseLoad 推导，不因品质或弹丸物理伤害提高而增加。
