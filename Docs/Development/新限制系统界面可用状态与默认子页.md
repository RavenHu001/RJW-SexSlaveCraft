# 新限制系统界面可用状态与默认子页

开发日期：2026-09-21（本地时间）。基于 `2ac62e0` 的界面调整；未发布，待维护者实机测试。

## 界面行为

1. ITab 的“展开行为限制”保留在调教设置紧邻上方。只有实际受系统管理且总限制开启的角色可以展开；未绑定或总开关关闭时按钮置灰、不可点击，悬停说明原因。切到不适用角色时右栏隐藏并回收宽度，会话内展开偏好仍保留。没有新增研究门槛。
2. 角色条目实际命中装备或已启用特化的强制来源时，勾叉显示当前生效值，文字及控件置灰，点击文字、图标或下属对象范围均不可修改。强制来源短标记继续显示，悬停说明原个人选择、有效值、来源和锁定原因；原选择不被显示值写回。关闭特化强制仅解除该来源，装备仍可锁定条目。
3. 设置主页仅保留限制总开关、特化强制开关、默认配置入口，以及本区块最下方的行为限制测试入口。测试说明移入悬停；无可配置地图角色时继续禁用测试入口。
4. “编辑行为规则默认配置…”打开独立滚动子窗口。六项模板编辑和批量应用都在子页；主菜单也能编辑模板，修改立即保存，不自动覆盖已有角色。
5. 批量应用按钮留在子页底部，使用橙色和 `!` 标记，文字明确“覆盖全部适用角色”。悬停提示影响范围，点击仍需确认；无存档或模板无效时禁用。确认时沿用模板和目标快照、同一存档检查以及逐角色结果报告。

## 实现边界

- `ITab_SexSlaveTraining.CanShowRestrictions` 共用 `SSCRestrictionResolver.IsApplicable` 判定，不复制身份或绑定规则。展开尺寸和绘制使用相同条件；原关闭键留位和主栏位置不变。
- `SSCRestrictionUI.DrawChoice` 只在界面区分个人值与有效值，并按解析来源锁定。侧栏与独立测试窗口的个体编辑页共用控件，所以两处锁定一致；默认模板没有角色强制来源，可正常编辑。
- `Dialog_SSCRestrictionDefaults` 管理模板子窗口及滚动；`DrawDefaults` 复用既有条目控件。批量按钮单独绘制，颜色、禁用状态和全局 GUI 状态均恢复，避免影响其他控件。
- 本批没有更改许可核心、实际主人优先级、XML 规则来源、存档格式或配置生命周期。底层编辑 API 仍能表达保存值，界面禁用不意味着把外部强制写进个人存档。

## 实机复测

- 在绑定与未绑定角色之间切换，确认展开按钮置灰、右栏隐藏及恢复，并检查关闭键仍能使用；关闭总限制后重复检查。
- 对受特化强制允许的角色查看勾叉，确认显示允许且不可修改；关闭特化强制后确认恢复保存值并可修改。
