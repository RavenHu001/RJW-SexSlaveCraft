# 狗终极己方动物训练分支实现与测试记录

记录日期：2026-10-06。基线：`6e54b92`，分支：`codex/cat-dog-specialization`。

## 本轮范围与参数

在已获实机确认的“定向驯导”中增加玩家阵营动物训练用途，继续使用一个技能按钮。野生动物直接驯服；己方动物一次完整完成一个当前有效训练项目，包括已学项目衰减后的补满。单次完整完成项目是本轮采用的实现基线，维护者已确认本轮实现有效并授权提交。

两个分支共用地图可达选取、走至同格、两秒原版预热、目标限时暂停、进度条、训导气泡／波纹和 `60000 tick` 一天冷却。仍无需食物或材料，不增加动物技能经验、SSC 特化经验或工作后事件。

## 实现与游戏影响

- [技能工具](../../Sexslavecraft/common/PetDogAbilityUtility.cs)保留玩家阵营终极狗施放者条件；目标共同要求同地图、存活、已生成、动物、无精神状态及原版 `CanBeAwake`。允许可唤醒的普通睡眠及仍有意识的倒地动物。其他阵营动物拒绝；野生分支继续使用 `TameUtility.CanTame`，己方分支排除原版普通训练不接受的树精。
- 己方项目按 `TrainableUtility.TrainableDefsInListOrder` 的原版优先级，筛选 `GetWanted`、`CanBeTrained` 与 `CanAssignToTrain`。前两者检查勾选、剩余步骤及前置，后者核验当前种族、有效智力、体型等原版资格；跳过不合法的残留勾选，不人为完成其前置。没有有效项目时拒绝选择或中止执行。
- 训练项目在实际生效时重新选择，不保存悬停时的项目。途中取消全部有效勾选会失效；若初始项目被别人完成，而另一已勾选项目已符合资格，则完成当前下一项。一次只调用一项训练，不连续完成其后解锁的项目。
- [Ability](../../Sexslavecraft/Comps/Ability_PetDogTame.cs)复用原版 `GetJob`，在驱动生成前把己方目标的任务改为 `SSC_Job_PetDogTrain`；原 `SSC_Job_PetDogTame` 继续表示野生驯服。[两个 JobDef](../../Defs/JobDefs/SSC_PetDogTameJobDefs.xml)使用同一驱动及相同执行设置。原版 Job 自带的定义存档固定分支，目标途中改变阵营时取消，不把已经被他人驯服的野生目标自动改为训练。
- [任务](../../Sexslavecraft/JobDriver/JobDriver_PetDogTame.cs)、[Verb](../../Sexslavecraft/Comps/Verb_PetDogTame.cs)及实际效果复查资格、同格与本次任务分支；地图选取和 UI 仍查询新目标当前资格，不被旧任务的分支阻止重新选取其他目标。成功驯服或项目完成后，任务允许正常收尾。
- 己方效果直接调用原版 `Pawn_TrainingTracker.Train(project, null, complete: true)`，由原版写入项目学习及步骤。传入空 trainer，使完成服从时不会自动给无主动物分配施放者；已有动物主人也保持原设置。不调用原版随机训练尝试或刚修整的普通工作经验入口。
- 成功必须同时满足原 tracker 仍在目标上、目标仍属玩家阵营、`HasLearned` 为真且 `CanBeTrained` 为假。已学项目仍可能缺补训步骤，单查 learned 无法识别第三方阻止补满。无实际效果时，现有 Ability 退回本次新冷却，不影响调用前的已有冷却。
- 训练成功后写入原版 `mindState.lastAssignedInteractTime` 并增加 `interactionsToday`，让普通训兽工作遵守后续近期互动间隔；失败不更新。主动技能使用自身一天冷却，不要求普通工作的 `15000 tick` 六小时训练间隔已结束。
- [单一效果组件](../../Sexslavecraft/Comps/CompAbilityEffect_PetDogTame.cs)为己方目标提供含动物和项目名称的悬停提示，并在实际训练成功后给出完成消息。能力、终极狗状态、两个任务及新反馈补齐简中／繁中／英语／俄语，源码语言镜像同步。

未增加自定义任务、Ability 或人格持久化字段，也没有改变技能类名、授予组件、旧普通 Hediff 终极狗兼容入口及绝对冷却迁移。新增己方任务定义由原版 Job 保存；已有野生任务继续按原定义执行。

## 实机测试建议

1. **单项完整训练**：准备一只玩家动物，在动物训练界面勾选它能学习且前置已完成的项目。使用终极狗技能，悬停应显示项目名；施放者走至同格、读条两秒后该项目完成，只消耗一次一天冷却。
2. **项目优先级**：同时勾选多个项目，检查按原版优先级完成当前可训练的一项。完成服从后，当次不顺带完成放出、救援或搬运；再次施放须等技能冷却。
3. **无项目与资格拒绝**：取消所有仍需训练的项目，或选训练已满、当前智力／体型不满足项目、树精、其他阵营动物；应无合法提示或给出拒绝原因，不进入有效施放。
4. **动态项目**：行走或读条时取消全部勾选，应中止且不扣新冷却；若别人先完成当前项目，而仍有下一合法勾选项目，则实际结算下一项。观察成功消息与最终项目一致。
5. **补训与主人**：已学项目发生训练衰减后应可一次补满。测试完成服从前无动物主人及已有主人两种情况，技能不自动分配或改派主人。
6. **分支隔离**：对野生动物发起技能后，途中由另一训兽师驯服它；原技能应取消，不改为训练。对己方动物发起训练后改变其阵营，原任务也应取消。野生正常施放继续直接驯服。
7. **冷却与普通工作**：成功训练和驯服共用同一一天冷却；取消／目标失效不扣新冷却。成功训练后普通训兽工作不会立即再次处理这只动物，施放本身不增加狗普通培养或动物技能经验，不触发工作后事件。
8. **存读档与迁移**：分别在己方训练接近、预热和成功后存读档，检查分支、剩余预热及冷却不重复结算；冷却中的人格提取、存放和植入沿用绝对截止时间。
