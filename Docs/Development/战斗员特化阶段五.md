## 3. 可重复运行的本机检查

新增 [Test-CombatantGameResources.ps1](../../Scripts/Test-CombatantGameResources.ps1)，在独立 PowerShell 7 进程运行：

```powershell
pwsh -NoProfile -File Scripts/Test-CombatantGameResources.ps1 -GameRoot '<RimWorld安装目录>'
```

`GameRoot`、`RepositoryRoot`、`ModAssemblyPath` 和 `ReportPath` 可显式传入，不把个人安装路径写入脚本。默认读取仓库根目录的发布资源及 `Assemblies/Sexslavecraft.dll`。脚本不下载、复制或分发游戏程序集。

检查包括：全部发布 XML 解析；四语必要 Keyed/DefInjected 项及重复键；能力、健康状态、研究、配方、八种凝胶与 Core 属性引用；生产 XML 字段与原版类型对应；实际构造原版效果组件并调用 `AbilityComp.Initialize`；编译 DLL 中的能力构造入口及授予组件；实际消失组件构造；原版 `GenTicks.SecondsToTicks` 对显示和效果时长的换算。

报告记录 XML 与程序集 SHA-256、通过项目、时间及失败原因。缺少 `compClass` 等必要配置直接失败。检查需要本机游戏，因此独立于无游戏依赖的 `Test-All.ps1`；两者分别运行，不能把未运行的本机检查记为通过。

范围：本脚本从 XML 读取并构造所需的局部配置，不运行完整游戏 XML 解析、完整 `Ability.Initialize`、真实施法、伤害或 Scribe。原版对象通过反射调用，避免 PowerShell 对 `props`/`Props`、`description`/`Description` 的大小写冲突。`durationSecondsOverride` 按原版 `FloatRange` 配置，而非自行假设为单浮点字段。
