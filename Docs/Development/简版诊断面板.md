# 简版诊断面板

开发日期：2026-09-20。基线：2.3.0 / `27820f4`。状态：已实现并编译，未发布。维护者已确认初版可见、可操作；去除列表后的版本待实机复核。

**更新定位：目前没什么明确作用的辅助更新。** 按维护者反馈保留为设置页右下角的次要入口。目前只提供信息查看与复制，没有确认解决具体问题或明显提升排查效率；面板可见、可操作不等于已经具有明确实用价值。

## 使用

进入 Mod 设置中的 SSC 页面，点击底部右下角的“诊断与兼容”小按钮。入口固定在滚动区域外，不占用顶部，也不遮挡设置项；按钮宽度按当前语言文字适配。窗口提供“刷新检查”和“复制诊断信息”；报告内容可滚动，复制按钮在成功写入剪贴板后显示“已复制”。设置页改为单列滚动，保留原有设置项和保存字段。

报告包括：

- 实际加载程序集的 SSC 产品版本及 MVID 构建标识、游戏版本、当前语言。
- Harmony、RJW、RimWorld Animations 已加载程序集的版本；无法检测到时明确显示未检测到。程序集版本不保证与第三方发布版本名称一致。
- SSC 补丁注册总数；Dubs Mint Menus、Equal Milking、Human Cattle 的所需接口与预期补丁类注册情况。预期类数量分别为 1、4、3；Human Cattle 此处检查三个条件接入类，不代表全部兼容路径。
- RimTalk 保持暂停的说明。

根据维护者实机反馈，面板和复制报告均去除完整模组列表及加载顺序，避免数百个模组占据报告；保留上述版本、依赖和兼容模块信息。

## 实现与边界

`SSCDiagnostics` 在打开窗口和手动刷新时生成快照；窗口绘制不重复扫描程序集或补丁。通过 Harmony 读取已有注册，并按补丁方法所属程序集筛选 SSC；不运行 `Prepare`、补丁安装器或其他兼容初始化逻辑。

未找到接口可能表示没有安装对应模组，也可能是接口变化，面板不会直接判定为“未安装”。接口存在但补丁类注册不完整时，列出缺失类并提示查看日志。单项兼容检查异常不会阻止后续模块检查；报告只包含异常类型，不复制可能带有本机路径的异常消息。

此简版不收集历史启动日志，不诊断所有补丁冲突，不承诺补丁实际执行成功，不读存档、角色资料或本机安装路径，不枚举或输出完整模组列表。没有新增存档字段或模组依赖。
