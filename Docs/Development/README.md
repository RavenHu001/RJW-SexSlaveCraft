## 开发前先查可复用接口

先读仓库[开发协作约定](../../AGENTS.md)和[现行开发规范与历史参考](Reference/README.md)。新增同类个人布尔能力，优先按[个人能力开关接入规范](Reference/个人能力开关接入规范.md)复用已有注册、原载体后端、状态查询、UI 行与上下文提交；框架三批已完成，归档的是实施规划和验收依据，接入规范继续用于后续开发。

1.7 调教管理窗口复用能力查询、提交和各功能的保存入口。概况与「身体与外观」共用窗口内的能力行，现行接入与放置规则见[个人能力开关规范](Reference/个人能力开关接入规范.md)。

## 2.5.3 接手顺序

1. 读[双语版本说明](../Releases/2.5.3/2.5.3发布说明.md)，确认无主性奴、绑定与解绑的正式规则，以及一并交付的 2.5.2 范围。
2. 从[2.5.3 完成索引](Completed/README.md#ssc-253-completed)进入[无主性奴主题索引](Completed/无主性奴/README.md)，按需查五批实现、凝胶往返、市值、文化及倒地修复；恶堕解耦、爆发初版与文化结算见[2.5.2 完成索引](Completed/README.md#ssc-252-completed)。
3. 查[版本验证](../Releases/2.5.3/2.5.3版本验证.md)，区分分批实机、合并前整仓回归和正式构建／安装包门禁。提交边界见[开发归并](../Releases/2.5.3/2.5.3开发归并核对.md)。
4. 后续实现从[当前规划](../Design/README.md#当前专项规划)进入，明确待确认的显示与兼容场景从[待验收](Verification/README.md#当前专项)进入。

## 已完成、待验收与后续规划

已关闭的实施与故障验收在 Completed；已交付设计在 Design/Archive；现行接入规范继续留 Reference。Verification 只跟踪已实现且尚未关闭的具体范围，Design 保留未实现、待设计或暂缓的需求。

历史提示词与交接保持原日期及适用范围，沿革中的“待发布”“待实机”和旧测试计数按原批次阅读。较早版本的阅读顺序与分批更新已移至[开发入口历史摘录](Reference/History/索引沿革/开发入口历史摘录.md)，现行版本范围统一从[版本索引](../Releases/README.md)进入。
