1. 读对应[版本发布说明](../Releases/README.md)，确认已经交付的范围。
2. 查[待验收事项](Verification/README.md)，确认尚未关闭的已知缺口。
3. 在下表找到完成记录，先读汇总或完成核查，再读阶段记录。
