## 按用途查找

| 资料 | 用来回答什么 | 入口 |
| --- | --- | --- |
| 已交付实现与修复 | 功能如何落地、为什么这样修、当时验证了什么？ | [已交付开发记录](Completed/README.md) |
| 已实现、待实机确认 | 哪些明确的验证或观察事项还没有关闭？ | [待验收事项](Verification/README.md) |
| 代码与机制复盘 | 某一历史基线的调用流程、问题和取舍是什么？ | [复盘资料](Reviews/README.md) |
| 历史交接与提示词 | 文案在哪些文件、此前如何改稿？ | [历史参考](Reference/README.md) |
| 按日期追溯 | 某次提交、同步或实机反馈发生在什么时候？ | [开发更新记录](开发更新记录.md) |
| 后续设计 | 尚未实现的功能准备怎样做？ | [当前规划](../Design/README.md) |

## 接手一个功能的阅读顺序

1. 读对应[版本发布说明](../Releases/README.md)，确认已经交付的范围。
2. 查[待验收事项](Verification/README.md)，确认尚未关闭的已知缺口。
3. 在下表找到完成记录，先读汇总或完成核查，再读阶段记录。
4. 需要设计依据时查[历史设计](../Design/Archive/README.md)和[代码复盘](Reviews/README.md)；准备扩展时再读[当前规划](../Design/README.md)。

第三批真实部位凭据与弱开发已获维护者实机确认，先读[实现与验收记录](Completed/欲望侵染第三批真实部位与弱开发实现与测试.md)。
