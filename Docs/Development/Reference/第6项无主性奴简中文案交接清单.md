## 调教管理与共用敏感度

行为控制和浪漫控制使用同一阶段标题后缀。无主阶段自动设置规则和敏感度档位，特化和装备仍可覆盖相应行为规则。

界面共用 `SSC_Romance_SexSectionShort`、`SSC_Romance_RomanceSection`、`SSC_Romance_Setting_*`、`SSC_Restrictions_Rule_*` 和 `SSC_Restrictions_Value_*`。概况和关系页从既有窗口资源取阶段、主人、调教员等名称。 [板块与浪漫规则](../../../1.7/Languages/ChineseSimplified/Keyed/SSC_Romance.xml) · [调教管理共用界面](../../../1.7/Languages/ChineseSimplified/Keyed/SSC_TrainingManagement.xml)

无主 Hediff 锁定身份时，概况复用 `SSC_Identity_BoundTip`，现有措辞以实际主奴绑定为前提。共用提示定稿时需覆盖无主锁定和有主绑定。印记锁定优先使用 `SSC_Imprint_GelTooltip`。 [身份切换提示](../../../1.7/Languages/ChineseSimplified/Keyed/SSC_Identity.xml) · [印记提示](../../../1.7/Languages/ChineseSimplified/Keyed/SSC_Imprint.xml)

有主手动档和无主自动档共用敏感度 Hediff。下列共用健康描述需要兼顾两种生效方式。 [简中敏感度健康状态](../../../1.7/Languages/ChineseSimplified/DefInjected/HediffDef/SSC_OrgasmSensitivity.xml)

| 字段 | 现有简中 |
| --- | --- |
| `SSC_OrgasmSensitivity.description` | 被微械侵蚀过的性奴，身子有多性敏感，全凭主人决定。 |

界面名称及档位查 `SSC_Sensitivity_Title`、`SSC_Sensitivity_Level0`–`Level4`。共用心情查 `SSC_OrgasmSensitivity_Thought.stages.0`–`.9` 的标题和描述。 [敏感度界面及档位](../../../1.7/Languages/ChineseSimplified/Keyed/SSC_OrgasmSensitivity.xml) · [敏感度共用心情](../../../1.7/Languages/ChineseSimplified/DefInjected/ThoughtDef/SSC_OrgasmSensitivity.xml)

## 奴性爆发与调教请求选项

无主、有主和首次成形候选共用开场信。精神状态的 `SSC_SlaveBreakdown.beginLetter` 以 `{0}` 接收发作者。风险警报、触发设置及发作健康状态沿用第 7 项资源。

[精神状态及开场信](../../../1.7/Languages/ChineseSimplified/DefInjected/MentalStateDef/SSC_SlaveBreakdown.xml) · [发作及冷却健康状态](../../../1.7/Languages/ChineseSimplified/DefInjected/HediffDef/SSC_SlaveBreakdown.xml) · [风险警报与触发设置](../../../1.7/Languages/ChineseSimplified/Keyed/SSC_SlaveBreakdown.xml)

[简中请求选项](../../../1.7/Languages/ChineseSimplified/Keyed/SSC_BreakdownTraining.xml)

| 键 | 现有简中 | 显示位置或参数 |
| --- | --- | --- |
| `SSC_BreakdownRequest_Dev_FormOwnerless` | [开发] 成为无主性奴 | 初次成形为无主。 |
| `SSC_BreakdownRequest_Dev_FormBound` | [开发] 成为有主性奴 | 初次成形并绑定当场主人。 |
| `SSC_BreakdownRequest_Dev_BindOwnerless` | [开发] 按原进度绑定 | 已有无主阶段，按原进度绑定当场主人。 |
| `SSC_BreakdownRequest_Dev_AdvanceOwnerless` | [开发] 继续无主调教 | 保持无主并继续成长。 |
| `SSC_BreakdownRequest_Dev_AdvanceBound` | [开发] 继续有主调教 | 已有绑定，向实际主人继续调教。 |

拒绝和稍后决定共用原版信件选项。`SSC_BreakdownTraining.reportString` 的 `TargetA` 为任务受方。`SSC_BreakdownSuccess` 第 0 格用于首次成形，第 1 格用于已有阶段，也覆盖保持无主的成长。失败心情与好感分别使用 `SSC_BreakdownFailure` 与 `SSC_BreakdownTrainerOpinion`。 [任务报告](../../../1.7/Languages/ChineseSimplified/DefInjected/JobDef/SSC_BreakdownTraining.xml) · [结果心情及好感](../../../1.7/Languages/ChineseSimplified/DefInjected/ThoughtDef/SSC_BreakdownOutcome.xml)

## 解除绑定、主人死亡与再绑定冷却

死亡通知只列已完成归属转换的角色，冷却提示供爆发请求和绑定仪式共用。解绑后效持续两游戏日，工作速度 ×0.75，持续心情 −8。

[简中解绑界面、通知与冷却](../../../1.7/Languages/ChineseSimplified/Keyed/SSC_BondRelease.xml)

| 键 | 现有简中 | 显示位置或参数 |
| --- | --- | --- |
| `SSC_BondRelease_Confirm` | [开发] 确认解除与 {0} 的绑定？会保留 {1} 阶、{2} 的进度。{3}\n解绑后两日内无法重新绑定，全局工作速度 ×0.75，持续心情 −8。 | `{0}` 为原主人，`{1}` 为阶段，`{2}` 为进度百分比，`{3}` 为拼入的阶段规则附句。 |
| `SSC_BondRelease_Rejected` | [开发] 当前的绑定或进度已变动。请重新确认。 | 绑定或进度在确认期间变化时的提示。 |
| `SSC_BondRelease_DeathNotice` | [开发] {0} 已死亡。以下从属者转为无主：{1}。 | `{0}` 为已死亡的主人，`{1}` 为完成转换的角色名单。 |
| `SSC_BondRelease_BindingCooldown` | [开发] 解绑后仍需等待 {0} 才能重新绑定。 | `{0}` 为已格式化的剩余时间。 |
