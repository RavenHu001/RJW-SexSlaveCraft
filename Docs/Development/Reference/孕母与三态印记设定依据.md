## 1. 孕母特化

孕母特化使成年性奴完全掌握自身已经完成改造的子宫。她能够更好地养育孩童，并让妊娠遵循主人的意志。

这项特化以完成子宫改造为基础；特化所体现的是对改造后身体的掌握，以及与之相连的养育能力。后续正文应围绕这一定位展开。

### 研究的本质

研发孕母特化，本质上是找到了训练与进一步改造性奴的方法，使其能够按照主人的意志控制已经完成改造的子宫。

## 2. 淫欲之子：初始印记

其来源是在孕母子宫中便经历了紫色微械的改造与融合。这使印记持有者比常人更优秀与漂亮。

初始印记蕴含尚未分化的微械潜能。儿童时期的表现限于健康、学习与感知方面；身份觉醒及与征服／被征服相关的成人设定承接此前成年准入规则，在成年后的对应绑定事件中展开。

成年持有者会在征服或被征服的快感中进一步与紫色微械融合，由此蜕变为主人态或性奴态。

## 3. 淫欲之主：主人态印记

设定来源包括：

- 现有主人由额外的欲望之种获得。
- 成年“淫欲之子”首次成功绑定性奴时转化。

他们在征服的快感中与紫色微械彻底融合，成为强大、不老，并以淫欲征服、支配他人的存在。

这一形态的核心是征服、支配，以及与紫色微械的彻底融合。

## 4. 淫欲之奴：性奴态印记

设定来源包括：

- 现有成年性奴由欲望之种获得。
- 成年“淫欲之子”首次成功被绑定为性奴时转化。

他们在被征服的快感中与紫色微械彻底融合，成为美丽又敏感，并永世为淫欲的奴隶的存在。

这一形态的核心是被征服、臣服，以及与紫色微械的彻底融合，与主人态形成对应。
