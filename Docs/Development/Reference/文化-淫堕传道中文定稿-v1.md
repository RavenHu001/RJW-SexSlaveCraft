## 命名与写作口径

- **思路**：性奴是**散播堕落的传道者**——与谁交合，就是向谁布道；对象的高潮，就是淫堕入体的那一刻。
- **议题名**：不用「同场恶堕」；按传道思路定名「淫堕传道」，与现行议题「性奴性别」同为短名词。
- **四档名称**：统一「传＋对象」三字句式——不传 / 传男子 / 传女子 / 传众生，文化界面一眼可辨。
- **描述**：第三人称教义体，沿用现行性奴性别戒律的露骨家风；每档一句「谁配听传道」的总纲 + 高潮布道场景 + 一句否定收尾。

## 备选

- 议题名：`肉身传道`／`高潮恶堕`／`性奴渡堕`。
- 四档名：从「谁被染」角度作 `不染 / 染男子 / 染女子 / 染众生`；从「谁堕」角度作 `不堕 / 男子堕 / 女子堕 / 众生堕`。
- 若想在教义里点出「主人免疫」，可在三个启用档加「唯主人不在其列」一类短语；现稿刻意不写，保持纯教义口吻。
