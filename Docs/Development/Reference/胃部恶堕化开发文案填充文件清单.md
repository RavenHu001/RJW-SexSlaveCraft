| `SSC_Surgery_StartStomachDevelopment.description` | `【WIP｜胃部开发｜手术说明】` | 手术的设定与施术内容。 |

手术描述可围绕紫色微械／催情纳米机械经制剂送入胃部、稳定滞留并为后续开发建立基础来编写。材料清单、医术门槛及前提条件由原版配方、账单和拒绝提示表达，不需要塞入叙事描述。手术只启动开发，不代表当场完成全部胃部改造。

## 4. 健康状态与阶段：6 项

写入 HediffDef 对应 DefInjected，并同步基础健康 Def。**当前只有一套通用健康描述，四档阶段各有名称；没有分阶段描述切换，也没有子宫开发的禁育／生育三态。**

| 注入路径 | 当前占位 | 显示范围 |
| --- | --- | --- | --- |
| `SSC_StomachDevelopment.label` | `【WIP｜胃部开发｜健康状态名称】` | 健康状态名称，沿用亮粉色显示。 |
| `SSC_StomachDevelopment.description` | `【WIP｜胃部开发｜健康状态说明】` | 四个阶段共用的健康说明。 |
| `SSC_StomachDevelopment.stages.0.label` | `【WIP｜胃部开发｜阶段0】` | 0%≤进度＜30%；正常手术从 1% 开始。 |
| `SSC_StomachDevelopment.stages.1.label` | `【WIP｜胃部开发｜阶段30】` | 30%≤进度＜70%。 |
| `SSC_StomachDevelopment.stages.2.label` | `【WIP｜胃部开发｜阶段70】` | 70%≤进度＜100%。 |
| `SSC_StomachDevelopment.stages.3.label` | `【WIP｜胃部开发｜阶段100】` | 进度 100%，开发完成。 |

阶段名称应体现胃部改造逐步完成，但不暗示额外机制。当前效果供定稿核对：

| 阶段路径 | 饥饿速率 | 进食速度 | 本项目食物中毒概率因子 |
| --- | --- | --- | --- |
| `stages.0` | ×1.00 | ×1.00 | ×1，尚无减免 |
| `stages.1` | ×0.90 | ×1.10 | ×1，尚无减免 |
| `stages.2` | ×0.75 | ×1.25 | ×1，尚无减免 |
| `stages.3` | ×0.50 | ×1.50 | ×0，原版正常进食口径免疫 |

健康说明为全阶段共用，应避免不加条件地写成“当前已免疫”。不能写成清除已有食物中毒或拦截所有模组强制添加中毒。数值信息由原版健康页展示，不要求在叙事中重复列出全部倍率。

## 5. 启动与拒绝提示：10 项

下表对应胃部专属 Keyed 文件；所有现有键均列入清单，包括正常路径较少出现的配置异常提示。

| 键 | 当前占位 | 实际用途／约束 |
| --- | --- | --- |
| `SSC_StomachDevelopment_CannotStart` | `【WIP｜胃部开发｜当前无法启动】` | 通用开发创建入口不可用；不要限定为某一种手术失败。 |
| `SSC_StomachDevelopment_AlreadyStarted` | `【WIP｜胃部开发｜已经接受开发】` | 身体已有本项目记录；覆盖培养中及已完成，不暗示能再次手术重置。 |
| `SSC_StomachDevelopment_MissingStomach` | `【WIP｜胃部开发｜无法启动：缺少胃部】` | 当前缺少可用胃部，或手术目标不是当前有效胃部。 |
| `SSC_StomachDevelopment_ConfigUnavailable` | `【WIP｜胃部开发｜开发配置不可用】` | 开发健康定义不可用的配置异常。 |
| `SSC_StomachDevelopment_CreateFailed` | `【WIP｜胃部开发｜创建记录失败】` | 创建身体开发记录未成功；不宣称已经启动。 |
| `SSC_StomachDevelopment_SurgeryUnavailable` | `【WIP｜胃部开发｜当前无法手术】` | 手术准入不可用的通用原因。 |
| `SSC_StomachDevelopment_AdultRequired` | `【WIP｜胃部开发｜需要成年身体】` | 受术身体须成年；没有女性限定。 |
| `SSC_StomachDevelopment_MissingMouth` | `【WIP｜胃部开发｜无法启动：缺少口部】` | 当前缺少可用口部，无法启动手术。 |
| `SSC_StomachDevelopment_SurgeryConfigUnavailable` | `【WIP｜胃部开发｜手术配置不可用】` | 手术配方不可用的配置异常。 |
| `SSC_StomachDevelopment_Started` | `【WIP｜胃部开发｜已启动，进度 {0}】` | 手术成功并建立记录后的消息；{0} 是已格式化的初始进度，正常为 1%。 |

`SSC_StomachDevelopment_Started` 仅提供 `{0}`，代码填入的是带百分号的进度文本；不要另加 `%`，不要增加角色名、医生名或 `{1}` 等未提供参数。其他胃部专属文本目前无格式化参数。
