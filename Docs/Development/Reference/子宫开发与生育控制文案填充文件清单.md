## 5. v1 废案与当前实现的差异

- v1 的 S05 及部分示例使用初始 **0%**；当前成功手术后从 **1%** 开始。
- v1 的 U01、U05～U08 等及详细面板示例已不对应当前身体管理栏；独立标题、进度、阶段、收益、生育状态和两态预览已移除。阶段名和收益仍可在 Hediff 中查看。
- v1 对 SSC 永久泌乳的旧叠加边界需要以现行规则替换：子宫开发满级且开启生育时，SSC 泌乳抑制中和为 ×1；退出后读取当前源配置，保留 HumanCattle 的 ×1 和其他独立不育因素。
- v1 的 `{PAWN}`、`{PROGRESS}` 等为审稿占位，不是当前代码参数契约。按第 2 节实际键和参数映射，不把草稿占位直接粘入 XML。
- v1 已按维护者要求归入废案，仅供追溯历史措辞，不再作为当前候选或定稿依据；不为收录草稿增加成长提示、阶段消息、额外心情或专属孕期消息。

手术叙事描述不塞材料和前提清单；相关条件继续由原版配方／账单及拒绝提示表达。文案应保留“自身生育能力”的范围，×2.5 不是固定怀孕概率；直接致死失败概率关闭也不意味着手术完全无风险。长描述不要写入 Hediff、Severity、Harmony、字段名等实现细节。
