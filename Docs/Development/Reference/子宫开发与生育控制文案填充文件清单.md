## 4. 参数、复用与显示边界

- `SSC_UterusDevelopment_Started` 只有 `{0}`，由代码提供格式化进度，正常为 **1%**；无角色名参数。`SSC_HediffFertility_Factor` 为 `×{0}`，参数为本状态的当前倍率，不是最终受孕概率。其他键没有新增变量。
- `ResearchRequired` 使用与对应语言研究标签完全相同的研究名；今后改名须同步。`AlreadyStarted` 同时覆盖已开始和已完成，不能写成允许重置。
- 三条 `Description*` 是无参数完整正文，随当前身体模式与语言读取；保留原版阶段与倍率追加。五阶段名称只作标签，不放入整段描述。
- 泌乳开关继续复用 `SSC_ITab_MilkProductionToggle`，医术门槛复用 `SSC_Cosmetic_MedicineRequired`；既有永久泌乳充盈度和原版／RJW 属性名称不另建译键。
- 泌乳抑制解除说明只在符合当前实现条件时追加，不改变倍率、中和条件或产奶状态。手术失败仍使用原版流程，不将直接致死分支关闭写成无风险。
- 当前健康名称行仍统一亮粉色 **#FF69B4**，描述正文不加颜色标签；身体管理只保留既有条目与开关，不恢复进度／收益／生育详情或独立标题。
- 不新增心情、成长／完成消息、孕期提示、面板、字段或游戏机制；1.6／Common、Def 名、类名、翻译键及存档结构不变。
