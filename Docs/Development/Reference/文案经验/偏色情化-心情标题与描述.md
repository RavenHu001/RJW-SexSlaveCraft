# 偏色情化文案经验：心情标题与描述

> **性质：偏色情化写作经验。** 本 mod 为色情向 mod，心情／身体／日志类文案默认按第一人称、露骨直白、色情化来写。本文不是功能规范，也不是交付文案，只沉淀「怎么写」的方向偏好。
>
> **来源：** 2026-10-27 编写「第27项 个人高潮敏感度」简中文案时，与维护者逐步对齐后沉淀；对应 [文案稿 v1](../RJW个人高潮敏感度简体中文文案稿-v1.md)。
>
> **适用：** ThoughtDef 的 `label` / `description`，以及同类第一人称色情自白。

## 一、心情标题：前缀 + 直接情绪

- **结构：** 前缀 = Hediff 名称（如「性敏感改写」），用全角冒号接后缀，让玩家一眼联想到同一项身体变化。
- **后缀 = 直接的心情本身**，不是对感受或情况的总结。

| 反例（总结／情况） | 正例（直接心情） |
| --- | --- |
| 抗拒 | 害怕 |
| 难熬 | 烦躁 |
| 一碰就到 | 兴奋 |
| 高潮迭起 | 沉溺 |

十格示例推进：害怕 → 难受 → 烦躁 → 羞耻 → 渴望 → 兴奋 → 满足 → 贪求 → 陶醉 → 沉溺。

## 二、心情描述：第一人称自白，不解释

| 规则 | 反例 | 改法 |
| --- | --- | --- |
| 只写当场感觉／念头，不解释 | 光是走路，我就一路高潮不停 | 走路藏进「腿软得连路都走不稳」 |
| 不要后置解读总结 | 脑子化了，只剩下一个念头：这是主人赏的，好舒服 | 停不下来了，好舒服 |
| 身体和心态揉成一股，不拆两块 | 身子热起来了。不要，别这样，我根本没想要…… | 小穴没来由地热了，湿意一点一点往外渗……陌生得发慌，这身子，不像是我的了…… |
| 不用名词式前奏罗列来源 | 乳尖的布料，私处的摩擦，去了❤去了❤ | 去了❤去了❤……小穴在喷水、在抽搐 |
| 默认女性，用女性身体词 | （中性泛称） | 小穴、乳尖、腿心 |

补充：

- **短句、断续、气促**，用感叹（去了❤、哈啊❤、唔❤）营造沉溺感。
- **机制／设定当背景**：微械、锁链、指令不硬塞进正文；心情只写「身体对快感愈发敏感」与「我是否接受这种自己无权控制的变化」。
- **二维递进**：阶段心态 = 抗拒 → 完全沉溺；档位身体 = 刚变敏感 → 日常活动就几乎不停高潮。

## 三、成稿示例（从抗拒到沉溺）

- **抗拒（S1·轻·−3）· 性敏感改写：害怕**：小穴没来由地热了，湿意一点一点往外渗……陌生得发慌，这身子，不像是我的了……
- **极易高潮（S3·深·+3）· 性敏感改写：兴奋**：乳尖被一碰，小穴就绞起来……去了，差点去了❤哈啊。别碰了，快，快撑不住了……
- **日常不停高潮（S4·极·+6）· 性敏感改写：沉溺**：去了❤去了❤……小穴在喷水、在抽搐，哈啊❤。停不下来了，好舒服❤……就这样，一直，唔❤
