# 文案经验

本文件夹存放**可复用的文案写作经验**，按主题分文件；不是当前功能规范、不是待交付文案，而是写作过程中与维护者逐步对齐后沉淀下来的「怎么写」的准则。

**当前收录的是偏色情化文案经验。** 本 mod 为色情向 mod，心情、身体状态、日志一类文案默认按第一人称、露骨直白、色情化来写；后续同类功能起稿前，先读本文件夹。

## 文件

| 文件 | 内容 |
| --- | --- |
| [偏色情化-心情标题与描述](偏色情化-心情标题与描述.md) | 心情标题的前后缀结构、后缀=直接情绪；描述的第一人称自白写法、正反例与成稿示例 |

## 使用方式

- 写新的心情／持续思想／身体状态描述前，先读对应主题的经验。
- 经验与具体功能冲突时，以维护者最新指示和当前源码／合约为准；经验用于起稿，不替代逐项审阅。
- 新增经验按主题建文件，并在本 README 登记，便于后续智能体检索。
- 入口：仓库 [AGENTS.md](../../../../AGENTS.md)、[开发资料入口](../../README.md)、[现行开发规范与历史参考](../README.md) 均已指向本文件夹。
