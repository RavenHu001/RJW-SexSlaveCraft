# 偏色情化文案经验：Hediff 描述

> **性质：偏色情化写作经验。** 本 mod 为色情向 mod，Hediff（身体状态／印记／特化）的 `description` 默认按第三人称、色情化、直写身体与仪态来写。它不是第一人称自白（那是[心情标题与描述](偏色情化-心情标题与描述.md)的写法），也不是功能规范、不是交付文案，只沉淀「怎么写」的方向偏好。
>
> **来源：** 2026-10-31 编写「三态印记」「孕母／终极孕母」「受孕技能」「生育研究」描述时，与维护者逐步对齐后沉淀；对应 [文案稿 v1](../生育特化与三态印记文案稿-v1.md) 与 [设定依据](../孕母与三态印记设定依据.md)。
>
> **适用：** HediffDef、AbilityDef、ResearchProjectDef 的 `description` 等第三人称说明性文案。

## 一、写「状态本身」，不写前因后果

Hediff 描述是「这是什么状态」，不是「怎么达成的」或「之后会怎样」。培养途径、加工配方、功能收益属于研究页／配方／功能说明，不在 Hediff 描述里重复。

| 反例（前因后果） | 正例（状态） |
| --- | --- |
| 在完成子宫改造的基础上，性奴进一步掌握了这具已经改造的子宫。她能更好地养育孩童……这便是「孕母」。 | 她已完全掌握这具恶堕化的子宫，能更好地养育孩童，妊娠也只遵循主人的意志。 |
| 普通培养完成后，在雕刻台加工人格凝胶并重新植入，孕母便抵达终极形态。 | 这具恶堕化的子宫已被彻底驯服，完全听命于主人的意志。 |

## 二、第三人称，直写身体与仪态，不落人称/指向主语

Hediff 不锚定「她／他」这类人称代词，也不用「这具身子／她的身子」这类指向主语；直接写身体部位与仪态，可用「生得／通体／一双眼底／肌肤／眉眼／身段／皮相」这类成语化、名词性描写。

| 反例（人称/指向） | 正例（身体/仪态直写） |
| --- | --- |
| 这具身子生得比常人更出众 | 生得眉眼含春、肌肤白腻，一副勾人的好皮相 |
| 她的身子已被孕育的本能支配 | 身段妖娆，肌肤敏感得轻轻一触便酥软发颤 |

- 身体词：小腹、乳房、肌肤、眉眼、身段、皮相、体魄。
- 仪态词：媚态、气息、风情、威压、举手投足、一双眼底。

## 三、进行时 / 完成时对应阶段语义

- 培养中的阶段用进行时：正、日渐、渐生、一点点、愈发。
- 已达成的终极态用完成时：已、彻底、完全。

| 阶段 | 例 |
| --- | --- |
| 孕母（普通培养中） | 身子正为孕育而熟成，小腹日渐温软丰腴…… |
| 终极孕母（已完成） | 身子已被孕育的本能彻底支配……完全臣服于主人 |

## 四、删掉复述设定/机制信息的句子

描述只写状态与意象，不把「来源、获取流程、资格、锁定规则」再讲一遍（由物品说明、健康详情、功能说明承担）。

| 反例（复述） | 处理 |
| --- | --- |
| 孩提时，这股潜能只显现在健康、学习与感知上；待到成年……由绑定决定。 | 删 |
| 此印记由欲望之种定型，或由……转化而来。一旦定型，主人身份便永久锁定，不因解绑而解除。 | 删 |

## 五、方向性印记用压缩的二分意象

同源、两方向的印记，用一对意象即可，不展开机制、不混写方向。

- 淫欲之子（未分化）：……只待一场淫欲的快感彻底唤醒——屈服，或升华。（屈服＝奴，升华＝主）
- 淫欲之主（征服）：通体透着支配者的威压与淫欲……令人俯首称臣。
- 淫欲之奴（臣服）：身段妖娆……举手投足尽是臣服的媚态，永世只愿沉沦于淫欲。

## 六、术语统一到现有称呼

沿用已有的统一称呼（如「恶堕化（子宫）」），不新造词；起稿前先查现有 Def／Keyed 用词。

## 七、并列项保持同类，避免混排

| 反例（名词＋主谓＋主谓混排） | 正例（统管动词＋并列特征＋名词收尾） |
| --- | --- |
| 生得一副勾人的好皮相，眉眼含春，肌肤白腻 | 生得眉眼含春、肌肤白腻，一副勾人的好皮相 |

## 八、流程提示

- 先按设定推导「应写信息／可新增信息／不可写边界」，再起稿；候选稿放独立文件（如「文案稿 v1」），审阅通过前不回填 Def／语言资源。
- 描述改动若改变特质表述（如「更健康、聪慧、敏感」→「更优秀与漂亮」），同步修订设定依据，避免两处打架。
