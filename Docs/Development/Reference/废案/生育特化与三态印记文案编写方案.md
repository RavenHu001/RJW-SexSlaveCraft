# 生育特化与三态印记文案编写方案

> 2026-10-31：维护者确认本方案不采用，归入废案。仅保留分析过程与改稿记录，不作为当前候选、待办或回填依据。当前文案范围仍以[交接清单](../History/生育特化与三态印记文案交接清单.md)与运行资源为准。

整理日期：2026-10-31（v5，补印记设定与色情化）。状态：**已归入废案（2026-10-31）**。仅保留创作来源与审改记录，不修改任何 Def、语言资源或运行产物。

## 0. 写法定死

**描述只做两件事：交代情况，点出主要特点。**

- **情况**：这是什么状态、这项特化是什么。
- **主要特点**：最突出的两三条，直接陈述。
- **到此为止**：前因（怎么变成这样）、后果（每条数值怎么变）、过程（怎么培养）都不写——它们各有去处（第 2.2 节）。
- **不复述**：Hediff 属性行已经展示的加成、以及尚未取得的能力，描述里再写一遍没有意义。
- **印记例外**：印记写来历、本质与它把人变成什么，并且色情化；不写属性、不写将来能做什么。

前三版都错在同一处：一直在替系统补因果链。v1 补成散文，v3 补成说明文，写法换了，功能没换，所以怎么读都像说明书。

## 2. 写法

### 2.1 规则

1. 第一句交代情况，后面一两句点特点，全文 2～3 句。
2. 特点是**并列陈述**，不推导、不举例、不铺过程。
3. 不写"因为……所以……""使……""随之……"这类因果句。
4. 不写数值方向（更容易、更短、更高）——写了就变成属性表。
5. Hediff 与科技不写来历和培养过程；印记反过来，写来历与本质。
6. 每条只留最突出的 2～4 点，宁可少写。

长度参考：Hediff 40～60 字，科技 50～80 字，印记 60～90 字。

### 2.2 机制信息去哪儿

| 信息 | 去处 |
| --- | --- |
| 名称、档位 | Def `label` 与 `stages.N.label` |
| 具体加成 | 健康详情的属性行（原生与 SSC 补丁已展示） |
| 培养途径、选择门槛、日上限 | Keyed `SSC_Fertility_Tip`／`FinalTip` |
| 技能规则、冷却、禁用原因 | 技能描述与 `SSC_FertilitySkill_*` |
| 研究细节 | 【培养途径】【功能概况】【终极化】三段 |

描述不重复这些内容。

### 2.3 锚点

[子宫开发的生育态](../../../../1.7/Languages/ChineseSimplified/Keyed/SSC_UterusDevelopment.xml)：

> 子宫已被彻底开发，成了一处随时准备受孕的孕宫。它比寻常的身体更容易怀上，而一旦怀上，妊娠期也会更短。

情况（已彻底开发、成了孕宫）＋两条特点，两句话结束，不讲怎么开发的。

[终极奶牛](../../../../1.7/Languages/ChineseSimplified/DefInjected/HediffDef/HediffOfPSEdited.xml)：

> 在经历过特化之后，奶牛的全身上下布满分泌腺，其汗液也成了奶。

一句情况加一个特点，不讲训练流程。

[驯兽](../../../../1.7/Languages/ChineseSimplified/DefInjected/AbilityDef/SSC_PetDogTame.xml)（技能是唯一例外，只写功能与冷却）：

> 靠近动物，以动作和呼唤建立信任，驯服野生动物或完成己方动物的训练项目。冷却 1 天。

## 3. 设定与事实

- 特化作用于**母性**，让这具身体更好地使用已被改造的子宫，为主人生孕与养育。
- 机制上体现为受孕、妊娠、授课与陪玩的收益，后期可指定胎儿性别与物种、给后代预设印记，终极取得主动受孕能力（[实现](../../../../Sexslavecraft/common/FertilitySpecializationUtility.cs)）。
- 印记设定（维护者 2026-10-31 明确）：淫欲之子由孕母诞下，落地前被紫色微械在骨血里刻印，因此生来比常人康健、聪慧、灵敏，日后可能蜕变；淫欲之主是"生而为主人"那一侧的印记，淫欲之奴是"生而为性奴"那一侧的印记。三条都写来历、本质与色情，不写属性。
- 印记机制：`Vulnerability` 是性脆弱度而非承伤（[印记规划](../../../Design/Archive/生育向性奴特化阶段规划与设计分析.md)、[PNA 规划](../../../Design/Archive/PNA机制重置开发规划.md)）；淫欲之子不锁身份、不停龄；分化态永久锁身份。机制只供作者核对，不进描述。
- 技能：选人、走近、完成性行为、自身受孕、冷却 7 天（[实现](../../../../Sexslavecraft/common/FertilityAbilityUtility.cs)）。

## 5. 定稿稿

### 5.1 淫欲之子

> 孕母生下的孩子，落地之前就被紫色微械在骨血里刻下这枚印。它让这具身子生来比常人康健、聪慧、灵敏，也把一点还没有方向的淫欲一并埋了进去。印还没有定型——等身子长成，等第一次被谁系住，它才蜕变，长成主人，或者长成性奴。

### 5.2 淫欲之主

> 生来就该做主人的印。它把支配刻进骨血里：眼神、嗓音、落到别人身上的手，都天生带着让人腿软的分量。它要的从来不是顺从，是有人心甘情愿地跪下来，把自己交出去。

### 5.3 淫欲之奴

> 生来就该做性奴的印。它把这具身子养得只会往人身上贴：被按住比站着自在，被灌满比空着踏实，听见主人开口，腿间就先有了反应。它不认别的去处，只认一个能拴住它、能把它用到底的主人。

### 5.4 普通 Hediff

> 这具身体正处于孕母特化阶段：改造完成的子宫被调教得更适于受孕与养育，母性随之显现，使她更愿意替主人生养。

### 5.5 终极 Hediff

> 孕母特化已经完成。母性被彻底开发，改造后的子宫随时可用于受孕与养育，她并取得主动受孕的能力。

### 5.6 科技设定段

放在 `description` 最前，其后保留【培养途径】【功能概况】【终极化】；"自克隆后续开放"删掉。

> 孕母特化的对象是母性，而非器官。子宫改造让这具身体能够受孕与养育，特化则使她把这两件事当作本分，更适于为主人所用。

### 5.7 技能

> 选择同地图的一名成年类人，走近并完成性行为后使自己受孕。冷却 7 天。

## 6. 风险

1. 在描述里补因果、补过程（前三版的错）。
2. 在印记里复述属性行已有的加成，或写尚未取得的能力。
3. 把 `Vulnerability` 写成承伤；把三种病写成百病不侵；给淫欲之子写停龄。
4. 技能描述重新塞回限制（描述只写功能与冷却，行为不变）。
5. 漏改名称引用与四语镜像；把"生育"开关连带改名。
6. 写自克隆（暂缓）。
