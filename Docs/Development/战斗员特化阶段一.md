## 已实现

- 枚举末尾追加 `Combatant`，沿用组件当前进度、各方向历史及明确留空标志，不增加专属存档字段。
- 选择入口使用已有 `SSC_RES_Combatant`，成本仍为 1200、前置仍为 `SSC_RES_SlaveSpecialization`。已有页签支持的殖民者、殖民地囚犯及原版奴隶均须为 SSC 性奴才可选择，不要求绑定或锁链阶段。
- 特化区仅向 SSC 性奴显示，主人与未设定身份不预留特化区高度；绘制和滚动范围使用同一高度；战斗员进度长译文按实际宽度测量。其他方向保留原本的身份和基础训练研究入口限制，自己的额外资格规则继续生效。
- 新普通 `SSC_Hediff_Combatant` 包含 0%、20%、50% 三个阶段，普通完成继续使用熟练属性。无终极状态或能力。
- 战斗员只从组件进度派生严重度；零进度可以使用 0.01 的显示下限，但不会回写为经验。对账幂等，修复重复状态及损坏浮点值。
- 方向切换立即清理或恢复普通状态。明确留空后不从残留 Hediff 重新认领，其他方向终极成果保留。
- 读档结束规范化当前及历史进度并恢复战斗员普通状态，继续使用已有低频对账兜底。
- 完成文字使用公共 `0.999f` 容差；未完成进度保留一位小数，避免整数舍入显示 100%。完成显示为“普通培养完成”。
- 简中、繁中、英文、俄文的研究说明、界面名称和阶段文本已接入根目录发布资源。

## 阶段属性

每一阶段都是完整效果，进入熟练阶段时替换基础效果。

| 属性 | 20% 基础 | 50% 熟练及普通完成 |
| --- | ---: | ---: |
| `ShootingAccuracyPawn` 原始评分 | +2 | +4 |
| `MeleeHitChance` 原始评分 | +2 | +4 |
| `AimingDelayFactor` | ×0.95 | ×0.90 |
| `MeleeCooldownFactor` | ×0.95 | ×0.90 |
| `MentalBreakThreshold` | −0.02 | −0.04 |
| `IncomingDamageFactor` | ×1.00 | ×0.90 |

精神崩溃临界值的降低在日常也生效；命中加成作用于原始评分，不表示最终概率增加相同百分点。

## 代码与验证边界

`Comp_Train.SpecializationHealth.cs` 从原组件提取既有对账和清理方法，并接入战斗员。这样新增回归直接调用生产对账，而不是在测试中复制清理算法。既有数据测试继续隔离健康宿主，新增套件编译完整特化健康分部。

`Tests/CombatantSpecialization` 已登记到统一验证脚本，覆盖 17 组规则、状态、边界与资源测试。保存恢复采用序列化边界模型，不等同于实际 RimWorld Scribe 读档；阶段检查读取真实发布 XML，不等同于游戏伤害计算或 Unity 渲染。

构建使用本机现有引用覆盖文件 `.builds/ritual-fix/LocalReferences.targets`，通过 Visual Studio MSBuild 重编译根目录 `Assemblies/Sexslavecraft.dll`。个人依赖路径未写入项目。

最终验证结果：主工程 Release 构建成功；统一回归 19 个套件、799/799 项通过，其中战斗员新增 17/17 项通过。259 个根目录 Defs/Languages XML 均可解析，Keyed 翻译无重复键；`git diff --check` 通过。本机测试汇总保存在 `.builds/combatant-stage1/validation-final/summary.json`。

## 实机验收

本机构建同步后，维护者确认阶段一可用并批准提交。同步更新 34 个文件，443 个运行资源和文档文件的 SHA-256 核对通过。以下清单保留为后续回归参考；本次反馈未逐项列出测量结果。

1. 研究前后分别查看自由殖民者、原版奴隶、SSC 主人及未设定身份角色的菜单；确认仅 SSC 性奴显示特化区，选择战斗员还需完成对应研究；原版奴隶身份不能代替 SSC 性奴身份。
2. 阶段一尚无自然经验来源。通过调试器或测试存档设置组件进度为 0、0.1999、0.20、0.4999、0.50、0.999、1，再触发对账。只修改 Hediff 严重度会被组件进度覆盖。
3. 核对健康页与角色属性解释中的阶段收益；实际测试熟练承伤 ×0.90，并确认普通完成没有主动能力。
4. 切换方向再切回、明确留空、解绑及退阶；确认进度历史与普通状态符合规划。
5. 保存退出再读档，检查零进度、熟练进度、留空和多方向历史；在四语界面下检查长进度文字与滚动范围。

两类经验属于阶段二，终极状态及人格凝胶完整接入属于阶段三，特殊能力属于阶段四。阶段一研究说明已明确这些内容尚未接入；阶段一交付时普通方向不能通过正常事件自然成长；后续经验接入见[阶段二开发记录](战斗员特化阶段二.md)。
