## 2 HAR新生kind映射

### 2.1 已证实的选择语义

| 实际接口 | 程序集token | 对当前接入的意义 |
| --- | --- | --- |
| `RaceProperties.AnyPawnKind` | 游戏`170001BF:P` | 仅取第一个同race kind，无新生适用筛选，不能视为稳定映射。 |
| `Utility.GetRacesPawnKind(Pawn)` | 月经`0600026E:M` | 优先当前同race kind，再同race Colonist名称或首个kind；也不保证适合新生生成。 |
| `BirthOutcomeHelper(Pawn,Pawn)` | HAR`060000BB:M` | 自然选种可经childKind／hybrid，不保证等于显式所选亲代物种。 |
| `PawnGenerator.GenerateRandomAge(...)` | 游戏`060023B8:M` | Newborn设年龄0，跳过kind普通生成年龄范围，无需专用婴儿kind。 |
| `TryGenerateNewPawnInternal(...)` | 游戏`060023AF:M` | 保留请求Faction和HAR生成流程；kind abilities仍可能添加，不能只看race便宣称所有kind等价。 |
| `GenerateTraits(...)`／`FinalLevelOfSkill(...)` | 游戏`060023BA:M`／`060023C6:M` | Newborn跳过原版特性生成，技能基础为0。 |

显式物种从可核验的ThingDef→PawnKindDef候选解析，最终检查kind.race与目标物种一致；“自然”沿原规则。保留原种族能力、基因规则和真实亲代，不为映射改造这些系统。

该包只声明1.5／1.6，当前游戏`ModContentPack.InitLoadFolders`（游戏`0600196E:M`）按不高于当前版本的最大DefinedVersion回退，预期采用1.6及已启用内容。作者XML和加载推导不替代当前合并Def／生成实测。

## 3 当前接口与后续验证

技能优先核验现有`PregnancyHelper.StartVanillaPregnancy`（RJW`060005A6:M`）；实际婴儿生成位置为原版ApplyBirthOutcome、RJW GenerateBabies或环境启用的预生成AddNewBaby，详细签名和token见[首批接口](生育特化首批接入点取证.md#4-婴儿生成与物种选择)。

最小验证只围绕所支持生成入口：选择后的物种／性别正确、初始印记正确、其余生成由环境继续处理。基因与胎数不新增控制，保存／恢复和孕中流程沿原机制。前两轮遗传与周期源码细节不再保留为开发要求；具体五部分顺序和最小验收由[阶段规划](../../Design/生育向性奴特化阶段规划与设计分析.md)统一安排。
