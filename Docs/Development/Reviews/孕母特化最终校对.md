日期：2026-10-31。基线：`1b0930e9`之后的工作区，包含已同步且经维护者实机认可的普通／终极孕母配色。维护者已将分身系统划为独立开发项目；孕母特化按现有五部分视为开发完成，分身不再是其未完成项。

## 1. 五部分核对结果

| 范围 | 核对入口与结论 |
| --- | --- |
| 三态印记 | `SSCImprintUtility`、`Hediff_SSCImprint`、身份／种子／绑定入口：Hediff保存唯一形态及身份锁；无印记者先获资格、已有资格再获主人态，SSC性奴优先走性奴态；已有任一印记不能再用种子。天生初始态的成年主人准入与新绑定分化分开，恢复旧链不重放分化。年龄上限、免疫、互斥去重与凝胶精确恢复均有回归。 |
| 培养与阶段效果 | `FertilitySpecializationUtility`、`Comp_Train.Fertility`、课堂／陪玩及统一训练结算：选择要求阶段3和完整子宫；既有成果不额外因阶段下降停用。课堂不要求学生获得经验，照料计时保留余量、同Tick去重且无日限。终极化筛料及加工末端复查；孕期缩短复用原子宫固定待遇。普通与终极魅力不重复叠加，失格暂停，印记魅力可另行相加。 |
| 胎儿调控 | `SSCFertilityPreconceptionUtility`、子宫Hediff及能力后端／ITab：三项预设仍随身体，不进入人格凝胶；分别按20%／50%／普通完成解锁。生育关闭仍可编辑，孕期及临产禁改；菜单提交核对原人格、Comp及原子宫实例。失格保留保存值但不应用。 |
| 婴儿生成与出生 | 生成／出生局部补丁：在真实生成时读取当前资格与预设，不追补已存在婴儿；HAR选种只改变物种Kind，原基因参数和胎数处理保留。初始印记不继承亲代分化态；活产按分娩调用范围结算一次培养，异常／死产不补奖。孕期人格排泄拒绝提取但保留准备，主人身份仍删除准备。 |
| 受孕技能 | `Ability_FertilityConception`、同场驱动和`FertilitySceneUtility`：全图选成年非敌对类人对象，实际走近并完成同场任务后才建孕；目标性别及生育能力不作为自然配对筛选。成功建孕才起算7天冷却，中断不建孕／不扣冷却。孕期保留技能但禁用，绝对冷却截止时间随人格保存；仅按本场数据隔离自然受孕，清理不误结束后来换入的任务。 |

印记及特化人格流转继续复用现有凝胶标签／组件字段，胎儿调控仍只保存于子宫。印记清除和恢复不新增解绑操作，主人排泄禁用保持；本轮没有修改人格系统原有的绑定清理或来源关系恢复行为。

## 2. 发现并修正的问题

### 研究说明仍预告自克隆

四语研究说明及英文基础Def仍以“自克隆后续开放”等句子结尾，与分身已独立立项的范围不一致。本轮只移除这句预告，保留已验收的正文、培养途径、功能概况及终极化说明，并更新既有镜像；不添加分身入口或新功能。

### 原生测试宿主未登记新魅力属性

魅力XML加入后，隔离宿主没有加载原版`PawnBeauty`，首次印记入口在交叉引用阶段报错，尚未运行用例。补入引用后，印记21／21通过；生育分区首次18／19，健康展示用例因这个夹具Stat缺少label而失败。随后从本机`Stats_Pawns_Social.xml`同时读取其零基础值和名称，相关分区全部通过。

这是隔离测试环境缺项，不是游戏缺少该Stat。复用已有印记效果和普通／终极阶段用例补验实际魅力计算、互斥、印记叠加及失格停用，不新增用例、不改变登记数量；生产C#和DLL均未修改。
