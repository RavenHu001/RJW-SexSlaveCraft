# 统一受调教门槛实现与测试记录

实现日期：2026-10-08。分支：`codex/unified-training-eligibility`；起点：`main` 的 `cd97b5c`（2.3.8 发布结果记录）。本轮为未发布开发内容，未调整版本号或替换正式包；完成自动化验证后按维护者要求同步本机，结果见下方。自动化验证与真实游戏验收分别记录。

## 规则与职责

日常自动、手动、绑定仪式受训目标，以及新增非空调教员指派，均要求 `SSCIdentityUtility.IsSexSlave`。原版殖民者、囚犯、奴隶、组件、锁链、阶段和恶堕不能代替 SSC `PawnIdentity.Slave`。身体、研究、启用、冷却、排班、预约、执行者资格、指派和许可继续由各自既有入口判断。

`SSCRestrictionTrainingUtility.Evaluate` 返回独立 `TargetIdentityRequired` 失败原因，仍携带原许可结果；实际主人许可、限制总开关关闭或强制命令都不能授予受训身份。普通互动、人格排泄等不接入本项身份门槛。`SSCRestrictionResolver.IsApplicable` 继续依据真实绑定，保障尚未补齐身份的旧档也受既有保护；通用 `SSCBondUtility.Bind` 保留建绑时转换身份的原职责。

未绑定的性奴可通过身份层，但首次建绑仍要求有效指定 SSC 主人。玩家先设性奴身份，再进行首次绑定。自我调教继续要求性奴身份与锁链，保留独立许可及原有条件。无主自由培养、多调教员与身份／绑定拆分仍属独立规划。

## 入口与生命周期

- 自动粗筛、完整日常准备、调教员候选和指派提交在副作用前拒绝身份失格对象；身体／兼容校验返回后再查身份。
- 仪式基础目标资格、预览、提交、开始和各新阶段复用同一身份入口；候选提示不代替实际提交检查。
- UI 的训练开关、姿势、排班和指派回调复查角色身份；身份菜单固定原 Pawn，旧档恢复确认固定组件、锁链及主人。
- 日常和仪式将受训身份视为持续资格。已开始场景与读档恢复的开始凭据不豁免；结算前失格中止本次调教或取消匹配整场，释放临时占用，不发 SSC 完成收益或完成冷却。
- 身份切换先取消该角色参与的匹配仪式，再按原规则清理配置。已有锁链或仍有绑定对象的身份锁保持。
- 外部通知、动作选择、接收交接、Start、Tick、ProcessSex 和收尾返回后核对固定任务／目标；Job 对象复用、编号或目标变更使旧回调失效，不写新目标成长或清理新任务占用。
- 整场仪式结算保留一次性认领，并在外部结算及各后续收益、关系变更前复查固定场次、角色和身份。

持续身份与已开始场景的许可语义独立：受训身份失格中止；其他许可、指派和执行者资格变化沿用既有已开始场景收尾规则，在新请求或下一仪式阶段重查。

结算中的外部调用若改变身份或任务，返回后停止后续结算，不回滚该调用及之前已合法发生的效果。一次性认领防止重入和重复发奖；这不是对第三方效果的原子事务。

## 旧档恢复

没有 SSC 性奴身份但保留模式、指派和成长的对象不产生新调教，保存数据不被自动改写。已有失格任务在运行恢复后接受同一身份检查。

仅当身份为 `Unset`、角色及历史锁链主人引用有效、没有矛盾主人侧有效绑定对象且不处于加载或人格恢复事务时，面板提供“恢复历史性奴身份”。确认后再次验证原组件、锁链和主人；API 仅补设 `Slave`，保留锁链严重度、恶堕、特化、训练模式、指定者和归属，不自动解绑、重绑或运行可能改写成长的即时维护。

没有有效历史锁链的对象仍使用正常身份选择。死亡主人不自动视为解绑。当前缺身份字段与显式 `Unset` 读入相同默认值，因此本轮不进行无差别自动认领。

## 实机测试清单

使用测试存档，先确认启用的是上述本机模组目录。建议按以下顺序验收；每次比较经验、绑定和冷却时记录测试前后值。

1. **身份拒绝。** 准备未设 SSC 身份的普通小人及 SSC 主人，检查受训配置、调教员指派、手动调教和仪式目标选择；两者均不得获得受训资格。关闭行为限制、强制命令及实际主人许可也不能使其成为受训目标；候选图标与拒绝提示应一致。
2. **首次绑定。** 将没有锁链的目标先设为 SSC 性奴，再指定具备有效 SSC 主人身份和主持条件的调教员，完成首次绑定。应能选人、正常经过阶段并结算，归属与锁链正确，不因尚未绑定而被身份层错误拒绝。
3. **日常和后续仪式。** 对已绑定 SSC 性奴启用训练并配置排班，分别完成自动、手动调教及后续仪式。应正常交接、移动、播放动画和结算一次，冷却与研究／许可规则沿用原行为。
4. **中断与新任务。** 首次绑定尚无锁链时将目标切回未设置身份，应取消该场并释放临时占用，不产生完成收益。再通过正常新工作命令中断日常或仪式，随后启动另一合法任务；旧回调不能结束新任务、清除其占用或重复结算。已有绑定的正常身份菜单应保持锁定。
5. **存读档与旧档。** 合法日常／仪式中途保存后读入，应正常恢复或按实际条件退出，完成只结算一次。若有“未设身份＋有效历史锁链”的旧档，应暂停新调教并提供明确恢复按钮；确认后身份成为性奴，原主人、锁链严重度、成长、模式和指派保持，不自动续接已终止旧任务。没有有效链或存在矛盾绑定时不应显示恢复入口。
6. **界面与兼容。** 在常用及较大 UI 缩放检查恢复提示、确认框、训练设置与选人反馈，至少覆盖当前使用语言和常用动画／家具／UI 模组组合。普通互动保护及自我调教应保持原行为，控制台无新增红字或反复刷屏。

反馈异常时附失败步骤、角色 SSC 身份及绑定状态、是否读档／旧档、相关界面截图和对应 `Player.log` 红字，便于复现。
