# 宠物可见亲昵实现与测试记录

记录日期：2026-10-06。基线：`4a14549`，分支：`codex/cat-dog-specialization`。

## 本轮实现与游戏影响

普通亲昵由附近短暂转向改为“接近实际绑定主人 → 两秒可见互动 → 完成结算”。猫、狗及旧档合法宠物成果共用此流程；兔选择入口仍禁用。本轮只交付表现与任务保护，不接入概率后续事件或新的玩家手动亲昵按钮。

- [自动安排及资格](../../Sexslavecraft/common/PetSpecializationUtility.cs)沿用 `CompTickRare` 和 `2.9` 格附近发现范围。双方必须存活、同图、已生成、未倒地、未征召、意识合格且实际清醒，无精神状态或战斗。实际绑定、当前普通方向或保留终极成果仍持续复查。
- 双方只允许空闲漫步、无到期时间的普通等待或当前无任务。玩家强制命令、已有任务队列、带到期时间的等待及 `Wait_MaintainPosture` 均不被自动替换。后两者可能是其他交互的准备等待。开始时还检查原版 `CanReach(Touch, Danger.Some)`；任务到期期限设为 `600 tick`，让附近慢速行走也有时间完成两秒互动。
- [亲昵驱动](../../Sexslavecraft/JobDriver/JobDriver_PetAffection.cs)先用原版 `GotoThing(Touch)` 接近；期间只检查接近资格及主人空闲。接触阶段改用原版 `ReachabilityImmediate.CanReachImmediate(Touch)`，不在发现范围边缘或隔墙结算。到达与等待初始化之前，主人变忙就取消。
- 原版 `WaitWith` 停止宠物移动、创建主人的限时等待、保持宠物朝向并提供进度条；附加主人朝向，让双方停留互动。宠物互动持续 `120 tick` 两秒，主人等待 `121 tick`，只多一 tick 余量以避免双方更新顺序使等待先自然到期。正常完成立即释放等待，原版可恢复主人的原空闲任务。
- [独立爱心 Effecter](../../Defs/EffecterDefs/SSC_PetAffectionEffects.xml)使用原版 `Heart`，每 `30 tick` 一颗、首次无延迟，两秒约四颗。驱动通过原版 `WithEffect` 接入，离开互动 toil 时清理喷射效果，已产生的粒子自然淡出。缺失此视觉定义不会阻断原有亲昵结算。
- 保存本次等待的主人 Pawn、Job `loadID` 和互动已启动事实。原版在 toil 初始化前也检查失败条件，所以尚未启动时检查主人空闲，启动后检查确切等待归属。取消、完成及重入只释放这次创建且仍在执行的等待，主人换成其他任务后不再改其朝向或结束其任务。
- 等待初始化采用 `try/finally` 认领确切新等待；原版初始化抛异常仍原样传播，恢复清理可以释放已安装的等待。若主人旧任务清理回调反过来取消或替换宠物任务，认领后立即释放等待，旧驱动回调也不能影响宠物的新任务。
- [统一完成入口](../../Sexslavecraft/common/PetSpecializationUtility.cs)保留先写入 `lastPetAffectionTick` 再产生记忆和经验的顺序。给主人原有 `+5`、持续四分之一天、最多一份记忆；当前合法 SSC 普通猫获得 `0.01`，狗／兔／终极不加亲昵经验。成功后一天冷却；接近、等待、中断及失效不发奖励或消耗完成冷却。
- 四语任务报告和既有亲昵说明同步，根 `Languages` 与源码语言镜像一致。已有亲昵说明键仍不代表本轮新增了玩家按钮。

新增任务归属字段通过 `Scribe` 保存，当前 toil、剩余时间与原版等待由原版负责恢复；加载字段本身不再次创建等待或发奖。缺失新字段使用未开始／无等待归属的默认值，不认领其他交互的等待。旧版本进行中的短亲昵不保证续接，新任务按新流程执行。

## 实机测试步骤

1. **完整互动**：准备有实际绑定主人的普通猫或狗，两人均清醒、未征召且空闲，相距一至两格。等待稀疏更新，应看到宠物靠近到接触位置，双方停留朝向彼此，进度条持续两秒并冒出爱心；主人得到原有亲昵记忆。
2. **奖励与冷却**：普通猫当次增加 1 个百分点；狗和终极宠物不加亲昵培养经验。成功后当天不再自动亲昵；一天后满足条件才能再次完成。可用开发模式查看进度及记忆。
3. **双方工作保护**：让任一方建造、搬运、进食、睡眠、征召或执行玩家命令，应不自动亲昵。主人在宠物接近时开始工作，宠物任务应取消；其他互动的限时等待与排队任务也不被抢占。
4. **中断与换任务**：互动中取消宠物任务或给宠物新的工作，主人应解除本次等待；给主人新命令时亲昵应中止并保留新命令。中断不增加记忆／经验，不启动完成冷却，爱心停止喷射。
5. **资格与接触变化**：途中解除或更换绑定、撤销普通宠物方向、失去终极成果、倒地、失去意识、进入精神状态、离图或不可接触，应停止任务。原有终极宠物转练非宠物或留空仍可亲昵，继续遵守身体与绑定条件。
6. **存读档**：分别在接近、两秒互动中和成功后保存并加载。互动不重新从两秒开始，不重复创建主人等待或再次发奖；加载后取消仍只解除这次等待。成功后的冷却继续有效。
