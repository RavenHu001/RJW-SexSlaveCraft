## 实机步骤

1. **成长展示。** 选择 SSC 主人，打开“调教”页，应出现“主人成长”，显示阶段、累计经验、当前阶段区间进度、下一阶段所需经验及加成摘要。原“已设定为主人”占位提示不再显示。悬停加成可见原版能力、社交影响与自然愈合倍率；只表示阶段自身的加成。
2. **跨阶刷新。** 利用原 +10 调试按钮与正常调教准备经验。11→12、39→40 后阶段与进度重置为新阶段区间；例如第二阶段经验 16 时条为 4/28，剩余 24。100 显示最高阶段，条满格，无下一阶段需求。保持页签打开获得经验也应及时刷新。
3. **四语与缩放。** 检查简中、繁中、英文、俄文，尤其窄屏或较高 UI 缩放下的长译文。文字不重叠、勾选框不挡字，左栏可以滚动到最后一项，顶部关闭键与右侧限制栏仍可操作。
4. **开关与伤害。** 已绑定的玩家主人在面板反复关闭／开启“伤害分担”。关闭后按正常条件受伤不转移；开启后仍按原规则分担 70%。原角色 Gizmo 中不再有第二个开关。性奴倒地、离开地图等情况只影响实际承伤，不妨碍保存开关偏好。
5. **保存与解绑。** 关闭后保存读档，面板保持关闭。解绑到缰绳移除后开关置灰，打开面板不能创建缰绳；重新建立绑定沿用新缰绳默认开启。该开关继续归属于缰绳，不随主人阶段或人格凝胶额外迁移。
6. **角色与特殊记录。** 切换不同主人不会串用经验或开关；手动成为主人但无永久资格者也能按已有规则操作。现代明确无成长记录者显示“暂无成长记录”，不因打开面板补建；保留主人身份的空壳显示加成未生效。可见的非玩家角色只能读取。
7. **身份与人格流转。** 无绑定时退出主人，面板回到对应身份分支；返回后显示原成长。凝胶植入低经验人格，应显示来源阶段，不保留宿主较高值；无记录来源继续显示无记录。结合第一、二批测试说明复核既有规则。
