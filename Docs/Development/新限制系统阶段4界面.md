# 新限制系统阶段 4：后半界面完善

开发日期：2026-09-21（本地时间）。按维护者提供的截图及后续确认，将限制编辑区改为与“是调教员”一致的左文右绿勾/红叉样式。前半清理已提交为 `fddc73f`；本批未发布。维护者已确认界面及展开按钮位置修正无问题，并授权提交；此反馈不代表全部缩放、语言及存档场景均已逐项验收。

## 界面与交互

- 角色右侧规则栏、独立窗口的个体编辑页、Mod 设置默认模板共用一套紧凑控件。主 ITab 的位置和宽度保持；按后续反馈将展开/收起按钮移至身份区之后、调教设置紧邻上方，随左栏滚动。两侧顶部预留原版关闭键区域，避免内容覆盖。
- 六项规则按主动、被动、调教排列。每项使用游戏原生 `Widgets.Checkbox` 的绿勾/红叉，左侧文字区域也可点击；文字和图标的热区互不重叠，避免一次点击触发两次翻转。没有方形勾选框或规则值下拉菜单。
- “发起自愿性行为”下属“仅限主人／不限对象”互斥单选。关闭主项时置灰并保留原选择，重新开启恢复；窄栏或较长译文不足以并排时，单选项自动改为上下两行。
- 勾叉表示个人保存值，强制期间仍可编辑。仅受装备/特化强制影响的条目显示“装备禁止”“特化允许”等短标记；无效条目显示错误标记。标记即使与保存值一致也保留，以说明当前由外部来源决定。
- 悬停显示该项简短用途。存在覆盖时再说明个人选择、当前结果及具体来源，装备使用游戏名称，公交车使用特化名称；定义异常时保留原标识。调教指定者被锁定的说明移入对应项提示。
- 顶部保留角色名称和一条操作/主人许可说明，保存机制放入悬停。删除日常编辑区常驻的接管范围、全局开关摘要及逐项生效说明；总限制关闭时才显示暂停提示，不清空或锁住个人编辑。
- 配置缺失、不适用和损坏时仍保留必要提示；不适用对象只读，不自动修复数据。独立许可测试页继续保留用途、方向、结果和来源的诊断信息。
- 中英文文本及源码内嵌副本同步，移除仍声称总开关与旧运行路径共用的过时说明。

## 对象范围偏好与兼容

实际自愿发起规则仍为“禁止／仅限主人／允许”三态，许可核心及覆盖优先级没有变化。新增可选保存字段 `preferredConsensualTarget`，仅用于关闭时记住对象范围，不构成新许可，也不参与六项规则有效性判断。

- 开启时以实际规则为权威；通过 `Set` 关闭时捕获当前范围，重复关闭不丢失偏好；改选范围同步更新偏好。
- 旧档缺少偏好时，从实际已开启的规则推导；旧档原本禁止时默认记住“仅限主人”，不自动扩大发起范围。
- 界面偏好损坏时仅显示为“仅限主人”，不修改原许可，也不以此拒绝本来合法的整份规则。实际规则损坏仍沿用原有拒绝逻辑。
- 角色配置和全局默认模板共用规则结构，偏好随各自配置保存；复制和批量默认得到独立值。保持配置版本 1，不重新迁移已有角色。
- 只打开、绘制或切换角色不会修改规则、偏好或指派。个体操作继续经过 `SSCRestrictionEditor.TrySet`，保留恢复期间拒绝写入和调教指定者协调。

## 实机检查建议

1. 打开右侧规则栏，确认左文右勾叉、三组分区和悬停可读，展开/收起不移动主 ITab。
2. 选择“不限对象”，关闭自愿发起、保存读档并重新开启，确认仍选“不限对象”；关闭期间单选不可操作。切换角色后各自选择独立。
3. 装备保护服装，修改个人接收强制许可，确认短标记仍显示装备禁止、悬停能说明来源；脱下后回到剩余特化或个人值。
4. 切换总开关、特化强制开关，确认暂停提示和强制标记随实际来源变化；实际主人许可不被绿勾/红叉误表示为普通条目限制。
5. 检查默认模板和独立窗口编辑页使用相同控件，许可测试页仍能显示详细结果；检查较窄窗口或英文下的换行与滚动。
