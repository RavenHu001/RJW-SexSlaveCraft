# 猫狗终极技能原版目标选择复用记录

日期：2026-10-05。分支：`codex/cat-dog-specialization`。实现基线：`4585b00`。维护者在核验原版可复用方式后要求“进行优化”。

## 改动与游戏影响

- [猫 Verb](../../Sexslavecraft/Comps/Verb_PetCatComfort.cs)与[狗 Verb](../../Sexslavecraft/Comps/Verb_PetDogTame.cs)改为继承原版 `Verb_CastAbilityTouch`，删除重复的 `DrawHighlight`／`OnGUI`，复用原版目标圈、鼠标附件、效果预览与附加文字入口。
- 保留自定义 `ValidateTarget`，新增 `IsApplicableTo` 转调它。原版接触技能的高亮只检查 `IsApplicableTo`，因此这里仍需完整检查阵营、意识、地图、同格可达性及所有效果组件；合法远处目标可以高亮，失格目标不会误显示合法圈。自定义 `ValidateTarget` 不调用 `IsApplicableTo`，调用链没有递归。
- 原版人物高亮使用目标当前绘制位置和原版 `TargetHighlighter`，替代此前直接调用 `DrawTargetHighlightWithLayer` 的方式。圈与人物叠放的逐场景观察项目见下方复测清单；提示文字继续由现有效果组件提供。
- 保留 `CanHitTarget`、`CanHitTargetFrom`、开始施放和实际激活的同格保护，以及追踪目标的自定义任务。原版 `CastAbilityOnThingMelee` 只走至相邻 `Touch`，无法直接满足本项目同格需求。
- 保留现有 `range=0`。原版非正射程允许远处选取，不依赖虚设大射程；自定义执行保护继续阻止隔格预热或结算。猫／狗目标名单、效果、两秒预热、爱心／训导波纹、一天冷却与人格迁移沿用既有入口。
- 保留两个自定义 Verb 的类型名及所有保存字段，没有新增存档转换。原版接触 Verb 没有 DLC 使用门禁，复用该类不增加 DLC 依赖。

## 实机验收与补充复测

同步游戏目录后，维护者于 2026-10-05 反馈“有效，提交”，确认本次目标选择复用优化有效并授权提交。未提供逐场景验收明细，以下项目用于补充记录。

1. 分别对远处玩家人形目标使用猫技能、对远处合法野生动物使用狗技能；悬停显示原版圈、技能光标与目标名。目标行走和不同缩放下，圈应跟随目标且可见；隔墙但可绕路仍能选。
2. 无意识、阵营不符、不同地图、不可达及猫／狗各自非法类别不显示合法圈和名字提示，使用禁用光标；目标或施放者在悬停期间失格时，提示及时变化。
3. 选择后仅行走，到达同格才开始两秒预热、暂停目标与特效。行走或预热中取消不生效、不消耗新冷却；预热中移开任意一方不隔格结算。
4. 使用已有技能的存档升级，检查技能、现有冷却、行走／预热中的目标引用与任务延续。成功施放仍只结算一次；人格提取／植入继续保留原绝对冷却结束时间。
