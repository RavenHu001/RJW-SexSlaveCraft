# 训导官特化阶段 5：界面与整体验证

记录日期：2026-09-24。

## 源码实现

- 特化菜单始终包含“训导官”。研究、SSC 身份、自由殖民者身份、实际绑定主人和当前锁链阶段不满足时，选项置灰并显示首个具体原因。有效或禁用的终极记录均禁止重复选择。菜单打开与点击提交共用只读资格入口，防止状态变化越过门槛。
- 方向按钮识别训导官，进度下方独立显示培养中、20% 基础阶段、普通 100% 完成、有效终极和终极禁用。终极记录跨方向仍显示；禁用状态不被误写成未完成。按长译文及兔特化模式增加面板与滚动高度。
- 调教员开关显示保存选择及有效身份的区别，并在悬停时显示实际失格原因。失格时可以关闭原先保存的开启选择。终极禁用状态悬停显示持续条件失败原因；满足条件但尚未维护时显示等待恢复提示。
- 状态悬停说明训导官特化的两项主动发起强制条目从选中方向起效，20% 仅约束调教员任职。限制栏继续使用阶段 4 的统一解析、来源名称和锁定显示，不写回个人保存选择。
- 新菜单、状态、失格原因及提示同步简体中文、繁体中文、英文和俄文。自动退出和迁移没有增加高频通知；持续状态由面板与原有停用指派标签呈现。

## 实机待验

1. 加载本模组与依赖，检查新增研究、训导官 Hediff、人格凝胶配方和四语翻译是否正常加载；在不同分辨率及 UI 缩放下检查菜单、状态行、俄文长文本和兔特化并存时的布局。
2. 对自由殖民者、原版奴隶、无主、锁链第 2/3 阶段及研究未完成分别打开菜单；打开菜单后改变资格，再点击旧选项。检查 20% 前后开关、普通完成、终极跨方向、终极禁用恢复及个人关闭选择。
3. 在真实存档中检查旧调教员开关迁移、世界及间接指派对象、跨主人指派、停用标签、同床、床位标签、自动工作、手动任务与仪式选人。限制栏检查两项强制值、来源、锁定、总开关及装备优先级。
4. 同一存档、同一场景比较基线与实现版：无训导官、大量候选、多人频繁状态切换；记录低频维护次数、稳定状态 Hediff 写入次数、Tick 和工作查询耗时。现有生产维护器在无关角色上仍会扫描一次 Hediff 列表后返回，不能未经实测称为零开销。
5. 比较接受调教、施教和主动双人行为的实际每日经验收益，尤其考虑日常调教 22500 tick 冷却与主动行为频率。是否调整当前单次 0.05／0.025／0.01，依据游戏内结果决定。

完成上述实机核验并记录结果后，再把总规划标为发布验收完成，并更新玩家指南和更新日志。
