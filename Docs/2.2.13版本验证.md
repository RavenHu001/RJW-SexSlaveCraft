# 2.2.13 版本归并与验证

记录日期：2026-09-15。维护者已分别确认本会话四项修复有效，并要求统一归入 `2.2.13`。本次完成版本、文档及 DLL 同步；尚未创建正式发布标签、安装附件或 GitHub Release。

面向玩家的更新见 [CHANGELOG](../CHANGELOG.md) 与 [2.2.13 发布说明](2.2.13发布说明.md)。2.2.12 及更早版本的发布文档保留原始版本和验证记录。

## 四项修复及来源

| 修复 | 结果 | 原修复提交 |
| --- | --- | --- |
| 人格植入隔空完成 | 等待期间持续检查接触，最终写入前再次校验目标，失败时保留凝胶和原人格 | `a850cf1` |
| 性别重置术后记忆 | 统一定义名称；缺失定义时保留诊断并安全跳过，避免手术收尾空引用 | `306fb74` |
| 仪式 UAP 位置锁兼容 | 新阶段启动前及已启动阶段收尾时释放双方旧位置锁，避免旧任务检查误停动画 | `3907ef3` |
| 仪式备用动画查找 | 按运行时动画类型读取正确的定义库，再调用框架匹配和启动接口 | `c90c705` |

上述四项均已提交至 `Bug-fix` 并由维护者确认有效。本次在这些提交之上进行版本归并，游戏运行逻辑保持已确认状态；打包脚本补入本轮新增套件。

## 游戏内确认与边界

维护者已逐项确认四项修复有效，未提供完整的角色、体位及模组组合清单。自动化宿主不执行 Unity 绘制、真实地图调度或完整存档往返，不能替代这些场景的游戏内验证。

- 人格植入失败时不会通过本次受保护的结算入口覆盖人格或消耗凝胶；不保证所有任务中断都自动重试。
- 手术修复不会补发过去已漏掉的记忆。
- UAP 修复不会重建旧失败存档中已经清空的动画队列。
- 备用动画修复不提供动画资源。只有安装框架且存在适用动画时才能播放；真正没有匹配项时保留原有警告及仪式计时。

各套件的详细覆盖范围见 [人格植入](../Tests/PersonalityInsertion/README.md)、[手术记忆](../Tests/GenderChangeMemory/README.md)、[仪式生命周期与 UAP](../Tests/RitualLifecycle/README.md)、[备用动画](../Tests/RitualAnimationFallback/README.md)。正式发布和打包流程见 [发布与打包](发布与打包.md)。
