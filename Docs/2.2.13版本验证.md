## 正式构建与交付

补齐正式发布文档后提交，从干净工作区执行：

```powershell
pwsh -File Scripts/New-Release.ps1 -Build `
  -ReferenceTargetsPath .builds/ritual-fix/LocalReferences.targets `
  -OutputDirectory Releases/Published/2.2.13
```

脚本重新编译 DLL 并运行上述 11 套件共 215 项检查。安装包内 `RELEASE-MANIFEST.json` 记录最终发布提交、`workingTreeDirty: false`、`assemblyRebuilt: true`，以及每个有效载荷文件的大小和 SHA-256。ZIP 中只包含本模组 DLL，不分发源码、测试、PDB 或第三方程序集。

安装包与 `.zip.sha256` 位于忽略目录，作为 GitHub Release 附件上传。发布前核对 ZIP 的全部清单条目与本地文件，上传后再核对服务端返回的附件大小及 SHA-256；最后公开草稿并设为最新版本。`v2.2.13` 标签指向同一最终发布提交。完整 ZIP 校验值以 Release 附带的 `.sha256` 文件为准。

## 游戏内确认与边界

维护者已逐项确认四项修复有效，未提供完整的角色、体位及模组组合清单。自动化宿主不执行 Unity 绘制、真实地图调度或完整存档往返，不能替代这些场景的游戏内验证。

- 人格植入失败时不会通过本次受保护的结算入口覆盖人格或消耗凝胶；不保证所有任务中断都自动重试。
- 手术修复不会补发过去已漏掉的记忆。
- UAP 修复不会重建旧失败存档中已经清空的动画队列。
- 备用动画修复不提供动画资源。只有安装框架且存在适用动画时才能播放；真正没有匹配项时保留原有警告及仪式计时。

各套件的详细覆盖范围见 [人格植入](../Tests/PersonalityInsertion/README.md)、[手术记忆](../Tests/GenderChangeMemory/README.md)、[仪式生命周期与 UAP](../Tests/RitualLifecycle/README.md)、[备用动画](../Tests/RitualAnimationFallback/README.md)。正式发布和打包流程见 [发布与打包](发布与打包.md)。
