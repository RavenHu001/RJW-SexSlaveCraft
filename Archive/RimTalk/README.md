# RimTalk 旧兼容归档

2026-09-15 按维护者要求暂停旧兼容，整个模块等待重新设计。归档基于提交 `4219bee`（2.2.13）；此目录中的 C# 文件不参与运行时编译，也不进入安装包。

隔离范围：

- 移除启动反射初始化、RimTalk 动态 Harmony 补丁和每 tick 对话预约更新。
- 移除日常调教、绑定仪式、人格排泄、公交车交易和宠物犬事件中的旧兼容调用。
- 设置界面只显示暂停提示，保留三个旧设置字段的序列化供将来迁移；旧开关值不能恢复模块。
- 调教排班、训练收益、仪式推进和原有事件继续由 SSC / RJW 执行。SSC 不再插入打断句、清理 RimTalk 队列、预留生成位置或发起对话请求。

旧实现不能直接重新接回：本机 RimTalk 1.2.13 的 `AddTalkRequest` / `AddUserHistory` 重载与反射查找不匹配；初始化失败状态会被误判为成功；历史记录调用参数数量不匹配。此外旧实现会清理全局待播回复，重做时需要重新确定对话调度与其他扩展的边界。

未来方案见 [开发规划第 9 项](../../Docs/Design/未来内容开发规划.md#9-rimtalk-兼容模块重置)。重新设计时应重新核对接口、失败处理、上下文范围与用户设置，不把本归档视为已验证的兼容实现。
