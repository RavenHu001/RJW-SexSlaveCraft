# 1.7 凝胶 Shader 原生编译验证

```powershell
pwsh -File Tools/GelatinizationShader/Run.ps1 -GameRoot 'D:\STEAM\steamapps\common\RimWorld'
```

需要 .NET 10 SDK 和目标 1.7 的完整游戏安装。`-DotnetPath` 可指定 SDK；默认先使用仓库内的便携 SDK，再查 PATH。依赖从给定游戏目录读取，不下载、不复制游戏 DLL。报告默认放在 `.builds/gel-visual/shader/`，可用 `-ReportDirectory` 改写。

工具按实际 `ShaderProgramDefinition` 校验字段/枚举，检查顶点与片元接口及材质布局，再由游戏自带 `RuntimeShaderCompiler` 编译每个定义的普通/INSTANCED 顶点和片元阶段，当前身体、FA遮罩／深度皮肤及两种原版眼部保护变体共二十四个阶段，并核对实际类型解析后的深度配置，核验 SPIR-V 头并保存输出。故意错误的 GLSL 必须被编译器拒绝。JSON 记录游戏构建、游戏程序集哈希、Waylith MVID、资源哈希与各阶段结果。

这是显式依赖实际游戏的构建验证工具，单独运行；`Tests/Gelatinization` 的 260 项模型、像素函数与头部分层回归仍由统一 net9 门禁执行。没有运行 GPU 绘制、场景深度/透明排序或游戏存读档。工具不启动游戏、不部署、不写入游戏目录、不生成 ZIP；最终观感需要维护者进游戏确认。

已验收的身体材质处理身体和现有 SizedApparel 入口：将黑线抬为深紫色，不改变贴图轮廓宽度；保留明暗次序，少量提亮高光。维护者已确认黑边改善良好；首次试色偏淡，恢复原紫色后改用深紫色 RGB `(0.46, 0.20, 0.68)`，配色已获确认；不透明度经 `0.9` 对比后调回 `0.85`，维护者已确认最终效果，见[视觉验收记录](../../Docs/Development/Completed/1.7全身凝胶化身体视觉调整与验收.md)。新头部皮肤复用同一配色与 0.85 不透明度，增加遮罩及保留原深度写入的变体；原生头部和 FA 皮肤按原程序的深度状态选择，覆盖层不统一写深度。此前实机反馈暴露头颈遮挡缺陷，维护者确认修复后的头部遮挡及眨眼正常，见[测试说明](../../Docs/Development/Completed/1.7头部凝胶化与深度线程修复验收.md)。1.6 冻结资源保持不变。身体预缓存的原生定义或注册项缺失时会警告并降级为内置透明染色，降级效果不包含黑边柔化；头部及 SA 的最终材质入口遇到缺失则保留原材质，避免破坏遮罩和深度。

可额外传入 `-FaAssemblyPath` 指定当前 FA DLL，只读核验节点字段、控制器和图层等 14 项元数据契约，并记录其哈希/MVID；未提供时报告该项为 null，不声称已核对 FA。工具不运行 FA 代码或安装 Harmony 补丁。

当前另有[光照后阶段统一](../../Docs/Development/Completed/1.7凝胶化光照阶段统一与验收.md)：仅对完全凝胶化且渲染开启的角色调整头部组材质副本队列，身体/SA继续原光照后阶段；本轮不修改GLSL/ShaderDef，核对9项资源哈希后沿用上批原生编译结果；维护者确认配色一致性改善、眨眼和遮挡正常。

当前[原版／FA自动适配](../../Docs/Development/Completed/1.7原版与FA凝胶渲染自动适配与验收.md)新增眼部保护的写深度／不写深度两种程序；24阶段原生编译及14项FA契约通过，原有16阶段SPIR-V哈希保持一致。原版头图不拆分，使用运行时生成的眼部遮罩保留原色及Alpha，皮肤仍用深紫色／0.85／光照后阶段；未改写或分发原版贴图。

本批[个体凝胶外观](../../Docs/Development/Completed/1.7个体凝胶外观设置与验收.md)为六种片元程序加入独立`_GelColor`，游戏绘制调制与凝胶RGB／Alpha分离，原版眼睛不再反除基础色。24阶段及材质布局需按本批源码重编；不能沿用上一批SPIR-V逐项不变的结论。`_Color`保留源Alpha，个体Alpha仅乘一次；默认值仍是深紫／0.85。
